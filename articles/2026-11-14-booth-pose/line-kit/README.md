## 無料プランで、配信に頼らない

コミュニケーションプラン（月額0円）の無料メッセージは、月200通です。通数に入るのは、一斉配信、絞り込み配信、ステップ配信、Messaging APIの Push / Multicast / Broadcast / Narrowcast です。

通数に入らないのは、あいさつメッセージ、キーワードの応答メッセージ、チャットの手返信、Messaging APIの Reply です。根拠は LINEヤフー for Business の料金説明です。

https://www.lycbiz.com/jp/manual/OfficialAccountManager/account-settings/

それでも、一斉配信とステップ配信はこのアカウントでは使いません。50人に月4回送ると、200通は終わります。手順は、相手が「ポーズ」などと送ったときに返します。

## 2. あいさつ

`greeting.md` の本文を、ふきだし1つで保存する。300字以内にしてある。

「設定」→「応答設定」で、あいさつメッセージをオンにする。オフのままだと、保存していても届きません。

## 3. キーワード応答

`keywords.md` の5つを、応答メッセージとして1件ずつ作る。

- キーワードは完全一致
- タイトルは、相手に見えない管理用の名前
- キーワードの無い応答は作らない
- ステータスは利用中

「設定」→「応答設定」で、応答メッセージをオンにする。

Messaging APIを連携したあと、Webhookがオンになり、管理画面の応答が止まることがあります。ボットを別に動かさないなら、Webhookはオフに戻す。返すのは、管理画面のキーワード応答のままにする。

## 4. リッチメニュー

画像は `richmenu/richmenu.png`（2500×1686、1MB以下）。領域は `richmenu/richmenu.json`。左上から、ポーズ、記録、説明、30分、つまずき。右下だけ https://x.com/comback_nao6 を開く。ほかの5つは、そのキーワードをトークに送る。

メニューは最初から開かない（`selected` は false）。トーク欄の「手順を開く」で開く。あいさつが隠れないようにするためです。

登録は API だけです。

```sh
cd line-kit/richmenu
export LINE_CHANNEL_ACCESS_TOKEN='ここに貼る。ファイルには保存しない'
bash register.sh
```

チャネルアクセストークンは、LINE Developers の Messaging APIチャネルで発行する。長期トークンでも短期トークンでも、このスクリプトは環境変数以外から読みません。シェルの履歴に残したくないときは、`export` の代わりに、その場限りの入力を使ってください。

`register.sh` がやるのは3つだけです。メニューを作る、画像を載せる、友だち全員のデフォルトメニューを付け替える。メッセージは送りません。既にあるデフォルトメニューは置き換わります。
