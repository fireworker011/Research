# キーワード応答

完全一致だけ使う。キーワードの無い応答（何を送っても返る文）は作らない。作ると、雑談にも長文が返る。

メニューのボタンは、下のキーワードをそのまま送る。Xのボタンだけは、トークを送らず https://x.com/comback_nao6 を開く。

数字とプロンプトの実物は空欄。練習と資料用の線画素体、として扱う。

## 1. ポーズ

管理画面のタイトル（相手には見えない）: ポーズ集のチェック

キーワード: ポーズ

返信:

・今日の工程は1つ。出す、選ぶ、まとめる、置く
・その工程は、スマホの中で閉じる

出す
・線画素体。練習と資料
・描かせないもの。背景、衣装のデザイン、文字
・残す言葉。線、素体、資料、動詞、余白
・打った文言は【要確認: 実際のプロンプト】

・1コマを拡大する。手、足、接地、重心
・読めないコマは落とす

・価格、枚数、形式は【要確認: 価格、収録枚数、ファイル形式】

記録シートは「記録」。説明文の型は「説明」。

## 3. 説明

管理画面のタイトル: 商品説明文の型

キーワード: 説明

返信:

BOOTHの説明文は、この順で埋める。上手い絵の話は書かない。

誰の止まり方か：
絵を描く人が、ポーズで線が止まるとき用。

何が置いてあるか：
練習・資料用の線画素体。背景なし。衣装のデザインなし。文字なし。

入り：
枚数【要確認: 収録枚数】
形式【要確認: ファイル形式】
価格【要確認: 価格】

使い方：
1コマを拡大して、体の角度の資料にする。

空欄：
商品URL【要確認: 商品URL】
サムネに書く文言【要確認: サムネに書く文言】

練習と資料から外れる絵柄は、この型に入れない。

## 4. 30分

管理画面のタイトル: 今日の1工程

キーワード: 30分

返信:

今日の30分は、下の6つから1つだけでいい。

1. 棚を見てから作る。見た事実だけ書く
2. 工程はスマホの中で閉じる
3. 今日は1工程だけ。出す、選ぶ、まとめる、置く
4. 描かせないものを3つ書く
5. 拡大して、手・足・接地・重心
6. いいねの隣に、保存を見る。知らない数字は書かない

終わったら「記録」と送ると、残す欄が返る。
