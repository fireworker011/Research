# キーワード応答

完全一致だけ使う。キーワードの無い応答は作らない。

メニューは本番登録済みだ。キーワードは「ポーズ」「記録」「説明」「30分」「つまずき」のまま変えない。Xのボタンは https://x.com/comback_nao6 を開く。

各返信は、吹き出し1つに収める。LINEのテキスト上限は5000字。ここにある文は、その中の短い版だ。手順の全部は `gift/pose-kit.pdf` にある。応答文では、PDFをこのトークで渡している、と書く。ファイル自体の送信は、チャットで手渡しする。この作業では送っていない。

## 1. ポーズ

管理画面のタイトル（相手には見えない）: ポーズ集のチェック

キーワード: ポーズ

返信:

今日動かす分だけ返す。手順の全部は、配布のPDFにある。

1本は、線画素体のポーズ集だ。練習と資料。背景も、衣装のデザインも、文字も入れない。

今日の30分は、この4つのどれか1つだけ。

出す。GrokのImagineで、1ポーズずつ出す。動詞は1つ。4×4の完成は、この回に頼まない。

選ぶ。1枚ずつ拡大する。見る順は、手、足、接地、重心。1つでも読めなければ落とす。

まとめる。採用したコマだけを、スマホのキャンバスで同じ余白に並べ、PNGで書き出す。

置く。題名に動詞を書く。説明には、誰の止まり方に置くかを書く。Imagineで出した線だとも書く。

コピペ用のテンプレは6本、PDFにある。あれは汎用の例で、僕が打った実物ではない。動詞の行だけ、自分のテーマに替えて使う。

## 3. 説明

管理画面のタイトル: 商品説明文の型

キーワード: 説明

返信:

説明は、この順で書く。記入例の全文は、配布のPDFにある。例の題は「床に座る線画素体・8ポーズ」。僕の商品名ではない。

1. 誰の、どの動詞で線が止まるか
2. 置いてあるのは、練習・資料用の線画素体だということ
3. 白い背景、黒い線。衣装のデザイン、部屋、文字は無いこと
4. 数えた枚数と、PNGかZIPか
5. GrokのImagineで出した線を、スマホで選んで並べたこと。手描きではないこと
6. 個人の練習と資料に使う想定と、再配布は断る、という条件。自分の条件に書き換えてよい

価格の円は、この返信に置かない。棚で見た価格を自分のメモに残してから、PDFの「価格の考え方」で自分の数字を入れる。
