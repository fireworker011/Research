# konkatsu_013_drama3 — Grokアプリ用プロンプト一覧(ステップ実行版)

各シーンごとに、①画像プロンプトをGrokに貼って画像生成 →
②できた画像を選んで動画化ボタン →③動きの指示(動画プロンプト)を貼る。
完成したらファイル名を `scene_01.mp4`〜`scene_06.mp4` にして
このチャットに送る(またはinput/フォルダに配置)。

**注意**: ナレーション音声は後からパイプライン側で合成します。
動画生成時は「口を閉じたまま、話しているように見える動きはさせない」よう
動画プロンプトに必ず含めてください(リップシンクのズレ防止)。

---

## シーン1 (目安10秒)

**① 画像プロンプト(コピペ用)**
```
以下の2人の日本人女性が登場する婚活ドラマ。各シーンで指定した人物を、全シーンを通じて同一人物として完全に一致させること。縦長9:16のリアルな写真風、高詳細。
クライアント役「ミキ」: 30代前半、茶色がかった黒髪ミディアム、細面、清楚感のある顔立ち、ベージュのニット。
カウンセラー役: 40代、黒髪の上品なショートボブ、知的で少し厳しさのある顔立ち、紺色のジャケット。 クライアント役「ミキ」が夜、ベッドの上でスマートフォンを持ったまま、限界を迎えたような疲れ果てた表情を見せる瞬間。口は閉じたまま、話していない。今にもスマホを放り出しそうな緊張感。暗めの室内、スマホの光。 テキストなし。
```

**② 動画化の動きの指示(コピペ用)**
```
口を閉じたまま、話さない。カメラが素早くズームイン。スマホを持つ手にぐっと力が入り、目を閉じて大きく息を吐く動き。
```

保存ファイル名: `scene_01.mp4`
