# Grok Imagine Agent Mode — 一括実行プロンプト(konkatsu_016_hitori_futari)

> Grok Imagine の Agent Mode にこのブロックをそのまま貼ってください。
> 画像生成→動画化を6シーン分、Agentが自動で連続実行します。
> テロップ・ナレーション音声・BGMは不要(パイプライン側で自動合成するため)。

---

あなたは婚活ジャンルのショート動画クリエイターです。
以下の6シーンについて、①画像生成 → ②その画像を動画化、を順番に自動で行ってください。
音声・BGM・テキスト(テロップ)は一切不要です。各シーンの動画だけ作ってください。

【重要】ナレーション音声は別撮りで後からパイプライン側が合成します。
動画内の人物は口を閉じたまま、話しているように見える動きは一切させないでください
(リップシンクさせると、後から乗せるナレーションと口の動きがズレて不自然になります)。
表情の変化・まばたき・うなずき・視線の動きだけで演技してください。

【全シーン共通のキャラクター設定・必ず統一すること】
30代前半の日本人女性、茶色がかった黒髪ミディアム、細面、清楚感のある顔立ち。アイボリーのニット(最終シーンのみ淡いピンクのカーディガン)。縦長9:16のリアルな写真風。
全シーンで同一人物として描くこと。

---

### シーン1(保存名: scene_01.mp4 / 尺目安10秒)
**画像**: 深夜、自室のベッドの上でスマートフォンのマッチングアプリ画面を見て、ふっとため息をつく女性。口は閉じたまま、話していない。少し涙目で疲れた表情。暗めの間接照明。 テキストなし。
**動画化**: 口を閉じたまま、話さない。カメラ固定でゆっくり寄る。ため息をつき、目を伏せる自然な動き。

### シーン2(保存名: scene_02.mp4 / 尺目安10秒)

**動画化**: 口を閉じたまま、話さない。カメラ固定。手を止めてスマホ画面を見つめる静かな動き。

### シーン3(保存名: scene_03.mp4 / 尺目安10秒)
**画像**: カフェの窓際の席で、テーブルの向かいにいる友人と話しながら少し苦笑いする女性。口は閉じたまま、話していない。昼下がりの明るい光。 テキストなし。
**動画化**: 口を閉じたまま、話さない。カメラがゆっくり横に動く。友人の方を向いて小さく苦笑いする動き。

### シーン4(保存名: scene_04.mp4 / 尺目安10秒)
**画像**: 自室でスマートフォンを耳に当てて、ノートにメモを取りながら真剣な表情で電話をしている女性。口は閉じたまま、話していない。落ち着いた室内照明。 テキストなし。
**動画化**: 口を閉じたまま、話さない。カメラがゆっくり近づく。ペンを持つ手が小さく動き、頷く仕草。
