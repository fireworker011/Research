# Grok Imagine Agent Mode — 一括実行プロンプト(konkatsu_015_line_ng)

> Grok Imagine の Agent Mode にこのブロックをそのまま貼ってください。
> 画像生成→動画化を6シーン分、Agentが自動で連続実行します。
> テロップ・ナレーション音声・BGMは不要(パイプライン側で自動合成するため)。

---

あなたは婚活ジャンルのショート動画クリエイターです。
以下の6シーンについて、①画像生成 → ②その画像を動画化、を順番に自動で行ってください。
音声・BGM・テキスト(テロップ)は一切不要です。各シーンの動画だけ作ってください。

【重要】ナレーション音声は別撮りで後からパイプライン側が合成します。
動画内の人物は口を閉じたまま、話しているように見える動きは一切させないでください
(リップシンクさせると、後から乗せるナレーションと口の動きがズレて不自然になります)。
表情の変化・まばたき・うなずき・視線の動きだけで演技してください。

【全シーン共通のキャラクター設定・必ず統一すること】
30代前半の日本人女性、茶色がかった黒髪ミディアム、細面、清楚感のある顔立ち。ベージュのニット(最終シーンのみ淡いグレーのカーディガン)。縦長9:16のリアルな写真風。
全シーンで同一人物として描くこと。

---

### シーン1(保存名: scene_01.mp4 / 尺目安10秒)
**画像**: 電車の中でスマートフォンのLINE画面を見て、はっとした表情を見せる女性。口は閉じたまま、話していない。夕方の車窓、少し焦った表情。 テキストなし。
**動画化**: 口を閉じたまま、話さない。カメラが素早くズームイン。目を見開き、スマホを持つ手に力が入る動き。

### シーン2(保存名: scene_02.mp4 / 尺目安10秒)
**画像**: 職場帰りのオフィス街を歩きながら、スマートフォンで長文を打っている女性。口は閉じたまま、話していない。夕暮れの街並み。 テキストなし。
**動画化**: 口を閉じたまま、話さない。カメラ固定。歩きながら親指だけが速く動く。

### シーン3(保存名: scene_03.mp4 / 尺目安10秒)
**画像**: 自宅のキッチンで、スタンプだけを送ってスマートフォンを置いてしまう女性。口は閉じたまま、話していない。夜、暖かい照明。 テキストなし。
**動画化**: 口を閉じたまま、話さない。カメラ固定。スマホをぽんと置いて、少し気まずそうに視線を逸らす動き。

### シーン4(保存名: scene_04.mp4 / 尺目安10秒)
**画像**: 公園のベンチで、スマートフォンの通知欄を何度も確認して落ち着かない女性。口は閉じたまま、話していない。昼下がりの公園。 テキストなし。
**動画化**: 口を閉じたまま、話さない。カメラがゆっくり寄る。何度もスマホを確認する落ち着かない動き。

### シーン5(保存名: scene_05.mp4 / 尺目安10秒)
**画像**: 明るいカウンセリングルームでスーツ姿の女性カウンセラーからLINEのやり取りについてアドバイスを受け、メモを取る女性。口は閉じたまま、話していない。温かい照明。 テキストなし。
**動画化**: 口を閉じたまま、話さない。カメラがゆっくり近づく。頷きながらメモを取る前向きな表情。

### シーン6(保存名: scene_06.mp4 / 尺目安10秒)
**画像**: 淡いグレーのカーディガンを着た女性が、カフェのテラス席でスマートフォンを見ながら柔らかく微笑む。口は閉じたまま、話していない。明るい午後の光。 テキストなし。
**動画化**: 口を閉じたまま、話さない。カメラ固定。画面を見ながら自然な微笑みを浮かべる。
