# konkatsu_016_hitori_futari — Grokアプリ用プロンプト一覧(ステップ実行版)

各シーンごとに、①画像プロンプトをGrokに貼って画像生成 →
②できた画像を選んで動画化ボタン →③動きの指示(動画プロンプト)を貼る。
完成したらファイル名を `scene_01.mp4`〜`scene_06.mp4` にして
このチャットに送る(またはinput/フォルダに配置)。

**注意**: ナレーション音声は後からパイプライン側で合成します。
動画生成時は「口を閉じたまま、話しているように見える動きはさせない」よう
動画プロンプトに必ず含めてください(リップシンクのズレ防止)。

---

## シーン1 (目安10秒)

**① 画像プロンプト(コピペ用)**
```
30代前半の日本人女性、茶色がかった黒髪ミディアム、細面、清楚感のある顔立ち。アイボリーのニット(最終シーンのみ淡いピンクのカーディガン)。縦長9:16のリアルな写真風。 深夜、自室のベッドの上でスマートフォンのマッチングアプリ画面を見て、ふっとため息をつく女性。口は閉じたまま、話していない。少し涙目で疲れた表情。暗めの間接照明。 テキストなし。
```

**② 動画化の動きの指示(コピペ用)**
```
口を閉じたまま、話さない。カメラ固定でゆっくり寄る。ため息をつき、目を伏せる自然な動き。
```

保存ファイル名: `scene_01.mp4`
