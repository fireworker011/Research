# 02 貼り付けとテストプレイ

bat では自動化しない。Editor のクリップボード貼り付けは GUI 操作。

1. `output/woditor/event-code.txt` をメモ帳で開き、Ctrl+A → Ctrl+C
2. マップイベント（起動条件: 自動実行、条件0個）を開く
3. コマンド欄で右クリック → 「クリップボード→コード貼り付け」
   - ショートカットは E。V では貼れない（はなまるノートおよび YADOT の記述）
4. F9 でテストプレイ。選択肢の両分岐を終端まで通す
5. 文章が切れる・選択肢が1つしか出ない場合は、生成コードを捨てて Editor 上で直す。壊れたコードを量産するな

[102] の数値 `50` は YADOT「宿屋の人」からコピーした。公式のビット定義は未確認。挙動がおかしければ Editor の選択肢ウィンドウで作り直す。
