# 同人成人ゲーム自動工場（最小版）

これは「ウディタでエロRPGを週1本自動生成して月利200万」を、そのまま実装したものではない。  
実装したのは、その計画がどこで死ぬかを先に固定し、**スマホでプレイテストできるIR** までである。

## 今すぐ動かす（PC不要）

Cloud Agent / ローカル:

```bash
cd doujin-game-factory
node --test
node src/cli.js generate --seed data/seeds/sample-adult-adv.json
node src/cli.js preview --in output/ir/game.json
node src/cli.js gate --price 2200 --copies 0 --works 0
```

`output/preview/index.html` をスマホのブラウザで開く。18歳確認のあと、分岐付きの最小成人ADVが動く。

ウディタの `Game.exe` は出ない。出ないことを仕様とする。

## フェーズ1：問題定義

語られた問題「自動で同人エロゲーを作る仕組みが無い」は、症状の記述であって目的ではない。

| 層 | 内容 |
|---|---|
| 症状 | 売上0、出荷0、制作パイプライン無し |
| 希望 | 週1作成、PF販売、月利200万 |
| 制約 | ほぼPC不可、スマホ動画メイン、Grok/Cursor Ultra、ウディタが理想 |
| 事実 | 未出荷。需要・品質・審査通過は未測定 |
| 推測 | 自動化すれば週1が回る。ウディタが最適。200万は本数で届く |
| 感情 | 仕組みさえあれば、という焦り |
| 希望的観測 | 「自動」と「RPG」と「エロ」と「週1」と「200万」が同時に成立する |

根本原因の候補（まだ検証されていない）:

1. **販売可能な完成物が一度も無い**（これが現時点で唯一の確定）
2. 制約とエンジン選定の不一致（ウディタ = Windows Editor.exe）
3. PFのAI作品キャップが週1と両立しない
4. 目標数字が、未検証ユニットエコノミクスの上に載っている

不足情報で意思決定を最も動かす1問（本ターンでは未回答のまま進めた）:

**Windows（自宅・クラウドVM・代行のどれでも）で Editor.exe を一度でも回せるか。**  
Yes ならウディタを last mile に残す。No ならウディタは趣味要件であり、販売エンジンから外す。

## フェーズ2：情報収集

一次情報を優先した。X MCP はこの環境で `needsAuth` のため**検索していない**。X上の「稼げる」話は未収集。人気と正しさは混同しない。

確認できたこと:

- WOLF RPGエディター公式ヘルプ: `Editor.exe -txtoutput` / `-txtinput` / `-gamedata` が存在する。テキスト入出力は **Editor.exe 起動が前提**。[基本操作](https://silversecond.com/WolfRPGEditor/Help/01control.html)
- 作成ゲームの販売は公式に「自由に配布・販売可」。Editor.exe 自体は配布物に入れない、が公式インストール案内の趣旨。
- `.dat` / `.mps` は独自バイナリ。コミュニティによる解析はあるが、公式仕様書ではない。本リポジトリでは逆工程でバイナリを捏造しない。
- DLsite: AI生成物は申告必須。「AI生成」は専用フロア。サークルヘルプ二次引用および英語ヘルプ: メインコンテンツがAIなら AI Generated。申請は **各月3作品**、同一運営の複数サークル超過は不可、という運用が複数の公式ヘルプ要約で一致。日本語ヘルプのWebFetchは本環境で 500/timeout になり、**ページ全文の再取得は失敗した**。運用前にサークルヘルプを自分の目で開け。
- FANZA同人公式: https://dojin.dmm.co.jp/help/ai_generation_rule （2026-02-01時点とページに記載）。AI生成ゲームは **AIフロア**。コミック/CG/動画の一部AI・AI生成は月3。**ゲーム行は「1オーナーあたり毎月2作品まで」とセル結合して見える。** 通常ゲーム全体の制限なのかAIゲームのみなのか、colspan をこの環境で確定できなかった。curl は年齢確認リダイレクト。サークル登録後に原本を確認すること。
- DLsiteゲーム販売数の中央値403本（万灯あお、2026-07-15時点の調査メモ）は **累計の中央値** であり月次ではない。
- 卸価格は価格帯の階段。4000円以上で卸が売価の80%という公式規約の骨格はある。現行の税込表はインボイス区分で分岐する。コード内 `takeRate=0.6` は**推定**。

確認できないこと:

- ナオミチ名義で成人同人ゲームが何本売れるか
- AI生成フロアのRPGの中央値（本調査では未取得）
- ウディタの `-txtinput` が、ここで出すコマンド文を無改変で飲めるか（公式の自動テキストと、エディタの「コマンド文コピー」は別物）
- X上の賛成/反対の分布

賛成側に出やすい主張（二次、検証用）: 同人ゲームは単価が高く手数料率が下がる帯がある。RPGは総合ランキングに出やすい、という2023年分析がある。  
反対側: AI作品は隔離・月次キャップ・審査遅延。フルAIのRPGは「ゲーム」として遊べないと返品・低評価になりやすい。PC必須エンジンはスマホ運用と喧嘩する。

## フェーズ3：第一原理

同人成人ゲームが売れる最小要素:

1. 買いたい性的コンテンツ（画像か文章か音声）
2. 動作するプレイヤー体験（最低は選択肢付き文章）
3. PFに載る（年齢・AI申告・ファイル形式）
4. 見つけられる（AIフロアは発見性が落ちる、という公式の隔離がある）
5. 継続（レビュー、シリーズ）

RPGの戦闘・マップ・敵データは 1 にも 4 にも必須ではない。最初に切る。

変えられない: 成人法・PF倫理、AI申告、月次キャップ、Editor.exe が Windows、ナオミチがPCをほぼ触れない。  
変えられる: エンジン、ジャンル、本数、価格、月200万をいつ語るか。

最短経路: **IR（JSON）→ 検品 → HTMLプレビュー（スマホ）→ 需要が出てから Windows でウディタ梱包。**  
週1フルAIウディタRPGは、最短でも最安でも最少工程でもない。

## フェーズ4：並列分析と相互反論

**顧客:** 金を払うのは「動く成人ゲーム」であり「自動生成の仕組み」ではない。短いHルートでも、キャラが成人で絵が揃っていれば買う人はいる。RPG combats は期待値を上げる場合と、AIの薄さを露呈する場合がある。

**競合:** 手描きの既存RPGサークルと、AIフロアの量産CGが両方いる。フルAI週1は後者の土俵で、発見性が弱い棚に積む。

**実務責任者:** ボトルネックはシナリオLLMではなく、画像の一貫性、Hシーンの密度、Windows梱包、審査待ち、バグ。スマホ運用なら「エージェントがIRを出す → 人間がHTMLを1回通す」以外は滞る。

**財務責任者:** 売価2200・取り分0.6仮定で月200万は約1516本/月。月3本なら1作約505本。未出荷でこれを予算にするな。固定費（Cursor Ultra、画像生成、Windows VM）は売上0でも出る。

**批判者:** 自動化された成人ゲームは粗製のゴミとしてBANと低評価を集める。倫理フィルターを外して売上を取りに行く誘いが来るが、それはアカウントと法の話であり成長戦略ではない。

**長期:** シリーズIPと「一部AI」（手描きキャラ）に寄せないと、AIフロアの棚卸しに埋まる。今の週1フルAIは長期在庫にならない。

相互反論:

- 顧客「絵が要る」vs 実務「今絵が無い」→ 最初の販売物をゲームではなく需要テスト用の短いADVプレビューに落とす。ゲームとして出すのはゲート4以降。
- 財務「本数を増やせ」vs PF「月3」→ 本数では200万に届かないので、単価・シリーズ・AI以外フロア（手作業が増える）が要る。自動化の勝利条件と目標数字が食い違う。
- 長期「ウディタRPGで差別化」vs 制約「PC不可」→ 差別化の前に実行不能。

## フェーズ5：意思決定

選択肢（3つ）:

| ID | 内容 | 失敗条件 |
|---|---|---|
| A | 本IR工場で月1の短い成人ADVをHTMLで検証し、売れたらWindowsでウディタ化 | プレビューすら開かない。または開いて「これでは金を払わない」が30日続く |
| B | 今すぐウディタRPG週1を目指す | DLsite月3、Windows無し、RPG工数。失敗は高確率で出荷前 |
| C | ゲームを捨て、AI-CG/シナリオのみ | ゲームよりキャップと隔離が厳しいジャンルもある。月200万は別問題として残る |

可逆: エンジン、価格、月次本数、RPG化の延期。  
不可逆: 虚偽AI申告、未成年表現、複数サークル回避、一度BANされたアカウント。

今決めること:

1. 週1を捨て、キャップ内（検証は月1）にする
2. 最初の成果物は HTML ADV。ウディタは last mile
3. 月200万は「初作が30日30本を超えてから」語る

後で決めること: 価格、世界観の量産、RPG戦闘の有無、FANZAゲーム行の月2の確定。

最も不都合な事実: **PCを触れない人間が、Windows専用エディタのRPGを週1で自動出荷する計画は、ツールの公式経路とPFの月次キャップの両方で既に死んでいる。** GrokとCursor Ultraはその死を覆さない。
