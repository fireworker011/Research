WOLF RPG Editor コマンド文エクスポート（人間がEditorに貼る用）
公式: Editor.exe -txtoutput / -txtinput は Windows の Editor.exe が必要。
このファイルを Linux/Cloud Agent から .mps に直接は書けない。

タイトル: 終電後の事務所
開始: n1

# node n1 type=say
■文章の表示
【森 健太】
終電を逃した。事務所の蛍光灯だけが残っている。

# node n2 type=say
■文章の表示
【青山 綾】
私も。タクシー割り勘にする？ それとも、もう少し残る？

# node n3 type=choice
■選択肢
- タクシーで帰る => end_soft
- 残る（成人向けルート） => h1

※ウディタの分岐はコモン側の条件分岐に手で結ぶ。このテキストは設計図であり、-txtinput 可能な完全バイナリではない。

# node h1 type=hscene
■文章の表示
【Hシーン】成人同士・合意済み。画像は別アセット。
二人は合意のうえで近づく。具体的な描写はアセット工程で差し込む。ここでは『成人・合意・職場の同僚』だけがロックされる。

# node end_soft type=end
■文章の表示
雨の車内。売れる作品にするなら、このルートは短い。需要検証用の分岐。
■ゲーム終了

# node end_h type=end
■文章の表示
朝。これはプレビュー用の最小エロゲー骨格であり、RPGでもウディタ製でもない。
■ゲーム終了
