# 朝のOK待ちまとめ（review digest）形式案
目的: 夜の結果のうち「ナオミチのOKが要るもの」だけを、毎朝 07:30 JST ごろに1通でまとめる。返事は番号で返せるようにする。

## 作り方
- 07:20 JST に Grok Bot（箱）が作る。材料:
  1. PC の `out\night-summary-YYYYMMDD.md`（PCが Drive「動画倉庫/00_確認待ち/_night」に写しを置く or 次回PC接続時に取得）
  2. Drive「動画倉庫/00_確認待ち」の新着
  3. 各Botの OK待ち（まとめ.md の「ナオミチOK待ち」: CW送信、CG採用、BOOTH出品、サクラ post:true、PR判断 など）
- 置き場所: `/home/box/bots/night-run/digest/digest-YYYYMMDD.md`。07:30 にチャットで本文を出す（送信先はナオミチ本人のみ。外部へは送らない）。
- OK をもらったら、その番号の作業だけを各Botへ回す。返事が無い項目は翌朝に「2日目」として上に寄せる。

## 書式
```
# おはようございます。OK待ち {N}件（{M月D日} 夜の分）
昨夜: 完了 {a} / 確認待ち {b} / 失敗 {c} / 持ち越し {d}　Imagine異常: {あり・なし}

## すぐ見てほしい（期限が近い順）
1. [動画] kane-07「引かない0.36」 — 00_確認待ちにあり（Driveリンク）
   QC5: ①○ ②○ ③○ ④○ ⑤表あり　気になる点: 0:12 の手が小さい
   → 返事: 「1 OK」/「1 NG 理由」
2. [サクラ] 在庫 10/30分 — post:true にしてよいか
3. [CG] 灯台町 05 の 18枚 — Eagle に登録済み、採用を選んでほしい

## 失敗・止まったもの（判断が要るものだけ）
- pet-n2: 参照静止画3回NG → 作り直す／台本を変える／飛ばす
- 90-upload: Drive ログイン切れ（BLOCKED.png）→ PCでログインが必要

## 今夜の予定（変えたければ返事で）
- 1-video: …  / 2-cg: … / 3-sakura: …

返事の例: 「1 OK、2 OK、3 は 3,5,9 だけ」
```

## ルール
- 1件1〜3行。数字は事実だけ（秒数・本数）。推測は書かない。
- 並び: 期限（投稿日・在庫切れ日）が近い順 → 動画 → サクラ → CG → その他。
- 動画は QC5 の結果と通し表の有無を必ず付ける。表が無い動画は「OK待ち」に出さず「失敗」側へ。
- 0件の日は「OK待ちなし」の1行だけ。
- 自動化: 箱の定期実行「朝のOK待ちまとめ」07:20 作成・07:30 表示（登録はナオミチの了承後）。
