# 動画QCの通し視聴表

完成動画を人が最初から最後まで見るための表を、字幕ファイルとシーン表から下書きする。画面の正否は機械が決めない。見ていない動画を OK にしない。表が無い動画は確認待ちに出さない。

## 5項目

1. 元音声がある素材にナレーションを重ねない。
2. セリフと字幕が画面と合う。
3. 体の欠けや崩れたシーンがない。
4. セリフ間は1.5秒以内。
5. 最初から最後まで通して見る。

1と4は、シーン表の「元音声」列と字幕の時刻から下書きできる。2と3と5は、表を見ながら動画を通して見て、人が ○ か × を書く。

## 入力

字幕は `.srt` か `.vtt`。声も字幕も無い動画は、中身が空の `.srt` を渡す。

シーン表は markdown の表か CSV。列名は次のどれか。

| 意味 | 列名 |
|---|---|
| 開始 | 開始 / start |
| 終了 | 終了 / end |
| 画面 | 画面 / 画面に映っているもの / visual |
| セリフ | セリフ / line |
| 元音声 | 元音声 / original_audio（あり・なし） |

```markdown
| シーン | 開始 | 終了 | 画面 | セリフ | 元音声 |
|---|---|---|---|---|---|
| 1 | 00:00:00.000 | 00:00:02.000 | 猫が窓辺にいる | 夜になった | なし |
| 2 | 00:00:02.000 | 00:00:04.000 | 手元のコップ | もう一杯 | なし |
```

## 手順

1. 字幕とシーン表のパスを決める。動画ファイル自体はまだ開かない。
2. 下書きを出す。

```bash
python3 ops/skills/video-qc-sheet/draft_qc_sheet.py \
  --subs path/to/captions.srt \
  --scenes path/to/scenes.md \
  --out path/to/qc-sheet.md
```

3. 出た表の「セリフ間が1.5秒を超えた箇所」と、QCの1（元音声）を先に読む。NG候補があれば、通しの前にその秒へ飛ぶ。
4. 動画を最初から最後まで止めずに見る。各行で、セリフ、画面に映っているもの、一致を照合する。体の欠けや崩れた絵があれば、その行の一致列に書く。
5. 一致列の「要目視」を、見た結果の ○ か × に書き換える。書き換えていない表は未了。
6. 表と mp4 を、ジョブが指定する `out\` に置く。表が無い mp4 は Drive の確認待ちに上げない。

スクリプトは投稿しない。パスワードも聞かない。
