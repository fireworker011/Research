# アカウント台帳

台帳は `ops/accounts/registry.md`。パスワード、確認コード、トークン、Cookie は書かない。不明は「不明」のまま残す。推測で埋めない。

## 作業前のチェック

1. 触るサービスの行を台帳から1つだけ選ぶ。サービス、ハンドル、Googleアカウント、ログイン場所（箱か PC か、プロファイル名）を声に出して照合する。
2. 同じ Googleアカウントが他の行にもあれば、そこで止める。ログインしない。ナオミチに、どの行が衝突しているかを渡す。
3. ログイン場所が「不明」、または「箱ブラウザ」だけでプロファイル名が無い行は、ログインしない。PC なら `edge://settings/profiles` と `chrome://settings/manageProfile` の表示名を見て、台帳の行と一致するものだけを開く。
4. プロファイルの表示名と、中に入っているハンドルが逆なら（例: 表示名 threads-nurse の中身が妻）、そのプロファイルでは操作しない。
5. 行が「触らない」「PCから触らない」なら開かない。X は箱の X運用係以外が触らない。

## 台帳の更新

1. 行を直す前に、いまの表を残す。列は変えない（#、サービス、ハンドル、Googleアカウント、ログイン場所、担当Bot、状態、注意）。
2. 直してよいのは、画面で見た事実だけ。ハンドル、どのプロファイルに誰が入っていたか、ログインできたか失敗したか。
3. 更新のあと、次を数え直して「矛盾一覧」を書き換える。
   - 同じ Googleアカウントが2行以上
   - ログイン場所が「不明」の行
   - 表示名と中身が逆、またはプロファイル名が無い行
4. 矛盾が残っていても、行を推測でマージしない。判断はナオミチに返す。
