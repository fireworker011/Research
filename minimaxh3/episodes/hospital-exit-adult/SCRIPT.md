# 病棟出口 — 理想台本（叩き）

架空サバイバル・ショート。コールドオープン。タイトルカードなし。
スラッグ `hospital-exit-adult`。霞東アダルト（`kasumi-late-desk-adult`）とは別スラッグ。混ぜない。
感染した成人だらけの架空病院から出る。HUD の相手名は「感染者」。

**面白いところ: Colab の構成を選ぶと、ミッションが完了するか失敗するかが分かれる。**
1本の予告は 12 ビート。構成は予告全体の方針（みき→れい→かなで同じ系統）。相手ごとに別のコマンドを混ぜない。

# 撮るときの枠

受け入れる: みきクンニ（戸惑い）→ れい後背位中出し・抜く・垂れ・去り際キス → かな挿入開始 → 仰向け中出し → **接合のまま出口・完了**。

誘う: 同じ手順をノリノリで。12 で扉の前に止まる → **失敗・淫欲に呑まれた**。

回避: キスですり抜け → れいとかなにも触れない → **一人で出口・完了**。

戦って勝つ: みき回避 → れい打倒＋じゅぼ口内 → かな打倒 → **一人で出口・完了**。

戦って負ける: れいまでは勝ち → かなに倒される → **敗北H（仰向け中出し）・失敗**。
