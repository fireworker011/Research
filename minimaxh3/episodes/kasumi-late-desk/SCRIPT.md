# 霞東フロア — 理想台本

架空オープンワールド・ショート。コールドオープン。タイトルカードなし。
遅刻した朝、成人 OL が「いま着いた」顔で自席へつく。コマンドは毎回同じ四択。ぶっとび本線は戦い（Combat LoRA）。ビジネス最適も同じ失敗に着く。

借りるのは三人称カメラ、カバー、覗き、バー、コマンド、失敗カードの文法だけ。山田・定時退社・働き方改革・5分だけ・エレベーター・喫煙の階段は出さない。原クリップはモーションにしない。全員成人。血は出ない。怪我はしない。飛び蹴りはしない。

---

## 世界

霞東 Dist. 開かれた執務フロア。ベージュのパーティション、薄いオークの机、グレーのカーペット、朝の蛍光灯と東窓。看板・モニターに読める文字はない。時計も出さない（時刻は HUD にも書かない）。

ミッションは二つだけ。途中まで **自席につけ**（「自席」が赤）。かばんを開けた瞬間 **出退勤を打て**。どちらも完了しない。

# 四択の中身（選んだらこうなる）

本編で撮るのは A の△△△、または B の○○×。下は理想のゲームとして全部書く。予告一本には入れない。

## 警備員

**△ 体当たり**　本線A。トート→左肩→着座。

**○ 通行証**　本線B。バッジ。通れる。ヒートは下がらない。

**□ にこっと**　みおが腰を上げ、口角だけ上げる。青木が止まる。

みお
「あさ　から　その　ボード　いい　です」

「おくさん　なに　してます」

みおはまだしゃがんでいる。ヒート 5 のまま発見。ここから△に戻しても、もう「隠」は消えている。失敗はまだ先。発見だけでは終わらせない。

# 撮るときの枠（理想を H3 一本に落とすなら）

理想は上。エンジンはビート 12、ui 連続不可、1 本 2 行、生成 10 秒を 3–6 秒に切る、顔は増やさない。

一本に収めるなら、ルートAから次を残す。

| 残す | 落とす |
|---|---|
| 01 カバー | ルートBの通し（予告は A だけ） |
| 02 コマンド警備 | □×の実写 |
| 03 体当たり | 青木の「…え」（口を開けない） |
| 04 覗き | CUT 08 の席列だけのつなぎ（07 のあとに 09 を重ねる） |
| 05 コマンド課長 | |
| 06 ファイル払う **または** 07 の言い訳（両方はビートが足りない） | 三戦目を残すなら 06 を残して 07 を 2 行に圧縮 |
| 09 コマンド同僚 | |
| 10 マグ | |
| 11 かばん | |
| 12 着席→失敗 | 完了フラッシュ |

三戦を全部残すと会話が削られる。会話を残すと三戦目が削られる。**理想は三戦＋黒木の二行**。足りなければ三戦目を「コマンドだけ出して×席へ急ぐ」に戻す（以前のたたき）。

LoRA は 03 / 06 / 10 だけ `prfight2, prfin1`。daily（Larry+シネマ）の後ろ。turbo と同時に積まない。③ スタジオに足さない。inbox に置かない。15 秒にしない。

`episode.json` はまだ 25 秒 mundane。この台本を採用してから json とスチールを書き換える。
