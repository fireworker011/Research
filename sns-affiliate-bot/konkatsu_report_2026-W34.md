## 2. 最も効果的だった投稿タイプと理由

### 🏆 trust_building（信頼構築型）が唯一機能しているタイプ

**特に高パフォーマンスだった上位3本の共通点を分析：**

```
1位：年齢のせいじゃなかった    402views / ER 0.75%
2位：婚活やめたいと思った日    335views / ER 0.60%
3位：夜中に泣いた話            93views  / ER 1.08%（ER最高値）
```

**なぜ効くのか？3つの理由：**

**① タイトルが「否定の解放」構造になっている**
「年齢のせいじゃなかった」は、ターゲット（30代婚活女性）が心の中で抱えている自己否定（年齢が原因かも…）を代弁し、かつ「違った」という希望を同時に提示する。クリックしない理由がない構造です。

**② 感情の具体性が高い**
「夜中に泣いた話」はER最高値1.08%。抽象的な「つらかった」ではなく、**時間帯（夜中）＋行動（泣いた）**という具体描写が読者の追体験を促します。

**③ ミキのペルソナが最も活きるジャンル**
6年間・100人超という実体験は、このカテゴリでしか発揮できない圧倒的な説得力があります。

## 3. 改善が必要なタイプと具体的改善案

### 🔴 advice（アドバイス型）：16views・ER 0.0% → 即刻設計変更が必要

**現状の問題構造：**

フォロワーがほぼゼロの段階でadviceを出しても、**「あなたは誰？なぜあなたの言うことを聞くの？」**という信頼の前提がないため、スルーされます。これはコンテンツの問題ではなくシーケンスの問題です。

**具体的改善案 3点：**

**① adviceはtrust_buildingで信頼を積んだ後に出す**
現時点での適切な投稿比率は `trust_building : advice = 8 : 2` 。adviceを出す場合も必ず冒頭に「6年・100人経験した私が…」という権威付けフレーズを入れること。

**② adviceのタイトル構造を変える**
```
❌ 現状（推定）：「婚活でやるべき3つのこと」
✅ 改善案：「100人と会って全滅した私が、最後に気づいた1つのこと」
```
体験談の延長としてアドバイスを包む形式にすることで、trust_buildingの文脈を引き継げます。

**③ リプライを誘発する問いかけで終わる**
```
例：「あなたはどんな理由で婚活を続けていますか？
コメントで教えてもらえると嬉しいです🙏」
```

### 🟡 視聴数ゼロ近傍投稿の共通問題

「プロフ修正しても変わらなかった（9views）」「メッセージで消耗した2年間（5views）」の低迷は**タイトルの弱さ**が原因です。

```
❌ プロフ修正しても変わらなかった
→「修正した」という行動を主語にしており、感情的フックがない

✅ 改善例：「50回プロフを直したのに、なぜ誰も振り向かなかったのか」
→ 数字（50回）＋感情（なぜ）＋問い（疑問形）の三重構造
```

```
❌ メッセージで消耗した2年間
→ 「消耗した」で終わっており、読む理由がない

✅ 改善例：「2年間、毎晩メッセージを打ち続けた私が壊れた日」
→「壊れた日」という具体イベントへの好奇心が生まれる
```

## 4. 投稿時間帯の評価と推奨

### ⚠️ 現状：12:00・21:00ともにデータなし（投稿実績ゼロ）

これは**戦略上の重大な機会損失**です。Threadsにおける婚活コンテンツのゴールデンタイムに一切投稿できていません。

**Threads婚活ターゲット向け推奨時間帯：**

| 時間帯 | 理由 | 優先度 |
|--------|------|--------|
| **21:00〜22:00** | 帰宅後・入浴後リラックス時間。感情系コンテンツへの受容性が最高潮。「夜中に泣いた話」系との相性◎ | 🥇 最優先 |
| **12:00〜12:30** | 昼休み。スクロール消費が活発。タイトルで瞬間的に引く投稿向き | 🥈 次点 |
| **7:00〜7:30** | 通勤前。習慣的チェック層に届く。短文・共感系に有効 | 🥉 補助枠 |

**推奨アクション：**
> 来週から必ず **21:00投稿を週3本以上確保** することをルール化してください。投稿時間の一貫性はThreadsアルゴリズムの学習にも影響します。
