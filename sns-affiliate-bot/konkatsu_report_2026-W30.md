## 2. 最も効果的だった投稿タイプと理由

### 🏆 trust_building（信頼構築型）が唯一の機能タイプ

**上位3投稿の共通法則を解剖する**

```
1位：年齢のせいじゃなかった       → 402 views / ER 0.75%
2位：婚活やめたいと思った日       → 335 views / ER 0.60%
3位：夜中に泣いた話               →  93 views / ER 1.08%
```

#### なぜこの3本が伸びたのか？

**① タイトルに「認知の裏切り」がある**

「年齢のせいじゃなかった」→ *34歳女性の婚活=年齢問題* という世間の固定観念を真正面から否定している。読者は「え、じゃあ何のせいなの？」と続きを読まずにいられない。

「婚活やめたいと思った日」→ *婚活アカウントなのに婚活を否定する* という逆説的フックが好奇心を刺激する。

**② 感情の固有名詞化ができている**

「夜中に泣いた」という表現は**時間帯（夜中）×行動（泣く）**の組み合わせで、読者の記憶にある「あの夜」と直結する。「悲しかった」より100倍リアル。

**③ ミキのペルソナ（6年・100人・全滅）との文脈一致**

フォロワーはミキに「同じ痛みを持つ先輩」を求めている。苦しさを正直に語る投稿ほどエンゲージメントが高い傾向は、このペルソナ設計と完全に整合している。

## 3. 改善が必要なタイプと具体的改善案

### 🔴 Problem 1：advice型がほぼ機能していない

**「タイトルなし・16views・ER0%」**

これは投稿設計の問題以前に、**タイトル（冒頭フック）の欠如**という致命的ミスが原因と推定される。

#### 改善案
```
❌ 現状：タイトルなしでアドバイス本文を書き始める

✅ 改善：最初の1行を「ミキが6年で学んだ◯◯」という
         体験談フレームに変換してから advice に入る

例）
「アプリで100人会った私が、今なら絶対やらないこと3つ」
→ これはadviceだがtrust_buildingの文脈から入っている
```

**advice型はミキのアカウントでは単独機能しない。必ずtrust_buildingと抱き合わせにすること。**

---

### 🔴 Problem 2：低ビュー投稿（5〜15views）の量産

以下4本が壊滅的数値：

| タイトル | Views | 推定原因 |
|---------|-------|---------|
| メッセージで消耗した2年間 | 5 | 冒頭フック弱・テーマが内向き |
| プロフ修正しても変わらなかった | 9 | 具体性はあるが感情フックなし |
| 自分を偽って疲れた | 13 | タイトルは良いが冒頭文が弱い可能性 |
| 6年間で失ったもの | 15 | タイトルは良いが続きへの引きが弱い可能性 |

#### 共通改善策

**「投稿の最初の2行」を完全リニューアルする**

Threadsはタイムラインで**冒頭2行しか表示されない**。この2行で「もっと読む」を押させられなければ、どんな良いコンテンツも埋もれる。

```
✅ 冒頭2行の黄金フォーマット（ミキ版）

[衝撃の事実 or 感情的告白] + [読者への問いかけ]

例）
「マッチングアプリに6年・200万円を溶かした。
 でも一番失ったのはお金じゃなかった。」

例）
「婚活中、私は毎晩プロフを直してた。
 今思うと、本当に直すべきは別のものだった。」
```

### 🟡 Problem 3：リプライが全投稿で0件

エンゲージメントの最上位指標であるリプライが皆無。アルゴリズム評価・読者との関係構築の両面で損失が大きい。

#### 改善策：**投稿末尾に「返答しやすい問いかけ」を必ず置く**

```
❌ 現状の終わり方（推定）：
「〜だった。今は幸せです。」で完結

✅ 改善後の終わり方：
「あなたはアプリで何人と会いましたか？
 コメントで教えてもらえたら、正直に答えます🙋‍♀️」

「婚活中、一番つらかった瞬間はどこですか？」

「このあと戦略を変えた話、読みたい方は『読みたい』と
 コメントください。続き書きます。」
```

最後の手法（**予告型コメント誘導**）は特に効果的で、リプライ数を増やしながら次回投稿へのアンカーも張れる。

## 4. 投稿時間帯の評価と推奨

### ⚠️ データ上の問題

12:00・21:00ともにcount=0、つまり**この時間帯での投稿実績がない**。時間帯最適化の以前に、**投稿時刻の記録・管理ができていない**状態と判断。

### 推奨投稿時間帯（Threads×婚活ペルソナ根拠）

**ターゲット読者像：20代後半〜30代女性・会社員・婚活中**

```
🥇 最優先：21:00〜22:00
   理由：帰宅後の「一人時間」。婚活の不安や孤独を
         感じやすいゴールデンタイム。共感コンテンツとの
         親和性が最も高い。

🥈 次点：  12:00〜12:30
   理由：昼休みのスマホタイム。短い時間で読める
         投稿が刺さりやすい。

🥉 補助：  07:00〜08:00
   理由：通勤時間。「今日も婚活どうしよう」という
         朝の不安感情にリーチできる。
```

**来週からは21時投稿を基本ルールとして固定し、1週間後に時間帯別ERを計測すること。**
