## 2. 最も効果的だった投稿タイプと理由

### ✅ trust_building（信頼構築型）が圧倒的優位

**トップ3投稿の共通構造を分析：**

```
1位「年齢のせいじゃなかった」    402ビュー / ER 0.75%
2位「婚活やめたいと思った日」    335ビュー / ER 0.60%
3位「夜中に泣いた話」            93ビュー  / ER 1.08%
```

**なぜこのタイプが機能するか：3つの理由**

**① 「言語化の代理」効果**
婚活疲弊者が「自分では言えなかった感情」をミキが代わりに言語化している。読者は「これ、私のことだ」と感じ、保存・シェア衝動が生まれる。

**② タイトルの「感情ワード」が強い**
「やめたい」「泣いた」「年齢のせい」——これらはすべてThreadsのホームフィードでスクロールを止める**「ストップワード」**として機能している。

**③ Threadsのアルゴリズムとの相性**
Threadsは現在、**「共感ベースの感情的コンテンツ」を優遇する傾向**がある。trust_buildingは構造的にこれに合致している。

## 3. 改善が必要なタイプと具体的改善案

### ❌ advice型：16ビュー / ER 0.0%（完全機能不全）

**問題の根本原因：**

タイトルが空白（""）という致命的なミスが発生している。Threadsにおいて**最初の1〜2行がすべて**だ。タイトル＝フック文が存在しない投稿は、アルゴリズムにも人間にも無視される。

**構造的問題の整理：**

```
現状のadvice投稿の問題点
├── フック文なし → スクロールを止められない
├── 「誰が言っているか」の文脈が薄い
└── 「なぜミキが言えるのか」の根拠が見えない
```

**具体的改善案：**

**改善前（推定）：** いきなりアドバイスを箇条書き

**改善後（推奨フォーマット）：**
```
【フック】共感できる失敗談や問い（1〜2行）
　↓
【実体験リンク】「6年間・100人超の私が気づいたのは」
　↓
【アドバイス本文】（短く、具体的に）
　↓
【結語】読者への問いかけ or 次投稿への引き
```

**重要：** advice型は今週の比率1/10（10%）のまま維持し、**trust_buildingで信頼を積んでからadviceを挟む**という順序を徹底すること。

## 4. 投稿時間帯の評価と推奨

### ⚠️ 現状：12:00・21:00ともにデータゼロ

これは**最重要の改善ポイント**の一つだ。

データがゼロということは、この2つの黄金時間帯に一度も投稿できていないことを意味する。ビュー数の低い投稿（5・9・13ビュー）は、**時間帯の問題がパフォーマンスを下げている可能性が高い**。

**Threadsの推奨投稿時間帯（婚活ジャンル・女性ターゲット）：**

| 時間帯 | 理由 | 優先度 |
|--------|------|--------|
| **12:00〜12:30** | 昼休みのスマホ閲覧ピーク | ⭐⭐⭐ |
| **21:00〜22:00** | 帰宅後〜就寝前。婚活層が「今日もダメだった」と感情的になる時間 | ⭐⭐⭐ |
| **7:00〜8:00** | 通勤時間。朝の感情的な読書行動 | ⭐⭐ |

**来週から必ず実施すること：**
- 投稿は上記時間帯のいずれかに集中させる
- 特に**21:00台を最優先**とする（ミキのペルソナ＝「夜中に泣いた」体験と感情が同期しやすい）
