## 2. 最も効果的だった投稿タイプと理由

### 🏆 **trust_building（信頼構築型）が唯一機能しているタイプ**

上位3投稿の共通構造を分解します。

| 順位 | タイトル | Views | 共通要素 |

### なぜこのタイプが機能するのか

**① 検索意図との一致**
Threadsで婚活関連コンテンツを見るユーザーの多くは「自分だけじゃないか確認したい」心理を持っています。ミキさんの実体験ベースの投稿はその欲求に直撃しています。

**② 「年齢のせいじゃなかった」が402viewsを獲得した理由**
このタイトルには**認知的不協和**が組み込まれています。「34歳婚活＝年齢が問題」という多くの人の固定観念を否定する言葉が、思わずタップさせる力を生んでいます。

**③ ER上位投稿の共通点**

```
友達に打ち明けた日     → ER 1.43%  （具体的な「日」という時間軸）
100人会ってわかったこと → ER 1.19%  （数字＋学び）
夜中に泣いた話        → ER 1.08%  （感情×時間帯の具体性）
```

**「具体的な数字・時間・場面」がある投稿ほどERが高い**という明確な法則が見えています。

## 3. 改善が必要なタイプと具体的改善案

### ⚠️ 課題① adviceタイプ（ER 0.0%）

**問題の本質**
現時点でadviceタイプを出すのは時期尚早です。Threadsのアルゴリズム上、**フォロワーが少ない段階でのハウツー投稿は「誰に言ってる？」状態**になります。信頼残高が貯まる前のアドバイスは読まれません。

**改善案**
```
❌ 現在：「〇〇すべき3つのこと」式のアドバイス投稿
✅ 改善：アドバイスをストーリーに包む

例）
❌「婚活プロフィールで大事な3つのポイント」
✅「プロフを20回直して気づいたこと。結局、写真でも文章でもなかった」
```

adviceの要素は残しつつ、**trust_buildingの皮をかぶせる**ことで自然に機能します。

---

### ⚠️ 課題② 低ビュー投稿の構造問題

**5〜15viewsに沈んだ投稿の共通点**

| 投稿タイトル | Views | 問題点 |
|------------|-------|--------|
| 自分を偽って疲れた | 13 | 感情だけで「学び」も「逆転」もない |
| 6年間で失ったもの | 15 | ネガティブで終わっている予感を与える |
| プロフ修正しても変わらなかった | 9 | 失敗談で終わる印象。続きを読む理由がない |
| メッセージで消耗した2年間 | 5 | 共感は生むが「で、どうなった？」がない |

**構造的改善テンプレート**

```
【現在の構造】
感情吐露 → 終わり

【改善後の構造】
感情吐露（共感）→ 転換点 → 小さな希望or学び → 問いかけ

例）「メッセージで消耗した2年間」の改善版タイトル
→「メッセージで消耗した2年間が、ある一言で終わった話」
```

### ⚠️ 課題③ リプライゼロ問題（最重要）

これが現在の**最大の構造的問題**です。Threadsのアルゴリズムはリプライ数を重要な拡散シグナルとして扱います。

**即効性のある改善策3つ**

```
① 投稿の末尾に必ず「問いかけ」を入れる
   例：「あなたはどんな理由で婚活続けてましたか？」

② 自分の投稿のリプライ欄に自分で「追記コメント」を入れる
   →リプライ欄を先に温めることで他者が入りやすくなる

③ 同じ婚活系アカウントの投稿に毎日5件、本気のリプライをする
   →相互リプライの文化を作る
```
