## 2. 最も効果的だった投稿タイプと理由

### 🏆 trust_building（信頼構築型）が唯一機能

**トップ3投稿の分析：**

```
1位「年齢のせいじゃなかった」    402views / ER0.75%
2位「婚活やめたいと思った日」    335views / ER0.60%
3位「夜中に泣いた話」            93views  / ER1.08%
```

**なぜこの3本が伸びたか：**

**①「年齢のせいじゃなかった」の成功構造**
- タイトルに「否定の逆転」が入っている（年齢→犯人じゃなかった）
- 34歳婚活層が最も恐れている「年齢の壁」というペインポイントに直撃
- 「じゃなかった」という結論提示がスクロールを止める

**②「婚活やめたいと思った日」の成功構造**
- 婚活中の誰もが経験する「限界点」の普遍的感情
- 「やめたい」という弱音の開示が共感を呼ぶ
- ネガティブ感情タイトルはThreadsで特に停止率が高い

**③「夜中に泣いた話」のER最高（1.08%）の理由**
- 具体的シーン（夜中）× 感情（泣いた）の組み合わせ
- 読んだ人が「私も」と感じる具体性
- ERが高い＝ビューが少なくてもいいねした人の比率が高い→コアファンが反応している

**共通する成功パターン：**
```
✅ 感情の固有名詞化（「つらい」ではなく「夜中に泣いた」）
✅ 自分の弱さ・失敗の開示
✅ 婚活層全員が経験するペインポイントへの言語化
```

## 3. 改善が必要なタイプと具体的改善案

### 🔴 課題①：adviceタイプが完全に機能していない

```
advice: 平均16views / ER0.0% / 1本のみ
```

**問題の本質：**
信頼が構築される前のadvice投稿は「誰だかわからない人の意見」として処理される。ミキさんのアカウントはまだ認知獲得フェーズであり、「教える」コンテンツを受け入れてもらえる段階にない。

**改善案：**
```
❌ やめる → 「婚活で大切な3つのこと」型の教訓投稿
✅ 変える → 「私が気づいたこと」型の体験ベースアドバイス

構造: 失敗エピソード(8割) → 気づき(2割)
例:「6年間プロフを30回以上直したけど、変えるべきは
    写真じゃなかった。変えて初めて連絡が途切れなく
    なったのは○○だった。」
```

### 🔴 課題②：低ビュー投稿群の構造的問題

```
「メッセージで消耗した2年間」     5views
「プロフ修正しても変わらなかった」  9views
「自分を偽って疲れた」            13views
「6年間で失ったもの」             15views
```

**共通の問題点分析：**

| 問題 | 詳細 |
|------|------|
| タイトルが「状況説明」で終わっている | 「消耗した」「疲れた」→読む理由が生まれない |
| 結論・逆転・気づきがタイトルにない | 続きを読みたい動機がゼロ |
| 「私だけの話」になっている | 普遍的共感への橋渡しがない |

**具体的リライト例：**
```
❌「メッセージで消耗した2年間」
✅「毎日メッセージを送り続けた2年間、私がやっと
   やめた理由」（逆転・結論提示で続きを読ませる）

❌「自分を偽って疲れた」
✅「婚活で"明るくハキハキ"を演じた3年間。
   やめた途端に変わったこと」（Before/Afterで共感喚起）
```

### 🔴 課題③：リプライ誘発設計がゼロ

**全10投稿でリプライ0は構造的問題。**

Threadsはリプライがつくと急激にリーチが拡大するアルゴリズムを持っています。現在の投稿はすべて「読んで終わり」で設計されており、コメントするきっかけが存在しない。

**改善案：投稿末尾に必ずリプライ誘導文を入れる**
```
パターンA（共感型）:
「同じ気持ちになったことある方、
 ↓に一言だけ教えてもらえると嬉しいです」

パターンB（質問型）:
「婚活中に一番つらかったのは何でしたか？
 私は○○でした。」

パターンC（二択型）:
「婚活アプリ、続けてよかったと思う？
 A:思う / B:思わない
 私はBでした。理由は後日投稿します」
```

## 4. 投稿時間帯の評価と推奨

### 現状評価：🔴 データが存在しない（深刻）

```json

"21:00": { "count": 0, "avg_er": 0.0 }

**12:00・21:00の投稿が1本もない状態**です。これはThreadsで最もリーチが取れる黄金時間帯を完全に活用できていないことを意味します。

**Threadsにおける推奨投稿時間（婚活女性ターゲット）：**

   理由: 電車内スクロール需要

⚠️ 避けるべき時間帯:
   14:00〜17:00（業務集中時間）
