## 2. 最も効果的だった投稿タイプと理由

### 🏆 trust_building（信頼構築型）が唯一機能しているタイプ

**トップ3投稿の共通点分析：**

```
1位「年齢のせいじゃなかった」   402 views / ER 0.75%
2位「婚活やめたいと思った日」   335 views / ER 0.60%
3位「夜中に泣いた話」           93 views  / ER 1.08%
```

**なぜ効くのか：3つの構造的理由**

**① タイトルに「否定の解放」がある**
「年齢のせいじゃなかった」は、34歳婚活女性が最も内面化している自己否定（年齢呪縛）を代弁しています。Threadsのタイムラインをスクロールする指が**自然に止まる設計**になっています。

**② 「やめたい」「泣いた」という感情の臨界点を描写している**
婚活疲弊層が「自分だけじゃないんだ」と感じる瞬間を直撃しています。これはミキのペルソナ（6年・100人超・全滅）が最も武器になる領域です。

**③ 完結しない余白がある（＝続きを読みたくなる）**
タイトルだけで完結せず、「なぜ？どうなった？」という問いが残ります。

## 3. 改善が必要なタイプと具体的改善案

### 🔴 問題① advice型：完全機能不全

```
「（タイトルなし）」advice投稿 → 16 views / ER 0.0%
```

**根本原因：信頼残高ゼロの段階でのアドバイスは逆効果**

フォロワーがまだ少ない段階で「〜すべき」「〜が正解」という情報提供型投稿をしても、**「誰あなた？」で終わります**。これはミキの最大の強み（体験・感情・失敗の深さ）を全く活かせていない投稿形式です。

> **改善案：adviceは当面封印。trust_buildingの中にノウハウを「後日談として」埋め込む**

❌ 悪い例：「婚活で大切な3つのこと」
✅ 良い例：「100人会ってやっと気づいた、私に足りなかったたった1つのこと」

---

### 🟡 問題② trust_building内の格差（低視聴投稿群）

```
「プロフ修正しても変わらなかった」  9 views
「メッセージで消耗した2年間」       5 views
「自分を偽って疲れた」             13 views
```

**共通の構造的弱点：**

| 弱点 | 詳細 |
|------|------|
| **タイトルが内向き** | 「私が消耗した」→読者のベネフィットが見えない |
| **時間軸が曖昧** | 「2年間」は長すぎて感情移入しにくい |
| **解決の匂いがない** | 苦しいだけで終わる予感がするとスルーされる |

**具体的改善フレームワーク：「共感→転換の予告」構造**

```
【弱いタイトル】「メッセージで消耗した2年間」
　↓
【強いタイトル】「毎晩メッセージを送り続けた2年間。やめた日に全部変わった」
```

タイトルに**「転換点の予告」**を入れることで、「この話には出口がある」と読者に伝わり、クリック率が上がります。

---

### 🟡 問題③ リプライ誘発設計の完全欠如

全10投稿でリプライ0は、**投稿の末尾にエンゲージメント設計がない**ことが原因です。

**改善案：投稿末尾に「1行の問いかけ」を必ず入れる**

```
❌ 現状：感情の吐露で終わる
✅ 改善：「あなたはどのタイミングで婚活が辛くなりましたか？」
　　　　「同じ経験した人いますか？」
　　　　「コメントで教えてもらえると嬉しいです」
```
