## 2. 最も効果的だった投稿タイプと理由

### 🏆 trust_building（信頼構築型）が圧倒的優位

```
advice       → 平均ビュー  16.0 / 平均ER 0.00%
trust_building → 平均ビュー 114.0 / 平均ER 0.56%

**ビュー差：7.1倍 / ER差：測定不能レベルの差**

#### なぜtrust_buildingが機能しているか

**① 感情的共鳴トリガーの有無**

上位3投稿のタイトル構造を見ると明確なパターンがあります：

| 順位 | タイトル | ビュー | 共通要素 |

→ 共通点は「**婚活女性が心の中で思っているが言語化できていないこと**」を代弁していること。Threadsユーザーはスクロール中に「これ私のことだ」と感じた瞬間に止まります。

**② adviceが失敗している根本理由**

唯一のadvice投稿はビュー16・ER0%。タイトルも空欄という問題もありますが、本質的な問題は**「まだ信頼口座の残高がゼロの状態でノウハウを語っても誰も聞かない」**ということです。フォロワー数が少ない今、専門知識より先に「この人の話を聞きたい」という関係性構築が必須です。

## 3. 改善が必要なタイプと具体的改善案

### ❶ advice投稿：現時点では封印推奨

**問題点**
- タイトル未設定はThreadsでは致命的（最初の1行がタイトル兼フックになる）
- ビュー16は拡散ゼロ＝アルゴリズムに評価されていない
- 信頼構築前のノウハウ提供は「誰？」で終わる

**改善案（段階的アプローチ）**
```
今週：advice完全停止 → trust_buildingに集中
2週間後：体験談に自然に溶け込む形でノウハウを1文だけ混ぜる
1ヶ月後：「私がやめた3つのこと」など体験ベースのadviceに転換
```

### ❷ trust_building下位投稿の共通問題

下位4投稿（ビュー5〜15）の分析：

| タイトル | ビュー | 問題点 |
|---------|-------|-------|
| 自分を偽って疲れた | 13 | 結論が見えない・誰でも言えそう |
| 6年間で失ったもの | 15 | 抽象的すぎる・具体性ゼロ |
| プロフ修正しても変わらなかった | 9 | ターゲットが狭すぎる |
| メッセージで消耗した2年間 | 5 | 暗さだけで出口がない |

**共通の失敗構造：「共感入口」はあるが「希望の出口」がない**

Threadsで伸びるtrust_buildingには以下の構造が必要です：

```
❌ NG構造：苦しかった → 以上
✅ OK構造：苦しかった → でも気づいた → だから今がある
```

**具体的改善テンプレート**
```
冒頭（1〜2行）：強い感情ワード＋具体的状況
中間（3〜5行）：当時の自分のリアルな心理描写
転換（1行）  ：「でも、あの時〇〇に気づいた」
着地（2行）  ：今の自分 or 読者への短いメッセージ
```

## 4. 投稿時間帯の評価と推奨

### 現状評価：🔴 データ不足・時間帯戦略が機能していない

```json
"12:00": { "count": 0, "avg_er": 0.0 }
"21:00": { "count": 0, "avg_er": 0.0 }
```

**推奨時間帯の投稿実績がゼロ**という致命的な状況です。現在の投稿時間が最適タイムゾーンから外れている可能性が高く、ビュー数の不安定さの一因になっています。

　 → 孤独感・婚活疲れが最も高まる時間帯
　 → エンゲージメント率が最も高い

📌 推奨投稿頻度：1日1〜2本（現在の10本/週は維持でOK）
📌 必ず21:00枠を毎日確保すること
