# Grok Imagine Agent フル完結プロンプト テンプレート（ペットジャンル用）

Grok Imagine の Agent Mode に1回貼るだけで、画像生成→動画化→ナレーション音声→
字幕同期→結合まで全てAgent側で完結させるためのテンプレート。
CapCut・FFmpeg・Voicevox・手動編集は一切不要になる。

## 使い方
1. 下のテンプレートの【 】部分を各動画の内容で埋める
2. Grok Imagine の Agent Mode に全文を貼り付ける
3. 完成した1本のMP4をダウンロード → YouTubeアプリからそのまま投稿

## 前提（現行の確定方針 2026/08〜）
- 猫のみ主演・人物なし・CTAなし
- シーン数は5前後で可変
- リップシンク不要（人物が映らないため口パク問題は発生しない）
- ナレーションとキャプションの内容・タイミングが一致していることだけが必須

---

## テンプレート

```
以下の指示だけで、完成した縦型ショート動画を1本作ってください。
途中の確認は不要です。最後に完成動画1本だけを出力してください。

【完成物の仕様】
- 縦型 9:16（1080×1920）のMP4を1本
- 構成は下記の全シーンを順番に繋いだもの
- 各シーンにナレーション音声とキャプション（字幕）を付ける
- ウォーターマーク・ロゴ・キャプション以外のテキストは入れない

【テンポの仕様（最重要・厳守）】
※ここで削るのは「ナレーションとナレーションの**間の無音**」だけです。
　声の読み上げ speed は速くしないでください（下の音声の仕様を優先）。
- 各シーンの尺は固定ではなく「そのシーンのナレーションの長さ＋0.3秒」に合わせて詰める
  （読み終わった後に映像だけが続く余韻の時間を作らない）
- シーンが切り替わったら即（0.3秒以内に）次のナレーションを開始する
- ナレーションとナレーションの間の無音は最大でも0.5秒。間延びした沈黙を作らない
- 上記を守れば全体は20〜25秒程度に収まるはず。尺を縮めるために早口にはしないこと

【音声の仕様】
- 音声はナレーションのみ。**BGM・効果音・環境音は完全に入れない**
  （ナレーションが無い瞬間は完全な無音でよい。BGMは投稿時にYouTube側で追加するため）
- 日本語・自然な女性の声
- **読み方はゆっくり穏やかに、優しく語りかけるトーン。癒し系の動画なので
  早口・急いだ喋り方は絶対にしないこと。**一文一文を丁寧に読む
- 人物は映らないためリップシンクは不要
- ナレーションとキャプションの内容とタイミングが必ず一致すること

【キャプション（字幕）の仕様】
- 各シーンのナレーション文をそのまま画面下部中央に表示
- 白文字・黒縁取り・読みやすい太めのゴシック体
- 画面の下端から10〜15%上に配置（スマホUIと被らない安全圏）
- そのシーンのナレーションが流れている間だけ表示

【各シーンの内容】

■ scene1（映像）: 【シーン1の映像の指示】
（ナレーション・キャプション）: 【シーン1のナレーション文】

■ scene2（映像）: 【シーン2の映像の指示】
（ナレーション・キャプション）: 【シーン2のナレーション文】

■ scene3（映像）: 【シーン3の映像の指示】
（ナレーション・キャプション）: 【シーン3のナレーション文】

■ scene4（映像）: 【シーン4の映像の指示】
（ナレーション・キャプション）: 【シーン4のナレーション文】

■ scene5（映像）: 【シーン5の映像の指示】
（ナレーション・キャプション）: 【シーン5のナレーション文】

【映像の共通スタイル】
- 実写風・シネマティック・日本の住宅
- キジトラ猫（同一個体として一貫させる）
- 人物は登場させない
- 動きは自然でゆったり、コミカルなトーン

以上をすべて実行し、結合済みの完成動画1本を出力してください。
```

## 運用メモ
- これが成功したら assemble_grok.py / make_audio_petXX.py / Voicevox は不要になる
  （フォールバックとして残しておく）
- ナレーションの声質が毎回変わる場合は「前回と同じ声で」と追記して調整する
- キャプションのズレ・誤字が出た場合はそのシーンだけ再指示する

## 改訂履歴
- 2026/08 第2版: 初版はナレーション間の無音が長くテンポが悪かったため、
  テンポ仕様を新設（シーン尺＝ナレーション長+0.3秒、無音は最大0.5秒）。
  2026年のShorts標準（無音・間延びの全カット）に準拠。
  あわせて音声仕様を「ナレーション以外は完全無音」に変更
  （YouTube投稿時にBGMを自動追加する運用のため、動画側にBGM・環境音を入れない）。
- 2026/08 第3版: 第2版に入れた「読み上げ自体もテンポよく／朗読調にしない」を**撤回**。
  **削るべきは無音（間）だけであって、声の速度ではない**というのが正しい設計。
  根拠: ①市場リサーチが言っていたのは「無音部分のカット」であり早口化ではない
  ②当チャンネルの上位実績（⑰3,419・㉑3,542・㉗3,873）はすべて
  `SPEED 0.88 / INTONATION 1.4` のゆっくりした感情的な読みで達成しており、
  速い読みで伸びた実績は無い ③癒し系ジャンルで語りが速いと情緒が壊れる。
  → 逆に「ゆっくり穏やかに、早口にしない」を明示する指示へ変更。
  尺は読み速度ではなく行数・文字数で調整する。
