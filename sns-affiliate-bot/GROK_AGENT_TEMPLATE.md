# Grok Imagine Agent フル完結プロンプト テンプレート（ペットジャンル用）

Grok Imagine の Agent Mode に1回貼るだけで、画像生成→動画化→ナレーション音声→
字幕同期→結合まで全てAgent側で完結させるためのテンプレート。
CapCut・FFmpeg・Voicevox・手動編集は一切不要になる。

## 使い方
1. 下のテンプレートの【 】部分を各動画の内容で埋める
2. Grok Imagine の Agent Mode に全文を貼り付ける
3. 完成した1本のMP4をダウンロード → YouTubeアプリからそのまま投稿

## 前提（現行の確定方針 2026/08〜）
- 猫のみ主演・人物なし・CTAなし
- シーン数は5前後で可変
- リップシンク不要（人物が映らないため口パク問題は発生しない）
- ナレーションとキャプションの内容・タイミングが一致していることだけが必須

---

## テンプレート

```
以下の指示だけで、完成した縦型ショート動画を1本作ってください。
途中の確認は不要です。最後に完成動画1本だけを出力してください。

【完成物の仕様】
- 縦型 9:16（1080×1920）のMP4を1本
- 構成は下記の全シーンを順番に繋いだもの（各シーン約5〜6秒）
- 各シーンにナレーション音声とキャプション（字幕）を付ける
- BGM・効果音は不要（あっても音量控えめなら可）
- ウォーターマーク・ロゴ・キャプション以外のテキストは入れない

【ナレーション音声の仕様】
- 日本語・自然な女性の声（落ち着いた優しいトーン、機械的すぎない読み方）
- 各シーンのナレーション文を、そのシーンの映像に合わせて読み上げる
- 人物は映らないためリップシンクは不要
- ナレーションとキャプションの内容とタイミングが必ず一致すること

【キャプション（字幕）の仕様】
- 各シーンのナレーション文をそのまま画面下部中央に表示
- 白文字・黒縁取り・読みやすい太めのゴシック体
- 画面の下端から10〜15%上に配置（スマホUIと被らない安全圏）
- そのシーンのナレーションが流れている間だけ表示

【各シーンの内容】

■ scene1（映像）: 【シーン1の映像の指示】
（ナレーション・キャプション）: 【シーン1のナレーション文】

■ scene2（映像）: 【シーン2の映像の指示】
（ナレーション・キャプション）: 【シーン2のナレーション文】

■ scene3（映像）: 【シーン3の映像の指示】
（ナレーション・キャプション）: 【シーン3のナレーション文】

■ scene4（映像）: 【シーン4の映像の指示】
（ナレーション・キャプション）: 【シーン4のナレーション文】

■ scene5（映像）: 【シーン5の映像の指示】
（ナレーション・キャプション）: 【シーン5のナレーション文】

【映像の共通スタイル】
- 実写風・シネマティック・日本の住宅
- キジトラ猫（同一個体として一貫させる）
- 人物は登場させない
- 動きは自然でゆったり、コミカルなトーン

以上をすべて実行し、結合済みの完成動画1本を出力してください。
```

## 運用メモ
- これが成功したら assemble_grok.py / make_audio_petXX.py / Voicevox は不要になる
  （フォールバックとして残しておく）
- ナレーションの声質が毎回変わる場合は「前回と同じ声で」と追記して調整する
- キャプションのズレ・誤字が出た場合はそのシーンだけ再指示する
