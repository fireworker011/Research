# サクラIG — 専属マネージャーキット

ゴールはフォロワー増ではない。**Instagramリールで非フォロワーに届き、プロフィールのリンクをタップさせ、Fanvueの有料が判定できる数まで来ること。**

制作は Grok Imagine に丸投げする。投稿と数字の記入は人間（スマホ）。自動投稿しない。Threadsエンジンにも繋がない。

## 役割

| 誰 | やること | やらないこと |
|---|---|---|
| マネージャー（このリポの後続セッション） | パケット更新、型の残棄、判定 | 動画をその場で創る、ジャンル転換 |
| Grok Imagine エージェント | `packets/` を読んで静止画→動画まで完成 | 投稿、衣装の追加、顔の変更 |
| 人間 | バイオのリンク、投稿、インサイト4数字 | 同じ赤着物の量産を自分で考えない |

Imagine エージェントは `.cursor/skills/sakura-imagine/SKILL.md` と `GROK_IMAGINE_AGENT.md` を先に読む。

## 今スプリント（2026-08-23 〜 09-05）

14本。1日1本。投稿時刻は **21:00 JST**。

| ゲート | 数字 | 未達のとき |
|---|---|---|
| 再生 | 1本でも再生 ÷ 2468 ≥ 10（24,700） | その型以外を捨て、冒頭0.5秒だけ入れ替える |
| 弱い再生 | 14本すべて 2倍未満（5,000未満） | 本数は維持。型を変える。量産しない |
| 導線 | リンクタップ 週15 | タップが足りない週は着地を語らない |
| 成果 | Fanvueチェックアウト | タップ週15未満では案件判定しない |

赤着物は記号として週3本。他の日は同じ顔で別の着。

## 人間が最初に1回だけやること

1. プロフィールに外部リンクを1本置く（Fanvue）。自分の別端末で開けるか確認する
2. バイオを `bio.md` に差し替える
3. 既存の顔写真があれば `refs/sakura-face.jpg` に置く（任意。あると顔が固定しやすい）
4. 完成した `output/<id>/reel.mp4` をリールとして投稿する。キャプションは同フォルダの `caption.txt`

毎日メモするのは4つだけ。日付、再生、再生÷2468、リンクタップ。`data/reel_log.csv` に追記。

## コマンド

```bash
cd sakura-ig
node src/validate-packets.js
node src/print-packet.js --next          # Grok Imagine UI に貼る文
node src/imagine-run.js --next           # XAI_API_KEY があるとき完成ファイルまで
node src/imagine-run.js --date 2026-08-24
```

APIキーが無いときは `print-packet.js` の出力を grok.com / X の Imagine に貼る。エージェントは質問せず、パケットの数値どおりに出す。

## やらないこと

- 人間を装うDM・自動返信
- リールへのFanvue URL
- TikTok / X の同時立ち上げ
- 水着・別顔・別事業への転換
- `affiliate-engine` の投稿ワークフローへの接続
- 調べていない口座を成功例としてパケットに書く
