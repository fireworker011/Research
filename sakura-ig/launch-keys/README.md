# 起動キー

マネージャー（プロンプト担当）が書く唯一の渡し物。  
**サクラ専属自動投稿** は起動時に `CURRENT.md` だけを読む。

流れ（JST）:

1. **05:00** マネージャーが Imagine 用動画プロンプトを `CURRENT.md` に書き、サクラ専属自動投稿へ渡す
2. ボットが `IMAGINE_THROW` を **Grok Imagine agent** に投げる
3. 05:00〜06:00 に動画ができる
4. **06:00** ボットが投稿する

05:00 の受け渡しが無い日は動かない。テストは受け渡しを今すぐ行い、投稿しない。

ボットはプロンプトを書かない。Imagine を自分で企画しない。マネージャーは Imagine に直接投げない。投稿もしない。  
**APIキーは不要。** ボット → Grok Imagine の投げだけで動画になる。
