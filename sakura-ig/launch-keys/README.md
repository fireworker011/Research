# 起動キー

マネージャー（プロンプト担当）が書く唯一の渡し物。  
**サクラ専属自動投稿** は起動時に `CURRENT.md` だけを読む。

流れ:

1. マネージャーが Imagine 用動画プロンプトを `CURRENT.md` / `CURRENT.json` に書く
2. サクラ専属自動投稿が起動キーとしてそれを読む
3. ボットが `imagine_prompt` を **Grok Imagine agent** に投げる
4. 動画ができる
5. ボットが毎朝 06:00 JST に投稿する

ボットはプロンプトを書かない。Imagine を自分で企画しない。マネージャーは Imagine に直接投げない。投稿もしない。
