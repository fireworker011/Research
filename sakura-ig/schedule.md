# 時計（JST）

投稿の時計は **Grok Bot A のルーチン**。GitHub の cron は使わない（デフォルトへ向けない。円の席を壊さない）。

Issue「サクラ起動キー」の鏡は、マネージャーが毎朝 `set-current.js` で `CURRENT.json` を JST 今日に写して push する。

| JST | 誰 | 仕事 | 無いとき |
|---|---|---|---|
| **05:00** 毎日 | マネージャー | `set-current.js` → CURRENT.json を今日に写して push → Issue に今日のキー | キー 404 なら何もしない |
| **05:00** 毎日 | A | `keys/<今日>.md` を読む → B に IMAGINE_THROW＋参照2枚 → mp4 を確認 | 404 なら今日は動かない。05:00 過ぎの再開は今すぐ作れ |
| 05:00〜06:00 | B | STEP 1 静止画 → STEP 2 動画 → mp4 を返す | 顔が別人なら1回やり直し、次は参照をそのまま動かす |
| **06:00** 毎日 | A | リール投稿。キャプションそのまま | 失敗は 06:30 に1回。06:00 過ぎの再開はでき次第。08:00 過ぎたら明日 |
| **07:00** 日曜 | A | Insights → `data/reel_log.csv` に7行 → push。コメントに保存済み返信（20件まで） | 数字が取れない欄は空欄 |
| push 直後 | Actions | `judge.js` が Issue「サクラ判定」に切り分け | — |
| 銀行が尽きる前 | マネージャー | `build-keys.js` で延ばす（最終日は `keys/INDEX.md`） | — |

銀行: **2026-09-13 〜 2027-03-31**（200日）。尽きる前に `node src/build-keys.js --from 2026-09-13 --days 400` で延ばす（同じ日は同じキーのまま）。

人間の毎日: なし。`席: …` の1行が出た時だけ動く。
