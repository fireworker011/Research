# 毎日の時計（JST）

投稿が 06:00 なので、Imagine の生成時間を見て、起動キーは **05:00 までに渡す**。

| JST | 誰 | 仕事 |
|---|---|---|
| **05:00** | マネージャー（このセッション系） | その日の動画プロンプトを `launch-keys/CURRENT.md` に書き、**サクラ専属自動投稿** に渡す。Imagine には投げない |
| 05:00〜06:00 | サクラ専属自動投稿 | 起動キーの `IMAGINE_THROW` を Grok Imagine agent に投げる。動画を完成させる |
| **06:00** | サクラ専属自動投稿 | `reel.mp4` を投稿。キャプションはキーのまま |

1日1本。05:00 の受け渡しが無い日は、ボットは新しいプロンプトを作らない。昨日のキーを使い回さない。

テストのときだけ例外: 受け渡しは今すぐ。投稿はしない。
