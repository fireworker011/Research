# Instagram 初回設定（A が1回だけ実行）

対象 `sakura_ai_beauty`。全部 Instagram の公式画面でやる。外部ツール・非公式 API は使わない。

## 1. プロアカウント

設定 → アカウントの種類とツール → **クリエイター** になっているか。なければ切り替える（カテゴリ: デジタルクリエイター）。

## 2. プロフィール

表示名はそのまま `サクラ🌸AI和装美女研究家`。

本文（コピペ。`bio.md` と同じ）:

```
『雅』を発信する、仮想美女モデル
画像・動画の人物はAI生成による成人モデルです
Virtual beauty model. AI-generated adult.
続き・限定は下のリンクから。
```

リンク: `config/links.json` の `fanvue` を **1本だけ**。空なら他を続けて、最後に `席: Fanvue URL` と書く。リンクツリーは挟まない。

## 3. 保存済み返信（4本）

設定 → クリエイターツール → 保存済み返信。

| ショートカット | 文 |
|---|---|
| `ai` | AI生成の成人モデルです。続きはプロフィールのリンクから。 |
| `link` | プロフィールのリンクが本編です。 |
| `pay` | 内容と料金はプロフィールのリンク先に書いてあります。 |
| `ng` | 個別のやり取りはしていません。リンク先だけ見てもらえれば十分です。 |

使うのは自分の投稿への **コメント** だけ。DM は開かない。会話は続けない。

## 4. コメントの非表示

設定 → プライバシー → コメント / 非表示ワード。

- 「不適切なコメントを非表示」**ON**
- カスタム非表示ワード（1行ずつ）: `LINE` `ライン` `副業` `稼げ` `無料で` `DMして` `カスタム` `個撮` `会える` `脱いで` `裸` `小学` `中学` `高校生` `JK` `loli`

## 5. Meta AI の自動返信

プロフェッショナルダッシュボード → あなたのAI → 自動返信 **OFF**。作っていなければ作らない。彼女のふりをする自動会話は禁止。

## 6. やらない

- いいね・フォローの自動化ツール
- DM の自動送信
- ハイライトの追加（今あるものは残す。`which one` は「どっち」系リールの受け皿）

## 7. 報告

Issue「サクラ起動キー」に1行だけ:

- 全部できた → `初回設定: 完了`
- 足りない → `席: <足りないもの>`（例 `席: Fanvue URL`、`席: IGログイン`）
