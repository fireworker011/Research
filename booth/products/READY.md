# 作品22〜26 使う順番

公開しない。BOOTHもDLsiteも、下書きまで。申請と公開は人間が、音声を聞いてから行う。

価格は PR #186 の企画で置いた数字。売れる本数ではない。尺の分秒は、書き出したファイルを測ってから紹介文の1行を差し替える。

作品16（澄香・30歳・耳かきと手・本番なし）と作品17（美咲・32歳・添い寝・本番あり）の型に合わせてある。年齢をタイトルに書く。触る前に聞く。耳の奥を舌で舐める音は入れない。本番があるのは作品24だけ。人物は16・17とは別。

## 0. 用語

```bash
python3 booth/products/check_terms.py
```

`OK works 22-26` と出るまで、下書きに貼らない。

## 1. 作品ごとに、この順

22 → 23 → 24 → 25 → 26。フォルダは `booth/products/22` から `26`。

1. `listing.txt` のタイトル、価格、BOOTHのカテゴリとタグ、DLsiteの年齢指定とジャンルと「AI一部利用」を、それぞれの下書きに貼る。
2. 紹介文は、BOOTHとDLsiteに同じ文を貼る。
3. `cover_imagine.txt` の囲みだけを Imagine に貼る。1枚。横560、縦420。文字は入れない。公式キャラの顔は使わない。できた絵を両方の下書きに置く。
4. `script.txt` の `<<<TTS` と `TTS>>>` のあいだだけを、パート順に COEIROINK に貼る。話者は `product.json` の `voice`。`間:` と `音:` は読ませない。無音と合成の効果音を DAW で足す。`…` を「てんてん」と読んだら、記号を消して無音にする。ひらがなは漢字に戻さない。
5. WAV は part ごと。MP3 は part ごとと、全編の `full.mp3`。フォルダ名は紹介文のとおり。
6. ファイルの実時間を測り、紹介文の「尺:」の1行だけ差し替える。
7. 体験版は紹介文に書いた範囲で切る。手や本番の前まで。
