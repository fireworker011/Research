# fx-candle-stats — 5分足 次足方向の統計ツール

1つの通貨ペアに絞り、**次の5分足が陽線(上昇)になる確率を%で出す**ツール。
確率は「過去60日間で現在と同じ条件だった場面のうち、実際に次足が陽線になった割合」
という**純粋な頻度カウント**であり、機械学習・モデル推論・裁量的な予想は一切含まない。

## 使い方

Node.js 18以上のみ。外部パッケージ・APIキー不要（データはYahoo Financeの公開チャートAPI）。

```bash
cd fx-candle-stats

# 1. いま次の5分足が上がる確率を出す（データ取得込み・約1秒）
node src/predict.js USDJPY
node src/predict.js EURUSD --payout=1.85   # ペイアウト倍率を指定して損益分岐勝率と比較

# 2. 過去60日の条件別統計を一覧する（どの条件に偏りがあるかの調査用）
node src/analyze.js USDJPY
node src/analyze.js USDJPY --cached        # 前回取得したデータを再利用
node src/analyze.js USDJPY --min-n=100     # 標本数の下限を変更

# 3. データ取得のみ（data/ にキャッシュ）
node src/fetch.js USDJPY
```

通貨ペアは `USDJPY` / `EURUSD` / `GBPJPY` など6文字表記ならYahooにある限り何でも指定可。

## 見ている条件（すべて過去データからの頻度）

| 条件 | 内容 |
|---|---|
| 直前1〜3本 | 直近の陽線/陰線パターン別の次足陽線率 |
| 時間帯(JST) / セッション | 東京・欧州・NY・閑散時間帯ごとの偏り |
| 連続数 | 同方向N連続後の反転/継続の頻度 |
| RSI(14) | 売られすぎ/買われすぎゾーン別の頻度 |
| 直前足の実体サイズ | ボラティリティ状態の代理変数 |

各推定値には **標本数n と Wilson 95%信頼区間** を必ず併記する。
区間が50%を跨ぐ条件は「優位性なし」（＝その条件に予測力はない）と表示する。

## 出力の正しい読み方（重要）

- **統合推定が50%近辺で「優位性なし」ばかりの時間帯は、見送りが統計的に正しい判断。**
  このツールは「常にどちらかに賭けるための道具」ではなく「賭けてよい場面かを判別する道具」。
- ペイアウトが1.88倍なら勝率53.2%以上でようやく期待値プラス。5分足の偏りは大きくても
  数%であり、**ほとんどの場面は分岐点に届かない**。ツールはその事実を隠さずそのまま表示する。
- レポートの「地合い超/割れ」列に注意。直近60日が上昇トレンドだと全条件が50%超に見えるが、
  それは地合い（トレンド）であって条件の予測力ではない。トレンドが変われば消える。
  地合いを超えて有意な条件（例: 陰線3連続後の反発）だけが条件固有の偏りといえる。
- 過去頻度は将来の保証ではない。60日窓は市場レジームが変わると陳腐化する。
  定期的に `analyze.js` を回して偏りが維持されているか確認すること。

## 制約

- Yahoo Financeの仕様で5分足は直近60日分まで（約16,000本）。
- 週末・配信停止中は `predict.js` が検知して予測を中止する（exit code 2）。
- 同値(doji)足は方向の標本から除外。週末を跨ぐサンプルも除外済み。

## ファイル構成

```
src/fetch.js    データ取得（Yahoo Finance chart API・キャッシュ管理）
src/stats.js    統計コア（方向判定・条件抽出・頻度テーブル・Wilson区間・加重統合）
src/analyze.js  過去60日の条件別統計レポート
src/predict.js  現在の市況から次足の上昇確率%を出力
data/           取得データのキャッシュ（git管理外）
```
