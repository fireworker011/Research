# いらすとや型ショートと、アフィテーマの再生数

取得日: 2026-10-12

再生数と公開日は、その動画の YouTube 視聴ページ HTML から取った。`views` の `simpleText` と `publishDate` の `simpleText`。タイトル、チャンネル、尺は、同じ日の yt-dlp 検索で、返ってきた id が視聴ページの id と一致したものだけ。一致しなかった検索結果は捨てた。

生データは `research/youtube-views-2026-10-12.json`。

投稿日から 2026-10-12 までの日数で割った数は、このファイルの計算であり、YouTube の伸び率ではない。公開日が古い動画の累計は、今伸びている証拠にはしない。

Transcript API はクレジットが無く、視聴ページのタイトルタグは空だった。尺は視聴ページ HTML からは取れなかった。

## この枝のパイプラインに載せるテーマ

パイプラインは縦9:16、25〜40秒、会社員のいらすとや、5テンプレ（スカッと、ビフォーアフター、あるある、ランキング、問い）。美容の顔出しレビューと、ペットの実写は、この絵では作れない。ペットの再生数を、ペット保険が売れている数字にはしない。

作るのは次の5つ。根拠は上の再生数で、絵が会社員のまま話せるもの。

1. 保険。2026年9月のショートドラマが 3,497,215 回。学資保険の長尺は 2022-12-29 公開で 3,503,946 回。
2. 副業。2025年11月の解説が 988,646 回。住民税でバレる話は長尺にも切り抜きにもある。
3. マッチングアプリのあるある。2024年12月に 279,613 回。
4. クレジットカード。2021年の切り抜きが 1,793,990 回。消費者庁の解説が 42,081 回。直近の急増とは別にして、テーマとしては残す。
5. 給料日と固定費。節約動画が 20万回から53万回。2026年の新規急増ではない。

美容とペット保険は、この12本には入れない。

## 導線

YouTube ヘルプ「視聴者とリンクを共有する」（https://support.google.com/youtube/answer/13748639?hl=ja ）には、ショート動画のコメントと説明に書かれた URL はクリックできない、とある。クリックできるのはチャンネルプロフィールのリンクである。

したがって、アフィリエイト URL は説明にも固定コメントにもコミットしない。人間がプログラムを選んだあと、チャンネルプロフィールに1件置く。説明には #PR と、選んだプログラムの種別だけを書く。動画本編に CTA は入れない。投稿はしない。
