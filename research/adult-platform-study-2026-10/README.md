## 何を「売れている」「売れていない」と呼んだか

販売数が公開されているのは、今回の対象では DLsite だけだった。BOOTH、DiGiket、Ci-en に販売数の表記は無かった。FANZA、Fantia、メロンブックス、とらのあなはサークル行を作っていない。

- DLsite の selling は、週間ランキング（フロアごとに最大2ページ）に載ったサークル。同一サークルは、最も順位が良いジャンル1件。全年齢表記と、未成年を示す語がタイトルかタグにある作品は除外した。
- DLsite の not_selling は、発売カレンダー（2026-09-01、09-08、09-15、09-22、09-29）に載り、product info の販売数が25以下、その作品の発売日が2026-09-28以前、サークル一覧の作品数が3以上、取得した作品の最大販売数が120以下、かつ週間ランキングの取得範囲に無いサークル。カレンダーURLの work_type 指定は無視され、ジャンルは各作品の data-work_type で分けた。
- DiGiket の selling は、男性向同人の月間ジャンルランキング掲載。販売数はページに無かった。
- DiGiket の not_selling は、新着（sort=new）に出て、上記ランキング取得分にサークルが無く、作品一覧が3件以上で、作品ページに「最初のレビューを募集中」とあるもの。販売数は空欄。
- BOOTH の selling は、年齢確認の「はい」のあと、検索の popular 順でカードに R-18 と出たショップ。販売数は非公開。
- BOOTH の not_selling は、同じ検索の new 順で、popular 採用ショップではなく、ショップ1画面の商品リンクが3以上のもの。収集時はカード整数が30以下（空ならその条件は使わない）も見ていた。整数21が新着24件中14件で同一だった。この14件は「21が30以下」で入っている。21が作品ごとの数でなければ、その14件は低側の条件を満たしたとは言えない。残りは整数1が4件、3が2件、2が1件、11が1件、18が1件、整数なしが1件。このレポートではカード整数をスキ数にも販売数にも使わない。BOOTH の not_selling は販売数で切った集団ではない。
- Ci-en の selling は、検索結果から開いたプロフィール（accept=r18）で、ハート横の a.e-follower（リンク先 /supporter）が大きい順。この数を支援者数とは書かない。販売数はプロフィールに無かった。ハート数5以下かつ記事リンク3以上、という低側の条件に合うプロフィールは0件だった。

販売数の大小そのものは、DLsite では選定条件に入っている。あとから「販売数が多いことが売れる共通点」とは書かない。比較に使うのは、選定に使っていない公開値（お気に入り、表示価格、発売間隔、声優欄、説明の見出し語、外部リンク、options の AIP、タイトルの形）である。
