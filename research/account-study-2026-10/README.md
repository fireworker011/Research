この版は、同じ日の続きである。チャンネル検索を足し、伸びている側に「90日以内に10万再生」という絶対値の基準を列で分けた。タイトルがジャンル語に当たらない突出は、件数から外した。

伸びていないは、基準を満たしたチャンネルがペットと婚活で 50 を超えた。ジャンルあたり 50 までを表に入れ、超えた分は載せていない。超えた分はペット 60、婚活 19。選び方は、ジャンル語がタイトルに当たる割合が高い順。

## どこまで見たか

YouTube は、動画検索に加えてチャンネル検索を足した。ユニークなチャンネル ID は 3,306。そのうち、ショートが 8 本以上、タイトルにかながあり、ジャンル語が当たったのは 1,012。公開日は RSS の最新 15 本と、突出候補の視聴ページ。

TikTok は、YouTube の概要欄と公開記事からハンドル 80。動画一覧は yt-dlp、フォロワーはプロフィール JSON（`webapp.user-detail`）で 72 件。検索結果ページはログイン前の殻で、ユーザー一覧が空だった。

Instagram は、プロフィール API が 401（`require_login`）。公開 HTML も、この環境ではログイン前の殻が返り、リールの再生数は取れない。前回の API で取れた本人アカウントと、再生が空の 3 件だけ残した。

取れないものを取るには、ログイン済みのブラウザのクッキー、または各社の公式 API のトークンが要る。YouTube Data API のキーはこの環境に無かった。

## 判定

今日を 2026-10-12 とし、直近 90 日の境界を 2026-07-14、半年の境界を 2026-04-15 とした。

伸びているは、次のどちらか。列 `伸び基準` にどちらだったかを書いた。両方なら両方。

- `5倍かつ1万以上_90日内` … ショートタブ 8 本以上の中央値の 5 倍以上、かつ 1 万以上で、その動画の公開日が 2026-07-14 以降。タイトルがジャンル語に当たる
- `10万再生以上_90日内` … 同じ期間に、タイトルがジャンル語に当たる縦動画が 10 万再生以上

登録者の 90 日増減は、履歴が取れなかったので使っていない。

伸びていないは、開設が 2026-04-15 以前、RSS の最新動画が 2026-07-14 以降、ショート 8 本以上。列 `伸びていない基準` は次の二つ。

- 厳しめ … 中央値 1,500 未満、最大 1 万未満、登録 8,000 未満。203 件のうち 176
- 広め … 中央値 5,000 未満、最大 3 万未満、登録 2 万未満。残り 27。美容 12、お金 13、婚活 1、サクラ 1

TikTok の伸びていないは、取得した動画の最古が 2026-04-15 以前、最新が 90 日以内、8 本以上、中央値 5,000 未満、最大 3 万未満、とした。該当は 0。見つかったアカウントは、期間が半年に満たないか、すでに再生が付いているか、投稿が止まっている。

再生数は概数で、万の位で丸まっているものがある。平均は突出に引っ張られる。中央値を併記した。平均はショートタブの取得分で、90 日では切っていない。

## フック、声、テロップ、BGM

字幕 API はクレジットが無かった。視聴ページの自動字幕も、この環境では空だった。声と BGM は、音を聞いていないので空欄。

フックの列は、視聴していないことが分かるように `未視聴。タイトル:` でタイトルを入れた。サムネは、伸びている全件の OCR を試したが、日本語として読める行が残らなかった。目で見た 5 枚だけ、`サムネや表紙` に書いた。お金のメモと、なりのスキンケアは、サムネの文字がタイトルと同趣旨だった。紫藤乃やこのサムネに大きな文字は無かった。猫の見守りカメラの 1 枚は、箱の中の猫で、文字はタイトルと同一とは確認できなかった。TOWA のサムネは暗く、文字は読めなかった。
