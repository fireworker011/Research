# いらすとや　口を顔の口に合わせる

金メモ3本の共通手順。各本の指示書にも、同じ手順とその本の秒を書いてある。投稿しない。Imagine は使わない。

根拠は、既存の書き出し前確認（`affiliate-shorts/*/QA.md`）と、口の線の置き方（顔の中の口。あごの影や襟には置かない。体ごと上下には動かさない）。

## 使う絵

一人の顔が一つある絵だけ。集合絵、顔が複数ある絵は使わない。過去の確認では、土下座の集合と、上司の三段階は顔が複数あった。怒る顔は、口があごに落ちやすい。落ちていたら直してから書き出す。

硬貨に数字を書かない。紙や画面の中に、読める文字を焼かない。金額は置かない。

## 書き出す前

1. 口の開きは、その顔の口の線にだけ描く。位置は、両目の下にある横長の暗い部分。鼻の下で、両目のあいだ。
2. あご、ほお、額、襟、後頭部、手、顔の外には置かない。
3. 体は上下に動かさない。開閉は口の線だけ。
4. 口を開けるのは、話者が画面にいて、その行の `mouth_s` が 0 より大きいときだけ。
5. ナレーション、黒カード、クレジットは口を閉じたまま。画面に人がいても、話者がナレーターなら口は閉じる。
6. 開いている長さは、その行の `mouth_s`。声の開始で開き、`mouth_s` 秒で閉じる。
7. 冒頭のテロップは 2.000 秒で消す。シーン1の絵と口は 2.370 秒まで。2.000 秒で口を閉じない。

ツールで赤点を出すときは、赤点がこの口の線の上にあること。あごや襟の上なら、その絵は採用しない。

## 書き出したあと

1. 話しているシーン（口を開けるシーン）ごとに、フレームを1枚抜く。
2. 動画の全秒について、1秒ごとに1枚抜く。
3. 抜いた顔を見て、口の塗りが鼻の下、両目のあいだにあることを確認する。
4. ほお、あご、額、顔の外にあれば差し戻す。
5. 閉じておくシーンで口が開いていれば差し戻す。
6. 開いている秒が `mouth_s` と違えば差し戻す。

3本とも、口を開けるのはシーン1（2.370 秒）とシーン4（5.530 秒）だけ。シーン2とシーン5は人がいるが、話者はナレーターなので口は閉じる。

## 声の名前

クレジットの文字列は消さない。概要欄に書くときも同じ文字列。

```
VOICEVOX:四国めたん
VOICEVOX:白上虎太郎
VOICEVOX:玄野武宏
VOICEVOX:剣崎雌雄
```

シーン1の声は玄野武宏。シーン4の声は白上虎太郎。ナレーションは四国めたん。
