# AIアフィ実践ロードマップ（スクール講義①〜④）

出典: スクール会員サイト「実績づくりコンテンツ」コースの AIマネタイズ章、AIアフィ実践ロードマップ①【前編｜準備・アカウント設計】②【中編｜商品選び・動画制作】③【後編｜投稿・収益確認】④【改善編｜比較・改善・継続】。2026-11-05に本文を読み出して整理。

目的: TikTok Shopの商品紹介動画で売上を出すこと。知識をためることではない。常に「今どのSTEPか」「次に売上につながる一手は何か」を出す。

注意: 各レッスン冒頭に「本記事は個別サポートの対象外」とある。画像・図・Loom動画・外部マニュアルの中身は未確認の項目がある。未確認の所は推測で補わない。

## 基本の仕組み

- AIアフィ = AIを動画制作に使い、TikTokで商品を紹介して報酬を得る。
- 3者: アフィリエイター（紹介して売る）、企業（商品と報酬）、お客さん（買う）。
- 報酬は「動画内の商品リンクから購入」で発生する。クリックだけでは入らない。
- TikTokオーガニック（プロフィールの外部リンクへ誘導）より、最初はTikTok Shop（アプリ内で購入まで完結）の方が成約しやすい。動画で購入の熱量を上げて、そのまま買える場所へ誘導する。
- 顔出しなし・自分の声なしで進められる。商品選び・実際の使用・撮影・仕上がり確認は自分でやる。
- 伸びている人を見つける→構成をメモする→自分の動画に落とし込む、が基本。

## STEP1 仕組みと参加条件

TikTok Shopの申し込み条件は4つ。
1. 18歳以上
2. フォロワー1000人
3. コミュニティガイドライン違反なし
4. アクティブなアカウント

## STEP2 アカウント準備

- TikTokアプリとアカウントを用意。既存アカウントがあれば使ってよい。
- 見る専で使っていた古いアカウントは、新規より申請が通りやすい場合がある。

## STEP3 フォロワー1000人

- ここでの投稿・交流は申請条件を満たすための準備。商品紹介のジャンルに合わせる必要はない（コンセプトはSTEP5で決める）。
- 流れの例: 1〜2週間投稿（風景・趣味など）→他クリエイターと交流→ある程度時間を置いてフォロワー購入→1000人超えたら審査→審査中にアカウント設計。
- 増やし方: ペット・趣味の投稿と同ジャンルのアカウントをフォロー／フォロバ100%系と相互（一気にやらず1日何回かに分ける）／同じ趣味でつながる（フォローが少なすぎる・大手すぎる所は避ける）。
- 申請前の確認: Shop開設の招待が来ていないか／投稿を5〜10本入れておく。
- 講義はフォロワー購入を「手っ取り早い」としているが、運用開始直後や急激な増加は不審と判断されて審査に通らないと明記。審査に落ちやすい例: 1年以上放置、AIだけで作った投稿のみ、いきなりフォロワーを増やした。

## STEP4 TikTok Shopに申請

- 必ず「クリエイター用TikTok Shop」で申請。「セラー用」と間違えない。
- フォロワー1000人未満では申請できない。
- 落ちたら次の申請は30日後。承認されたら、申請前の関係ない投稿は削除して統一感を出す。

## STEP5 ジャンル・コンセプト・プロフィール

コンセプト = 誰に、何を、どんな伝え方で紹介するか。商品を売るためのアカウントを作る。

組み立ての順番:
1. ジャンル（自分が興味を持てて、実際に使って紹介できるもの。市場が大きい方がよい）
2. ターゲット（「モテたい20代独身男性」「子持ちの30代ママ」のように絞る。「20代の人」だけはNG）
3. ベネフィット（商品を使った先のうれしい変化まで言葉にする。「肌がきれいになる」→「褒められる・モテる・自信がつく」）
4. キャラ付け（先生目線／友達／挑戦していく初心者／本音で切る、など。無理なく続けられるもの）

- 有益性・共感・ユーモア・憧れのどれかを入れる。感情を動かす。
- 「100日後に〜」「1年後に〜」の挑戦系は、過程がコンテンツになり、途中から来た人がさかのぼってくれる。
- 一文にまとめる例: 「外出の多い人に向けて、持ち歩きに便利なガジェットを、実際に使った感想と一緒に紹介する」。
- 広さ: 「買ったガジェットを紹介します」はふわっとしすぎ、「ハンドクリーム専門」は絞りすぎ。ジャンルは大枠で、切り口で差をつける。
- 参考アカウントを探してTTP（構成・見せ方を学ぶ。全く同じアカウントはダメ）。
- 簡易シート: ジャンル／誰に／何を／どのように／どうなれる。
- プロフィールは4つ: ユーザー名、アカウント名、プロフィール文、アイコン。
  - 名前は「名前/ジャンル/コンセプト」が短く分かるもの。
  - 文の型: 1行目 共感できる要素→2行目 誰に向けてか→3行目 フォローすると得られるもの→4行目 根拠（あれば）。
  - アイコンは講義ではStudio.Stock（AI生成フォトストック、商用可・クレジット不要）を紹介。ペット写真など発信と関係ないものは避ける。

## STEP6 商品リサーチ

まず1商品。ランキング上位でも、自分の発信に合って実際に使って紹介できるかを見る。

探し方は2つ。
1. 商品マーケットプレイス→商品ランキング→ジャンル→売上上位。目安: 販売済み500個以上、肯定的レビュー80%以上。
2. 参考アカウントのショーケース（プロフィールの商品一覧）の上5〜10個を見る。販売数500個以上を目安にサンプル申請。

- 数字は傾向を掴むためのもので「売れる」とは限らない。自分のアカウントとの相性もある。
- 売れる商品は変わるので毎日リサーチする。

## STEP7 無料サンプルと商品を試す

- 申請: 商品マーケットプレイス→商品ランキング→商品を選ぶ→無料サンプルリクエスト。
- 枠: 無料サンプル＋返金可能サンプルで合計5枠。無料は投稿完了で復活。返金可能は復活に約2ヶ月かかるのでなるべく使わない。
- 到着後13日以内に必ず動画を投稿。守らないとペナルティ（サンプルが通りにくくなる等）。投稿の目処が立ってから次を申請する。
- 在庫切れ: 「一時的に利用不可」で動画を作れない。10日続くと投稿不要。復活したら13日以内（在庫切れの日数は数えない）。毎日確認。
- 届いたら3つをメモ: どんな場面で使ったか／便利だと感じた点／気になった点。商品ページの機能と自分の感想は分ける。

## STEP8 参考動画・台本

TTPは「言葉の組み立て方・構成・見せ方」を学んで自分の紹介に取り入れること。他人の映像をそのまま使うことではない。丸パクリ・一部使用も絶対NG（アカウントBANの可能性）。

リサーチ: ジャンルか商品名で検索→フィルターで「いいねの数」順・投稿日「過去6ヶ月」（フィルターはスマホのみ）→上から見る。
見る5点: 冒頭3秒のフック／テロップ／編集テンポ／訴求（誰に、買う理由は何か）／プロフィール誘導。まずフックと訴求。

フックの型: 逆張り（「騙されるな」「金ドブ」「買うな」）、煽り（「全員これ使っとけ」）など。冒頭の映像も見る。
長さの目安は15〜40秒。

台本の順番は「フック→訴求→CTA」。
穴埋め:
- フック「［使う場面の悩み］はありませんか？」
- 訴求「この商品は［確認した機能］。実際に使って、［自分が感じたこと］」
- CTA「詳しくは動画の商品リンクから確認してみてください」

訴求の作り方:
- 価格訴求: 具体的な金額の提示はペナルティのリスクがあるので避ける。出品者が公式に出している割引率と期限をそのまま伝える（例「10/15〜20まで30%OFF」）。現在の条件と合っているか確認。
- スペック訴求: 機能を複数の角度から伝えて「買わない理由」を消す。
- 慣れたら安心系（不安への回答）・憧れ系（買った後の理想）。最初は価格＋スペック。

実例の型:
「めっちゃバズってる〇〇が、今ならセール中！」→スペック①②③→「売り切れる前に左下の黄色いボタンからゲット！」

表現の注意:
- 「治す・改善・効く・効果絶大」はNG（薬機法）。主観の感想はOKだが断定しない（「私は好み」「調子よくなってきた気がする」）。
- 迷ったら商品ページの表現を使う。
- ダイエット系は「痩せる」「体重が落ちる」に厳しいので、講義ではおすすめしていない。

## STEP9 撮影

必要なもの: スマホ、背景シート（必要なら）、スマホ用三脚。グリッド線を出す。

4点:
1. 商品は画面の中央（下のキャプション・右のボタンに被らないように）。
2. 手で持って動きをつける。比較する動きで使用イメージを出す。
3. カメラはゆっくり動かす。
4. 1カット最低3秒。後から削れるが伸ばせない。

台本の場面ごとに「参考動画を見る→自分の商品で撮る→再生して確認→台本に撮影済みとメモ」。最初は手元だけの場面から。撮影中に台本を読む必要はない（後でAI音声）。

## STEP10 CapCutで編集

AI音声・映像・テロップを合わせて1本にする。AI音声はCapCutを使う（③に「CapCut以外の音声ツールは違反になる可能性が高い」とある）。

進め方: まず台本1行目で「AI音声→合う素材→テロップ→再生確認」を試し、最後まで繋げてから見やすさを整える。

講義の手順1の要点:
- 新しいプロジェクト、最初の動画の音量はゼロ。
- フォント「けいふぉんと」白抜き＋黒縁。
- テキスト読み上げ「ホリデーツイスト」×1.7倍速。
- 無駄な間・空白はカット。行ごとに映像を合わせる。
- 読み間違い・イントネーションは直す。
- セリフに合わせて動画をカットし、隙間を埋める。
- BGMは小さめ、セリフは大きめ。
- 書き出しは60fps推奨（手順2）。

完成後は最初から最後まで再生して確認し、保存先から再生できることを確かめる。

## STEP11 投稿前のNG確認と商品リンク

ガイドライン違反はアカウント停止・Shopが続けられなくなるリスクがある。

NG:
1. AIで、ないものをあるように見せる。過度な煽り、明らかに違和感のあるビフォーアフター（ボロボロの肌が一瞬でツヤツヤ等）はやめる。
2. 昔の投稿をそのまま再投稿。他者の投稿も自分の過去投稿もNG。似た投稿にするなら背景・場所・角度を変える。
3. 自分で撮っていない映像。自分の別アカウントでの使い回しも避ける。
4. 止まっているだけの投稿。メインは実物の動き・使用シーン。静止画は補足に留める。

商品が見やすく分かりやすい投稿にする。お店も投稿を見ているので、サンプルを渡したくなる質を保つ。

投稿の流れ: +ボタン→写真アルバム→動画を選ぶ→音楽→次へ→説明文とハッシュタグ→リンク→商品→商品を選ぶ→名前を変更（「セール中！」等）→リンク確認→投稿。
投稿後7日間は1日1回キャプション・サムネイルを編集可。動画そのものは変えられないので投稿前に確認。

## STEP12 反応と収益の確認

収益: クリエイター用TikTok Shop→収益→引き出し可能な残高。引き出しには銀行口座（名義一致）、振込手数料、約3営業日。収益の確定は1か月後なので、待ちながら投稿を続ける。

数字は「再生→商品リンクのクリック→購入」の順で見る。必ず伸びるわけではない。
記録の型:
```
確認した日:
対象の動画・投稿日:
再生:
商品リンクのクリック:
購入:
次に確認したいこと:
```
画面に出ない項目は「未確認」。数字だけで原因を決めつけず、STEP13で参考動画と見比べる。次の動画で試すことを1つ決める。

## STEP13 比較・改善・継続

- 一度に全部直さない。気になった反応から、比べる所を絞る。
- 見直す候補: 冒頭のフック／魅力の伝え方／自分で欲しいと思うか／商品そのもの／規約違反／伸びている動画の見直し。
- 参考動画と自分の動画を1枚ずつシートに書く:
```
【冒頭のフック】
↓
【訴求】①②③
↓
【CTA】
【自由メモ】秒数・ワード・つなぎ方の違い
```
「どの言葉を何秒で」「どの順番で商品の良さを見せているか」を比べる。投稿直後は数字が出ないので3日後などに見比べる。
- 次の投稿で変える点を1つだけ決める。必要ならSTEP6（商品）やSTEP8（台本）に戻って、撮影・編集・投稿・確認を回す。
- 伸びた時・売れた時も「なぜか」を考える。運やまぐれと片付けない。

## おわりにの心構え

- 特別な才能ではなくPDCAの積み重ね。
- 単発で売れても満足せず、5万→10万→30万と改善を続ける。
- 「視聴者に感謝される動画を作り続ける」。稼ぎたい気持ちだけでは収益につながらない。お客さんに得をしてもらえれば、その一部が自分に還元される。

## このスキルを使うときの出し方

1. まず現在地をSTEP1〜13のどこかで特定する。
2. そのSTEPのゴールと、足りないものを1つに絞る。
3. 次の一手を、スマホの隙間時間でできる大きさで出す。
4. 数字は画面で見たものだけ。分からない所は「未確認」。
5. 投稿・申請・支払いなどの実行は本人が行う。こちらは手順と文面の下書きまで。
