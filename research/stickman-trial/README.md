# 火柴人試作（会社員の金メモ・1本）

投稿はしていない。mp4 はリポジトリに入れず、`/opt/cursor/artifacts/kinmemo-paper-stickman.mp4` に置いた。シーン表は同じ場所の `kinmemo-paper-scene-table.md`。

## 選んだ題材

`research/` を「金メモ」「kane」で探すと、台本として使えるのは `research/affi-templates/stories/kinmemo_*.json` の4本だった。このブランチの作業ツリーには無く、履歴の `9daa884b` にある。

そのうち1本、`kinmemo_paper.json`。題は「返すと言ったメモの裏に、硬貨が貼りついたままの話」。金額が無く、画面に数字を置かない条件と合う。

原文のセリフは次の5つ。

1. メモしとけ。後でな。
2. デスクの無地メモに、硬貨を乗せたまま置いた。
3. 紙が財布。
4. 貼りついた側を、一回だけめくって見た。
5. 返すと言った紙の裏に、硬貨が貼りついたままや。

この5つだけをやや速い男性声で読むと、間を1.5秒以内に収めた合計が30秒に届かない。同じJSONの ideas / imagine に書いてある動作だけを、画面と揃えるために5行足した。新しい出来事、金額、商品名は足していない。

- 会社の机で、無地のメモを斜めに持って止まった。
- 硬貨は紙の上に乗ったまま、紙だけが一回傾いた。
- 返すと言ったのに、その紙は机に残った。
- めくった紙の裏に、硬貨が貼りついていた。
- 顔が、そこで止まった。

## 使ったもの

- [kaomei/stickman-video-director](https://github.com/kaomei/stickman-video-director) `5841335`。画風はスタイル1（白地・黒い線・中空の頭・腕2本・脚2本）。比率は指定どおり 9:16。尺は指定の30〜45秒に合わせ、10秒刻みには丸めていない。
- 映像生成（Grok Imagine、Gemini）は使っていない。火柴人はコードで線を描いた。手は紙の左端を掴む。中央に置くと、手の丸が硬貨に見える。
- 声は edge-tts の `ja-JP-KeitaNeural`、速度 `+18%`。声は1本。元の映像音は無い。BGMも重ねていない。
- 字幕はセリフと同じ文。画面の文字に数字は無い。
- 最後の2秒だけ「PR」「広告を含みます」。声なし。URLは置いていない。
