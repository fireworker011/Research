# 通し視聴の表

自動チェックのあと、動画を最初から最後まで見る。シーンごとに 1 行。空欄のまま提出しない。

| 時刻 | セリフと字幕 | 画面に映っているもの | 一致 |
| --- | --- | --- | --- |
| 00:00.000–00:00.000 |  |  | はい / いいえ |

- 一致がいいえの行がある動画は出さない。
- 体の一部が欠けている、手・指・顔が壊れているまたは崩れている場面は、そのシーンの行に書く。その動画は出さない。
- セリフとセリフの間が 1.5 秒を超える区間も、1 行にする。その動画は出さない。
- 元の映像に声やナレーションがあるときは、消してからこちらのナレーションを足す。重ねたままの動画は出さない。

方針の正本は `research/knowledge/video-finish.md`。
