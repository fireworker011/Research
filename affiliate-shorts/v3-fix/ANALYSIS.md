# 二重音声の原因と対象（2026-10-18）

書き出しは止めた。このメモは原因と対象の一覧で、出力の採用ではない。

## 原因

Grok Imagine のソースクリップには、すでに声が入っている。仕上げがそれを残したまま、こちらのナレーションを重ねている。

`shorts-stock/finish.sh`（PR #203、ブランチ `cursor/shorts-finish-queue-77d2`）の `mix_voice` は、クリップ音声を `bed.wav` に抜き、音量 1.0 でナレーションおよび BGM（振幅 0.15）と `amix` している。下げるのでも消すのでもない。PR #230 の注記も「ナレーションを乗せるときは既存を下げる」で、無音化ではなかった。

直すなら、ナレーションを足すときは元音声を混ぜない。ffmpeg では `-an`。音量を下げるのでも、ダッキングするのでもない。完成ファイルの音声はナレーションと BGM だけ。`cursor/mute-imagine-bed-bb29` は、ナレーションがあるときだけ bed を無音に置き換える差分。
