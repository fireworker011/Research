# 動画の必須チェック5つ（ナオミチ決定 2026-10-19 6:37）
ナオミチに確認を頼む前に、全動画で必ず通す。CursorとPCのGrok Buildの指示書には全部これを入れる。
1. 元の声やナレーションが入っている映像に、上から別のナレーションを重ねない。元の音声はミュートしてから、AIナレとBGMだけにする。
2. セリフや字幕は、その瞬間に映っているものと合わせる（例: 猫が床にいるのに「ソファ」と言わない）。
3. 体の一部が欠けた人物や崩れた絵（指・手・顔など）が出るシーンは使わない。
4. セリフとセリフの間は空けすぎない（最大1.5秒）。
5. 機械のチェックだけで済ませない。最初から最後まで通して見て、シーンごとに「秒数／セリフ・字幕／映っているもの／合っているか」の表を付けて提出する。
