# プロフィール

おすすめは 1 です。選んだ番号の YouTube と TikTok を、そのまま貼ってください。

TikTok は80字以内です。字数は Python の `len`（絵文字なし）です。80字は、このセットへの依頼の上限です。TikTok 公式の自己紹介の文字数ページは、この環境では本文が取れませんでした。二次情報として、Shopify の解説は80文字と書いています（https://www.shopify.com/jp/blog/tiktok-bio-ideas）。

どの文にも、登録・フォロー・リンクへの誘導は入れていません。アフィリエイト URL も入れていません。
