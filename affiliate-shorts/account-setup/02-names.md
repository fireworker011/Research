# 名前

5つとも、12本の共通項である「会社員のお金」から取っています。チャンネル名に「いらすとや」は入れていません。収益の数字も入れていません。

YouTube の空きは、2026-10-12 に yt-dlp で `https://www.youtube.com/@ハンドル/about` を見た結果です。HTTP 404 かつ “Requested entity was not found” を、その時点で未使用とみなしています。対照として `@kanememo` は「カネのメモ帳」（登録者数 5）が返ったので、使用中です。作成ボタンを押す直前に、もう一度同じ URL を開いてください。404 のハンドルも、そのあと他の人が取ることはあります。

TikTok の `https://www.tiktok.com/@ユーザー名` は、この環境では公式アカウント `@tiktok` を含む全件が「Couldn't find this account」とキャプチャのページでした。空きの判定には使っていません。TikTok のユーザー名は、作成画面で空いているものをナオミチが選びます。

YouTube のハンドル規則は [YouTube ハンドルについて](https://support.google.com/youtube/answer/11585688?hl=ja)。TikTok のユーザー名規則は [Changing your username](https://support.tiktok.com/en/getting-started/setting-up-your-profile/changing-your-username)。下のラテン文字のハンドルは、どちらにも収まる長さです。

## おすすめ

**1. 会社員の金メモ / YouTube @kaishain_kane / TikTok 表示名 会社員の金メモ / TikTok @kaishain_kane（空きは未確認）**

12本は、クレカ、副業、給料日、マッチングアプリ、保険、ポイント、貯金です。名前が「明細」「給料日」「固定費」だけだと、残りの本が名前からはみ出ます。「ゆる金ショート」は形式の話で、誰の話かが弱いです。「会社員の金メモ」は、誰の金の話かを一語で残します。

公開アカウントでは、BUSON【あるあるちゃんねる】、ほのぼの猫ミーム、最高の2chスカッと話、楽ゆるポイ活 けーチャンネルのように、中身が名前に入っている例がありました（`01-market.md`）。ねむほしのような一語の固有名は、登録者 210,000 の既存チャンネルの型で、新規の説明としては中身が見えません。

「いらすとや」を名前に入れると、素材サイトの名前をチャンネルの識別に使うことになります。この12本の絵は、その素材そのものではありません（`04-visuals.md`）。
