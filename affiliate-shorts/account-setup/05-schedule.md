# 最初の14日

12本を、開始日からの14日で出します。1日1本。6日目と12日目は両方とも出しません。出す日は、YouTube と TikTok の同じ日に、同じ `out.mp4` を出します。時刻は指定しません。`01-market.md` の17時は、ほのぼの猫ミームの概要と RSS の時刻であり、このチャンネルの指定時刻ではありません。

同じテーマが続く並びにはしていません。副業は4日目、8日目、14日目。保険は7日目と13日目。クレカとポイントのあいだには、別のテーマを1本入れています。

説明に、登録、フォロー、プロフィール、リンク、申し込みの文はありません。アフィリエイト URL もありません。

`#PR` は、プロフィールに紹介リンクを置いた状態で出すときの行です。リンクをまだ置かない日に出すときは、説明の先頭の `#PR` と、ハッシュタグの `#PR` だけを外します。フィクションの2行と、VOICEVOX の4行は残します。表記の根拠は `06-links.md`。

各ブロックは、YouTube のタイトルと説明に分けて貼れます。TikTok にタイトル欄は無いので、ブロック全体をキャプションに貼ります。
