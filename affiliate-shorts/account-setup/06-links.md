# リンクの置き場と表記

URL の文字列は、このフォルダに書いていません。プログラムはナオミチが1件選び、選んだあとにプロフィールへ1件置きます。報酬額は、管理画面を見ていないので書きません。

## 置く場所

YouTube でクリックできるのは、チャンネルプロフィールのリンクです。最大14件まで表示できます。ショート動画の説明とコメントに書いた URL はクリックできません。出典は [視聴者とリンクを共有する](https://support.google.com/youtube/answer/13748639?hl=ja)。

置くのは、チャンネルプロフィールのリンク1件です。動画の説明、固定コメント、コミュニティ投稿には URL を書きません。

TikTok でウェブサイトのリンクをプロフィールに置けるのは、フォロワーが1,000人以上のアカウントか、認証済みのビジネスアカウントです。出典は TikTok ヘルプの次のページです。この環境では本文の描画が空で、検索インデックスに残っていたヘルプ本文を読みました。英語、スペイン語、オランダ語の URL で、1,000人とビジネスアカウントの条件は一致していました。

- https://support.tiktok.com/en/using-tiktok/growing-your-audience/switching-to-a-creator-or-business-account
- https://support.tiktok.com/es/getting-started/setting-up-your-profile/linking-another-social-media-account
- https://support.tiktok.com/nl/getting-started/setting-up-your-profile/linking-another-social-media-account

1,000人に届く前、かつ認証済みビジネスアカウントではないあいだは、TikTok のプロフィールに URL を置く欄が使えません。そのあいだ、キャプションにも URL を書きません。YouTube のプロフィールリンクが、押せる場所です。

## YouTube の有料プロモーション

紹介リンクを置いた状態の動画は、YouTube Studio で有料プロモーションとして申告します。出典は [有料プロダクト プレースメント、スポンサーシップ、おすすめ情報を追加する](https://support.google.com/youtube/answer/154235?hl=ja)。

ヘルプの手順は次です。

1. パソコンで YouTube Studio にログインする
2. 左側の「コンテンツ」を選ぶ
3. その動画を開く
4. 「その他のオプション」を選ぶ
5. 「私の動画には、プロダクト プレースメント、スポンサーシップ、おすすめ情報などの有料プロモーションが含まれています」にチェックを入れる
6. 保存する

申告すると、動画の冒頭に開示メッセージが出ます。国内の表示義務は、このチェックとは別に、投稿する側が守ります。同じヘルプがそう書いています。

## TikTok の開示

ブランド、商品、サービスを宣伝する投稿では、コンテンツの開示設定をオンにします。他の事業者のためのブランドコンテンツは “Paid partnership” と表示されます。開示が無い投稿は、削除や制限の対象になり得ます。出典は [Promoting a brand, product, or service](https://support.tiktok.com/en/business-and-creator/creator-and-business-accounts/promoting-a-brand-product-or-service)。

日本語のアプリのメニュー名は、この環境では公式ページの本文が取れなかったので、ここには書きません。投稿画面で、ヘルプと同じ「他者の商品の宣伝」に当たる開示をオンにしてください。

## ステルスマーケティングの告示

2023年10月1日から、広告であることを隠す表示は景品表示法の不当表示です。消費者庁のページは https://www.caa.go.jp/policies/policy/representation/fair_labeling/stealth_marketing です。

告示の名宛人は、表示内容の決定に関与した事業者（広告主）です。依頼を受けて投稿するアフィリエイターは、原則として告示の対象外です。報酬をもらって投稿する場合、その投稿は「事業者の表示」に当たる可能性が高い、と Q19 は書いています。Q&A は https://www.caa.go.jp/policies/policy/representation/fair_labeling/faq/stealth_marketing/ です。

明瞭な語の例は「広告」「宣伝」「プロモーション」「PR」です。「A社から商品の提供を受けて投稿している」のような文も例に入っています（Q11）。このセットの完成文は、先頭に `#PR` を置きます。返信やコメントだけに書く方法は、気付かれにくい、と Q14 が書いています。

動画は、冒頭の一回だけでは途中から見た人に届かないことがあります。画面上に常時「広告」と出すことが望ましい、と Q15 が書いています。PR #192 の12本は、動画の中に CTA が無く、画面上の「広告」も入っていません（`affiliate-shorts/READY.md`）。説明の `#PR` と、YouTube の有料プロモーション、TikTok の開示設定が、今のファイルでできる表記です。画面に常時文字を足すなら、動画を作り直す作業になり、この開設セットの範囲外です。
