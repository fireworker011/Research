このツールについて

チャンネル机（以下「このツール」）は、運営者が自分の端末で動かすスクリプトです。運営者のサーバーへ動画やトークンを送りません。通信先は、運営者が実行したときに限って、Google（YouTube）と TikTok です。

このツールは YouTube API Services を利用します。YouTube の利用規約は https://www.youtube.com/t/terms です。Google のプライバシーポリシーは http://www.google.com/policies/privacy です。

扱う情報

  • OAuth のクライアントID、クライアント秘密、refresh token、access token。運営者の端末のファイル、またはその端末の環境変数に置きます。
  • YouTube のチャンネルID、チャンネル名、ハンドル。TikTok の open_id と表示名。
  • 運営者が指定した動画ファイル、タイトル、説明文、公開範囲、予約時刻。
  • 投稿後にAPIが返す動画ID、公開URL、再生数、高評価数、コメント数、シェア数。YouTube Analytics を有効にしたときは、指定期間の再生数。

アフィリエイトのクリック数と成果数は、このツールでは取得しません。

このツールは広告SDKを使わず、ブラウザへクッキーを置きません。端末から広告識別子を読みません。

使い方

運営者自身のチャンネルへ動画を投稿し、投稿先が意図したアカウントかを確認し、公開統計を手元で見るために使います。販売、第三者提供、広告配信には使いません。

YouTube から受け取ったデータは、YouTube API Services の開発者ポリシーに従います。ポリシーが求める期間を超えて保存せず、取り消しのあとは削除します。公開統計の延長保存は、YouTube の監査で認められた場合だけにします。

預ける相手

動画とメタデータを送る相手は、運営者が投稿を実行したときの Google と TikTok です。運営者以外の開発者のサーバーには送りません。

保持と削除

トークンと投稿記録は運営者の端末にあります。不要になったファイルは運営者が消します。YouTube API のデータは、開発者ポリシーの更新・削除の期限に従います。

Google へのアクセス権の取り消しは https://security.google.com/settings/security/permissions です。取り消し後、このツールは新しい access token を取れなくなります。運営者は、そのアカウントについて端末に残した token と API 由来の記録を消します。

TikTok の許可は、TikTok のアプリ権限の画面から外します。外したあと同じく、端末の token と記録を消します。
