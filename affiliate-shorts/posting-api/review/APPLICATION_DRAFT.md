## YouTube 同意画面

アプリ名: チャンネル机

概要: 運営者が自分のYouTubeチャンネルへ、自分の動画ファイルをアップロードし、公開設定と再生数を確認するツールです。

スコープの理由:

- `https://www.googleapis.com/auth/youtube.upload`  
  運営者自身のチャンネルへ動画をアップロードし、タイトル、説明、公開状態、予約公開時刻を設定するため。削除や他者のチャンネルの管理はしない。より広い `youtube.force-ssl` では足りないのではなく、アップロードにこのスコープが要る。
- `https://www.googleapis.com/auth/youtube.readonly`  
  許可したアカウントが、意図したチャンネルかをアップロード前に確認し、累計の再生数・高評価数・コメント数を読むため。
- `https://www.googleapis.com/auth/yt-analytics.readonly`（付けるときだけ）  
  指定期間の再生数を読むため。累計で足りるなら、このスコープは申請しない。

利用者は運営者のGoogleアカウントだけ。第三者へこのツールを配布しない。

## YouTube 監査フォーム

APIクライアント名: チャンネル机

URL: [公開URL]

プライバシーポリシー: [公開URL]/privacy.html

用途: 運営者が所有するチャンネルへの動画アップロードと、その動画の公開統計の確認。社内ツール。エンドユーザーへ販売・配布しない。

他者のチャンネルへ投稿する機能は無い。認証情報の共有は無い。

デモ用パスワードは空欄。ログイン付きの公開デモが無いので、画面録画を Other Supporting Materials に置く。録画は、同意画面、スコープ、非公開アップロード、YouTube Studio でその動画を開くところ、Googleアカウントのアクセス権のページまで。

Googleアカウントごとにプロジェクトと OAuth クライアントが1つ。監査フォームは、出すならそのAPIクライアントごとに出す。メソッドは `channels.list`、`videos.insert`、`videos.list`。Analytics を有効にしたときだけ YouTube Analytics の `reports.query`。

既定の `videos.insert` 1日100回で足りるあいだは、枠の増加を求めない。増加が必要になったときに同じフォームで本数を書く。

YouTube API Services を使うこと、Google のプライバシーポリシー、取り消しページは、公開するプライバシーポリシーに書いてある。

フォーム: https://support.google.com/youtube/contact/yt_api_form

## TikTok アプリ説明（ユーザーに見える短い文）

自分のTikTokアカウントへ、自分の動画を下書き送信または投稿し、再生数を確認するツールです。

## TikTok 審査の説明

チャンネル机は、運営者 [運営者名] が自分で管理するTikTokアカウントに動画を送るためのツールです。

- Login Kit: 対象アカウントが、本人のアカウントであることを表示名で確認する。
- Content Posting API の Upload（`video.upload`）: 動画を受信箱の下書きとして送り、投稿完了はTikTokアプリ上で本人が行う。
- Content Posting API の Direct Post（`video.publish`）: 審査で認められたあと、本人が明示したときだけ、そのアカウントへ投稿する。審査前は申請しない。
- `video.list`: 投稿済み動画の再生数、高評価数、コメント数、シェア数を読む。

第三者のアカウントへ投稿する機能は無い。投稿前に、送る動画と文面は実行した本人の画面に出る。定期実行では送らない。

このツールは運営者自身のアカウントのためのものです。TikTokの審査ガイドラインには、個人利用のアプリは承認しない、とあります。その前提で申請します。承認前の公開投稿は行いません。承認前に使うのは、受信箱への下書きです。

デモ動画（Sandbox、未承認のうち）:

1. 対象アカウントで許可する画面。
2. 下書きを送り、TikTokアプリの受信箱に届くところ。
3. `video.publish` も申請するなら、Direct Post で非公開の投稿が自分のアカウントに出るところ。
4. 再生数を読む画面。

申請しないスコープは、アプリの設定から外してから出す。
