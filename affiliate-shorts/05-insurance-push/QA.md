# 口の位置

判定: pass

書き出す前に、採用した8人のいらすとやへ口を描いて見た。怒る人の口があごに落ち、土下座の集合絵と上司の三段階は顔が複数あった。集合絵は落とし、口は両目の下の横長の暗い部分に置くように直してから、この mp4 を書いた。

この mp4 では、話しているシーンごとに1枚と、1秒ごとに1枚を抜いて、顔の範囲を見た。口の塗りは、鼻の下、両目のあいだにあり、ほお・あご・額・顔の外には無かった。

尺: 25.54 秒。25〜40秒の範囲: True。
