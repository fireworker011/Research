# H3 エロ動画の現金化 — 判定シート（駐車。本線に足すな）

対象: MiniMax H3 で既に作った実写風の成人動画。  
目的: 「海外アダルトの視聴報酬に繋げる」「モザイクして国内販売する」の可否を切る。  
これは 9/30 確定100万の本線ではない。円は `approved_yen`。無いあいだは 0。  
FANZA アフィ（他人の商品を紹介する）とも別物。既存の駐車は PR [#49](https://github.com/fireworker011/Research/pull/49)。  
H3 制作本体は独立体 `bc-01a07bb1-da1a-7a05-a8a2-2c4a85bcf112` の管轄。このシートは指揮しない。デフォルトへマージするな。

## 結論（先に）

| やりたいこと | 判定 | 理由 |
|---|---|---|
| 海外チューブの**視聴数報酬**に、今の H3 実写風を載せる | **不可** | 視聴報酬は検証済みの人間出演者向け。実写風 AI はディープフェイク扱いで落ちる |
| 海外アダルト**アフィ**（Pornhub / xHamster へ送客） | 動画の活用ではない | 他人のサイトへ人を送る仕事。自作 H3 の再生課金ではない |
| 海外クリップ販売（Clips4Sale 等） | **条件付き・本命にしない** | CG/AI は書類免除の記述あり。ただし実写風・有名人顔は不可。H3 ライセンスは米欧英韓での出力公開を禁じる |
| 国内 FANZA/DLsite に**自作を売る** | **モザイクだけでは足りない** | 隠蔽は必須だが、実写主体・実写風は審査落ちしやすい。AI は月3本上限 |
| 自動モザイクを入れて国内を「可能」にする | **補助まで。绿灯ではない** | 1フレームの漏れで法令と審査が死ぬ。人間の全コマ確認が本体 |

YouTube / TikTok / Instagram / Threads 9アカ / ペット Shorts には出さない。公式が性的コンテンツと成人サイト誘導を禁じている。混ぜた瞬間に既存資産を焼く。

## 混同しやすい3つ

1. **アフィ** = 他人の FANZA/DMM 商品やチューブへ送客して成果報酬。H3 動画は商品ではない。
2. **視聴報酬** = チューブの Model / Creator プログラム。広告を動画の横に出して、検証済み出演者の再生で払う。
3. **自作販売** = サークル登録して、自分のファイルを売る。モザイク・AI申告・実写禁止がここ。

「エロ動画を作ったから海外アフィの再生課金に載せられる」は 1 と 2 を混ぜた読み方で、今の H3 実写風には当てはまらない。

## 海外 — 視聴報酬が死ぬ理由

Pornhub Model Program は、検証済みクリエイターの**人間出演**に広告収益を払う。追加出演者も身分と同意が要る。[Verification / moderation](https://help.pornhub.com/hc/en-us/articles/34927506861843-Verification-Upload-and-Content-Moderation-Process)

非同意・ディープフェイク方針は、実在の識別可能な人物に見える AI 改変を禁じる。[Non-Consensual Content Policy](https://help.pornhub.blog/hc/en-us/articles/4419871787027-Non-Consensual-Content-Policy)

アニメ経路は「自分が描いた／作った」検証動画が要る。H3 の実写風ペニス固定（PR #118）はアニメ枠ではない。

xHamster の Ad Revenue も「全出演者の検証」と権利保有が前提。[Creator](https://xhamster.com/creator)  
AI をラベルする条項はあるが、実写風の人間に見える生成物を視聴報酬の本線にした一次情報は無い。

チューブの **Partnership Affiliate** は、自作動画の再生課金ではなく、サイトへ人を送った成果である。H3 の活用先ではない。

Fansly はフォトリアル／実写風 AI を明示禁止。ラベルしても許可にならない。[Fansly Help 2026-07-08](https://help.fansly.com/en/articles/12315578-ai-generated-content-on-fansly)

## 海外 — クリップ販売が「条件付き」な理由

Clips4Sale は、実在出演者がいない Animated / CG / AI はコンプライアンス書類免除、と書いている。有名人の顔を使えば書類が要る。[公式 Help](https://clips4salecreator.freshdesk.com/en/support/solutions/articles/151000157680-my-content-is-animated-computer-generated-and-never-uses-real-performers-what-do-i-need-to-know-)

それでも本命にしない。

- 実写と区別がつかない顔は、ディープフェイク／ TAKE IT DOWN の対象になり得る。
- 未成年に見える体・顔は、フィクションでも禁止。
- MiniMax H3 Community License は、出力の利用・配布・展示を Applicable Territory 内に限る。除外は EU・英国・韓国・米国。[LICENSE](https://huggingface.co/MiniMaxAI/MiniMax-H3/raw/main/LICENSE) Section V.4。米系ストアへ載せるのはライセンス違反になり得る。
- 公開するなら機械生成であることの明示が AUP 12。他人の顔のなりすましは AUP 13。
- Hailuo 系のホスト利用規約は NSFW 自体を禁じていることがある。作った経路がホストなら、販売以前に利用規約違反。

確認できないこと: ManyVids の公式 AI 条項の現行文面、今の H3 クリップの実在人物類似、ホスト経由か Colab 重みか。管理画面とファイルを見ていない数字は書かない。

## 国内 — モザイクは入口、実写風が本体の壁

国内で不特定多数に出す成人映像は、局部の隠蔽が慣行であり、漏れは刑法とアカウント停止の話になる。Fantia は動画を静止画より強く、全フレーム確認せよと案内している。[Fantia 2026-05](https://spotlight.fantia.jp/news/260515_notification)

FANZA 同人の倫理規定は、最小 4px 平方かつ長辺×1/100 程度、輪郭を含める、と制作者向け解説で繰り返し引用される。最新の正は FANZA 公式の倫理規定であり、ブログの目安を最終根拠にするな。

それと別に、FANZA 同人は **実写を主体とした作品を禁止**している、という制作者向けまとめが複数ある。H3 の実写風・人間ペニス固定は、モザイクしても「実写風」で落ちる可能性が高い。公式本文は年齢認証の向こうにあり、このシートは管理画面を見たとは書かない。

AI 生成のコミック / CG / 動画は、FANZA・DLsite とも **1オーナー月3作品**が現行の運用として報じられている。複数サークルでの回避は禁止。ランキングから AI は除外される。

国内アフィ（DMM Affiliate で他人の FANZA を紹介）は、自作 H3 を売ることではない。混ぜるな。既存判定は #49。

## 自動モザイク

`mosaic_apply.py` は **人が指定した枠**を粗くピクセル化する補助。検出器は入れない。入れた瞬間「機械が隠した＝出せる」になる。

やること:

1. 人が枠 JSON を書く（大きめ。局部の輪郭を含める）
2. スクリプトがマージンを足して粗くかける
3. 1秒ごとのコンタクトシートを出して、人が全コマ見る
4. 漏れ・透過・細すぎを直す。直るまで出品しない

やらないこと:

- 「FANZA 準拠」「合法」とラベルする
- 自動検出で枠を推測する
- モザイク済みを自動アップロードする
- 本線の円に足す

粒度のヒューリスティック（公式の代替ではない）: `max(4px, 長辺/100)`。動画はこれより粗くする。

## 人間の席（やるなら1本だけ）

今日の 100万ゲート（overlay）をこれで置き換えるな。

H3 を使うと決めた日の席はこれだけ:

1. 既存ファイル 1本を選ぶ（量産しない）
2. 実在の顔・未成年に見える体でないことを人が見る
3. `boxes.json` を書いて `mosaic_apply.py` を回す
4. コンタクトシートをコマ送りする。漏れがあれば枠を広げて再実行
5. 国内に出すなら、サークル側の「実写風」「AI 申告」「月3」を公式で読んでから出す。読んでいないあいだは出さない

海外クリップは、H3 ライセンスの領土制限を読めないあいだは出さない。
