# ふたなりレイ — 異形洞窟脱出

追加物語のカット単位プロンプトパック。ゲームエンジンは作らない。Colab ノートも作らない。

正本: ユーザー配布の CURSOR TASK PACK。参照画像4枚は敵デザインの正本。

- 1枚目＋2枚目 = シーン1の敵1（同一個体。正面円口＋エイ／ウナギ全体）
- 3枚目 = シーン3の蛾女（森背景は無視。場所はニクカベ）
- 4枚目 = シーン4のサキュバス（全裸。羽・角・チョーカー・顔の紋・手足の爪はそのまま。股間カバー／生体鎧は外す）

このフォルダ以外を作るな。病棟・かすみ本編・西条・青木・白石・女ゾンビ・誘うルートは開くな、編集するな、importするな。

使い方: `MASTER_LIST.md` の順に各ファイルの **Prompt** 節を 16:9 サイドビューで生成する。モデルは前カットを忘れるので、S01以降は Prompt 内の Character Lock と末尾 Negative を毎回付ける。S00 の Prompt にはレイを入れない。
