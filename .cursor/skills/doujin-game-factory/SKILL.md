# 同人成人ゲーム工場（PC / ウディタ）

量産の前にこれを使う。実行本体は `doujin-game-factory/`。作業主体は Windows PC。

## 先に疑うこと

- 「仕組みが無い」は、売れない原因ではない。出荷ゼロなら需要も品質も未測定。
- PCが使えるならエンジンはウディタでよい。それでも `.mps` を Linux から公式経路で書くことはできない。貼り付けと `-gamedata` は PC の Editor.exe。
- 「週1」は DLsite の **AI生成作品 月3申請** と衝突する。PCがあっても枠は増えない。FANZA のゲーム行は公式表で月2に見えるがセル結合のため未確定。
- 「RPG」は工数最大。初作は自動実行の短い成人ADV。戦闘は後。
- 累計販売中央値を月次売上に使うな。
- Xの人気と販売事実を混同するな。X MCP が未認証なら「調べていない」と書け。

## 変えられない制約

- 成人向けは登場人物 18+ かつ見た目成人。学生・ロリショタ語は本パイプラインで拒否。
- AI利用は申告。無申告はアカウントリスク。
- 秘密情報をリポジトリに置かない。
- Editor.exe は配布物に入れない。

## 変更できる前提

- 戦闘の有無
- 本数ペース（週1を捨てて月1〜3）
- 月200万を初月KPIにしない
- HTMLプレビューを検図に使うかどうか

## ゲート（数字を発明するな）

1. IR が `node src/cli.js generate` を通る
2. `event-code.txt` を Editor に貼り F9 で両分岐が通る
3. サークル登録とAI申告文が用意できる
4. 初作30日の実販売本数が 30 未満 → 量産しない
5. プラットフォーム月次キャップを超える計画は棄却

月200万を語るとき（取り分は推定、公式卸価格表が正）:

- 売価2200円・取り分0.6なら 1本あたり1320円。200万円には約1516本/月。
- 月3本なら1作あたり約505本。未出荷の人間がこれを計画値にするな。

## コマンド

```bat
cd doujin-game-factory
node --test
node src/cli.js generate --seed data/seeds/sample-adult-adv.json
node src/cli.js woditor --in output/ir/game.json
node src/cli.js gate --price 2200 --copies 0 --works 0
set WOLF_DIR=C:\path\to\WOLF_RPG_Editor
scripts\windows\01_check.bat
```

貼り付け手順は `scripts/windows/02_paste_and_test.md`。

## 人間が承認すること

- F9 で最後まで遊べること
- 販売ページのAI申告区分
- 画像・声・実在人物に似せないかの最終目視
- Editor.exe でのパッケージ化
- 「需要がある」という判断（本数が無いのに承認するな）

## やってはいけないこと

- 検品をスキップしてLLM本文を直販
- 未成年に見えるキャラの「グレー」
- 複数サークルで月次上限回避
- HTMLプレビューを完成RPGだと報告する
- 壊れたイベントコードを直さずに量産する
- 動画キャッシュループやアフィ投稿ワークフローにこの工場を繋ぐ
