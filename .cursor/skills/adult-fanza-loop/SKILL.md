# アダアフィキャッシュループ

このリポジトリのアダ案件で、エージェントや量産を提案する前に使う。  
定期実行の本体は `affiliate-engine/src/adult-judge.js`。  
`video-judge.js` と混ぜるな。`insight.js` を使うな。Claudeでジャンル転換するな。

## 先に疑うこと

- 「仕組みが無い」は、ペット動画が無いという意味ではない。`@pet_story_select` は別事業として動かす。
- 指定媒体が YouTube / TikTok / Instagram でも、アダをそこに出すな。公式に性的コンテンツと成人サイト誘導を禁じている。
- やり方を変えてよい条件は「禁止媒体を捨てる」ときに限る。禁止媒体のまま自動化するな。
- Grok / Cursor を投稿の実行者にするな。Xの投稿・DMM登録・成果確認は人間（スマホ）がやる。
- 最大70%や先月ランキング数百万円は上限と上位値である。新規の予測に使うな。
- 確認できない報酬・EPC・クッキー期間は、DMM管理画面を見たと書かない限り仮定する。
- X bot / Playwright での投稿は凍結事例がある。採用するな。

## 切り分け

1. 禁止媒体に出している → 止める。判定は `WRONG_CHANNEL`。
2. 記録が無い → CSVを書け。改善案を出すな。
3. 表示はあるがクリックが少ない → 導線。媒体を足すな。
4. クリックはあるが成果0（累計50超） → 着地を1つだけ変える。同じ紹介を増やすな。
5. 成果が出ている → その型だけ複製する。YouTubeは開くな。

クリックが十分かの目安:

- 週15クリックが最低の次ゲート。
- 週50クリックが3週続いて、初めて月100万を語ってよい。
- 最初の現金ゲートは公式の支払下限 ¥5,000。

## 月100万を語るとき

基準仮定（報酬¥1,050、CVR1%、承認80%）でも、月100万は約11.9万クリックが要る。  
`node src/adult-funnel.js` を回せ。公式値と仮定が混ざった文章を書くな。

## やってはいけないこと

- ペットチャンネルのジャンル転換
- YouTube / TikTok / Instagram / Threads へアダを出す
- 3媒体を同時に立ち上げる
- 実投稿を自動化する
- アフィリンクをコミットする
- 体験談の捏造、#PRなしのリンク誘導
- 他人の画像・動画の転載
- 調べられないアカウントを成功事例として使う

## 定期実行（このエージェントが起きたとき）

1. `cd affiliate-engine && node src/video-judge.js --self-test && node src/video-judge.js` を先に回す。ペットを止めない。
2. `node src/adult-judge.js --self-test && node src/adult-judge.js` を回す。
3. `output/adult/TODAY.md` を読む。数字が無い行を埋めない。
4. 投稿しない。媒体を足さない。ペットの台本を触らない。
5. 記録不足なら、人間に CSV 追記とDMM登録だけ頼む。
6. コードを変えるのは、判定ロジックがゲートと食い違っているときだけ。

GitHub Actions `affiliate_engine_adult_judge.yml` が毎日同じ判定を書く。cronが動くのはデフォルトブランチへマージされたあと。

## 人間が承認すること

- DMMアフィリエイトの登録とサイト審査
- 新しい案件の採用
- 「使った」「比較した」など体験を含む文言
- 実投稿
- landing の追加
- 量産開始
- 月100万の話を始めること（ゲート未達なら拒否）
