# 動画キャッシュループ

このリポジトリの動画案件で、エージェントや量産を提案する前に使う。

## 先に疑うこと

- 「仕組みが無い」は、制作が無いという意味ではない。`@pet_story_select` は2ヶ月で32本出せている。
- 「成果が出ない」は、案件が死んでいるという意味ではない。クリックが月数十件なら、成果0は普通に起きる。
- Grok bot を自動化のメイン実行者にしない。Shorts の投稿・固定コメント・成果確認は人間（スマホ）がやる。
- Cursor は実験の記録とコード変更に使う。プロジェクト管理の組織図は作らない。
- テロップはみ出し・BGM・不自然さの検査は、クリックが週15件を超えてから入れる。

## 切り分け

1. 再生が無い → 型と冒頭3秒。量産しない。
2. 再生はあるがクリックが少ない → 導線（動画内CTA、固定コメント）。エージェントを増やさない。
3. クリックは十分あるが成果0 → 案件と着地。同じ動画を増やさない。
4. 成果は出ている → その型だけ複製する。新しい媒体を同時に増やさない。

クリックが十分かの目安（このチャンネルの現況）:

- 2ヶ月で 11-50 クリックは不足。成果判定不能。
- 週15クリックが最低の次ゲート。
- 週50クリックで初めて案件の生死を語ってよい。

## 月100万を語るとき

Furbo 系は A8 公開情報で購入10%。本体はセール時で数千円、通常は数万円、さらにサブスクがある。

仮に報酬 3,000円/件、CVR 2% でも、月100万には約 16,650 クリック/月が要る。  
現在は月 5-25 クリック。ギャップは量産やbot分割では埋まらない。

確認できない報酬・EPC・確定率は、A8管理画面を見たと書かない限り推測するな。

## やってはいけないこと

- YouTube / TikTok / Instagram を同時に立ち上げる
- 癒し動画の再生数を「売れている」と読む
- 一番再生された動画に商品CTAが無い状態で、同じ型を量産する
- アフィリンクをコミットする
- 実投稿を自動化する
- 体験談の捏造、#PR なしのリンク誘導

## 人間が承認すること

- 新しい案件の採用
- 「比較して選んだ」など体験を含む文言
- 実投稿
- 媒体追加
- 量産開始
