# 動画キャッシュループ

このリポジトリの動画案件で、エージェントや量産を提案する前に使う。
定期実行の本体は `affiliate-engine/src/video-judge.js`。Claudeやinsight.jsで動画を改善するな。

## 先に疑うこと

- 「仕組みが無い」は、制作が無いという意味ではない。`@pet_story_select` は2ヶ月で32本出せている。
- 「成果が出ない」は、案件が死んでいるという意味ではない。クリックが月数十件なら、成果0は普通に起きる。
- Grok bot を自動化のメイン実行者にしない。Shorts の投稿・固定コメント・成果確認は人間（スマホ）がやる。
- Cursor は実験の記録とコード変更に使う。プロジェクト管理の組織図は作らない。
- テロップはみ出し・BGM・不自然さの検査は、クリックが週15件を超えてから入れる。
- Shorts の固定コメントや説明欄にアフィURLを置くな。公式ヘルプ上、Shorts ではクリック不可。[YouTube Help](https://support.google.com/youtube/answer/13748639)
- 「固定コメントで再生が落ちる」は未確認の噂。根拠にして案件や量産を止めるな。根拠にしてリンクを量産するな。押せる場所はプロフィール。
- 他ジャンルの成功例は参考であり、転換ではない。動画・サムネ・台本はコピーするな。コピーしてよいのは「押せる場所に1回誘導する」ことだけ。
- 婚活・美容・健康・転職の長尺専門チャンネルは、年単位の個人/会社ブランドか自社高単価商品が多い。107登録・2ヶ月のペットShortsとは別事業。同時に始めない。駐車場は `affiliate-engine/docs/video-cash-loop.md`。

## 切り分け

1. 再生が無い → 型と冒頭3秒。量産しない。
2. 再生はあるがクリックが少ない → 導線（動画内でプロフィールへ）。Shorts固定コメントにURLを置くな。エージェントを増やさない。
3. クリックは十分あるが成果0 → 案件と着地。同じ動画を増やさない。
4. 成果は出ている → その型だけ複製する。新しい媒体を同時に増やさない。

クリックが十分かの目安（このチャンネルの現況）:

- 2ヶ月で 11-50 クリックは不足。成果判定不能。
- 週15クリックが最低の次ゲート。
- 週50クリックで初めて案件の生死を語ってよい。

## 月100万を語るとき

Furbo 系は A8 公開情報で購入10%。本体はセール時で数千円、通常は数万円、さらにサブスクがある。

仮に報酬 3,000円/件、CVR 2% でも、月100万には約 16,650 クリック/月が要る。  
現在は月 5-25 クリック。ギャップは量産やbot分割では埋まらない。

確認できない報酬・EPC・確定率は、A8管理画面を見たと書かない限り推測するな。

## やってはいけないこと

- YouTube / TikTok / Instagram を同時に立ち上げる
- アダルトをこのチャンネルに混ぜる。アダは `adult-fanza-loop` の別トラック
- 癒し動画の再生数を「売れている」と読む
- 一番再生された動画に商品CTAが無い状態で、同じ型を量産する
- アフィリンクをコミットする
- 実投稿を自動化する
- 体験談の捏造、#PR なしのリンク誘導
- 「参考」のチャンネルを見てジャンル転換する
- 調べられないチャンネルを成功事例として使う

## 定期実行（このエージェントが起きたとき）

1. `cd affiliate-engine && node src/video-judge.js --self-test && node src/video-judge.js` を回す
2. `output/video/TODAY.md` を読む。数字が無い行を埋めない
3. 投稿しない。媒体を足さない。ジャンルを変えない
4. 記録不足なら、人間に CSV 追記だけ頼む
5. 実験中なら次の3本を再掲するだけ。新しい台本を創るな
6. コードを変えるのは、判定ロジックがゲートと食い違っているときだけ

GitHub Actions `affiliate_engine_video_judge.yml` が毎日同じ判定を書く。Cursor側で定期実行するなら、この手順以外を足すな。両方回っても判定は上書きするだけ。

## 人間が承認すること

- 新しい案件の採用
- 「比較して選んだ」など体験を含む文言
- 実投稿
- 媒体追加
- 量産開始
