## 先に疑うこと

- 「海外アフィ」は他人サイトへの送客であり、自作の視聴課金ではない。
- チューブの視聴報酬は検証済みの人間出演者向け。H3 実写風は載らない。
- モザイク自動化は枠を粗くする補助。法令・FANZA 審査の代替ではない。
- ペット Shorts / Threads 9アカ / YouTube / TikTok / Instagram に出さない。

## 切り分け

1. 視聴数で海外チューブから払ってほしい → 不可。止める。
2. FANZA アフィで他人商品を紹介したい → #49 の許可媒体判定。H3 ファイルは使わない。
3. 自作を売りたい → 人が枠を書いて `mosaic_apply.py` → コンタクトシート全コマ。実写風で落ちる前提。
4. 自動検出を足したい → 拒否。漏れが「機械が隠した」になる。
