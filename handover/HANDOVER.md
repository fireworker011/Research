## 3. 婚活 — コンセプト設計 / 運用設計 / 動画設計

### コンセプト設計

- **ポジション: 「アプリ疲れ → 結婚相談所」の橋渡し。** マッチングアプリ訴求のアカウントは飽和。「アプリで消耗した30代が相談所を検討する」文脈は競合が薄い。
- 単価構造: 結婚相談所は**資料請求のみで数千円**の成果地点があり、新規入会だと相場4万円級の高単価ジャンル。提携済み: ウェルスマ（リーズナブル訴求が「アプリ疲れ」文脈と好相性）、パートナーエージェント。
- 発信者ペルソナ: 婚活情報を整理して発信する30代女性。共感ファースト、押し付けない、絵文字は控えめ。
- 禁止: 出会い系的・性的訴求（Meta ポリシー違反で BAN 最速）。真剣婚活の文脈のみ。

### 運用設計（実測で勝っている型）

9アカ中トップクラスの成績（平均225views/投稿）。実測の勝ちパターン（`output/top_posts.json` 上位）はほぼこの構造:

1. **観察による結論を先に断言**（「仮交際に進みやすい人には共通する行動が3つある」）
2. **箇条書き3点**（具体的・数字入り: 「LINEの返信は24時間以内」）
3. **逆説**（「停滞する人ほど条件確認に時間を使う」）
4. **保存喚起 + 質問締め**（「保存して見返して。あなたは意識してる？」）

- 比率は価値提供:リンク ≒ 4:1。リンク投稿は「資料請求は無料なので比較だけでも」の低ハードル訴求 + `#PR`。
- その他の勝ち型: 「カフェで耳にした会話」型（情景導入→よくあるパターン→兆候リスト→問いかけ）、「距離感チェック3つ」型。
- 会話が起きる投稿が最優先評価。**質問で締めない投稿は作らない。**

### 動画設計

- **今はやらない（判断済み）。** 婚活の長尺専門チャンネル（来島美幸 等）は年単位の個人ブランド+自社商品が前提で、今の体制とは別事業。ペットの14日実験が終わるまで新媒体・新ジャンルの動画は着手しない。
- 将来やる場合の入口は `video-semi-auto.js`（Threads の反応上位投稿を Shorts 化する半自動ツール）のみ。

## 4. ペット — コンセプト設計 / 運用設計 / 動画設計

### コンセプト設計

- Threads（未稼働）: 「ふく｜いぬと暮らしの手帖」。かわいい写真系が飽和 → **健康・お金・しつけの実用情報**で差別化。「迷ったら病院へ」の安全側に倒す。獣医療の診断的断定をしない。
- YouTube（稼働中）: `@pet_story_select` は**癒し・あるある型**。最多再生（5,219）は商品もリンクもない猫のおもちゃ話 = 伸びているのは商品動画ではない、を忘れない。
- 案件: Furbo ドッグカメラ（A8承認済み・購入10%。本体はセール時6,480円/通常29,980円+月額サブスク）。ペット保険・プレミアムフードが控え。

### 動画設計（最重要ナレッジ）

- **Shorts の説明欄・コメント欄の URL はクリック不可**（YouTube 公式仕様）。押せる外部リンクは**チャンネルプロフィールのみ**。だから固定コメントにアフィURLを置く実験は成立しない。
- CTA は動画の最後に1回だけ、口頭またはテロップで **「詳しくはプロフィールのリンク（PR）」**。URLは画面に置かない。説明文には `#PR` を付ける。
- 型: 冒頭で「あるある」提示 → 箇条書き2〜3点 → 「あなたの子はどっち？」の質問締め（コメント誘発）。次の3本の完成台本は `affiliate-engine/docs/youtube-next-3.md`。
- 型・BGM・投稿ペースは実験中に変えない。既存32本は触らない。

### 運用設計 — 14日実験（2026-08-22 開始・進行中）

見るのは「今のチャンネルでクリックを増やせるか」だけ。変更は上記CTA追加の1つのみ。

- 毎日5分（人間・スマホ）: A8 と YouTube Studio の数字を `data/video_cash_log.csv` に追記。
- 判定は `video-judge.js`（毎日 06:37 JST、GitHub Actions で**継続稼働中**）が CSV だけを見て行う。結果は `output/video/TODAY.md` と GitHub Issue。数字がない日は「記録不足」とだけ出る。
- **判定ゲート**: 週15クリック → 導線は生きている（同じ型を週3本まで）／ 週15未満 → 量産禁止・案件を安い/申込型に変えるか長尺1本で比較 ／ 成果1件以上 → その動画の型だけ複製 ／ 累計50クリック超で成果0 → 案件か着地を疑う。
- **月100万の話は週50クリックが3週続くまでしない。**
- 切り分けの順番: ①再生がない→型と冒頭3秒 ②再生はあるがクリックが少ない→導線 ③クリックはあるが成果0→案件と着地 ④成果あり→その型だけ複製。**「仕組みがない」「案件が死んでる」と先に言わない。**
- 役割: Grok Bot を自動化のメイン実行者にしない。実投稿・成果確認は人間（スマホ）。Cursor は記録とコード変更のみ。TikTok / Instagram / 新エージェント / 動画量産 / 案件総入れ替えは**同時にやらない**。

## 5. 美容 — コンセプト設計 / 運用設計 / 動画設計

### コンセプト設計

- Threads: 「みほ｜がんばらないケア」。成分解説系は専門アカウントが強い → **「ズボラ×時短」「疲れた夜に最低限これだけ」**の共感型。「10工程より2工程の今のほうが調子がいい」がアカウントの原点ストーリー。
- 発信者ペルソナ: 仕事と家のことで手一杯な30代後半女性。ゆるい、やさしい、頑張らせない。
- 案件: オルビスユー ドット（A8 `s00000008657021`・新規購入1,800円・エイジングケア）。ターゲット（35〜50歳）とアカウント文脈が一致。
- 勝ち型（実測 728views）: 「基本と言われる◯◯、実は△△派もいるらしい」→ 二択の質問締め（「変える派？変えない派？」）。

### 動画設計（affi-shorts-agent — 別リポジトリ `fireworker011/affi-shorts-agent`）

- 1体目 = オルビスユー ドット。YouTube Shorts、1日1本、20秒、9:16。TikTok / Instagram は後回し。
- **役割分担**: Grok Bot = 投稿トリガー・数値の読み取り・改善指示を**1つだけ**出す ／ Grok Build + Cursor = リサーチ・台本・動画生成・編集 ／ Cursor = 構成の一貫性・薬機法/PR表記・GitHub 管理。
- パイプライン順序（固定）: claims-allowlist から台本生成 → 15〜30秒レンダー → PRテロップ全編チェック → Shorts 投稿 → A8 クリック記録 → Grok Bot が改善を1つ出す。**計測できない投稿は改善対象にしない。**
- 完成条件（1体目）: 毎日1本が自動生成され Shorts に上がり A8 クリックが計測されること。**売上は完成条件に入れない。50体化・月200万の話は1体が回るまでしない。**
- 人間が承認する境界: 薬機法・景表法の最終文面、A8リンクの初回発行、各SNSの初回ログイン、公開リポジトリ化。

### 薬機法・表現ルール（美容は特に厳格）

- 使ってよい: 「エイジングケア」（化粧品の一般表現）、公式の商品名、テクスチャ・使い方・香り・続けやすさの**主観**。
- 使ってはいけない: シワが消える・若返る・治る等の医療効果、劇的 Before/After、根拠なき No.1、他社誹謗、未確認のキャンペーン金額。
- 必須: 冒頭から `#PR`/`広告` を画面内に常時表示、概要欄冒頭に「本動画はアフィリエイト広告を含みます」、YouTube の「有料プロモーションを含みます」フラグ ON。
- Threads 側も同じ: 効果断定は `compliance.js` が投稿前にブロック。「使用感」「個人の感想」の枠で書き、「感じ方には個人差があります」を添える。

## 7. 全ジャンル共通の運用原則（violate したら事業が死ぬ順）

1. **ステマ規制（景表法）**: リンク付き投稿・動画に `#PR` 必須。システムが自動付与するが、手動投稿でも外さない。
2. **薬機法**: 効果効能の断定（痩せる・消える・治る）禁止。美容・筋トレ・睡眠で特に注意。
3. **体験談の捏造禁止**: 使っていない商品の体験を装わない。「調べた」「比較した」「選択肢を整理した」の形にする。
4. **いいね・フォロー・DM返信の自動化禁止**: 公式APIが存在せず、Meta が最も積極的に凍結する行為。返信は AI が下書き・送信は人間。
5. **オマージュは「型」まで**: 他アカウントから学ぶのは構造（フック→本文→質問締め）・時間帯・比率のみ。文面コピー・プロフィール模倣は盗用でありリーチも落ちる。few-shot に使うのは自アカの実測勝ちパターン（`output/top_posts.json`）だけ。
6. **数字を発明しない**: 確認できない報酬・EPC・承認率は「A8管理画面を見た」と書けない限り推測しない。
7. **1アカウント250投稿/日が公式上限**（現運用は最大10/日で大幅マージン）。急な投稿数増はスパム判定要因。

## 8. Grok Bot / Cursor への具体的な指示

- **Grok Bot**: 数値の読み取りと「次の改善を1つ」の提案まで。実投稿・スケジュール再開・案件変更を自分で実行しない。数字がなければ「記録不足」と言い、人間に CSV 追記を頼む。
- **Cursor**: コード変更と実験記録のみ。2026-08-27 以降、ナオミチ直下の 24h スプリント（`docs/sprint-24h.md`）では毎時スコアボードを更新する。変更時は最低限 `node --check` → `strategy-engine.js --from-file` で破棄警告なし → `threads-poster.js --dry-run` を通す。スケジュール決定論（日付から計算）と重複ガード（直近7日ハッシュ照合）を壊さない。コミット前に `git pull --rebase`。
- **両者共通**: 停止中の Threads 自動更新を、リンク Secret 無しで再開しない。新媒体・量産・ジャンル転換・50体化を提案する前に、判定ゲート（週15/週50クリック）を確認する。期限 ¥1,000,000 の円の正本は `docs/grok-bots/HQ_100MAN.md` と `sprint-1m.js`。
