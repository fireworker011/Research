# アダアフィ — スマホ作業（人間だけ）

エージェントは投稿しない。リンクはチャットに貼るな。GitHubにコミットするな。

## 今日やること（未着手ならこの順）

1. 新規のXアカウントを1つ作る。ペット・Threads・YouTubeと同じ名前にするな。プロフィールに18+と「広告を含む」を書け。
2. [DMMアフィリエイト](https://affiliate.dmm.com/) にそのXをサイトとして申請する。登録料は公式に無料。
3. 承認前にFANZAのスクショや他人の画像を載せるな。不承認の定番は著作権と中身が空なこと。
4. 承認後、公式のアフィリエイトツールバーでリンクを作る。
5. 投稿は1日1本。必ず `PR` または `広告` を本文に入れる。体験したかのように書くな。
6. GitHubアプリで `affiliate-engine/data/adult_cash_log.csv` に1行足す。

CSVの列:

```
date,channel,posts,impressions,clicks,conversions,reward_jpy,note
2026-08-22,x,1,120,2,0,0,first
```

- `channel` は `x` か `landing` だけ。`youtube` / `tiktok` / `instagram` / `threads` / `pet` を書くと判定が止める。
- 数字はXの表示回数と、DMM管理画面のクリック・成果・報酬だけ。無い項目は0。推測で埋めるな。
- リンク・ID・トークンは `note` に書くな。

## 毎日5分

1. Xで1本出す（実験中は週7本まで）
2. DMM管理画面のクリックと成果を見る
3. CSVに1行
4. Issue「アダアフィキャッシュループ — 今日の判定」か `output/adult/TODAY.md` を読む
5. 判定が `WRONG_CHANNEL` なら投稿を止めろ

## 出す文の骨格（本文の性的描写は書くな）

```
[作品名またはジャンル] の紹介です。
公式ページはプロフィールまたはこの投稿のリンク。
#PR
```

比較した、使った、よかった、は事実として確認できるまで禁止。
