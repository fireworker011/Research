# 転職 Threads プロフィール（チケット・参謀・URL を Git に書くな）

指令塔がチケットで `Threadsあり` と返し、Secret に `転職_チケット` を入れたあとの仕事。
`YouTubeあり` / `項目なし` / `媒体なし` では使わない。cron は戻さない。投稿しない。
neo 用は `PROFILE.md`。混ぜるな。neo を既に置いたならチケットで上書きするな（次はバナー）。

A8 の一般FAQ: スレッド**本文**の広告リンクは控える。**プロフィールのリンク欄**は可。
プログラム詳細の掲載媒体に Threads が書いていなければ、プロフィールにも置くな。

## 置く場所

開設済みの **転職** Threads（`accounts.json` の key `tenshoku`。表示名候補は「けい｜しずかな転職準備」）。
ハンドルはファイルに無い。チャットにハンドルも URL も書くな。

置く欄: プロフィール編集の **リンクを追加する欄** 1つ。紹介文（自己紹介）には書くな。値は Secret に入れた `転職_チケット` と同じ広告リンク。そのリンクは、副サイト登録した転職 Threads を「掲載サイト」に選んで発行したもの。

この手順は GitHub Actions を通らない。プロフィール欄は Secret のあと人間が置く。本番 `loadLinks()` は PR #77 入済み（post/insight 用。プロフィールは通らない）。重ね待ちで置くな。cron は戻すな。自動投稿の再開とは別件（`CHECKOUT.md`）。

## やらないこと

- スレッド本文・返信・固定投稿に URL
- 紹介文（自己紹介）に URL を書く（リンク追加の欄ではない）
- neo が入っているリンク欄をチケットで上書きする
- いいね / フォロー / DM
- post / insight の schedule を戻す
- 転職 YouTube を始める
- 教育・副業・美容・ペットのプロフィールにチケットを入れる
- 開設していないアカウントを「ある」ことにする
- アフィURL を Git / チャット / Issue / dump に書く
- カタログ円を conversions に足す
