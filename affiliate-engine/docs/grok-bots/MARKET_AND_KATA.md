# 市場リサーチと動画の型（全エージェント共通）

確認日: 2026-08-23。数字は種別を分けて書く。推測で埋めない。  
機械可読の型: `data/video_kata.json`。エージェント本文へは `node src/genre-video-gen.js --write-agents` で流し込む。

コピーしてよいのは **押せる場所へ1回誘導する構造** だけ。動画・台本・サムネは複製しない。調べられないアカウントは成功例にしない。

## 市場で確認できたこと（媒体）

| 事実 | 種別 | 出典 |
|---|---|---|
| Shorts のコメント・説明欄の URL はクリック不可 | 公式 | [YouTube Help: Sharing links](https://support.google.com/youtube/answer/13748639)（2023-08-31 以降。2026-08 時点で撤回は確認できない） |
| 押せる外部導線はチャンネルプロフィール（と条件付きの関連動画／Shopping） | 公式＋自チャンネル | 同上。`@pet_story_select` は概要に A8 あり（2026-08-22 公開事実） |
| 冒頭でスワイプが決まる、という整理は運用記事に多い | 二次情報 | 冒頭3秒フックの解説が複数。視聴維持率の「70%で合格」等は自チャンネル未検証なので使わない |
| 日本の情報系 Shorts は「問い／切り分け／見る点」が先頭に来やすい | 二次・観察 | 便益語・対象者名指しが強い、という整理。自チャンネルの最多再生は商品なしの猫話 |

使わない二次情報:

- 固定コメントに URL を置けという日本語記事（公式と矛盾。実験にならない）
- 名前も再生も今日開けない美容・婚活チャンネルを「10倍アカウント」として使うこと
- 長尺専門（来島美幸、ぷらりーch、末永、サラタメ）の登録数をペット Shorts の目標に足すこと。参考は「押せる場所へ誘導している」構造だけ

## 自チャンネル（ペット Shorts）で確認できたこと

2026-08-22 公開事実。`docs/video-cash-loop.md` と同じ。

| 項目 | 値 |
|---|---|
| 登録 | 107 |
| 本数 | 32 Shorts / 約2ヶ月 |
| 1本の再生 | 660〜5,219 |
| 最多再生 | 猫のおもちゃ話。商品・PR・リンクなし |
| 2ヶ月クリック | 11-50（本人申告） |
| リポジトリのペットリンク | 空 |

市場から自社に移す型（転換ではない）:

1. 冒頭は挨拶しない。映像か問い
2. 本編は観察・あるある。商品デモにしない（最多再生が商品なしのため）
3. 末尾だけプロフィールへ1回。`#PR`

実験中はこの3点以外の型をペットに足さない。

## 型6つ（全エージェントがこれ以外を新造しない）

詳細秒は `data/video_kata.json`。新レシピを足すときもこの id どれかを付ける。

| id | 名前 | 冒頭 | 本編 | 閉じ |
|---|---|---|---|---|
| visual_question | 映像フック＋問い | 0.5秒動き | 観察1 | 二択＋CTA |
| aruaru3 | あるある3点＋問い | あるある導入 | 箇条3 | どれ？＋CTA |
| kiriwake | 切り分け | XとYは別 | 2〜3択 | 今どれ＋CTA |
| miruten | 見る点（調べた） | 見る点はN | 点2〜3 | プロフィールへ |
| yamenai | 扱わない宣言 | これは書かない | 代わりの範囲 | CTA |
| min_care | 削る／1つだけ | 全部やらなくていい | 最小＋個人差 | 効果断定なし＋CTA |

共通の閉じ: 口頭またはテロップで `詳しくはプロフィールのリンク（PR）` 1回。説明文に `#PR`。URLなし。Imagine は文字なし 9:16。

## エージェントの使い方

1. ジャンル体に「これだけ読んで」→ 既存レシピを生成（投稿しない）
2. 「型だけ見せて」→ このファイルと `video_kata.json` の該当 id
3. 新テーマを足すのは人間が `genre_video_packets.json` に1本足して `--write-agents`

ペット実験中に aruaru3 / visual_question 以外（商品見る点）を公開用に出さない。
