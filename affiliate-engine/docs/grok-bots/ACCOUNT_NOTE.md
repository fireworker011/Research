## 1. 売る人の名前（表示名）と自己紹介の型

**表示名（コピペ）**

```
なお｜顔も声も出さないShorts
```

**自己紹介の型（1文・コピペ）**

```
顔も声も出さずに、Shortsを毎日1本出す手順だけを観察してまとめています。
```

| 決めたこと | 根拠 |
|---|---|
| 新規の note アカウントにする | リポに既存noteアカウントの記載が無い。Threadsの「ゆう｜盛らない副業メモ」等はアフィ用（`account-setup-kit.md`）。同じ表示名で手順書を売ると、別商品の評価を混ぜる |
| 「なお」はキット未使用 | 使用済み: ゆう / みほ / たく / はな / あき / けい / ふく / よい。YouTubeは みくこんかつ。衝突を避ける |
| アイコンは人物の顔を描かない | 顔出しなし。Imagine制約も `no human faces`（playbook）。スマホとテロップ枠だけ |
| 自己紹介に本数・登録・月収・CW評価を書かない | 本文ルールをプロフィールでも守る。CWの4.9は受注仕事の数字であり、Shorts手順の根拠に使わない（景表法の不実証） |
| 年齢・家族は書かない | `account-setup-kit.md` ペルソナ規則 |

ユーザー名候補（上から空きを確認）: `nao_kaonashi_shorts` / `nao_shorts_tejun` / `kaonashi_tejun`

## 2. 手順書と素材は分ける（同じnoteに並べない）

**結論: 別記事。同じアカウントの棚に並べる。1記事に同梱しない。**

| 理由 | 種別 |
|---|---|
| 司令部がSKUを2つに分け、両方 980円、BOOTHはバナーだけ「後」と既に決めている | 確定 |
| noteは1記事1価格。同梱すると手順の買い手とバナーの買い手が同じ980を払うことになり、SKUが1つに潰れる | 公式仕様（有料記事は記事単位で価格） |
| バナーをあとでBOOTHに出す前提。手順書にファイル同梱すると同一素材の二重販売になる | 確定「BOOTHは後」から従属 |
| 完成バナーは「ファイル販売」、手順書は「文章の手順」。noteヘルプはファイルを有料エリアへ添付できると書くが、それは **1商品として売る手段** であり、別商品を混ぜる指示ではない | [動画やファイルを販売する](https://www.help-note.com/hc/ja/articles/19598976562457) |
| Canva公式: 売るならオリジナルの完成デザイン。素材単体や既存テンプレの再販は不可。SKU2は完成画像10枚として別記事の有料エリアに置く | [Canva Help: products for sale](https://www.canva.com/help/using-canva-to-create-products-for-sale/) |

**棄てた仮説:** 「1記事に手順とバナーを同梱した方が客単価が上がる」— 客単価は予測。確定SKUと矛盾。棄てる。

noteのクリエイターページでは、手順書とバナーを **2つの有料記事として並べる**。マガジンは1週目に作らない（追加SKUになる）。

## 3. 初回記事の有料ラインと、無料部に置く文

**有料ラインの位置:** 「渡すもの / 渡さないもの」を書いた直後。当日の作業順（用意→組み立て→投稿→記録）の見出しの直前。

根拠（公式）: 実用ノウハウ系は、無料エリアで「この記事を読むと○○ができるようになる」を伝えてから有料に入る。有料エリアを先に置いていきなり手順を出す型は、読み物系の話。文字数と売上の相関はほぼゼロなので、無料部を水増ししない。  
出典: [note株式会社 2026-01-07 分析](https://prtimes.jp/main/html/rd/p/000000360.000017890.html)（売上上位20%の分類。実用ノウハウの無料エリアは読み物系の約1.5倍）

確認方法（公式）: 自分のログインでは購入導線が出ない。[有料ラインの設定](https://www.help-note.com/hc/ja/articles/360008882894) のとおり、ログアウトまたはシークレットで見る。

**無料部（本文に価格・月収・実績数字を入れない。コピペ）**

```
この記事は、顔を出さない・自分の声を出さない前提で、Shortsを毎日1本出す手順をまとめたものです。

向いている人
- 顔を出したくない
- 自分の声を録音したくない
- 毎日1本の作業順が欲しい

向かない人
- 顔出しやトーク動画の方法を探している
- 再生数や収益の保証が欲しい

有料で渡すもの
- 当日の作業順（用意 → 組み立て → 投稿 → 記録）
- 置かないものの一覧

渡さないもの
- 月収の話、実績の数字、再生の保証
- 「必ず続く」「誰でも稼げる」という話

ここから先が有料です。
```

有料部に入れる作業順は、このリポの人間手順に合わせる（投稿は公式アプリ。Shortsの説明欄・コメントにURLを置かない。CTAは末尾1回。体験は捏造しない）。読み上げ音声は必須にしない。デフォルトは無音+テロップ（声出しなしに忠実）。

価格 **980** は note の価格欄だけに置く。タイトルと本文には書かない。

## 4. 価格は980を持つ（1842には上げない）

**結論: 初回も2本目も価格欄 980円のまま。**

| 事実 | 使う / 使わない |
|---|---|
| 司令部が初回SKUと2本目をどちらも 980 と確定 | 使う |
| 通常会員の設定範囲は 100〜50,000円 | 980は範囲内。[価格の設定](https://www.help-note.com/hc/ja/articles/360011270114) |
| 公式分析: 売れている実用ノウハウの平均 1842円、読み物 983円（各分類の **売上上位20%**。全体平均ではない） | 分類の参考にだけ使う。自前の販売実測が無いので 1842 に合わせない |
| 同型の公開商品（顔出しなし・声なし Shorts手順）の価格欄 | [seiさん 980円](https://note.com/am_l/n/nfb360d1fe402)、[ドラゴン副業 この記事のみ 980円](https://note.com/dra5on/n/nf8dfac637748)（2026-08-26 確認）。文面はコピーしない |
| 自前の note 売上 | ファイルに無い |

1842は「売れている実用記事の上位平均」であり、未販売アカウントの価格ではない。同棚の公開価格は 980。司令部確定も 980。上げる判断は、noteの販売実測がファイルに入ってから。

公開の同型記事は月収・「誰でも」を本文に書く例がある。こちらは `COMMON.md` で禁止なので、価格は合わせ、文面は合わせない。

## 棄てた仮説

| 仮説 | 判定 | 理由 |
|---|---|---|
| 実用平均1842に合わせる | 棄てる | 上位20%平均。自前実測なし。同型公開SKUと司令部確定は980 |
| 1記事同梱で単価を上げる | 棄てる | SKUが2つある。売上予想になる |
