## 3. 初回記事の有料ライン位置と、無料部に置く文

公開の有料ラインの切り方:

| 型 | 公開例 |
|---|---|
| 結論＋予告 | [FireWorks 顔出しゼロ・テキスト副業](https://note.com/ao_fireworks/n/n4a4245bf4c4c) 無料=結論と目次。有料5,030字。価格欄980 |
| 定義 | [いったれ億り人 CapCutスライド](https://note.com/upskilling/n/n900e433161d4) 無料=定義まで。価格欄980。メンシプ 2,980/月 |
| 内訳＋見本 | よぴ 10種など（SKU2向き） |
| 用途＋手順＋注意 | Lit.Linkテンプレなど（テンプレ商品） |

初回SKUは顔出しなし980の手順書。公開は FireWorks=結論と目次、いったれ=定義まで。**有料ラインは、結論・定義・目次の直後。当日の作業順の前。**

公開例のタイトル・本文にある月収はコピーしない（司令部: 本文に月収を書かない）。有料5,030字はFireWorksの公開字数であり、こちらの字数指定ではない。

**無料部（コピペ。価格・月収・実績数字なし）**

```
結論
顔も声も出さずに、Shortsを毎日1本出す手順を、この先の有料部に書いた。

定義
- 顔出しなし: 画面に自分の顔を出さない
- 声出しなし: 自分の声を入れない
- 毎日1本: その日の作業順を1周する

目次（有料）
- 当日の作業順（用意 → 組み立て → 投稿 → 記録）
- 置かないもの
- 注意

ここから先が有料です。
```

980は価格欄だけ。タイトルと本文には書かない。

SKU2（バナー）の無料部は公開の「内訳＋見本」型。1週目にバナーが揃ってから書く。
