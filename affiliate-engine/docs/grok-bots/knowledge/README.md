# knowledge

アフィ Shorts（ペット・婚活・美容・お金・睡眠）の台本と、MiniMax H3 プロンプトの作業フォルダ。事実の置き場は [`../research/`](../research/) で、このフォルダはそこから作業用に写す。

最終更新: 2026-10-17

## 役割

- 市場リサーチが事実を集める。日次・週メモ・[`../research/kata/`](../research/kata/) に、実測だけを書く。
- Cursor がこのフォルダを更新する。研究メモの数字を、台本とプロンプトの形に整理する。
- 台本係が [`script-skill.md`](script-skill.md) を読んで台本を書く。台本は [`scripts/`](scripts/) に置く。
- Grok Build（ナオミチの PC の video-to-h3-prompt）が動画を分析して H3 のプロンプトを書く。Cursor はその `prompts.md` を [`h3-prompts/`](h3-prompts/) に写す。
- 投稿後の実測で伸びたものだけを「勝ち」に昇格させる。参考動画の倍率は、その動画の事実であり、自分たちの勝ちではない。

## 状態

`h3-prompts/` の各ファイルは、次の3つのどれか。

- 未検証: 投稿後の実測が無い。試作もここ。
- 勝ち: 投稿後に、市場リサーチの日次が「伸びた」と実測している。
- 負け: 投稿後に、市場リサーチの日次が「伸びなかった」と実測している。

何倍から勝ちか、このフォルダでは決めない。日次の書き方（チャンネルの直近の中央値と比べた倍率）に従う。実測が「不明」のあいだは未検証のまま。

昇格の手順は、市場リサーチが日次に実測を書く、Cursor がその数を該当ファイルへ写して状態を変える、の順。台本係は自分の採点で勝ちにしない。

## 書き方

- 数字は、research に書いてある実測だけを引用する。取れない値は「不明」。新しい倍率や再生は作らない。
- 出典のセリフと映像はコピーしない。構成（何秒に何が起きるか、カットの有無、顔の有無）だけを使う。
- 本編は字幕なし、CTA なし。根拠は [`../research/2026-10-17-research70.md`](../research/2026-10-17-research70.md)（D の 63-66 と 70 は、この方針と合わないので使わない）。
- 量産に見えない差は [`../research/2026-10-15-anti-massproduced.md`](../research/2026-10-15-anti-massproduced.md)。公式の引用と、仮説と書いてある項目を混ぜない。

## 触らないもの

`agents/*.md`、`MARKET_AND_KATA.md`、`data/video_kata.json`、`research/` の既存ファイルは、このフォルダの更新では編集しない。投稿、外部への連絡、有料 API はしない。
