# 台本スキル

台本係が読む手順。ジャンルはペット、婚活、美容、お金、睡眠。出力は MiniMax H3 向けの、8〜15秒のショット割り。

基準: [`../research/2026-10-17-research70.md`](../research/2026-10-17-research70.md)。型の実測: [`../research/kata/`](../research/kata/)。TikTok の構成: [`tiktok-structures-2026-10-17.md`](tiktok-structures-2026-10-17.md)。量産の差: [`../research/2026-10-15-anti-massproduced.md`](../research/2026-10-15-anti-massproduced.md)。

H3 のプロンプト本文は、ここでは書かない。Grok Build（video-to-h3-prompt）が動画を分析して `prompts.md` に書き、Cursor が [`h3-prompts/`](h3-prompts/) に写す。

## 入力と出力

入力は、参考動画の構成。日次の #51（冒頭0〜2秒）、kata の秒割り、TikTok 構成メモのどれか。セリフと映像そのものは入力にしない。

出力は `scripts/YYYY-MM-DD-<genre>-NN.md`。中身は次の順。

1. 状態（試作。未検証。勝ちではない）
2. ジャンル、尺（8〜15秒のどれか）、カット数
3. 入力にした構成（URL と、どの型か。数字は引用）
4. ショット表。各ショットに、秒、動き1つ、カメラの動き1つ
5. 直前の同じジャンルの台本と変えた点（初回は「前作なし」）
6. 自己採点

1ファイルが1本。生成した結果と投稿後の数字は、対応する `h3-prompts/` のファイルに書く。台本側には写さない。

## 手順

1. ジャンルを1つ決める。下の制約を先に読む。
2. 入力にする構成を1つ選ぶ。その動画の顔の有無、カット、冒頭0〜2秒、尺を、出典の文言のまま控える。
3. 禁止に当たる部分を、使える形に置き換える。置き換えは [`tiktok-structures-2026-10-17.md`](tiktok-structures-2026-10-17.md) の「置き換え」に合わせて、新しい物語を足さない。
4. 8〜15秒に収める。ショットを分けたら、ショットごとに動きは1つ、カメラの動きは1つ。カット0の1ショットなら、動画全体で動き1つ、カメラの動き1つ。
5. 冒頭0〜2秒にフックを置く。フックは、選んだ構成か日次の #51 に書いてある絵にする。
6. 同じジャンルの直前の台本を見て、構成かテンポの少なくとも一方を変える。変えた点を1行書く。
7. 自己採点を埋める。状態は未検証のまま残す。

## ルール

- 本編に字幕と CTA は入れない。テロップ、心の声、登録、商品名、相談の URL、LINE は置かない。参考動画がテロップでオチを出していても、台本ではそのオチを絵の最初のフレームで見せる。
- 婚活は顔を出さない。人物の顔、サングラスで半分隠した顔、イラストの顔も入れない。スマホの画面、指、机の紙だけ。
- ペットは猫だけ。犬の見守り映像は入力にしない。人の顔は入れない。
- ショットごとに、動きは1つ、カメラの動きは1つ。撫でながら寄る、のように重ねない。カメラの「固定」は、そのショットのカメラの動き1つとして数える。
- 冒頭0〜2秒のフックは必須。#51 は、Shorts がスワイプされるかがこの秒で決まる、とリサーチ70にある。
- 量産に見えないよう、毎回、構成かテンポを変える。同じ状況から同じ結末へ着地する型を、次の本で繰り返さない。
- 数字は引用だけ。再生、倍率、いいね率、尺を新しく計算しない。
- 健康、お金、法律、政治で、人間の専門家のふりをしない。美容は効能を断定しない。お金は金額を事実として置かない。ペットで、誇張した苦痛や危険を見せる形にはしない。

量産メモの根拠の分け方:

- 必須にする公式の趣旨: 各動画の中身（ストーリー、焦点、コンセプト）が実質的に違うこと。出典は同メモの収益化ポリシーの引用。
- 仮説のまま強要しないもの: 尺を毎回変えること、投稿を1日2本にして時間を空けること、サムネや色を毎回変えること。同メモは、公式にその数字は無い、と書いている。このスキルが必ず変えるのは、構成かテンポ。

## ジャンル

kata の秒割りは、2026-10-14 の勝ちパターンメモのテンプレ。出典のセリフはコピーしない。倍率の詳細は各 kata を見る。ここに無い再生数は書かない。秒割りで動きが変わる境界は、ショットの境界にする。動きが複数ある秒割りを、1ショットにはまとめない。

### ペット

読むもの: [`../research/kata/pet.md`](../research/kata/pet.md)、直近の日次、TikTok 構成の猫。

- 型1「固定カメラに1歩近づく」（10秒）: 0〜2秒は部屋の固定映像で猫がカメラを見る。2〜6秒で猫が1歩近づく。6〜10秒で鼻を1回寄せて止まる。カメラは固定。
- 型2「見にいったら、猫は1か所で止まっている」（12秒）: 0〜2秒は定位置に猫が1匹いて動かない。2〜7秒でフレームの外へ1歩出る。7〜12秒で別の定位置に丸まって止まる。カメラは固定。文字は置かない。
- 2026-10-17 のねこある: 中央値を超えた本の共通は、冒頭0〜2秒が猫の体のアップで、手が体に触れていること。尺は18〜60秒で揃っていない（[`../research/2026-10-17.md`](../research/2026-10-17.md) の #8、#51）。
- 同じ日次は、見守りカメラの8〜15秒を H3 の勝ち型メモに落とすな、と書いている。見守りカメラの台本を書いても、状態は未検証のまま。勝ちにしない。

### 婚活

読むもの: [`../research/kata/konkatsu.md`](../research/kata/konkatsu.md)。TikTok の婚活2本は顔出しあり。絵のままは使わない。置き換えは TikTok 構成メモを見る。

- 型1「画面が1回動く」（10秒）: 0〜2秒はスマホの画面だけ。2〜6秒で指が1回スワイプする。6〜10秒で指が画面を伏せる。カメラは固定。顔は入れない。
- 型2「1条件で指が止まる」（12秒）: 0〜2秒は手がスマホを持って止まる。2〜7秒で指が1つの条件のところで止まる。7〜12秒で指が画面を閉じる。条件は1つ。
- 型3「紙を1回指す」（10秒）: 0〜2秒は机の上の紙だけ。2〜6秒で手が紙の1か所を指す。6〜10秒で手がペンを置く。

### 美容

読むもの: [`../research/kata/beauty.md`](../research/kata/beauty.md)。TikTok の美容3本（`@tobuy_desu`、`@cosme_ba`、`@dan_biyou`）は、いいね率 0.1〜1% で、出典が広告配信の可能性を書いている。この3本の倍率は、勝ちの根拠にしない。

- 型1「1本を持って、1回つける」（12秒）: 0〜2秒で1本を持って止める。カメラは固定。2〜8秒で同じ部位に1回だけつける。カメラが寄るなら、この1回だけ。8〜12秒でつける前と同じ画角で止まる。カメラは固定。
- 型2「手元で順番を2本」（12秒）: 0〜2秒で1本目を持って止める。2〜6秒で手の甲に1回つける。6〜8秒で2本目に持ち替える。8〜12秒で手の甲に1回つける。3本目は足さない。顔は必須にしない。
- 型3「1本をどける」（12秒）: 0〜2秒でどける物を持って止める。2〜7秒で机の外へ1回動かす。7〜12秒で残った1本だけが机にある。

### お金

読むもの: [`../research/kata/irasutoya-kanememo.md`](../research/kata/irasutoya-kanememo.md)。このメモは、直近60日でお金×いらすとやが3倍以上だったものは無かった、と書いている。型1の根拠は60日より前の再現。

- 型1「金額が1つ変わると、絵の反応が1回変わる」（12秒）: 0〜2秒で人物がお金の物を1つ持って止まる。2〜6秒でその物を机に1回置く。6〜10秒で別の人物の反応に切り替わる。反応は1つ。10〜12秒で最初の人物が1回うなずいて止まる。カメラは固定。文字は置かない。金額の段は1段。
- TikTok で顔が無いお金は、`@enokida.media`（テキスト静止画）と `@taka_kantanrecipe`（手元）。テキストの箇条書きを、本編の字幕としては使わない。

お金の kata は、いらすとや風の人物を使う。顔の実写は使わない。

### 睡眠

`research/kata/` に睡眠のファイルは無い。2026-10-17 の日次は睡眠を開いていない。勝ち型としては置かない。

入力にしてよいのは、TikTok 構成メモの睡眠のうち、顔なしに置き換えた形だけ。`@yuko31682` はいいね率 0.5% で、出典が広告の可能性を名指ししている。倍率は勝ちの根拠にしない。`@akiramenaiak` は顔のコントが本体で、顔なしの台本にはしない。

- その絵は、入力にした構成か日次の #51 に書いてある:

- ジャンルの制約を守っている（婚活は顔なし。ペットは猫だけ）:

- 尺が8〜15秒:
