## 自アカのキャラ（これ以外を作るな）

| 項 | 値 |
|---|---|
| 口を動かす主体 | 柴犬。画面に名前を出さなくてよい。出すなら「ふく」だけ |
| 一人称 | 関西弁の独白（「俺」「せやから」「おる」）。標準語ナレに戻すな |
| 飼い主 | **顔を出すな**。手元・後ろ姿・部屋だけ。固有名を付けるな（リンちゃんのコピーになる） |
| 場所 | 日本の普通のワンルーム〜2LDK。暖色。昼間の窓 |
| 尺 | 15〜30秒。9:16 |
| 媒体 | 既存 `@pet_story_select` 用の素材。今日は投稿しない |

## 落とし（1つでも落とし）

- 参考アカの名前・キジ白猫・飼い主の固有名が出る
- 他人の顔、商標、文字崩れした日本語テロップを画像に焼き込む
- 新しい顔の人間を正面で作る
- 商品名・アフィURL・「詳しくはプロフィール」をこのパックに足す
- 3本を一度に量産して投稿する
- Canva と CrowdWorks を Imagine と同時に開く（`BOX_MEMORY.md`）

判定は `通す` / `落とし` / `INSUFFICIENT` だけ。きれいさで落とすな。

## 1本の作り方

1. 下の **今回やる1本** だけ選ぶ（未着手なら ①）。
2. ブラウザは Imagine だけ。
3. 英語プロンプトで **9:16 動画**（口パクする柴犬。字幕は焼くな。声は後載せ可）。
4. 日本語VOは下の台本を **読み上げ用に使う**。文言を「参考アカっぽく」足すな。
5. 書き出し: 1080×1920、15〜30秒、MP4。Git にバイナリを置くな。パスだけ報告。
6. 1本できたら止まれ。次の番号は指令塔が出す。
