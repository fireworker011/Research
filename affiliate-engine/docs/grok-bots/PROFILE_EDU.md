# 教育 Threads プロフィールだけ（参謀・URL を Git に書くな）

指令塔が N高またはアイズで `Threadsあり` と返し、Secret に `教育_N高` または `教育_アイズ` を入れたあとの仕事。
`YouTubeあり` / `項目なし` / `媒体なし` では使わない。cron は戻さない。投稿しない。
転職用は `PROFILE.md`。混ぜるな。N高を転職アカに置くな。教育アカに neo を置くな。

A8 の一般FAQ: スレッド**本文**の広告リンクは控える。**プロフィールのリンク欄**は可。
プログラム詳細の掲載媒体に Threads が書いていなければ、プロフィールにも置くな。

## 置く場所

開設済みの **教育** Threads（`accounts.json` の key `education`。表示名「はな｜小学生の習い事メモ」）。
公開ハンドルは `accounts.json`。チャットにハンドルも URL も書くな。

置く欄: プロフィール編集の **リンクを追加する欄** 1つ。紹介文（自己紹介）には書くな。値は Secret に入れた `教育_N高` または `教育_アイズ` と同じ広告リンク。そのリンクは、副サイト登録した教育 Threads を「掲載サイト」に選んで発行したもの。

同じ欄に2本目を足すな。N高を既に置いたならアイズで上書きするな。

この手順は GitHub Actions を通らない。プロフィール欄は Secret のあと人間が置く。本番 `loadLinks()` は PR #77 入済み（post/insight 用。プロフィールは通らない）。重ね待ちで置くな。cron は戻すな。自動投稿の再開とは別件（`CHECKOUT.md`）。

## やらないこと

- スレッド本文・返信・固定投稿に URL
- 紹介文（自己紹介）に URL を書く（リンク追加の欄ではない）
- いいね / フォロー / DM
- post / insight の schedule を戻す
- 教育 YouTube を始める
- 転職・副業・美容・ペットのプロフィールに N高／アイズを入れる
- 開設していないアカウントを「ある」ことにする
- アフィURL を Git / チャット / Issue / dump に書く
- カタログ円を conversions に足す
