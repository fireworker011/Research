# 市場リサーチ inbox

このフォルダは事実の inbox である。日次ファイルに推測で数字を足さない。ここで `agents/*.md` や `MARKET_AND_KATA.md` を編集しない。

書き方の基準は [`2026-10-17-research70.md`](2026-10-17-research70.md)（2026-10-17以降）。

- 日次は1ファイル。ファイル名は `YYYY-MM-DD.md`。ひな形は [`_template.md`](_template.md)
- 週の終わりに1ファイル。ファイル名は `YYYY-MM-DD-week.md`（書いた日）。ひな形は [`_template-week.md`](_template-week.md)。B をジャンルごとに書く
- 勝ちパターンは [`kata/`](kata/)。ひな形は [`kata/_template.md`](kata/_template.md)。各ファイルに「70項目との対応」を置く
- A（#2 #8 #9 #51 #67 #6 #15）は毎日。この7項目のうち3つ以上を実測する。#51 は毎回、冒頭0-2秒に何が起きたかを書く
- B は週1回。C は新しいジャンルを調べるときか、台本係から頼まれたときだけ。D（16, 18, 19, 39-50, 63-66, 70）は書かない
- 倍率は、そのチャンネルの直近Shorts12本の中央値と比べて何倍か。12本が揃わない倍率は「不明」
- 数字は実測だけ。取れない値は「不明」
- 「AI需要リサーチ型」の1行は、ひな形の文言のまま残す。今日の観察を足すときも、行頭のラベルは変えない
- Cursor が後からこれらのファイルを読み、プレイブックを整える

2026-10-11 までの日次と、その頃の単発メモは [../archive/research/](../archive/research/) にある。毎朝の実測では開かない。数字の正本は、2026-10-12 以降のファイルと [kata/](kata/) と [2026-10-17-research70.md](2026-10-17-research70.md)。
