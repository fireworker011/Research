# A8 サイト登録（参謀・URL を Git に書くな）

指令塔が `Threadsあり` と返し、`G_hq_threads_exist.txt` が **`開設済み`** のあとの仕事。
`YouTubeあり` / `項目なし` / `媒体なし` / `未開設` では使わない。
Secret の **前**。未登録のままリンクを発行するな。cron は戻さない。投稿しない。新媒体を今日開くな。

A8 公式: SNS に掲載するには、主サイトまたは副サイトとして **事前に** その SNS アカウントの登録が必要。

出典:
- https://support.a8.net/a8/as/faq/2022/post_1955.html （SNS掲載。Threads 本文は控え、プロフィールのリンク欄は可。事前のサイト登録が必要）
- https://support.a8.net/a8/as/faq/2022/post_1953.html （複数サイト・SNSは副サイトで登録）
- https://support.a8.net/a8/as/faq/manual/change_registration_info.php （「副サイトを登録する」）

## 手順（公式のボタン名だけ）

1. 管理画面の【登録情報】→「サイト情報の登録・修正」
2. ページ下部の「副サイトを登録する」
3. **開設済み**の転職 Threads だけを登録する

未開設ならここで止まれ。アカウントを新造するな。チャットにプロフィールURLを書くな。
