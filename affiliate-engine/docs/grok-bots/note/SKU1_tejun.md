## 無料部（ここまで公開してよい）

結論
顔も声も出さずに、Shortsを毎日1本出す手順を、この先の有料部に書いた。

定義
- 顔出しなし: 画面に自分の顔を出さない
- 声出しなし: 自分の声を入れない
- 毎日1本: その日の作業順を1周する

目次（有料）
- 当日の作業順（用意 → 組み立て → 投稿 → 記録）
- 置かないもの
- 注意

## 有料部（下書き。公開ボタンは押さない）

### 当日の作業順

用意
1. その日の台本を1本だけ決める。実験中は新しい創作をしない。手元の完成台本から1本取る。
2. 末尾の言葉を固定する。「詳しくはプロフィールのリンク（PR）」。これ以外の誘導を足さない。
3. 画面・説明・コメントに URL を置かない。Shorts の説明欄とコメントのリンクは公式にクリックできない。
4. 説明文の末尾に `#PR` を付ける。YouTube の「有料プロモーションを含みます」をオンにする。

組み立て
1. 比率は 9:16。文字とロゴは載せない（載せる運用に変えるのは別判断）。
2. 冒頭は台本の1文目から始める。別チャンネルの映像・台本・サムネは使わない。
3. 自分の顔と自分の声は入れない。読み上げやテロップは台本どおり。
4. 長さは短尺のまま。別媒体用に作り直さない。

投稿
1. 投稿は人間が公式の画面から行う。予約も公式ツールだけ。自動投稿はしない。
2. いいね、フォロー、DM の自動はしない。
3. 固定コメントにアフィURLを置かない。

記録
1. その日の投稿本数、再生、クリック、成果を1行で残す。無い数字は空のまま。
2. 再生を売上と読まない。クリックを円にしない。確定した円だけを円として書く。
3. 記録が無い日は、次の台本を増やさない。

この4塊を1周したら、その日は終わり。同じ日に2本目を足さない。

### 置かないもの

- TikTok と Instagram を同じ日から始めること
- 新しいチャンネルを開くこと
- ジャンルを変えること
- 体験していない商品の感想を、使った体で書くこと
- `#PR` なしのリンク誘導
- 他アカウントの文面コピー

### 注意

- 広告であることは隠さない。
- 効果や収入を断定しない。「絶対」「必ず」「誰でも月○万」は書かない。
- 公開日は、下書きを置いた日ではない。公開ボタンを押した日を D0 とする。
- 2本目（告知バナー）は、この手順書が公開され、バナーが揃ってから別記事にする。1記事に同梱しない。
