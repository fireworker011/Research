# Threads プロフィールだけ（参謀・URL を Git に書くな）

指令塔が neo で `Threadsあり` と返し、Secret に `転職_neo` を入れたあとの仕事。
`YouTubeあり` / `項目なし` / `媒体なし` では使わない。cron は戻さない。投稿しない。

N高／アイズを教育 Threads のプロフィールに置く仕事は `PROFILE_EDU.md` / `dump/G_hq_threads_profile_edu.txt`。チケットは `PROFILE_TICKET.md`。このファイルと混ぜるな。neo を置いたあとも教育アカで N高へ進む（別アカ）。教育 YouTube は始めない。

A8 の一般FAQ: スレッド**本文**の広告リンクは控える。**プロフィールのリンク欄**は可。
プログラム詳細の掲載媒体に Threads が書いていなければ、プロフィールにも置くな。

## 置く場所

開設済みの **転職** Threads（`accounts.json` の key `tenshoku`。表示名候補は「けい｜しずかな転職準備」）。
ハンドルはファイルに無い。2026-08-28 の公開 fetch はアプリ誘導のみで、存在は証明できない。チャットにハンドルも URL も書くな。

置く欄: プロフィール編集の **リンクを追加する欄** 1つ。紹介文（自己紹介）には書くな。値は Secret に入れた `転職_neo` と同じ広告リンク。そのリンクは、副サイト登録した Threads を「掲載サイト」に選んで発行したもの。

この手順は GitHub Actions を通らない。本番 checkout に `loadLinks()` が無くても置ける。自動投稿の再開とは別件（`CHECKOUT.md`）。Issue #56 は API 投稿用トークン。プロフィールのリンク欄は止めない。

## やらないこと

- いいね / フォロー / DM
- post / insight の schedule を戻す
- 転職 YouTube を始める
- 副業・美容・ペット等の別アカのプロフィールに neo を入れる
- 開設していないアカウントを「ある」ことにする
- アフィURL を Git / チャット / Issue / dump に書く
