# アダアフィキャッシュループ — 意思決定と最小運用

ペット（`@pet_story_select` / `video-judge.js`）は止めない。  
アダは別事業。ジャンル転換ではない。

目的は月100万の保証ではない。今決めるのは「禁止媒体に出さない」「判定できる記録を始める」ことだけ。

## フェーズ1：問題の切り分け

| 層 | 中身 |
|---|---|
| 症状 | アダ用の案件・導線・計測が無かった |
| 事実 | ペット32本は既にある。`links.json` は全空。動画実験は記録0行。Threadsエンジンはアダを意図的に除外済み |
| 推測 | 仕組みを足せば月100万に近づく |
| 希望 | YouTube / TikTok / Instagram で回せる |

「仕組みが無い」は制作が無いという意味ではない。足りないのは、アダを置ける媒体と、判定できるクリックである。

人気と正しさは別である。上位ランキングは新規の予測値ではない。

## フェーズ3：第一原理

分解すると4つだけ。

1. 許可された場所に出す
2. 押せるリンクがある
3. クリックが週15を超える
4. 着地で成果が出る

変えられない制約: 3媒体の規約、景表法、ペット実験の継続、PCほぼ無し、アフィURLをコミットしない、体験捏造禁止。

変更した前提: 「使う媒体はYouTube / TikTok / Instagram」は捨てる。必要ならやり方を変える、という指示に従った。

最短・最安・最少工程:

1. 新規Xを1つ作る
2. DMMにそのXを審査提出する
3. 公式ツールバーで1日1本、#PR付きで出す
4. CSVに数字を書く
5. `adult-judge.js` がゲートだけ返す

サイトもYouTubeもbotも、最初は作らない。

## フェーズ4：6視点と相互反論

顧客: 欲しい作品へ最短で行きたい。癒しShortsの視聴者ではない。  
競合: 勝っているのはSEOサイトと、公式素材で語れるX。3媒体の「ほのめかし」はBAN待ち。  
実務: スマホなら公式ツールバーとGitHubアプリで足りる。Grokに投稿させるな。  
財務: 基準仮定（報酬¥1,050、CVR1%、承認80%）で月100万は約1191成約、約11.9万クリック。最初の現金は¥5,000。  
批判者: ペット実験当日に新事業を足している。記録0のまま規模の話をしている。  
長期: SNS単体は凍結でゼロ。後でlandingを足す。最初から3媒体は自殺。

相互反論:

- 顧客「Xは発見に弱い」→ 財務「弱い媒体でも許可媒体のクリックだけがデータになる」
- 競合「サイトを先に作れ」→ 実務「PCが無い。審査用SNSが先。サイトは後で決める」
- 批判者「今やるな」→ 決定済み。ただしペットは止めない。混ぜないことが条件
- 長期「X依存は危険」→ 同意。14日はXだけ。サイトは可逆。3媒体は不可逆に近い

## フェーズ5：選択肢

| 選択肢 | 中身 | 失敗条件 | 可逆性 |
|---|---|---|---|
| A 採用 | 新規X + 判定CSV。14日は媒体を足さない | 14日で週クリック15未満、または審査非承認 | 可逆。アカウント削除で終わる |
| B 却下 | 指定の3媒体で「ほのめかし→プロフィール」 | 1回のポリシー違反でチャンネル停止。ペットまで巻き添え | ほぼ不可逆 |
| C 保留 | 独自サイト先行 | 書き溜めがクリックゼロのまま続く。PC作業が必要 | 可逆だが遅い |

今決めること: A。ペットは継続。アダを3媒体とThreadsに出さない。月100万は週50クリックが3週続くまで語らない。  
後で決めること: どのFANZAカテゴリが売れるか。landingを足すか。1本あたりの報酬の実測。

最も不都合な事実: 指定した3媒体では、この商品は規約上まともに置けない。置いた瞬間、既存のYouTube資産を焼ける。
