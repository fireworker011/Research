借りるのは**型**だけ。文面・猫・ネタ・ユーザー名はコピーしない（`docs/account-strategy.md` のオマージュ規則）。

## 借りた型

1. 0秒で状況の真っ只中（自己紹介なし）
2. テロップが猫の内心を担う（短い・下中央・白＋縁取り）
3. 3拍: 状況 → 反応 → オチ（7〜12秒）
4. ごはん袋・器は物語の小道具。売り込み文は末尾1回だけ

## やらないこと

- 原文・サムネ・BGM・部屋・茶トラ＋白猫ペアの再現
- 「比較して選んだ」「毛並みが良くなった」など未体験の断定（人間が承認した実体験以外）
- Shorts の説明欄・コメントにアフィURL（クリック不可。導線はプロフィール）
- `links.json` の `ペット_フード` が空のままリンク投稿すること
- 自動投稿

## 制作パイプライン（このパック）

1. 起点画像を複数枚（Imagine。猫はブルーグレーのブリティッシュショートヘア1匹。茶トラ＋白は使わない）
2. 各画像を動画化（Wan I2V。Grok Imagine クリップは有料プランが必要）
3. 無音のままつなぎ、下中央テロップ
4. **最後に**ナレーションだけ載せる。BGM・効果音なし

```bash
cd affiliate-engine
npm run youtube:catfood:test
# clips を output/videos/catfood-homage/clips/{id}_b1.mp4 に置いてから
node src/catfood-homage-assemble.js --video catfood_01_bag_sound
```

完成ファイル: `output/videos/catfood-homage/{id}_narrated.mp4`（gitignore）


| id | タイトル | 3拍 |
|---|---|---|
| `catfood_01_bag_sound` | 袋の音がした瞬間、端から来た | この音 → 端から来る → 袋だけは別 |
| `catfood_02_empty_bowl` | 朝、器が空だと先に来る | まだ空 → ごはん係 → 時計より正確 |
| `catfood_03_sniff_check` | 新しい袋、まず匂いを確認する | 新しい袋 → 匂い、検査中 → 今日から？ |

末尾3秒は毎回 `詳しくはプロフィールのリンク（PR）`。説明文に `#PR`。URLなし。

## 実写で撮るとき（本命）

AIプレビューは画の確認用。オマージュ本体は**実在の猫の手元／床／器**。

- チャンネルに既に出している子を使う。別人の猫を借りて「うち」と書かない
- 袋はロゴが読めない向きか、無地。特定ブランドを「勝ち」と言わない
- カメラは目線〜少し上、暖色の部屋灯。カットは2〜3
- 音声は無しでも成立する（テロップ主導）。BGMは既存チャンネルの実験中の型を壊さない
