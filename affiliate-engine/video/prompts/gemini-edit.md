# Gemini 編集プロンプト（スキンケア縦型ショート向けに調整）

元の7プロンプトを、この案件用途（9:16 / 10〜22秒 / スキンケアアフィリエイト / AI生成素材）に合わせて調整したもの。

## 先に前提の確認

**Gemini 単体は編集済みの動画ファイルを描き出さない。** Gemini はチャット側の短時間プロジェクト向けコンソールで、タイムライン編集と長尺化は Google Flow 側の機能。Veo の1生成は最大8秒で、長尺は Flow のタイムラインでクリップを連結して作る。

なので7プロンプトの正しい使い方はこう：

| 工程 | 使うもの | 出るもの |
|---|---|---|
| 編集の設計 | **プロンプト1・2・3** | EDL（タイムコード付きの編集指示表） |
| 実レンダリング | Flow のタイムライン / ffmpeg / （どうしても手作業なら）CapCut | 動画ファイル |
| 検品 | **プロンプト5・6・7** | 修正指示 |
| 書き出し | **プロンプト4** | エンコード設定 |

「CapCut不要」は成立する。ただし成立の理由は Gemini が描き出すからではなく、**Gemini が出した EDL をそのまま Flow か ffmpeg に流せるから**。手動でカットを探す作業とエフェクトを考える作業が消える、というのが実態。

**推奨の投げ順：3（テロップ・フック）→ 1（編集プラン）→ レンダリング → 7（維持率監査）→ 6（最終レビュー）→ 4（書き出し）**
プロンプト2はお手本動画がある時、5は実写素材が混ざる時のみ。

## 全プロンプト共通で末尾に足す一節（スキンケア用ガードレール）

7つのどれを使う時も、これを最後に貼る。これがないと Gemini は平気で薬機法アウトのテロップを提案してくる。

```
【この案件の制約 — 提案は必ずこの範囲内で】
・日本の薬機法の対象です。化粧品の効能効果の範囲を超える表現を提案しないでください。
　NG例：シミが消える／ニキビが治る／シワがなくなる／美白になる／肌が生まれ変わる／医薬品級
・使用前後の変化（ビフォーアフター）を見せる編集・示唆する編集を提案しないでください。
　素材の人物はAI生成であり、肌の状態は効果の証拠ではありません。
・架空の人物に一人称の使用感・体験談を語らせる演出を提案しないでください。
・「絶対」「必ず」「100%」などの断定強調を使わないでください。
・広告表記 #PR を含む前提で構成してください。
・縦型9:16です。テロップは画面中央60%以内に収めてください（上下はUIに隠れます）。
```

## 1. 編集プラン作成 ← 主力

> YouTube とドキュメンタリー編集で15年以上の経験を持つシニア動画エディターとして振る舞ってください。これから素材映像の内容説明を渡します。それを分析し、視聴維持率の高い洗練された動画に仕上げるための、時系列に沿った明確な編集プランを作成してください。どのタイミングで何が起きているかを正確に示し、カット、テンポの変化、B-roll の切り替え、エンゲージメント目的の調整を含めてください。さらに、流れと訴求力を支えるために音楽のキュー、トランジション、効果音といった音声面の指示も加えてください。出力は次の列を持つ表形式にしてください：タイムコード / 編集アクション・カット / B-roll・ビジュアル / 音声・SFX / 編集メモ。エディターが手順どおりに実行できるよう、具体的かつ実践的に書いてください。
>
> **追加：尺は【N】秒、9:16縦型、平均カット尺は1.2〜2.5秒を守ってください。冒頭0〜2秒は視覚フックとテロップを同時に立て、商品名とロゴはこの区間に出さないでください。5秒に1回、SFX・ズーム・テロップ切替のいずれかでパターンインタラプトを入れてください。**
>
> **追加：出力の表の最後に、そのまま実行できる ffmpeg のコマンド案も付けてください（trim / concat / drawtext / afade）。**
>
> 素材の説明：【`output/<ブリーフID>.md` の「④ テロップ全文」の表と、Grokで作った各クリップの内容をそのまま貼る】

## 2. 他動画のスタイルの模倣

> 熟練の動画エディター兼ビジュアルスタイル分析者として振る舞ってください。私が提示する参考動画を分析し、テンポ、トランジション、1ショットの長さ、カラーグレーディング、サウンドデザイン、BGM、画面上のテキスト、全体のビジュアルリズムといった中核的な編集要素を分解してください。これらの要素がどう組み合わさってエンゲージメントを高め、ストーリーテリングを支えているかを説明してください。そのうえで、私の動画企画で同じスタイルを再現するための、段階的で明確なガイドを示してください。トランジション、タイミング、カラーグレーディング、サウンドデザインの実践的な提案を含め、最終的な仕上がりが同じ熱量と質感になるようにしてください。
>
> **追加：模倣するのは編集の構造（テンポ・カット割り・色・音の設計）だけです。台詞・テロップ文言・構成の順序をそのまま複製しないでください。**
>
> 私の動画企画：【`output/<ブリーフID>.md` の型の説明を貼る】
> 参考動画：【動画をアップロード】

> **注意**：参考動画は「型を学ぶため」に使う。カットとテロップをそのまま写すと著作権とプラットフォームの重複コンテンツ判定の両方に触れる。`docs/market-research.md` §2-3 参照。

## 3. テロップ ← 最初に投げる

> YouTube およびショート動画のコンテンツ維持率ストラテジストとして振る舞ってください。台本を精査し、テンポ・明快さ・エンゲージメントを分析してください。熱量が落ちる箇所、繰り返しになっている箇所、視聴者の注意が離れるリスクのある弱点を特定し、そのうえで冒頭のフックと最初の10秒を、より引き込まれ、好奇心を刺激するものに書き直してください。次に、動画全体で維持率を最大化するために、ジャンプカット、ズーム、テロップ、効果音、オーバーレイ、パターンインタラプトなどの具体的な編集テクニックを、どこに適用すべきかの明確な指示とあわせて提案してください。
>
> **追加：この動画は【N】秒しかありません。「最初の10秒」ではなく「最初の2秒」を最重要として書き直してください。フックの改稿案は3案出してください。**
>
> ターゲット視聴者：【`output/<ブリーフID>.md` の「⑦」に自動記入されている】
> 台本：【「④ テロップ全文」の表を貼る】

## 4. 書き出し設定

> 放送品質での納品を担当するポストプロダクション・スーパーバイザーとして振る舞ってください。私が指定するプラットフォームとコンテンツの傾向に基づき、映像・音声の品質を最大限に保ちつつ圧縮による劣化を最小限に抑える、最適な書き出し設定を提案してください。解像度、フレームレート、コーデック、ビットレートの範囲、カラープロファイル、音声設定を明示してください。アップロードがスムーズに通り、圧縮後も鮮明さが保たれるよう、プラットフォーム固有の指針も含めてください。
>
> プラットフォーム：【briefs.json の platform】
> コンテンツの傾向：【型の名前】

> **注**：`build-brief.js` が既定値を `output/<ブリーフID>.md` に自動で出しているので、通常はこのプロンプトを投げる必要はない。素材が特殊（極端な暗部・細いテロップ・高速カット）な時だけ使う。

## 5. 小技（素材の仕分け）

> プロの制作現場で素材映像を精査するチーフ動画エディターとして振る舞ってください。アップロードした映像を分析し、完成尺で最も価値のある瞬間を特定したうえで、結果を次の3つのカテゴリーに整理してください。
> ・ゴールド：強いショット、重要な瞬間、必ず残すべき映像
> ・カット：間延び、繰り返し、噛み・言い間違い、削るべき冗長部分
> ・磨き所：B-roll、テロップ、グラフィック、サウンドデザインで強化できる箇所、テンポを上げたりカットを目立たなくしたりできる改善ポイント
> 各項目にタイムコードを付け、その判断の根拠を簡潔に説明してください。
>
> **追加：AI生成クリップなので、「カット」の判定基準に次を必ず含めてください — 顔・手指の破綻、クリップ間での顔の不一致、商品ラベルの変形、不自然な物理挙動。1フレームでも破綻していたら該当区間をカット判定にしてください。**
>
> 【Grokで生成したクリップを全部アップロード】

> Grok の既知の弱点はクリップ間で顔が変わること。この工程は**破綻検出のために毎回通す**価値がある。

## 6. 最終仕上げレビュー

> 公開直前のほぼ完成した動画をチェックするクリエイティブディレクターとして振る舞ってください。初見の視聴者の視点で評価し、次の各項目を10点満点で採点してください：テンポ、音のバランス、映像の見やすさ、カラーグレーディング、ストーリーテリング。そのうえで、最終品質を明確に引き上げる「効果の大きい改善点」を3つ挙げてください。公開前に視聴体験そのものを良くする、重要でインパクトの大きい変更だけに絞ってください。
>
> **追加：採点項目に「6つ目：広告っぽさ（低いほど高得点）」を足してください。また、この動画がAI生成であることが視聴者にどの程度わかるかを10点満点（わかりにくいほど高得点ではなく、"不気味さがないほど高得点"）で評価してください。**

## 7. 視聴維持率の監査

> オンライン動画のパフォーマンスを専門とする視聴維持率アナリストとして振る舞ってください。提供する動画または台本を精査し、視聴者の関心が最も薄れる箇所、離脱の可能性が最も高い箇所を特定してください。具体的なタイムコードを示し、エンゲージメントを損なっている要因を説明し、注意を高く保つための的を絞った改善策を提案してください（パターンインタラプト、より詰めたカット、B-roll の追加、テンポの調整など）。さらに、最初の10秒で好奇心と維持率を最大化するための、高エネルギーな代替フックを3案作成してください。
>
> **追加：フックの約束が動画内で回収されているかを明示的に判定してください。TikTokの2026年アルゴリズムは中盤・終盤の構成の一貫性まで評価するため、フックだけ強く中身が伴わない動画は完走率で落とされます。回収できていない場合はどこで回収すべきかを指摘してください。**
