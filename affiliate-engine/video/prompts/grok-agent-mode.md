# Grok Imagine Agent Mode まるなげプロンプト

Agent Mode に商品情報と画像を投げたら、ほぼ完成したアフィ動画が出てくる状態にするための設計。
**スキンケア・ペットなど登録済みジャンルの案件は `node ../src/build-brief.js --id <ID>` が案件別に自動生成する**
（`config/briefs.json` に案件を足すだけ。ジャンルを新設する時は `data/domains/<domain>/` を追加する）。
このファイルは汎用マスター（新ジャンルを手動で試す時、または未登録ジャンル用）と、
Agent Mode 固有のクセへの対処をまとめたもの。

---

## 0. 前提：Agent Mode の実仕様

| 項目 | 実際のところ | プロンプト側での対処 |
|---|---|---|
| アクセス | grok.com（デスクトップ）→ Imagine → 入力欄で Agent Mode を ON。**SuperGrok（$30/月）以上**が必要。Lite（$10/月）は不可 | — |
| プリセット | Create Worlds / Short Film / **UGC Product Stories** / Brand Identity | アフィ動画は **UGC Product Stories** 一択 |
| 動作 | 無限キャンバス上で「計画 → 生成 → 編集 → スティッチ」を自律実行 | 途中で止まらないよう、承認ポイントを1回に固定する |
| ストーリーボード | プリセットは6〜12パネルを計画し、**6秒クリップ**を自動トランジションで連結 | シーン数は6〜12に収める。各シーンの目標尺を明示し「6秒で生成してトリム」と書く |
| 尺 | 1分前後のショートフィルムまで報告あり。公式仕様は未公開 | 15〜45秒に収める。長尺を狙わない |
| 使えるツール | Quick Animate / Group Images / Crop・Trim・Fade / Stitch / Extend | 「トリムして繋げ」と具体的に指示すると効く |
| **日本語テキスト** | **文字をピクセルとして描くので日本語は崩れる** | **焼き込ませない。**セーフエリアを空けさせ、テロップ台本をテキストで出させる |
| ループ癖 | クリップが同じ位置に戻ってループに見える | 「終端の状態を始端と変える」と明示する |
| コスト | 生成分に応じた従量。$4.20/分 という試算がある | まず15秒で試し、当たったら30秒に伸ばす |

**最重要は日本語テロップ。** ここを知らずに「自然なテロップを入れて」と頼むと、全シーンに意味不明な文字が焼き込まれた動画が出てきて作り直しになる。

## 1. マスターまるなげプロンプト（汎用）

商品写真を1〜7枚（正面・使用シーン・パッケージ）＋あれば人物画像をアップロードしてから貼る。

```
あなたはプロのアフィリエイト動画ディレクター兼UGCクリエイターです。
Grok Imagine Agent Mode として、以下をすべて活用し、視聴維持率が高くクリックしたくなる
縦型アフィリエイト動画を、まるなげで最後まで完成させてください。

【やること】
1. 5〜7シーンのストーリーボードを計画する
2. 一貫したキャラクターと商品を保ったまま各シーンを生成する
   （素材は6秒で生成し、各シーンの目標尺にトリムする）
3. スティッチして1本に繋ぐ
4. 効果音・BGM・CTAを最適配置する
5. 完成動画と納品物一式を出力する

【動画の条件】
- 形式: 9:16 縦型（YouTubeショート / TikTok / Instagramリール）
- 尺: 【15秒 / 30秒 / 45秒】
- トーン: 【自然なUGC風 / シネマティックで高級感 / テンポ速めのバズり狙い / 自虐ユーモア】
- ターゲット: 【例: 30〜40代の忙しい会社員】

【必須構成】
- シーン1（0〜3秒）: 強烈なフック。問題提起か衝撃ビジュアル。商品名とロゴはここに出さない
- 問題提起 → 商品登場 → 使用シーン → ベネフィット → CTA
- 各シーンの目標尺は1.5〜3秒。同じ構図を2回続けない

【商品情報】
- 商品名: 【】
- 主な特徴・メリット: 【箇条書き】
- 訴求したいポイント: 【】
- CTA文言: 【例: 詳細は概要欄のリンクから】

【参照】
アップロードした商品画像を厳密に参照し、商品の見た目・色・ロゴを正確に保ってください。
（人物画像がある場合）シーンをまたいで顔・髪型・肌の色・衣装が変化しないようにしてください。
変化したシーンは採用せず、生成し直してください。

【生成時のルール】
- 1シーンにつき動きは1種類だけ。複数の動きを重ねると破綻します
- カメラは1シーン内でフレーミングを保持。シーンの内側でカットを割らないでください
- ループ回避: 各シーンは終端の状態を始端と変えてください
- 不自然な物理挙動、手指の破綻、商品ラベルの変形があるシーンは採用しないでください

【テロップの扱い — 重要】
動画内に日本語の文字を焼き込まないでください。文字が崩れます。
代わりに次を守ってください。
1. 全シーンで画面の上15%と下25%を無地に近い状態に保つ（後からテロップを乗せるセーフエリア）
2. テロップ文言は焼き込まず、納品物④としてタイムコード付きテキストで出力する

【守ること】
- 効果・効能を断定しないでください
- 実在の人物・ブランド・キャラクターに似せないでください
- 「絶対」「必ず」「100%」などの断定強調を使わないでください
- 権利のない映像・音源を使わないでください

【進め方】
まずストーリーボードを提示してください。私が承認したら、生成・スティッチ・仕上げまで
止まらずに実行してください。

【納品物】
1. 完成動画（指定尺 / 9:16）
2. シーンごとの生成プロンプト
3. 編集判断の一覧（タイムコード / 編集アクション / ビジュアル / 音声・SFX / メモ）
4. テロップ台本（タイムコード付きテキスト。動画には焼き込まない）
5. 上の「守ること」への自己チェック結果（各項目 OK/NG と根拠）
```

## 2. バリアント（用途別アドオン）

マスタープロンプトの末尾に足す。実データは `../data/agent-variants.json`（`briefs.json` の `variant` で自動適用される）。

| キー | 用途 |
|---|---|
| `problem_solution` | 問題解決型。CVR最優先。「あるある → 解決」の感情曲線に振り切る |
| `cinematic` | 高級感・シネマティック。スロー、浅い被写界深度、ゆったりテンポ |
| `fast_buzz` | テンポ速めのバズり狙い。1.0〜1.8秒カット、ビート同期 |
| `self_deprecating` | 自虐ユーモア。共感で刺す |
| `from_existing_video` | 既存動画をベースにアフィ化。雰囲気を活かして再構成 |

## 3. 運用のコツ

- **まず15秒で試す。** 気に入ったら同じストーリーボードで30秒に伸ばす。最初から45秒を狙うと、破綻したシーンの引き当て確率が上がって作り直しコストが跳ねる
- **商品写真は多いほど一貫性が上がる。** 正面・斜め・使用シーン・パッケージ・テクスチャの5枚が目安
- **人物はChatGPT側で作って持ち込む。** Agent Mode に人物をゼロから作らせると案件をまたいで顔が変わる。`character-sheet.md` の固定キャラを使い回す
- **ストーリーボード承認は1回だけ挟む。** プロンプトに「承認したら止まらずに実行」と書いておかないと、各工程で止まって聞いてくる
- **当たった動画は同じストーリーボードで10バリエーション出す。** Agent Mode の本来の強みはここ（ヒーロークリップの量産とA/B）

## 4. 詰まった時

| 症状 | 対処 |
|---|---|
| 日本語テロップが崩れる | 焼き込ませない。テロップ台本を出させて自分で乗せる（構造的に解決しない） |
| シーンをまたいで顔が変わる | 人物画像を再アップロードし、崩れたシーンだけ `③ Grok Imagine 単体プロンプト` で作り直してスティッチ |
| クリップがループして見える | 「終端の状態を始端と変える」を該当シーンのプロンプトに追記 |
| 動きが出ない／静止画のまま | 動詞を強い語（drifts / unfurls / surges）に差し替える |
| 商品ラベルが変形する | 商品カットは生成させず、実物写真の静止画にゆっくりズームをかける形に変える |
| 途中で止まって質問してくる | OKを出して続行。次回から「承認後は止まらずに実行」を明記 |
| 尺が指定どおりにならない | 「6秒で生成して各シーンの目標尺にトリム」と、シーンごとの秒数表を渡す |
