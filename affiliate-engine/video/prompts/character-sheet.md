# ChatGPT：キャラクターシート（ベース画像の作り方）

同一の被写体（人物／動物）を安定して出せるかどうかで、このパイプライン全体の成否が決まる。
**テキストだけで毎回生成すると必ず特徴が変わる。** ベース画像を1枚作り、以降は毎回それを添付する。
手順自体はジャンルを問わず共通。ペルソナの実データは `config/briefs.json` の `personas.<domain>` を見る。

---

## 手順

### Step 1. ベース画像を1枚だけ作る（正面・素の状態）

**スキンケア案件**（`personas.skincare` — Threads @miho_yurucare と同一人格の「みほ」）

```
写真的にリアルな縦長ポートレートを1枚作ってください。
被写体: 30代前半に見える日本人女性。黒髪ミディアム、やわらかい印象の二重、
眉はナチュラル、ほぼノーメイクに近い薄化粧。気負っていない雰囲気。
特定の実在人物には似せないでください。
衣装: グレーのスウェット（部屋着）。
場所: 自然光の入る洗面台の前。白いタイル、木のトレー、生活感のある小物。
撮影: 9:16の縦構図、バストアップ、被写界深度は浅め、自然光のみ、レフ板なし。
肌は加工しすぎず、毛穴とうぶ毛が残る質感にしてください。盛らないでください。
表情はニュートラル。カメラ目線。
```

> 年齢感を30代前半にしているのは、案件（エイジングケアライン）のターゲットに合わせるため。
> 若すぎる人物にエイジングケアを持たせると訴求が刺さらないうえ、暗示型ナラティブとして不自然になる。

**ペット案件**（`personas.pet` — Threads @pet アカウント「ふく」。`docs/account-setup-kit.md` §7）

```
写真的にリアルな縦長ポートレートを1枚作ってください。
被写体: 2歳前後に見える柴犬。赤褐色の被毛、白いソックス状の足先、
立ち耳、巻き尾、人懐っこい表情。特定の実在の犬には似せないでください。
首輪: 生成り色の布首輪のみ、または首輪なし。ブランドロゴは入れない。
場所: 一般的な賃貸のリビング（フローリング）。自然光。
撮影: 9:16の縦構図、全身または上半身、被写界深度は浅め、自然光のみ。
毛並みは加工しすぎず、リアルな質感にしてください。不自然なツヤ足しはしない。
表情は穏やか。カメラ目線または少し横を向いた自然なポーズ。
```

> 子犬にしていないのは、アカウントのコンセプト「はじめて犬と暮らす人の困りごと整理」に
> 合わせるため。子犬は動物福祉の観点でも演出のハードルが上がる。

出力を見て、**特徴が好みでなければここで作り直す。**この1枚が全案件の資産になるので妥協しない。

### Step 2. キャラクターシート化（この工程を飛ばさない）

Step 1 の画像を添付して（ペットの場合は「人物」を「犬」に読み替える）：

```
この被写体の外見的特徴を、他の画像生成で同一の個体を再現するための
「キャラクターシート」として文章化してください。
（人物なら）顔の骨格、目・鼻・口の形と配置、髪の生え際と毛量、肌のトーン、体型、身長感、雰囲気を。
（犬なら）犬種、被毛の色・柄、耳と尻尾の形、体格、顔つきの特徴を。
できるだけ具体的な言葉で。主観的な形容（美しい、可愛い）は使わず、再現可能な記述にしてください。
```

出力を `config/briefs.json` の `personas.<domain>.features` に貼る。以降は毎回この文章が全プロンプトの先頭に入る。

### Step 3. カット別の差分生成

`node src/build-brief.js --id <ブリーフID>` が出力する「② ChatGPT 画像生成プロンプト」を、
**Step 1 のベース画像を毎回添付した上で**投げる。添付を忘れると特徴が変わる。

```
（ベース画像を添付）
この被写体と完全に同じ特徴を維持したまま、以下のシーンを作ってください。
（build-brief.js が出したカットNのプロンプトを貼る）
```

## 一貫性を保つコツ（リサーチで確認されたもの）

| 手法 | 効き目 | 備考 |
|---|---|---|
| **参照画像を毎回添付** | ◎ | これが最も効く。テキストのみは非推奨 |
| キャラクタープロファイルの詳細化 | ○ | 顔の特徴・服装・性格まで書くと解釈の幅が狭まる |
| シード値の固定 | ○ | 使えるツールなら固定する |
| 同一プロンプト × 同一シード × 同一 gen ID | ○ | チャットをまたいでも一貫性が保たれやすい |
| 1チャット内で連続生成する | ○ | 会話が長くなるほど崩れるので、崩れたらチャットを切って添付からやり直す |

## やらないこと

- 実在の芸能人・インフルエンサー・（ペットなら）有名犬アカウントに似せる（肖像権・パブリシティ権）
- 露出の高い服装、扇情的なポーズ（Meta ポリシー／アカウント凍結）
- 未成年に見える外見
- ブランドロゴの改変・捏造
- **状態の変化を示すビフォーアフター画像の生成**（効果の捏造。`docs/market-research.md` §3 / `docs/market-research-pet.md` §4）
- **（ペット）** 苦しんでいる・怯えているように見える表情や状況（動物福祉ポリシー違反）
