# ChatGPT：キャラクターシート（ベース画像の作り方）

同一人物を安定して出せるかどうかで、このパイプライン全体の成否が決まる。
**テキストだけで毎回生成すると必ず顔が変わる。** ベース画像を1枚作り、以降は毎回それを添付する。

---

## 手順

### Step 1. ベース画像を1枚だけ作る（正面・素の状態）

```
写真的にリアルな縦長ポートレートを1枚作ってください。
被写体: 26〜29歳に見える日本人女性。黒髪セミロング、やや目尻の下がった二重、
ナチュラルメイク、清潔感のある雰囲気。特定の実在人物には似せないでください。
衣装: オフホワイトのリブニットトップス。
場所: 自然光の入る洗面台の前。白いタイル、木のトレー、生活感のある小物。
撮影: 9:16の縦構図、バストアップ、被写界深度は浅め、自然光のみ、レフ板なし。
肌は加工しすぎず、毛穴とうぶ毛が残る質感にしてください。
表情はニュートラル。カメラ目線。
```

出力を見て、**顔が好みでなければここで作り直す。**この1枚が全案件の資産になるので妥協しない。

### Step 2. キャラクターシート化（この工程を飛ばさない）

Step 1 の画像を添付して：

```
この人物の外見的特徴を、他の画像生成で同一人物を再現するための
「キャラクターシート」として文章化してください。
顔の骨格、目・鼻・口の形と配置、髪の生え際と毛量、肌のトーン、
体型、身長感、雰囲気を、できるだけ具体的な言葉で。
主観的な形容（美しい、可愛い）は使わず、再現可能な記述にしてください。
```

出力を `config/briefs.json` の `persona.features` に貼る。以降は毎回この文章が全プロンプトの先頭に入る。

### Step 3. カット別の差分生成

`node src/build-brief.js --id <ブリーフID>` が出力する「① ChatGPT 画像生成プロンプト」を、
**Step 1 のベース画像を毎回添付した上で**投げる。添付を忘れると顔が変わる。

```
（ベース画像を添付）
この人物と完全に同じ顔・髪型・肌の色を維持したまま、以下のシーンを作ってください。
（build-brief.js が出したカットNのプロンプトを貼る）
```

## 一貫性を保つコツ（リサーチで確認されたもの）

| 手法 | 効き目 | 備考 |
|---|---|---|
| **参照画像を毎回添付** | ◎ | これが最も効く。テキストのみは非推奨 |
| キャラクタープロファイルの詳細化 | ○ | 顔の特徴・服装・性格まで書くと解釈の幅が狭まる |
| シード値の固定 | ○ | 使えるツールなら固定する |
| 同一プロンプト × 同一シード × 同一 gen ID | ○ | チャットをまたいでも一貫性が保たれやすい |
| 1チャット内で連続生成する | ○ | 会話が長くなるほど崩れるので、崩れたらチャットを切って添付からやり直す |

## やらないこと

- 実在の芸能人・インフルエンサーに似せる（肖像権・パブリシティ権）
- 露出の高い服装、扇情的なポーズ（Meta ポリシー／アカウント凍結）
- 未成年に見える外見
- ブランドロゴの改変・捏造
- **肌の変化を示すビフォーアフター画像の生成**（効果の捏造。`docs/market-research.md` §3）
