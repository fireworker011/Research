# 市場リサーチ：ペット（犬）× AI生成動画 アフィリエイト

調査日: 2026-08 / 調査手法: Web検索（一次ソースは末尾）
スキンケア案件の手法（`docs/market-research.md`）と同じ枠組みを、既存の pet アカウント
（`docs/account-setup-kit.md` §7『ふく｜いぬと暮らしの手帖』）と Furbo／ペット保険／ペットフード案件に適用する。

---

## 1. 結論

1. **アカウントの差別化方針を壊さない。** 既設のコンセプトは「かわいい写真系が飽和する中、健康・お金・しつけの実用情報で差別化」。動画も可愛さの消費で終わらせず、必ず Furbo／保険／フードのどれかに接続する
2. **恐怖訴求ではなく好奇心訴求。** 「見守りカメラがないと何かあった時に大変」ではなく「覗いたら意外とかわいかった」の方向で作る。動物の危険・苦痛を演出に使うと、TikTok の動物福祉ポリシー（虐待・ネグレクト・搾取は一切許容しない）に触れる
3. **ペット保険・ペットフードは、スキンケアの薬機法とは別系統の規制がある。** 保険業法（比較の誤認防止・断定表現の禁止）とペットフード公正取引協議会のガイドライン（効能効果を言えない構造は薬機法と同型）。詳細は `docs/compliance-checklist.md` A' 節
4. **AI生成の動物は、スキンケアのAI美女と同じ危うさを持つ。** 実在しない犬の「体験」「変化」を証拠として使えば、体験談の捏造（不変条件5）と優良誤認（景表法）の両方に触れる。暗示型ナラティブと同じ考え方で、AI犬は「世界観」の担保に限定する
5. **犬の生成はAI画像/動画の弱点が出やすい部位が人物と異なる。** 顔ではなく毛色・柄の一貫性、耳・尻尾の形、四肢の破綻が主な事故ポイント。プロンプトの「変えてはいけないもの」をそちらに向ける

## 2. 既存アカウント資産との整合

`docs/account-setup-kit.md` §7 に、開設済みのコンセプト・ペルソナ・固定投稿がある。これを動画の設計に流用した。

| 既存資産 | 動画への反映 |
|---|---|
| コンセプト「はじめて犬と暮らす人の困りごと整理」 | 型を実用情報寄りに設計（獣医に聞いた話型、お金のリアル型） |
| ターゲット「犬と暮らす（暮らし始める）25〜50歳」 | ペルソナの犬は2歳前後の成犬（子犬にしない） |
| プロフィール文「迷ったら病院へ、が基本方針」 | 獣医に聞いた話型で、保険・医療費を煽らず情報提供に徹する設計に反映 |
| 固定投稿「生涯200〜300万円といわれます」 | お金のリアル型（`pet_p4_cost_reality`）でそのまま映像化 |
| 既存テンプレ `pet_101`〜`103` の切り口 | 3案件（Furbo／保険／フード）それぞれの型のベースにした |

## 3. 商材ごとの型

### Furbo（見守りカメラ）

既存テンプレ（`pet_101`, `pet_20260708_03`）が繰り返し使っている「留守番中の様子が気になる」という切り口が最も反応が良い。これを恐怖訴求ではなく好奇心訴求に振った。

- `pet_p1_furbo_curiosity`（留守番のぞき見型）: 見送り→静かな部屋→カメラ視点でうたた寝→安心のオチ、という「覗いたら大丈夫だった」の構造
- `pet_p2_doorstep_wait`（お出迎え儀式型）: 帰宅時の出迎え行動。恐怖要素ゼロで生活導入として使える汎用型

### ペット保険

保険は最も規制リスクが高いジャンルの一つ。保険業法は「客観的事実に基づかない数値の表示」「一部のみを表示して誤解させる比較」を禁止しており、断定的な支払い保証表現は論外。

- `pet_p3_vet_reply`（獣医に聞いた話型）: コメント返信フォーマットで、契約を煽らず「比較してから決めた」という自分の判断の共有に留める
- `pet_p4_cost_reality`（お金のリアル型）: 数字は固定投稿で既に使っている一般的な相場（生涯200〜300万円）のみ使用。実在の病院・請求書を模した画は作らない

### ペットフード

ペットフード公正取引協議会のガイドラインが、化粧品の薬機法と同型の制約を課す。「グルコサミンで関節が良くなる」はNG、「グルコサミンは軟骨の構成成分です」はOKという構造。

- `pet_p5_food_texture`（ごはん比較型）: テクスチャ・原材料表示の事実提示に徹する。既存テンプレ `pet_103`「原材料と成分値の見方」の映像化

## 4. AI生成の犬について

### なぜ「証拠」に使わないか

スキンケアのAI美女画像と同じ理由。AI生成の犬に「この保険で救われた」「このフードで毛並みが変わった」と語らせれば、以下すべてに同時に触れる。

- **体験談の捏造**（本リポジトリの不変条件5）: 実在しないペットの実在しない体験
- **景品表示法（優良誤認）**: 存在しない効果を示す表示
- **保険業法／ペットフード公正取引協議会**: それぞれの業法上の禁止表現に直結する

そのため、AI犬は「世界観・生活の雰囲気」を作る用途に限定し、状態の変化・効果を見せる画は作らない設計にした（`data/domains/pet/domain.json` の `forbidden_visuals`）。

### 生成時の弱点（人物との違い）

スキンケア用の人物生成では「顔・髪型・肌の色・衣装」が崩れやすい部位だったが、犬の場合は次が主な事故ポイントになる。

- 毛色・柄の一貫性（特に柴犬のような複雑な差し毛パターン）
- 耳の形・立ち方、尻尾の巻き方
- 四肢の本数・関節の不自然な曲がり（動物のAI生成全般に共通する弱点）
- クリップ間で犬種そのものが変わって見える

`agentModePrompt` の「変えてはいけないもの」はこれに合わせて `stability_ja`/`stability_en`（`data/domains/pet/domain.json`）で毛色・柄・耳・尻尾・体格・首輪を明示している。

### 音声を作らせない

犬にセリフを喋らせる・不自然な鳴き声を出させる演出は使わない。AI音声の不自然さがそのまま「広告っぽさ」「気持ち悪さ」に直結し、実用情報アカウントのトーンとも合わない。

## 5. プラットフォームポリシー：動物福祉

TikTok は動物虐待・残虐行為・ネグレクト・搾取をいかなる形でも許容しないと明言しており、**演出であっても強い不快感を与えるものはNG**とされている。恐怖訴求（「何かあったら」）を避け、好奇心・安心感の訴求に振っているのはこのため。AI生成であっても「苦しんでいる／放置されているように見える」画は同じ扱いを受けるリスクがあるため作らない。
