# 投稿前チェックリスト（スキンケア動画）

`node src/build-brief.js` は禁止語と広告表記を機械的に検査するが、**画（え）の中身は機械では検査できない**。
投稿前にこのリストを人間が1回通す。1本1分で終わる。

---

## A. 薬機法（最重要・課徴金は売上の4.5%）

化粧品が広告できる効能効果は厚労省の**56項目**に限定される。範囲外の標ぼうは、映像・音声・テロップ・キャプションのどこに書いてもアウト。

- [ ] 「治る」「改善」「効く」「消える」を1つも使っていない
- [ ] シミ・シワ・ニキビ・毛穴が「なくなる／消える」と言っていない
- [ ] 「使えば使うほど肌が白くなる」系の表現がない
- [ ] 一般化粧品で「美白」を効能として言っていない（言えるのは**メーキャップで白く見せる**まで。例：「ファンデーションでシミ・ソバカスをきれいに隠し、お肌を白くみせてくれる」）
- [ ] 医薬部外品なら、美白は**「メラニンの生成を抑え、しみ・そばかすを防ぐ」**の言い回しに揃えている（"防ぐ"＝予防。"消す"ではない）
- [ ] 医薬品的な効果（アトピー、肌荒れの治療など）を想起させていない
- [ ] 最大級表現（No.1、最強、世界初）を根拠なく使っていない

### NG → OK 言い換え早見

| NG | OK |
|---|---|
| シミが消える | （効能としては言えない。テクスチャ・使用感の話に振る） |
| 毛穴が消える | 毛穴が目立ちにくく見える／メイクのりが変わる（主観として） |
| ニキビが治る | （医薬品領域。触れない） |
| 肌が生まれ変わる | 肌をすこやかに保つ（56項目内） |
| 美白になる | メラニンの生成を抑え、しみ・そばかすを防ぐ（**医薬部外品のみ**） |
| 保湿力が高い | うるおいを与える／乾燥を防ぐ |

## B. 景品表示法・ステマ規制（2023年10月施行）

金銭または商品の提供を受けている場合、個人アカウントでも「広告」。

- [ ] キャプションに `#PR` が入っている（`compliance.checkContent()` が自動付与するが目視確認する）
- [ ] `#PR` がハッシュタグの海に埋もれていない（先頭付近に置く）
- [ ] 他社製品との優劣を、実測の根拠なく断定していない（比較広告）
- [ ] 案件規約で比較・ブランド名の出し方が制限されていないか確認した

## C. 体験談・レビューの扱い（本リポジトリの不変条件5）

- [ ] **AI生成の人物に一人称の使用感を語らせていない**（音声・テロップとも）
- [ ] 「◯週間使ったら」のような使用経過の主張をしていない（実際に使っていない限り）
- [ ] レビューを引用する場合、出所が公開情報である
- [ ] 懐疑→転向型（`p4_skeptic_convert`）を使う場合、語り手は**運用者本人**である

## D. AI生成コンテンツの表示

- [ ] 投稿時にプラットフォームのAIラベルをONにした（Instagram / Threads / TikTok）
- [ ] キャプションに「※映像はAI生成です」を入れた
- [ ] 実在の人物・芸能人に似ていない
- [ ] 未成年に見えない

> 2026年7月時点で、日本にSNS投稿のAI表示を一律義務づける法律はない。ただし Meta のガイドラインは現実と見紛うAI生成の動画・画像にラベル表示を求めており、TikTok は2026年Q1だけで合成メディアポリシー違反として230万本超を削除している（前年同期比+180%）。**義務がないから付けない、ではなく、凍結を避けるために付ける。**

## E. プラットフォームポリシー

- [ ] 露出・扇情的表現がない（Meta ポリシー／既存の `compliance.js` BLOCKED_PATTERNS と同じ線）
- [ ] ビフォーアフターの直接表現をしていない（Meta / TikTok とも広告ポリシー上の制限がある）
- [ ] 他人の動画・音源をそのまま複製していない
- [ ] 商用利用可能なBGM・SFXを使っている

## F. 映像の品質（Grok の既知の弱点）

- [ ] クリップ間で顔・髪型・肌の色・衣装が変わっていない
- [ ] 手指が破綻していない
- [ ] 商品ラベルが変形・文字化けしていない
- [ ] 不自然な物理挙動（液体が逆流する等）がない
- [ ] 冒頭0〜2秒に商品名・ロゴが出ていない
- [ ] テロップが画面中央60%以内に収まっている

## 自動チェックで拾えるもの／拾えないもの

| | 自動（`build-brief.js` + `compliance.js`） | 人間 |
|---|---|---|
| 禁止語（テロップ・キャプション） | ○ | — |
| `#PR` の有無 | ○（自動付与） | 位置の確認 |
| 記入漏れプレースホルダ | ○ | — |
| 画の中身（ビフォーアフター、露出、破綻） | ✕ | **必須** |
| 案件ごとの規約 | ✕ | **必須** |
| 56項目の逐条判定 | ✕（禁止語リストによる粗いフィルタのみ） | **必須** |

禁止語リストは `data/hooks.json` の `banned_in_hooks` と `../../src/compliance.js` の `BLOCKED_PATTERNS`。
事故った表現を見つけたら**必ずリストに追記する**。同じ事故を二度起こさないための唯一の仕組み。
