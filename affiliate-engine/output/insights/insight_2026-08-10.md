# インサイトレポート 2026-08-10

## 転職

**市場トレンド（Web検索による）**
- Threadsは画像より言葉が伸びやすく、共感や会話を誘う一文（本音・観察系）が保存・コメントを集めやすい構造になっている（<cite index="1-1">Threadsは画像より言葉のほうが圧倒的に伸びやすい</cite>）
- 2026年春時点で求職者の約6割が『買い手市場』を実感しており、人手不足という実態とのギャップが話題になりやすい（<cite index="11-1">約6割が「買い手市場」を実感。人手不足の現状と求職者の市場実感にギャップ</cite>）
- 選考ハードルの上昇と専門性・実績要求の厳格化が求職者の共通の悩みとして語られやすい（<cite index="11-1">8割以上が選考ハードル上昇を痛感。専門性・実績への要求がよりシビアに</cite>）
- AI/DX人材需要の高まりと『衰退リスクの高い業界』論、ポータブルスキルの重要性がキャリア系コンテンツの定番話題になっている（<cite index="10-1">AI/DX人材を中心に高度な専門人材の確保を急務とする企業の増加が見込めます</cite>）
- 2026〜2027年にかけて働き方に関する法改正の動きが本格化し、『ルールを守る企業』を見極める視点が求職者の関心を集めている（<cite index="4-1">2026年〜2027年にかけては、働き方そのものを見直す法制度の動きが本格化すると見られています</cite>）

**自アカウント実測の所見**: 現時点で実測データのサンプルサイズが0件のため、伸びた投稿・伸びなかった投稿の傾向を数値で比較できる状態にありません。ただし要件定義にある『質問だけの投稿はいいね率0.1%』という既知の課題から、意見表明のない中立的な問いかけ単体では反応が薄いことは確認済みです。まずは新テンプレで意見先出し型を最低5〜10本投稿し、いいね率・保存率を比較できるデータを蓄積する必要があります。

**改善アクション**
- [ ] 1行目を『数字』か『はっきりした意見』で始める投稿を最低5本連続で試し、質問始まりの投稿と比較していいね率の差を検証する
- [ ] 『買い手市場ギャップ』『選考ハードル上昇』など市場トレンドの話題に、書き手自身の立場（例：私は◯◯派）を明言して乗せる
- [ ] チェックリスト形式（3〜5項目の判断基準）を必ず1本に1つ入れ、保存率を計測する
- [ ] エージェント紹介など直接CTA投稿は全体の中で1本に限定し、残りは価値提供型で信頼を積み、リンク投稿の反応率を比較する

## ペット

**市場トレンド（Web検索による）**
- ChatGPTの画像生成でペットを“擬人化”する投稿が急増し、実際に「ペット擬人化」がThreadsトレンド1位を獲得するほど拡散力が高い切り口になっている
- AI生成の“癒し系”ペット動画（AI犬・AI猫など）が短時間で爆発的に伸びるケースがあり、ウケた型を犬→猫→他の動物へと横展開するシリーズ化が有効とされている
- 保護犬・保護猫という「困難→幸せ」のストーリー性を持つアカウントが強い共感を集め、ペットフードやケア用品とのタイアップとの親和性が高いと評価されている
- Threadsは画像より言葉（テキスト）の投稿の方が伸びやすく、心情に触れる一言が保存や会話を生みやすい設計になっている
- インプレッションの約半分がリプライ経由で生まれるため、コメントを誘発する「会話設計」が露出増の鍵になっている

**自アカウント実測の所見**: 現時点でサンプル数・平均ビュー・top3/bottom3のいずれも実測データが0件のため、傾向分析はまだ不可能な状態です。ただし別途得られている知見として、質問だけで終わる投稿はビューは出てもいいね率が0.1%と低く留まっており、意見や結論を先に出さない構成がエンゲージメントに繋がっていないことが示唆されます。

**改善アクション**
- [ ] 直近10〜20投稿分のビュー・いいね・保存・リプライ数を記録し、伸びた投稿と伸びなかった投稿を1行目の型（意見/数字始まりか質問始まりか）で仕分けして相関を可視化する
- [ ] 質問オープナーを廃止し、全投稿の1行目を「結論」または「具体的な数字」で始める型に統一する
- [ ] AI擬人化・AI動画トレンドは模倣せず、その“保存されやすい構造”だけを抽出し、フード選びやケア用品選びの「基準・チェックリスト」型コンテンツに転換する
- [ ] 各投稿の末尾に軽い問いかけを1つ入れてリプライを誘発し、会話数を伸長トリガーとして次回投稿の切り口に反映する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 睡眠

**市場トレンド（Web検索による）**
- 夜20〜22時台の投稿は「共感・本音トーク」系が伸びやすい傾向がある一方、朝7〜9時は「今日も頑張ろう系」が伸びやすいというデータがある
- Threadsは画像より言葉（テキストのみ）の投稿が伸びやすく、本音・弱さを見せる短文が保存・会話を生みやすい
- 「〜投稿」を10本テストした実験では、時間帯×テーマの相性で反応率（いいね・リプライ・保存）が2倍以上変わったという再現性のある型が確認されている
- アルゴリズムはいいね数よりも「リプライがつき会話が続いたか」を重視するため、断定的な意見や具体的な基準を提示してコメントを誘発する投稿が優遇されやすい
- 逆に「エンゲージメント狙いの釣り投稿」は増加傾向にあり、Threads側が対策を進めているため、実質的な情報価値のない質問だけの投稿は評価が下がりやすい

**自アカウント実測の所見**: 実測データはサンプル数0件のため、伸びた投稿・伸びなかった投稿の傾向を定量的に比較することはできません。今回は市場トレンドをベースに仮説を構築し、次回計測分から実測データとの突き合わせを行う必要があります。

**改善アクション**
- [ ] 1行目を必ず「具体的な数字」または「はっきりした意見（◯◯派、結論◯◯でいい）」で始める構成にテンプレートを統一する
- [ ] 投稿時間を夜21〜22時台（共感・本音トーク向き）と朝7〜9時（実用Tips向き）の2枠に絞ってABテストする
- [ ] 質問だけで終わる投稿を廃止し、意見・基準提示→軽い問いかけの順序に統一する
- [ ] 投稿後1時間はコメントに即レスし、初速エンゲージメントを上げてアルゴリズム評価を狙う

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
