# インサイトレポート 2026-08-17

## 婚活

**市場トレンド（Web検索による）**
- 「婚活あるある」形式で、最初の高揚感→数か月後の変化（審査モード化）という時系列のビフォーアフター構造が強く支持されている
- 婚活を「採用面接」「チェックリスト」に例えて自虐的に笑いに変える切り口が拡散されやすい
- 街中や日常で偶然見かけた他人のカップルを観察し、距離感やモラハラの兆候を読み解く『第三者観察型』投稿が伸びている
- 『〜派』と自分の立場を明言してから、理由や基準を語る構造の投稿が支持を集めている
- 同棲・プロポーズ前の男女のズレなど、心理面の『罠』を指摘するマインド系の切り口も一定の反応を得ている

**自アカウント実測の所見**: 自アカウントの伸びた投稿（991views/8likes）は「①②③」の数字リストと自分の観察結論を先出しした構造で、実用性の高いチェックリストが機能している。一方540viewsの投稿は「私は◯◯派」の意見表明はあるものの、市場で伸びている『時系列のビフォーアフター』や『他人観察の物語性』が弱く、単なる基準列挙で終わっている点が差になっていると考えられる。

**改善アクション**
- [ ] チェックリスト単体ではなく「最初は〜→気づいたら〜」のようなビフォーアフター構造を組み込み、共感と実用性を両立させる
- [ ] 自分の体験談を捏造せず、街中や第三者の会話を『観察している』体で切り取る客観描写型の切り口を増やす
- [ ] 1行目の『はっきりした意見』の後に、必ず具体的な数字（3つ、2時間、24時間以内など）を伴う基準を続け、保存性を高める
- [ ] 質問だけで終わる投稿をやめ、意見→基準→軽い問いかけの順序を毎回守る

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 副業

**市場トレンド（Web検索による）**
- 「最近○○が流行ってるけど、私は△△派」のように、話題に対して自分の立場を一言添える『意見表明型』投稿が反応されやすい傾向が見られる。<cite index="10-1">「最近○○が流行ってるけど、私は△△派！」のように、ひとことコメントを添えるだけでも反応されやすいです。</cite>
- 冒頭で結論や結果を先に見せてから手順を展開する『結果先出し型』の構成が採用されている。<cite index="10-1">最初に「どんな結果になるのか」を見せると、読者が興味を持ちやすくなりますよ。</cite>
- 「乾燥肌におすすめ化粧水5選」のような情報を絞ったリスト・チェックリスト形式は保存目的で拡散されやすい。<cite index="14-1">Threadsは「乾燥肌におすすめ化粧水5選」や「ダイエットにおすすめのコンビニ食品」のように、情報がまとまった画像は保存されやすいです。</cite>
- ジャンルを『副業×節税』のように2軸に絞って専門性を出すポジショニングが集客に有効とされている。<cite index="12-1">「美容×時短」「副業×節税」など、ターゲットの悩みを解決するテーマを1〜2つに絞り込みましょう。</cite>
- 冒頭のフックには『知らなきゃ損する』『初心者が絶対やりがちな失敗』のような疑問喚起型の一言が使われ、離脱を防ぐ工夫がされている。<cite index="13-1">例えば「知らなきゃ損するThreads攻略法」や「初心者が絶対やりがちな3つの失敗」など。 · こうした〝キャッチーで疑問を喚起する一言〟は、高い確率で読み進めてもらえます。</cite>

**自アカウント実測の所見**: 実測データが未取得（サンプル数0）のため定量比較はできないが、運用側で確認済みの傾向として『質問だけで始まる投稿』はビュー数は出てもいいね率0.1%に留まっている。これは市場トレンドで見られる『意見表明→根拠→問いかけ』という順序と逆になっており、読者が態度を決める前に問いだけを投げているため反応が浅くなっている可能性が高い。

**改善アクション**
- [ ] 1行目を疑問文から『数字』または『はっきりした意見』に変更し、書き手の立場（◯◯派・結論◯◯でいい）を冒頭2文以内で明言する
- [ ] 本文中に保存価値のあるチェックリスト・基準（3〜5項目）を必ず1つ入れ、リスト形式の保存需要を取り込む
- [ ] ジャンルを『副業×初心者の選び方』『副業×継続の仕組み』のように2軸に絞り、投稿ごとのテーマのブレを減らす
- [ ] 質問で締める場合も、必ず自分の意見・結論を先に出したうえで軽く問いかける形に統一し、投稿後1時間は反応対応を行う

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 美容

**市場トレンド（Web検索による）**
- 「お悩み解決」型コンテンツが強い：乾燥肌対策や簡単ヘアアレンジなど、悩みに寄り添う実用情報が支持されやすい
- 最初の一文のフックが勝負：数字や「知らないと損する」など読むと得する言葉を冒頭に置く投稿が反応を集めやすい
- 『メリット＋意外性』の組み合わせが伸びやすい構成として挙げられている（例：3日で変わる系、実はNG系の切り口）
- 美容系コンテンツでは「万能成分」「AI診断・パーソナライズ」「クリーンビューティー」という個別最適化・無駄ゼロ思想が共通テーマになっている
- 美容・育児など生活密着型ジャンルはThreadsで成功事例が多いジャンルとされている

**自アカウント実測の所見**: 2投稿とも中立的な一般論・情報提示にとどまり、書き手自身の立場や結論を先に打ち出せていないため、閲覧はされてもいいねに繋がっていない（実測いいね0）。季節ネタの投稿（728ビュー）は具体的な行動例（重ねづけ・乳液を早める）を含んでいたため相対的に伸びたが、レチノール投稿（397ビュー）は意見表明はあるものの1行目が説明文から入っており、フックが弱かったと考えられる。

**改善アクション**
- [ ] 1行目を「私は◯◯派」「結論、◯◯でいい」という明確な意見表明に統一し、質問文や前置き説明から入らない
- [ ] 保存要素（チェックリスト・番号立て手順・判断基準）を必ず1つ以上入れて実用性を担保する
- [ ] 『メリット＋意外性』の型（当たり前だと思われていることへの逆張り・実は系）を切り口として積極活用する
- [ ] 質問で締める場合も、自分の結論・体験的観察を述べた後に軽く問いかける形に統一し、質問単体で終わらせない
