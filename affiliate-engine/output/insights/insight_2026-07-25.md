# インサイトレポート 2026-07-25

## 筋トレ

**市場トレンド（Web検索による）**
- 冒頭で読み手の悩みや状況を一言で言い当てる「フック型」の書き出しが視聴维持・保存率を伸ばしている（美容師リール分析でも同様の型が高反応）
- 「結果を先に見せてから理由を説明する」構成（〇選、法則、比較）で最後まで読ませる投稿が伸びやすい傾向
- 問いかけ・二択（例：「あなたは◯派？△派？」）で返信を誘発する投稿がコメント数を伸ばす型として定着
- Threads全体が『会話を深めるSNS』へ進化し、バズより関係密度・信頼構築を重視するアカウントが評価されやすい流れ
- 箇条書き＋絵文字で視覚的に区切った「型化コンテンツ」（ポイント5選など）が保存されやすい

**自アカウント実測の所見**: サンプル数が1件のみのため統計的な断定は難しいが、唯一のデータは「継続設計」という一般論的な気づきを短く提示した投稿で、閲覧1322に対し保存や返信を誘発する明確な問いかけ・箇条書き構造がなく、いいね数も1と低い。フック（悩み提示）や結末の質問締めが欠けている点が、エンゲージメント率を抑えている可能性がある。

**改善アクション**
- [ ] 冒頭1行に「あるある悩み」や「意外な事実」を提示するフック構文を追加し、自分ごと化を促す
- [ ] 文末に一問一答形式ではなく『あなたはどっち派？』のような二択・共感を誘う問いかけを必ず入れて返信率を上げる
- [ ] 箇条書き（3〜5点）で『継続のコツ○選』のように型化し、保存されやすい構造に変える
- [ ] 認知拡大フェーズ中はリンク入り投稿を全体の3割以下に抑え、価値提供型・質問型を主軸にする

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 教育

**市場トレンド（Web検索による）**
- <cite index="10-1">アカウントの属性で届く先が固定されにくく、育児や日常の共感ネタは専門ジャンル外の層にも届きやすい</cite>という傾向が指摘されており、教育ジャンルでも「家庭の価値観の違い」を扱う投稿が広く拡散しやすい
- <cite index="9-1,13-1">最初の一文で興味を引けるかどうかが勝負であり、読まれる投稿の多くは「メリット＋意外性」の組み合わせを使っている</cite>ため、冒頭で対比構造を提示するフックが重視されている
- <cite index="10-1">フォロワーが少なくてもチャンスがあるのは、投稿単位でアルゴリズムが評価するため</cite>であり、いいね・コメントが集まりやすい「二択で答えられる問いかけ」型が引き続き強い
- <cite index="12-1">自己満足型の投稿や一方的な発信はエンゲージメントが低下しやすい</cite>とされ、断定的な結論を先に言い切る投稿より、読者に委ねる中立的な問いの方が反応を得やすい傾向
- <cite index="12-1">アンケートや質問を取り入れることでエンゲージメントの向上が期待できる</cite>という指摘通り、家庭内の「あるある選択」を二択質問で締める構造が定番化している

**自アカウント実測の所見**: 伸びた上位3本はいずれも「Aタイプ家庭 vs Bタイプ家庭」という中立的な二項対立の観察を提示し、断定を避けたまま最後に開かれた質問で締めており、読者が『自分はどちら派か』を考えやすい構造になっている。一方、下位3本は『月謝の上限』という金銭ネタで比較対象が弱かったり、『点数が伸びやすいのは後者』のように自分の意見を先に断定してしまい対話の余地が狭まっていたり、そもそも問いかけがなく一方的な気づき共有で終わっている点が共通していた。

**改善アクション**
- [ ] 上位投稿に共通する『二項対立の家庭観察→中立表現→二択の質問』の型を教育ジャンルの新しい切り口（叱り方・褒め方・朝の支度・忘れ物対応など）に展開し、投稿本数を増やす
- [ ] 断定的な意見（『後者の方が伸びやすいと感じる』等）は先出しせず、両方の言い分を並列で提示してから問いを投げる形に統一し、コメント欄での対話余地を残す
- [ ] 月謝・費用など金銭系ネタは反応が弱かったため、認知拡大フェーズでは優先度を下げ、日々の関わり方・価値観の違いをテーマにした投稿を中心に据える
- [ ] 冒頭一文に『対比またはちょっとした意外性』を置く構成を徹底し、絵文字は視認性を保つため1つ程度に絞る

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 節約

**市場トレンド（Web検索による）**
- <cite index="9-1">Threadsはコメントのやりとりが評価される会話型SNSで、いいねが多い投稿よりも、コメントでやりとりされている投稿の方が評価されやすい</cite>ため、節約ジャンルでも家計の悩みへの共感コメントを誘う短文投稿が伸びやすい
- <cite index="2-1">Threadsは画像より言葉のほうが圧倒的に伸びやすく</cite>、生活のリアルな本音・あるあるを一言で切り取る投稿が保存・会話を生む切り口として目立つ
- <cite index="3-1">Threadsでは、投稿頻度が高いほど、1投稿あたりのインプレッション（表示回数）も増加する傾向がある</cite>ため、節約系でも小ネタ・チェックリストの高頻度投稿が支持されやすい
- <cite index="6-1">Threadsはアルゴリズム上「フォロワー数よりも投稿内容」で露出が決まる</cite>ため、フォロワーが少ない節約アカウントでも切り口次第で伸びる余地がある
- <cite index="2-1">最も伸びる時間帯は7時〜9時／12時〜14時／21時〜24時と言われている</cite>ため、家計・節約情報を朝の通勤時間や夜のリラックスタイムに合わせて投稿する動きが見られる

**自アカウント実測の所見**: 現状 sample_size=0 で自アカウントの実測データが取得できていないため、伸びた投稿／伸びなかった投稿の比較分析は不可。まずは市場トレンドに沿ったテンプレで投稿数を確保し、次回分析用のデータ（views・保存・返信数）を蓄積することを優先すべき段階。

**改善アクション**
- [ ] 投稿を7〜9時／12〜14時／21〜24時の枠に集中させ、初動の反応（いいね・リプライ）を最大化する
- [ ] 1投稿1テーマの短文・共感型（あるある・本音）投稿の比率を増やし、保存とリプライを狙う
- [ ] 質問で締める投稿を毎回セットにし、リプライ数を伸びのKPIとして週次で計測開始する
- [ ] 認知拡大フェーズにつきリンク投稿は全体の1〜2割以下に抑え、価値提供型投稿でフォロワー基盤を先に作る

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
