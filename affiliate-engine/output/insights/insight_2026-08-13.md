# インサイトレポート 2026-08-13

## 転職

**市場トレンド（Web検索による）**
- 単発の「バズ」よりも継続的な信頼構築が評価される流れが強まっており、感覚的な「伸びました」ではなく「インプレッションが1.8倍になった」のような具体的な数字を伴う成果提示が支持されやすい
- 投稿の型として「気づき・失敗談・数字・問いかけ・裏側」の5パターンを使い分け、中身だけ差し替えて継続発信するアカウントが結果を出している
- 「〇〇の特徴トップ7選」のようなランキング形式や、判断基準・チェックリストを提示する保存型フォーマットが好まれる
- 採用・転職テーマでは「求人広告」ではなく「仲間募集」のようなカジュアルな温度感で、企業や個人の“素の姿”を見せる投稿が反応を集めやすい
- Threadsは地域親和性や会話性を重視するアルゴリズムのため、断定的な意見表明→共感→軽い問いかけで締める投稿がコメント・いいねを誘発しやすい

**自アカウント実測の所見**: 実測では質問だけで始める投稿はビューは獲得できてもいいね率が0.1%に留まっており、閲覧はアルゴリズムに乗っても『意見や数字の欠如』がいいね・保存という深い反応への転換を妨げていると考えられる。現状はsample_sizeが0のため定量的な上位/下位投稿の比較はできず、まずは意見先出し型のテンプレートでABテストデータを蓄積する必要がある。

**改善アクション**
- [ ] 1行目を質問ではなく「私は◯◯派」「結論、◯◯でいい」という意見・数字の明言に統一し、質問はCTA直前の締めのみに限定する
- [ ] 各投稿に判断基準・チェックリスト・比較ポイントなど保存要素を最低1つ組み込み、いいね率だけでなく保存率もKPIに追加する
- [ ] 気づき型・失敗談型・数字型・裏側型の4テンプレートをローテーションし、どの型が自アカウントで最も反応が良いかをsample_sizeが貯まった時点で比較する
- [ ] 採用・転職エージェント紹介系の投稿は『求人広告』トーンを避け、担当者との相性や面談スピードなど生活者視点の“素の情報”として書く

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## ペット

**市場トレンド（Web検索による）**
- <cite index="9-1">SNS「Threads」で、ChatGPTの画像生成機能を使い、愛犬や愛猫を擬人化して投稿する行為がはやり始め、「ペット擬人化」がトレンド1位になった</cite>
- <cite index="9-1">特に小型犬をおじさんのように擬人化したり、子犬や子猫を赤ちゃんのようにしたりする投稿が可愛らしいとして関心を集めている</cite>
- <cite index="8-1">AI生成の犬・猫動画による「純粋な癒し」系投稿が約24時間で24万回表示、1.7万を超える「いいね」を獲得した事例もある</cite>
- <cite index="2-1">Threadsのアルゴリズムは関心がありそうな投稿をAIが個別に判断して表示するため、刺さる投稿一本でバズが起こりやすく、コメントから会話が生まれることでスコアが上昇し露出が増える仕組みがある</cite>
- <cite index="13-1">ペット関連の「お得な案件」情報には愛犬・愛猫家が強く反応する傾向があり、怪しい案件投稿でも400件近いコメントを集めるケースが見られる</cite>

**自アカウント実測の所見**: 現在の実測データはsample_size=0で投稿数・平均ビュー・上位/下位投稿とも記録がなく、傾向分析ができる状態にない。既知の課題として「質問だけ」の投稿はビューは出てもいいね率0.1%に留まったとの実測があるため、まずは意見・数字始まりの投稿でデータを蓄積し、比較検証できる状態を作る必要がある。

**改善アクション**
- [ ] 直近10〜20投稿分の「1行目のタイプ（数字/意見/質問）」「いいね率」「保存要素の有無」を記録し、質問始まり投稿の実測比較データを作る
- [ ] 1行目を必ず数字またははっきりした意見で始める運用ルールを固定し、質問始まりの投稿は当面停止する
- [ ] AI擬人化・癒し系トレンドに便乗する場合も、単なる可愛い画像投稿ではなく『自分の意見＋判断基準』を添えて他アカウントとの差別化を図る
- [ ] 保存要素（チェックリスト・数値基準）を毎投稿に最低1つ入れ、保存率を新たなKPIとして計測する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 睡眠

**市場トレンド（Web検索による）**
- 夏の暑さやお盆休みで生活リズムが乱れ、「眠れない」という共感型のつぶやきが相互に拡散される現象が起きている
- Threadsは「刺さる投稿一本」でフォロワー数に関係なくバズが起きやすく、共感を呼ぶ短い一言投稿が保存・会話を生みやすい
- いいね数よりコメントでのやり取りの多さが評価されやすく、共感を呼べる投稿の方が伸びやすい構造になっている
- 「なぜそれが起きるのか」「どうすれば再現できるのか」を言語化した“構造のある投稿”が保存・議論・再利用につながりやすい
- 長文よりも3行程度の短文＋箇条書き・チェックリスト形式が保存されやすい傾向がある

**自アカウント実測の所見**: 現時点でサンプル数0件・平均ビュー0のため統計的な傾向は算出できていない。ただし過去の実測で「質問だけで始める投稿」はビューは出てもいいね率0.1%に留まったことから、閲覧はされても感情的な反応（いいね）や関係構築（フォロー）にはつながっていないと考えられる。まずは投稿ログを再開し、意見先出し型とチェックリスト型で比較検証するデータ基盤を作る必要がある。

**改善アクション**
- [ ] 1行目を「結論、◯◯派」「◯◯以下だと眠りが浅い」など数字か明確な意見で始めるテンプレに全面切替し、質問始まりの投稿を廃止する
- [ ] 共感を呼ぶ観察型（暑さ・お盆による生活リズムの乱れなど季節ネタ）を週1〜2回、意見＋チェックリストの構造で投稿する
- [ ] コメントでの会話発生を狙い、意見を明言した後に軽い質問を添えて締める形式に統一する
- [ ] 投稿ごとにビュー・いいね率・保存数を記録し、意見先出し型 vs 質問先出し型で比較できるログ体制を再構築する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
