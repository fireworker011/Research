# インサイトレポート 2026-08-02

## 婚活

**市場トレンド（Web検索による）**
- 婚活を「採用面接」など別の物事に例えるメタファー型投稿が高共感を集めている（プロフィール条件確認が面接っぽくなる、という構造）
- 「〜あるある」形式で婚活中の心理変化を段階的に描写し、最後に気づき・教訓で締める構成が保存・共感を誘発している
- 結婚相談所や周囲から言われがちな「わきまえて」的な違和感を、当事者の観察・体験共有として投げかける投稿が反応を集めやすい
- 「〜な男性/女性がドキッとする○選」のようなリスト形式（数字＋選）が読みやすさと保存性を高めている
- 婚活・恋愛における思い込みを手放すマインドセット系投稿で、最後に「書き出してみて」等の自己ワークを促す質問締めが返信を誘発している

**自アカウント実測の所見**: 現時点で自アカウントの実測データ（sample_size=0、閲覧数・上位/下位投稿とも未取得）が存在しないため、伸びた/伸びなかった投稿の比較分析ができない。まずは投稿を蓄積し、次回分析で切り口別・投稿時間帯別の反応差を検証できる状態を作る必要がある。

**改善アクション**
- [ ] 直近1〜2週間で最低5〜10本投稿し、閲覧数・保存数・返信数を切り口別（あるある型/リスト型/観察型/質問型）に記録してベースラインを作る
- [ ] リンク誘導は最大1本/週に抑え、認知拡大フェーズの方針通り「保存したくなる価値提供」と「返信したくなる質問」を投稿の8割以上に配分する
- [ ] 婚活を別の物事（面接・買い物・スポーツ等）に例えるメタファー構造と、数字リスト構造の2パターンをテンプレとして交互にテストし、どちらが自アカウントで反応が良いか比較する
- [ ] 投稿末尾の締め方を「断定的な教訓」ではなく「読者に問いかける一文」に統一し、返信率の変化を追跡する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 副業

**市場トレンド（Web検索による）**
- 「後で見返したい有益なリスト」や「マインドセット」系投稿が保存目的でリポストされやすい傾向が続いている
- バズっている投稿の返信欄に自分から出向き、深掘りコメントや共感コメントを残すことで自アカウントへの流入を作る手法が定着しつつある
- フォロワー外リーチが強いアルゴリズム特性を活かし、フォロワー数に関係なく『役立つ単発投稿』を継続的に打つアカウントが伸びている
- AI活用・不動産投資・ライフハックなど『このジャンルならこの人』という特化ポジショニングを取るアカウントが先行者利益を得やすい状況
- 一方的な発信よりも、リプライ・引用・お題形式の投稿でユーザーとの双方向コミュニケーションを作るアカウントが評価されやすい

**自アカウント実測の所見**: 現時点で自アカウントの投稿サンプルが0件のため、伸びた/伸びなかった投稿の傾向を定量的に判断できる実測データがまだ蓄積されていません。まずは市場で確認されている『保存されるリスト型』『返信を誘う質問型』『共感を呼ぶ観察型』の3パターンを並行投稿し、次回分析でどの型がフォロワー外リーチ・保存・返信に効いているかを比較できるようにすることが優先です。

**改善アクション**
- [ ] 認知拡大フェーズの間は各投稿にビュー数・いいね数・返信数・保存(リポスト)数を記録し、次回分析用のサンプルを最低10〜20件確保する
- [ ] 『保存型（リスト/チェックリスト）』『質問型（返信誘導）』『観察型（共感）』の3パターンを均等な頻度で投稿し、型ごとの反応差を可視化する
- [ ] 伸びている同ジャンルの投稿の返信欄に、内容を深掘りする一言コメントを能動的に残し、プロフィール流入の導線を作る
- [ ] リンク付き投稿は全体の投稿頻度に対して最大1本に抑え、価値提供投稿とのバランスを維持してフォロワー外リーチを優先する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 美容

**市場トレンド（Web検索による）**
- 『保存版』『ここだけの話』など押し売り感を消す秘密感型の書き出しが定着しつつある
- 『〜な人の共通点』のように読み手を当事者化させる自分ごと化型フックが保存・反応を集めやすい
- 『過去の自分に伝えたい』のような共感型の振り返り投稿が支持されやすい傾向
- 問いかけで結ぶことでリプライを誘発する構造がエンゲージメント向上に寄与している
- 季節の髪色・肌質トレンド（艶感ブラウン系カラー、パーツケア、成分訴求など）を絡めた投稿が話題化しやすい

**自アカウント実測の所見**: 現時点でsample_size=0のため自アカウントの実測データが存在せず、伸びた/伸びなかった投稿の傾向分析はできない。まずは価値提供型・共感型・質問締め型の投稿を一定数配信し、閲覧数・保存数・返信数のベースラインを蓄積することが優先課題。

**改善アクション**
- [ ] 直近1〜2週間は『共感型』『自分ごと化型』の書き出しを使った投稿を1日1〜2本のペースで配信し、views/保存/リプライ数を記録してベースラインを作る
- [ ] 投稿の締めを必ず問いかけ形式にし、リプライ率を可視化・比較する（A/Bテスト運用）
- [ ] リンク付き投稿は認知拡大フェーズの方針通り最大1本/週程度に抑え、残りは保存したくなるTips・観察系投稿に振る
- [ ] 季節トレンド（髪色・肌質ケアなど）を切り口に使う際は元記事の言い回しをそのまま使わず、自分の観察・提案として言い換える

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
