# インサイトレポート 2026-08-14

## 婚活

**市場トレンド（Web検索による）**
- 「あるある」共感型のビフォーアフター構造が強い：<cite index="1-1">婚活の最初は「どんな人だろう、楽しみ！」だったのが半年後には「年収は、職種は、実家は、将来は」と条件確認ばかりになる、という時系列の変化を描く投稿が支持されている</cite>
- 婚活を別の行為に例えるメタファー構造が刺さる：<cite index="1-1">婚活が「採用面接」のようになっている状態を「審査モード」と名付け、それをやめた瞬間に恋が始まるという断定的な結論で締める構造</cite>が使われている
- 第三者目撃談から「見抜き方」を語る構造が伸びている：<cite index="6-1">婚約指輪を見に行ったカップルの敬語・距離感から「婚活あるあるな雰囲気」を読み取り、金銭感覚と気持ちのアンバランスさを指摘する投稿</cite>のように、観察→分析→教訓の流れが機能している
- 危険サイン・注意喚起系も需要がある：<cite index="8-1">結婚相談所で「わきまえましょう」と言われた経験や、40代女性へのSNS上の婚活の厳しさに気持ちが麻痺していたという振り返り</cite>のように、後から気づく“麻痺”や違和感の言語化がコメントを集めている
- リスト形式（◯選、チェック項目）は依然として保存されやすいフォーマットとして機能している

**自アカウント実測の所見**: 自アカウントの投稿は「距離感チェック3つ」という実用リスト構造自体は市場トレンドと合致しているが、1行目が「実はよくあるパターンだと思う」という控えめな導入で、意見の断定や具体的数字の提示が弱く、いいねは1件（サンプル数1のため母数は小さいが率は低い水準）にとどまっている。市場で伸びている投稿は「審査モード」のようなメタファーによる強い言い切りや、目撃談からの分析という“物語性”を先に立てており、自アカウントにはこの要素が不足している。

**改善アクション**
- [ ] 1行目を「実は〜だと思う」の弱い推測ではなく、「◯◯派」「結論、◯◯」という断定形に変更し、意見を先出しする
- [ ] 婚活を別の行為（審査・面接・マラソン等）に例えるメタファーの型を1〜2パターン用意し、共感と拡散力を強化する
- [ ] 第三者観察（電車・カフェ等での目撃談）→分析→教訓、という物語構造のテンプレを追加し、チェックリスト系と組み合わせる
- [ ] 質問で締める投稿は必ず自分の意見・基準を先に明言してから軽い問いを添える形に統一し、中立な問いかけのみの投稿は作らない

## 副業

**市場トレンド（Web検索による）**
- 2026年の住民税ルール変更を背景に「副業が会社にバレる仕組みと対策」を解説する記事・投稿が急増している
- 「副業収入20万円以下なら申告不要」という誤解を正す（住民税には20万円ルールが適用されない）コンテンツが支持されている
- 確定申告期限（2026年2月16日〜3月16日）に合わせた具体的な手順・チェックリスト型の実用コンテンツが保存されやすい傾向
- 「初心者でも簡単に10万円」「初月で50万円」といった誇大な副業アフィリエイト訴求への警戒・反発が強まり、誠実で現実的なスタンスの発信が信頼を得やすくなっている
- Threadsでは発信テーマを1つに絞り、断定的な意見や具体的な数字から入る投稿がアルゴリズム認知・拡散されやすいという運用ノウハウが広がっている

**自アカウント実測の所見**: 397ビューと一定の到達はあるものの、いいねは0件で、投稿が中立的な情報提示＋質問締めのみに終わっており、書き手自身の立場や結論が示されていないため『共感・支持』のアクションに繋がっていない。実測メモにある通り、質問だけで終わる構成はビューは出てもいいね率が伸びない典型パターンに該当している。

**改善アクション**
- [ ] 投稿の1行目を「数字」または「はっきりした意見・結論」から始める形に統一し、質問開始を廃止する
- [ ] 本文中盤〜後半で必ず書き手の立場（◯◯派/結論◯◯でいい）を明言し、中立的な説明のみで終わらせない
- [ ] 保存価値を高めるため、手順・チェックリスト・基準など『行動に落とせる情報』を1投稿に最低1つ含める
- [ ] リンク付き投稿は全体の中で1本に絞り、残りは価値提供型にして意見表明→軽い質問という締め方に統一する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 美容

**市場トレンド（Web検索による）**
- 2026年は「攻めと守りの両立」がキーワードで、レチノールなど攻めのケアの反動により、肌のゆらぎに気づく人が増え、敏感肌向けの“お守り的スキンケア”が支持を広げている
- 「美容医療をすると赤みが強くでる」「皮膚科で肌が薄いと言われた」など、肌の繊細さへの気づきを語る投稿が共感を集めている
- Threadsは写真映えではなく「言葉の温度」と「人柄の透明度」で選ばれるSNSであり、キラキラした宣伝文よりも率直な意見・人柄が伝わる文章が伸びやすい
- Threadsのアルゴリズムは投稿直後30〜60分の返信量・会話の総量を重視しており、保存よりも「返信したくなる余地」が拡散のカギになる
- 「乾燥肌対策の裏ワザ」のような悩み解決コンテンツが、ターゲットの共感と信頼を得やすい鉄板ジャンルとして挙げられている

**自アカウント実測の所見**: 質問投げかけ型（季節で順番を変える？）は724viewsと最も伸びたが、いいねは0で、実測データが示す「質問だけの投稿はビューは出るがいいね率が低い」傾向と一致する。一方、意見表明とチェックリストを含むレチノール投稿は394viewsに留まっており、保存性の高い内容でも1行目や構成次第でリーチが伸び悩む可能性がある。2投稿のみのサンプルのため、いいね変換率を上げる型（意見先出し＋チェックリスト＋軽い問いかけ）を複数投稿で検証する必要がある。

**改善アクション**
- [ ] 1行目を「◯◯だと思う」「結論、◯◯派」のような明確な意見・数字から始め、中立な一般論の書き出しをやめる
- [ ] チェックリストや基準（①②③形式）を毎投稿に入れて保存動機を作り、末尾の問いかけは意見の後に添える形に統一する
- [ ] 投稿直後30〜60分にコメント返信を行い、初速の会話量を増やす運用を並行して行う
- [ ] 2026年トレンドの「攻めと守りの両立」「肌のゆらぎへの気づき」を切り口に、悩み解決型の投稿を増やす
