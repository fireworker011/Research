# インサイトレポート 2026-08-25

## 転職

**市場トレンド（Web検索による）**
- 「年収600万円以上の人材の約6割がSNS経由でスカウトを受けた経験があり、77.3%が好印象と回答」という実態調査ネタなど、具体的な数字を提示するデータ引用型の投稿が反応を得やすい
- Threadsでは「企業の価値観や働き方」をテキストで丁寧に語る投稿が採用・転職文脈で相性が良いとされ、共感ベースの発信が伸びやすい
- 「転職の情報収集にSNSを使う人は約56%」といった調査データを切り口にした、読者の行動を裏付ける数字提示型の投稿が保存されやすい
- LinkedIn・Wantedlyなど転職特化SNSとの「使い分け・比較」を解説する実用系投稿が定番の切り口として存在する
- 退職エントリ・キャリアチェンジの体験談型投稿は引き続き話題化しやすい定番パターンとして語られている

**自アカウント実測の所見**: 実測データが sample_size=0 のため、伸びた/伸びなかった投稿の比較分析はまだ実施不可。ただし共有された制約条件から、質問開始型の投稿はビューは獲得できてもいいね率0.1%に留まったことが判明しており、次期投稿では意見・数字先出し型への転換が急務。

**改善アクション**
- [ ] 直近2週間の投稿を「1行目のタイプ（数字/意見/質問）」でタグ付けし、いいね率・保存率を最低limitでも計測開始する
- [ ] 質問オンリー投稿を廃止し、必ず結論→根拠（数字 or チェックリスト）→軽い問いかけ、の3段構成に統一する
- [ ] 週1本は「SNS経由スカウト実態」など第三者データを引用した保存型投稿を配信し、保存率の変化を検証する
- [ ] PRリンク投稿は全体の3〜4割以内に抑え、価値提供投稿とのバランスをA/Bで検証する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## ペット

**市場トレンド（Web検索による）**
- <cite index="4-1">保護猫・保護犬などのバックグラウンドを持つアカウントは、単なる癒しコンテンツを超えた共感と社会性を呼び、ブランドとの親和性も高い</cite>
- <cite index="7-1">「純粋な癒し」を求める需要にAI生成の犬・猫動画がハマり、24時間で24万回再生・1.7万いいねを獲得する例が出ている</cite>
- <cite index="6-1">数値を入れた投稿は説得力が増し、読者から「具体的で信頼できる情報」と認識されて保存・シェアされやすい</cite>
- <cite index="9-1">「あなたはどう思いますか？」のような問いかけを含む投稿はコメントが増加し、アルゴリズム評価が上がる傾向がある</cite>
- <cite index="2-1">Threadsは画像より言葉が伸びやすく、本音や日常の実感を短く言い切る投稿が保存・会話を生みやすい</cite>

**自アカウント実測の所見**: 実測データが0件のため定量的な傾向は判断不可だが、既知の実測として『質問だけの投稿』はビューはついてもいいね率0.1%に留まっており、閲覧はされても感情移入や保存行動には結びついていないことが示唆される。今後は投稿の冒頭で明確な立場や数字を提示し、その後に問いかけを添える構成へ転換する必要がある。

**改善アクション**
- [ ] 1行目を「◯◯派」「結論、◯◯が正解」など明確な意見表明にし、質問から入る投稿を廃止する
- [ ] 保護犬猫・老犬介護など共感度の高い実体験風の切り口（捏造ではなく一般化した観察）を月内に1〜2本取り入れる
- [ ] チェックリストや判断基準（通院の目安・フード選びの基準など）を必ず1つ本文に含め、保存されやすい構造にする
- [ ] 投稿の締めは『意見→軽い質問』の順に固定し、コメント誘発と共感形成を両立させる

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 睡眠

**市場トレンド（Web検索による）**
- 深夜に『起きれるか不安』『寝るか迷う』といった具体的な時刻・状況を挙げた共感投稿が拡散しやすい（漠然とした一般論より“具体的な時間軸”が刺さる）
- 『子どもが寝た後の静けさ』のような、生活シーンに紐づいた本音・共感型の一文が保存・コメントを誘発している
- Threadsは初速のコメント数・滞在時間がアルゴリズム評価に直結するため、結論を先に言い切ってから理由を展開する『BLUF型』構成が伸びやすい
- 『一般常識と逆のことを言う』逆説型の書き出しが関心を引きやすい傾向がある
- チェックリストや比較形式など、保存したくなる実用情報（画像/箇条書き）を含む投稿が伸びやすい

**自アカウント実測の所見**: 現時点で自アカウントの実測データはサンプル数0のため定量比較はできないが、過去の実測で『質問だけで始まる投稿』はビュー数は伸びてもいいね率0.1%に留まったことが分かっている。これは冒頭で書き手の意見・結論が示されておらず、読者が『自分ごと化』する前に離脱していた可能性が高い。

**改善アクション**
- [ ] 投稿の1行目を必ず『数字』または『はっきりした意見・結論』で始める型に統一し、質問始まりを廃止する
- [ ] 結論→理由→実用情報（チェックリスト or 具体的手順）→軽い問いかけ、のBLUF型構成をテンプレ化する
- [ ] 生活シーン（寝る前の行動・夜中の心理）に紐づく共感型の一文を必ず1つ盛り込み、保存・コメントを誘発する
- [ ] 投稿直後30分はコメント返信を行い初速エンゲージメントを作る運用ルールを追加する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
