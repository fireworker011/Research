# インサイトレポート 2026-07-27

## 婚活

**市場トレンド（Web検索による）**
- 婚活が「好きかどうか」より先に条件確認をしてしまう“審査化”現象を自虐・共感形式で描く投稿が伸びている
- 電車や街中で偶然見かけた婚活中らしき男女の様子を観察・考察する第三者視点の投稿が拡散されやすい
- 結婚相談所やお見合いの場での「違和感」「モラハラ気づき」など、後から振り返る系の気づき投稿が反応を集めている
- 潜在意識・思い込み系（同棲の意味の男女差、負けたくない心理など）のマインド解説投稿が保存されやすい
- Threadsのアルゴリズムは会話（リプライの応酬）を重視するため、投稿後1時間の即レスが拡散のカギになっている

**自アカウント実測の所見**: 現時点でサンプル数0のため、伸びた投稿・伸びなかった投稿の傾向はまだ判定できない状態です。まずは市場トレンドを参考にした複数パターンを投稿し、実測データを蓄積することが最優先です。

**改善アクション**
- [ ] 「あるある共感型」「第三者観察型」「マインド解説型」の3パターンを均等に投稿し、初期の反応差を計測する
- [ ] 投稿直後1時間はアプリを開いたままにし、リプライへの即レスで会話を活性化させる（Threadsは会話量が評価されやすいため）
- [ ] 保存されやすいチェックリスト・箇条書き構成を意識し、最初の一文で興味を引く工夫を入れる
- [ ] リンク入り投稿は認知拡大フェーズ中は最大1本に抑え、残りは価値提供・質問締めで反応データを優先的に集める

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 副業

**市場トレンド（Web検索による）**
- 確定申告・住民税・経費など「知らないと損する制度Tips」が保存目的で伸びやすい傾向
- 「続く人/続かない人」「稼げる人/稼げない人」といった二項対立の観察投稿が共感とリプライを集めやすい
- フォロワー0でも伸びる新規優遇アルゴリズムを前提に、1投稿完結型の実用情報で新規リーチを狙うアカウントが増加
- テーマを一つに絞り込んだ専門特化型アカウントの方が企業案件・信頼獲得に繋がりやすいという運用論調が目立つ
- 収益額や具体的な数字を見出しに置く「数字訴求型」の投稿が引き続き多い

**自アカウント実測の所見**: 3投稿平均2043viewsのうち、確定申告・住民税という「制度Tips」投稿が最も高い2993viewsを記録し、対策系Tips（バレる原因）は1196viewsと最も伸びが弱かった。閲覧数は取れているが3投稿ともいいね0件で、view数に対してエンゲージメント（いいね・保存アクション）への転換が弱い可能性がある。

**改善アクション**
- [ ] 税金・経費・制度など「保存したくなる実用Tips」を投稿の軸に増やし、1行目に数字や具体的な制度名を置いてフックを強化する
- [ ] 対比構造（〜な人／〜な人）＋オープンクエスチョンで終わる投稿を増やし、リプライ発生を狙う
- [ ] 『保存推奨』を促す一言や絵文字（📌など）を添え、閲覧から保存・いいねへの転換を促す
- [ ] リンク投稿は認知拡大フェーズの方針通り最大1本に抑え、価値提供型の投稿比率を高める

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 美容

**市場トレンド（Web検索による）**
- 冒頭1行で『悩みを言い当てるフック』（お悩み提示型)を使い離脱を防ぐ構成が伸びやすい
- 『〇〇におすすめ5選』のようなリスト型・まとめ型の投稿は保存されやすい傾向
- 宣伝色の強い投稿は敬遠され、役立つ情報や共感できる話題を中心にしCTAは結びにさりげなく添えるバランスが支持されている
- コメント返信や他ユーザーへの交流など双方向性のある運用が中長期的な伸びにつながっている
- Instagramでは届きにくかった40代以上の女性層にThreadsでリーチが広がった事例が見られる

**自アカウント実測の所見**: 現時点で投稿実績データ（sample_size=0）がなく、伸びた投稿・伸びなかった投稿の傾向分析は行えません。まずは複数パターンの投稿を出稿し、閲覧数・保存・返信率のベースラインを取得することが優先課題です。

**改善アクション**
- [ ] 認知拡大フェーズでは『お悩み提示フック＋共感の観察＋質問締め』のテンプレを中心に投稿し、まずはデータ母数を確保する
- [ ] 保存されやすい『◯選・比較・まとめ』型のリスト投稿を週1本以上取り入れ、保存率を計測指標に加える
- [ ] コメント返信・同ジャンルアカウントへの能動的なコメントを日次で行い、双方向性による伸びを検証する
- [ ] リンク付き投稿は最大1本に抑え、CTAは投稿末尾にさりげなく添えるトーンで統一する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
