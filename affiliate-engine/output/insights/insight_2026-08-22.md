# インサイトレポート 2026-08-22

## 転職

**市場トレンド（Web検索による）**
- 2026年6月の有効求人倍率は1.18倍で高止まりしている一方、求職者の約6割が『買い手市場』と実感するなど、求人数と体感のギャップが話題になっている
- 選考ハードルの上昇を8割以上の求職者が実感しており、『専門性・実績への要求がシビアになった』という切り口の投稿が共感を集めやすい
- 『4月入社』へのこだわりが薄れ、『時期より納得感』を重視する価値観の変化が転職者の間で話題になっている
- Threadsのアルゴリズムは共感・会話を生む投稿が伸びやすく、冒頭数秒で読み手の心を掴む一文が重要視されている
- 地域密着・採用系のカジュアルな『仲間募集』トーンの投稿が、企業アカウントを中心に反応を得やすい傾向がある

**自アカウント実測の所見**: 実測データがsample_size 0件のため、現時点では自アカウントの傾向を統計的に判断できない。まずは母数を確保し、次回分析で『伸びた投稿/伸びなかった投稿』の型を比較できるようにする必要がある。

**改善アクション**
- [ ] 直近2週間は最低10投稿を目標に、1行目を必ず『数字』か『明確な意見』で始めるフォーマットに統一してデータを蓄積する
- [ ] 質問だけで終わる投稿をやめ、意見→根拠/チェックリスト→軽い質問、の3段構成に統一してA/Bテストする
- [ ] 有効求人倍率や選考ハードル上昇など客観データを引用しつつ、書き手の立場（〇〇派・結論〇〇でいい）を明言する投稿を増やす
- [ ] 保存されやすい『準備チェックリスト』型と、共感されやすい『観察・あるある』型を交互に投稿し、いいね率と保存率を比較する

## ペット

**市場トレンド（Web検索による）**
- ChatGPTなどの画像生成AIで愛犬・愛猫を擬人化する投稿がトレンド化し、Threadsのトレンドランキング上位にも入った。<cite index="10-1">SNS「Threads」で、ChatGPTの画像生成機能を使い、愛犬や愛猫を“擬人化”して投稿する行為がはやり始めている。4月7日には「ペット擬人化」のワードが日本のトレンド入り。夜にはトレンドランキングの1位にもなった。</cite>
- AI生成の犬・猫動画による「純粋な癒し」訴求が短時間で大きく伸びるケースが出ている。<cite index="8-1">先日、私がThreadsに投稿した一本のAI動画が、約24時間で24万回表示され、1.7万を超える「いいね」をいただきました。</cite>
- Threads全体の傾向として、写真より“言葉”中心の投稿がコメント・保存を通じて伸びやすい設計になっている。<cite index="1-1">Threadsは画像より言葉のほうが圧倒的に伸びやすい。</cite>理由はコメントが会話を生みスコアが上昇する仕組みにある。
- 投稿タイミングによるエンゲージメント差が明確で、通勤・通学時間帯の朝投稿が効果的とされる。<cite index="6-1">データ分析によると、平日の朝7時〜8時に投稿すると、多くのユーザーの通勤・通学時間と重なり、エンゲージメント率が平均30%向上します。</cite>
- 「保護犬・ブリーダー・ペットショップ」など飼い主の選択に関する意見表明系の投稿はコメントが集まりやすく、賛否が分かれるテーマとして拡散しやすい傾向が見られる。

**自アカウント実測の所見**: 現状はsample_size=0で実測データが存在せず、伸びた/伸びなかった投稿の定量比較ができない状態。ただし運用メモにある「質問だけの投稿はビューが出てもいいね率0.1%止まり」という実測知見は、Threadsの『言葉と会話がスコアを押し上げる』仕組みと整合しており、意見や結論を先出ししないと反応が薄いことを示唆している。次回計測までに、意見先出し型と質問先行型を同条件（時間帯・文字数）でABテストしデータを蓄積する必要がある。

**改善アクション**
- [ ] 全投稿の1行目を「数字」または「はっきりした意見」で始めるテンプレートに統一し、質問始まりの投稿を停止する
- [ ] 保存されやすいチェックリスト型（選び方の基準・見分け方の手順）を投稿の型として週1〜2本組み込む
- [ ] 投稿時間を朝7〜9時・昼12〜14時・夜21〜24時に集中させ、時間帯別のいいね率を計測してsample_sizeを増やす
- [ ] AI擬人化・AI動画など画像生成トレンドは文面のコピーではなく『自分の飼育観点での気づき』を足して差別化する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 睡眠

**市場トレンド（Web検索による）**
- 2026年8月に入り「眠れない」「夜中に目が覚める」「生活リズムが崩れた」といった不眠・体内時計の乱れをテーマにしたSNSの投稿が繰り返し話題化しており、共感型の“あるある”投稿が伸びやすい土壌がある
- Threadsのアルゴリズムは2026年以降「なぜそれが起きるのか」「どうすれば再現できるのか」という構造を持つ投稿を評価する傾向が強まっており、単なる共感文だけでなく背景ロジックを添えた投稿が保存されやすい
- 書き出しの工夫として、断定的な本音や具体的な生活描写から入る投稿が保存・会話を生みやすいとされ、
- 曖昧な一般論より、投稿者自身のスタンスを明示したうえで再現可能な手順やチェックポイントを示す投稿の方が、フォロー・保存につながりやすい流れがある

**自アカウント実測の所見**: 現時点でサンプル数0のため定量的な傾向は抽出できないが、過去の実測で「質問だけで始まる投稿」はビューが出てもいいね率0.1%にとどまったという事実がある。これは、閲覧はされても『誰の意見か』が伝わらず、共感・保存のトリガーが弱かったことを示唆する。今後はまずデータを蓄積しつつ、書き出しの型を変えて再検証する必要がある。

**改善アクション**
- [ ] 1行目を質問文から「結論、◯◯派」「◯◯は△△が原因であることが多い」といった断定・意見表明に変更し、書き手の立場を先出しする
- [ ] 共感できる生活描写（夜中に目が覚める・スマホをやめられない等）と、保存したくなる簡易チェックリストをセットで1投稿に入れる構成に統一する
- [ ] 『眠れない』系の共感投稿と『改善手順・基準』系の実用投稿を交互に配信し、どちらのタイプがいいね率・保存率を伸ばすかをsample_sizeを貯めながら比較する
- [ ] 質問で締める場合も、意見・チェックリストを提示した後に軽く問いかける形式（現状の反応を聞く）に限定し、質問単体の投稿は当面控える

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
