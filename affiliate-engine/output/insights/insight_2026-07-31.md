# インサイトレポート 2026-07-31

## 筋トレ

**市場トレンド（Web検索による）**
- 会話（リプライ）から評価が伸びる仕組みが強化されており、フォロワーに問いかける投稿がインプレッション増に直結しやすい
- 1行目のフックと感情の動かし方が重視され、完璧に整った文章より人間味のある等身大の言葉の方が反応されやすい
- 答えを出し切らず、読者に考えさせる“余白”がある投稿ほど保存・議論が生まれやすい
- 新しい情報や通説の見直し（例：定説のアップデート）に自分の意見を添える投稿は反応が集まりやすい
- フォロワー数に関係なくコンテンツ単体の質で伸びる設計のため、新規アカウントでも切り口次第で認知拡大が狙える

**自アカウント実測の所見**: 生活リズムに関する『問いかけ＋共感』型の投稿が最も閲覧数を集めた一方、いいね数は全体的に0〜1件と低く、閲覧はされても反応（保存・返信）への転換が弱い状態。栄養Tips系（タンパク質量・プロテインタイミング）は情報価値はあるが最後の質問が長文で埋もれ気味になり、続ける/やめるの投稿も1行目のフックが弱く伸び悩んだと考えられる。

**改善アクション**
- [ ] 1行目を『問いかけ』または『意外性のある一言』で始め、本文後半に埋もれていた質問を冒頭または独立行に配置し直す
- [ ] 情報提供型の投稿では結論を言い切らず、あえて余白を残して読者にコメントで補足させる構成に変える
- [ ] 生活シーン（時間帯・休養日・気分など）に絡めた『あなたはどっち派？』型の二択質問を増やし、リプライ発生率を優先的に伸ばす
- [ ] 認知拡大フェーズ中はリンク投稿を1本以内に抑えたまま、価値提供投稿の本数を増やして保存率とリプライ率の改善を優先する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 教育

**市場トレンド（Web検索による）**
- 断定より「問いかけ」を含む投稿の方が返信が生まれやすく、Threadsは共感を大切にするSNSであるため率直な表現が反応を得やすい傾向がある
- 投稿は1テーマに絞り込むことで読みやすくなり拡散されやすい構造が推奨されている
- 育児・教育ジャンルでは自身の経験や家庭内の実例をシェアする投稿が同じ悩みを持つ親層の共感を集めやすい
- Threadsはフォロワーが少なくても『いいね』や『コメント』が集まれば関連テーマの非フォロワーにも表示が広がるアルゴリズム構造を持つ
- 投稿時間帯によって反応の質が変わり、朝は前向き系、夜は共感・本音トーク系が伸びやすいとされる

**自アカウント実測の所見**: 上位3投稿はいずれも「家庭によって方針が分かれるテーマ（宿題の見守り方・テスト結果の共有・給食費浮いた分の使い道）」を二択形式で問いかけており、閲覧数が1,800〜5,700と高い。一方、下位3投稿は『気づき・学び』を一方向的に提示するのみで問いかけが弱く、閲覧数は900台に留まっている。つまり自アカウントでは「賛否・派閥が分かれる二択型の問いかけ」が明確に伸び、単なる知識提供型は伸び悩む傾向が実測から読み取れる。

**改善アクション**
- [ ] 『◯◯派 vs △△派』のように家庭内で意見が分かれるテーマを毎回1つ選び、二択形式の問いかけで締めるフォーマットを標準化する
- [ ] 給食費無償化のような時事・制度ニュースは反応が良いため、教育関連の制度改正・学校行事の時期ネタ（夏休み明け・新学期など）を継続的にキャッチアップして投稿に組み込む
- [ ] 下位投稿のような『学び提示のみ』の投稿は、末尾に必ず具体的な二択または質問を追加し、返信のハードルを下げる形に作り替える
- [ ] 認知拡大フェーズのためリンク投稿は最大1本に抑え、残りは保存・返信を狙う価値提供型に振り切る

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 節約

**市場トレンド（Web検索による）**
- Threadsアルゴリズムは『いいね』より『リプライがどれだけ続いたか＝会話量』を評価する傾向が強まっている
- 画像より短いテキスト投稿の方が伸びやすく、共感を呼ぶ一言・自問自答調の書き出しが保存・コメントを誘発している
- ふるさと納税ジャンルでは『◯年連続1位』『訳あり』『数量限定』など具体的な数字・限定性を打ち出す投稿が反応を集めている
- 格安SIMジャンルは月替わりのキャンペーン条件（乗り換え特典・還元額変更など）を速報的に紹介する投稿が需要が高い
- 投稿頻度が高いアカウントほど1投稿あたりの表示回数が伸びる傾向があり、初動（投稿直後7〜9時・12〜14時・21〜24時）の反応が重要視されている

**自アカウント実測の所見**: 現時点で自アカウントの投稿データ（サンプル数0）が存在しないため、伸びた/伸びなかった投稿の傾向比較はできません。まずは一定量（10〜20投稿）を蓄積し、市場トレンドで見られた『会話誘発型』『共感の一言型』『具体的数字提示型』のどれが自アカウントの読者層に響くかを検証データとして貯める段階です。

**改善アクション**
- [ ] 認知拡大フェーズでは会話（リプライ）を生む一言共感投稿と保存されやすいチェックリスト型投稿を交互に投稿し、どちらが自アカウントで伸びるか比較データを取る
- [ ] 投稿直後の反応を最大化するため、7〜9時・12〜14時・21〜24時のいずれかに固定して投稿し、時間帯別の伸びも計測する
- [ ] ふるさと納税や格安SIMなど『具体的な数字・限定性・比較』を盛り込んだ価値提供投稿を週1〜2本試験投入し、リンク誘導は最大1本に絞る
- [ ] 投稿ごとに『保存数』『返信数』を記録し、次週の草案作成にフィードバックするサイクルを回す

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
