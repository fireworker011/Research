# インサイトレポート 2026-08-26

## 婚活

**市場トレンド（Web検索による）**
- 婚活パーティー帰りの男女の会話をカフェ・電車・百貨店などで『たまたま聞いてしまった』という目撃談フォーマットが継続的にバズっている。<cite index="10-1">百貨店内のブルガリから出てきた2人の会話をたまたま地下鉄が一緒でしばらく聞いてしまったという投稿が伸びている</cite>
- 婚活が『採用面接化・審査モード化』している、という自己批判的なあるある切り口が支持されている。<cite index="4-1">婚活あるあるとして、最初はときめきで始めた出会いが半年後には年収・職種・実家の確認ばかりになり、採用面接のようになっているという投稿が話題になっている</cite>
- 目撃した会話から『金銭感覚より気持ちのアンバランス』のような危険信号（モラハラ・力関係の偏り）を指摘する分析型の投稿も伸びている。<cite index="10-1">共有された会話が日常なら、擦り合わせではなく男性が自分側に寄せようとしているという分析が加えられている</cite>
- 断定的な一人称オピニオン（『〜だと思う』『一回やめた方がいい』）から始まり、最後にチェックリストや行動指針で締める構成が定番化している
- 恋愛・婚活ジャンル全体では、片方に負担が偏る関係性（奴隷系・尽くしすぎ）への注意喚起や、同棲・プロポーズ前のズレを指摘する投稿も一定数流通している

**自アカウント実測の所見**: 自アカウントの実測では、①1行目が明確な意見・行動基準で始まり②チェックリスト形式の実用性を含む投稿（998views/いいね8）が最も伸びており、いいね率も高い。一方で、目撃談のみで結論・行動指針が薄い投稿（587views/いいね2）や、あるある共感止まりの投稿（544views/いいね1、400views）は視聴数は取れても『いいね変換率』が低く、意見の強さと保存性の弱さが差を生んでいると考えられる。サンプルが4件と少ないため、今後は同構造で母数を増やして検証する必要がある。

**改善アクション**
- [ ] 全投稿で1行目を『結論、〜だと思う』『私は◯◯派』などの断定意見で開始し、質問や状況説明から書き始めない
- [ ] 目撃談・あるある型を使う場合も、観察の後に必ず自分の結論（進展基準・危険信号の見立て）を明言し、単なる共感止まりで終わらせない
- [ ] チェックリスト（3項目程度）を毎投稿に固定装備し、保存されやすい『実用性』を担保する
- [ ] 『審査モード化・面接化』のような自己批判系の切り口を自アカウント用の独自エピソードで展開し、市場の伸びている構造を取り入れる

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 副業

**市場トレンド（Web検索による）**
- 2026年のThreadsアルゴリズムは「問いかけを含むオリジナル投稿」と「リプライでの深い会話」を重視する傾向が強まっており、単純ないいね数より滞在時間・議論の白熱度が評価軸になっている
- 「舞台裏」と「ノウハウ」を組み合わせた発信（実体験の裏側＋具体的な手順）が伸びやすい型として広がっている
- 投稿の終わりに意見を求める問いかけを添えて議論を誘発する構造が、拡散を後押しする要因として言及されている
- 「会社員向け副業」「SNS運用初心者向け」のようにターゲットを絞り込み、悩みに直接刺す発信が支持されている
- Threads単体収益化ではなく、プロフィールやnoteなど外部への誘導設計を明確にした投稿が収益化の主流になっている

**自アカウント実測の所見**: 現時点でサンプル数0件のため統計的な傾向は抽出できないが、直近の実測情報として「質問だけで始まる投稿はビュー数自体は出ても、いいね率が0.1%程度に留まる」ことが判明している。これは一次情報が乏しく、書き手の立場や結論が見えないため読者が反応する動機（同意・反論・保存）を作れていない可能性が高い。

**改善アクション**
- [ ] 1行目を「数字」または「明確な意見」で始めるテンプレートに統一し、質問文からの導入を禁止する
- [ ] 本文中に必ず書き手の立場（◯◯派/結論◯◯でいい）を明言する一文を入れる
- [ ] 保存需要を作るため、判断基準・チェックリスト・手順のいずれかを最低1つ本文に含める
- [ ] 締めの質問は「意見を出した後の軽い問いかけ」に限定し、単独の質問投稿は運用を停止する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 美容

**市場トレンド（Web検索による）**
- ファンデーションで隠すより下地・スキンケアの段階で毛穴やくすみを整える「素肌を良く見せる」ケアへの注目度が上昇している
- 肌の透明感だけでなく髪の「面ツヤ」も美肌印象を左右する要素として注目されている
- 韓国発の「水光肌」「毛穴ケア」系アイテムのビフォーアフター訴求が拡散されやすい状況が続いている
- レチノールなど定番成分系アイテムが新作コスメと並んで殿堂入り的に安定してバズっている
- Threads全体では単発の共感投稿より、なぜそうなるか・再現できるかというロジックを示す「構造がある投稿」が保存・議論を生みやすい傾向にある

**自アカウント実測の所見**: サンプルは4件と少ないが、平均453viewsのうち上位3件はいずれも「私は◯◯派」「結論◯◯」と立場を明言し、チェックリストや基準を提示した投稿で、344〜728viewsとほぼ横並びに安定している。一方、質問だけで始まる投稿はview自体は出てもいいね率0.1%に留まっており、閲覧はされても行動（いいね・保存）には転換していないことが読み取れる。

**改善アクション**
- [ ] 1行目を必ず「◯◯派」「結論、◯◯」のような明言型に統一し、質問文からの書き出しは廃止する
- [ ] 毛穴・くすみ・面ツヤなど今のトレンド話題を、中立な紹介ではなく自分の立場を先に置いた意見形式に変換して発信する
- [ ] 肌ゆらぎサインの3項目チェックリストのような「保存したくなる基準・手順」を毎投稿に1つ以上必ず入れる
- [ ] 質問は投稿の締めにのみ使い、必ず自分の意見・結論を先出しした後に軽く問いかける形に統一する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
