# インサイトレポート 2026-08-08

## 婚活

**市場トレンド（Web検索による）**
- 婚活を「採用面接・書類審査」に例え、婚活疲れの構造を言い切る形の投稿が伸びている。<cite index="1-1">「気づいたら婚活アプリじゃなくて採用面接してた」「これ、審査モード入りすぎ問題」</cite>のように、あるあるを断定的なフレーズで畳みかける構成が支持されている
- 電車やカフェでの他人の婚活シーンを目撃した「観察エピソード」型が反応を得やすい。<cite index="6-1">「婚約指輪見に行ったっぽいのに敬語、独特の距離感、相談所で知り合って、仮交際かな？という感じ」</cite>のように、第三者視点のリアルな距離感描写が共感を呼んでいる
- 「〜な思考パターンは結婚から遠ざかる」と断定してからセルフワークを促す、恋愛心理・潜在意識系の投稿が伸びている。<cite index="7-1">「婚活や恋愛は負けたくない！という意識が強ければ強いほどうまくいかない」</cite>のような一文目の強い意見表明が特徴
- 「同棲」「結婚観のズレ」など男女の認識差を対比構造で見せる投稿が反応を得ている。<cite index="7-1">「男性の『一緒に住もう』は、ただの現状維持。女性の『一緒に住もう』は、結婚への準備」</cite>のような対比フレーズが保存・共有されやすい
- 「この状態になったら一度立ち止まった方がいい」というチェックポイント提示型の締めが多い。<cite index="1-1">「ときめきより先にチェックリストが出てくるようになったら、一回、婚活やめた方がいい」</cite>のように基準を明示してから結論を出す構成が伸びている

**自アカウント実測の所見**: 自アカウントの投稿は「距離感あるある」の切り口自体は市場トレンド（観察型・あるある型）と合致しているが、1行目が観察の描写のみで意見や結論がなく、最後も質問だけで締められているため、閲覧はされてもいいねに変換されていない（473viewsに対しいいね0）。市場で伸びている投稿は共通して「筆者の断定的な立場表明」→「あるあるの一般化」→「基準やチェックリスト」という順で構成されており、この骨格が自アカウントに欠けている。

**改善アクション**
- [ ] 1行目を「観察の描写」から「具体的な数字」または「はっきりした意見・結論」に変更する（例：「結論、〜派」「3回に1回は〜」）
- [ ] あるあるを提示したあとに必ず筆者の立場（◯◯派／◯◯すべき）を明言し、中立的な感想で終わらせない
- [ ] 保存性を上げるため、チェックリストや基準（3つのポイント等）を1投稿に1つ入れる構成をテンプレ化する
- [ ] 電車・カフェ等での第三者観察エピソード型（自分の実体験ではなく一般的な観察として描写）を月1〜2本試験投稿し、反応を比較する

## 副業

**市場トレンド（Web検索による）**
- Threadsのアルゴリズムは2026年にかけて「会話が生まれる投稿」を優先する方向にシフトしており、コメント・返信数が多い投稿ほど拡散されやすい
- 投稿頻度自体もインプレッションに影響するため、短文でも継続投稿しているアカウントが伸びやすい
- 副業ジャンルは「Ambition（将来・キャリア）」領域としてHARMの法則に該当し、成約率が高いジャンルとして注目されている
- 「宣伝っぽさ」を消した自然な体験共有型の投稿がクリック率・共感を集めやすい傾向がある
- バズより「関係密度」＝フォロワーとの信頼構築を重視するアカウント設計が2026年の主流になりつつある

**自アカウント実測の所見**: 現状、直近データのサンプル数が0件のため定量的な傾向は抽出できない。ただし要件定義にある「質問だけの投稿はビュー止まりでいいね率0.1%」という実測値から、意見・立場の提示がないコンテンツは保存欲求やリプライ誘発力が弱く、アルゴリズム上も会話性の低い投稿として評価されにくいと考えられる。

**改善アクション**
- [ ] 最低でも直近20投稿分のビュー数・いいね数・保存数を記録するトラッキング表を用意し、次回分析までにサンプルを確保する
- [ ] 冒頭を質問文で始める投稿を廃止し、必ず「結論＋数字」または「はっきりした意見」から書き出す構成に統一する
- [ ] 各投稿に「手順・基準・チェックリスト」のいずれかを1つ以上含め、保存されやすい実用性を担保する
- [ ] 投稿末尾の質問は意見表明の後に軽く添える形に変更し、リプライ発生率をKPIとして追加測定する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 美容

**市場トレンド（Web検索による）**
- 「攻めるケア」から「守るケア」へのシフトが進み、肌のゆらぎに対応する“お守り的スキンケア”が支持を広げている。
- メイクは「パーツ盛り」ではなく、細部のテクニックで肌なじみを良くする“似合わせ盛り”が主流になりつつある。
- 塗るケアだけでなく、NMNやコラーゲン系サプリなど“飲む美容”＝インナーケアへの関心が高まっている。
- 詰め替え・リフィル文化がデパコス層にも浸透し、サステナブルな美容行動が話題になりやすい。
- Threads攻略の型として「1行目で手を止めるフック文」「保存を促す軽い声かけ」「押し売り感のない優しいCTA」が伸びる投稿の共通構造として挙げられている。

**自アカウント実測の所見**: 現時点で実測データ（表示回数・いいね数）が0件のため定量比較はできないが、唯一得られている実測知見として、質問だけで始めた投稿はビューは伸びてもいいね率0.1%に留まっており、断定的な意見や数字の提示が不足すると『読むだけで終わる』投稿になりやすいことが示唆される。

**改善アクション**
- [ ] 1行目を必ず「数字」か「はっきりした意見」に変更し、質問文から入る構成を撤廃する
- [ ] 書き手の立場（◯◯派・結論◯◯でいい）を冒頭で明言し、中立な一般論の言い回しを避ける
- [ ] 『守る美容』『似合わせ盛り』など2026年の実トレンド語を絡めてチェックリスト形式の保存要素を毎投稿に1つ入れる
- [ ] 締めは意見表明→軽い質問の順にし、CTAは『保存して』『コメントで教えて』など押し売り感のない声かけに統一する
