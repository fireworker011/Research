# インサイトレポート 2026-07-26

## 転職

**市場トレンド（Web検索による）**
- 「NGワード→言い換え」型の教育的リスト投稿（面接での回答例をBefore/After形式で紹介）が保存されやすく伸びている
- 「転職活動あるある」形式の共感リスト投稿（証明写真の悩み、エージェントからの着信恐怖、志望動機の使い回し罪悪感など）が『わかる』の反応を集めている
- 転職回数が多い人向けの『退職理由を一本の軸で語る』というキャリア文脈の再構成テクニック投稿が支持されている
- Before/After型の年収・労働環境比較ストーリー投稿（残業時間や年収の変化を対比する構成）が採用されている
- 学歴・経歴コンプレックスに寄り添い『可能性はまだある』と背中を押す切り口の投稿が見られる

**自アカウント実測の所見**: 現時点で自アカウントの投稿実績データ（サンプル数・平均閲覧数・トップ/ボトム投稿）が0件のため、自社の傾向分析はまだ行えない状態。まずは市場で効果が確認されている『あるある共感型』『言い換えリスト型』『質問締め型』の3構造を試験投稿し、初期データを蓄積することが優先。

**改善アクション**
- [ ] 認知拡大フェーズの間は『あるある共感型』と『NGワード→言い換えリスト型』を交互に投稿し、保存・返信を狙う構造でデータを蓄積する
- [ ] 全投稿の末尾に具体的な問いかけ（他にもある？／あなたはどう？）を入れ、リプライ率を測定できるようにする
- [ ] 初期3〜5投稿はリンクなしで反応を見て、閲覧数・返信数が安定してから週1本を上限にリンク投稿を混ぜる
- [ ] 投稿後24〜48時間の伸び方（保存数・リプライ数・フォロー転換）を記録し、次回のtop3/bottom3比較ができるよう実測データを整備する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## ペット

**市場トレンド（Web検索による）**
- AIで生成した犬猫の癒し動画・画像が短時間で高再生数を獲得しやすく、同じ「型」をシリーズ化して横展開する動きが目立つ
- 「あなたはどう思う？」型の問いかけを含む対話型の投稿は、コメントの質と滞在時間が評価されやすく伸びやすい
- 「○選」「チェックリスト」形式の情報まとめ画像・テキストは保存率が高く拡散の起点になりやすい
- 加工されていないリアルな日常風景・ビフォーアフター的な投稿は共感コメントを集めやすい
- 保護犬・多頭飼育など賛否が分かれるペット業界の話題は意見表明を誘発しやすいが、扱い方次第で炎上リスクもある

**自アカウント実測の所見**: 現時点で投稿実績データ（サンプル数0件）がなく、自アカウントの傾向を定量的に分析できる材料がありません。まずは基礎データを蓄積し、次回分析で市場トレンドとの相関を確認する必要があります。

**改善アクション**
- [ ] 認知拡大フェーズ中は「まとめ・チェックリスト型」の保存訴求投稿を週内に複数本投稿し、保存数・フォロー転換率のデータを蓄積する
- [ ] 投稿末尾に「あなたはどう思う？」「うちの子はどっち？」等の問いかけを必ず入れ、コメント発生率を測定する
- [ ] 投稿直後30分〜1時間はコメント返信を優先し、会話性を高めてアルゴリズム評価を上げる
- [ ] リンク付き投稿は全体の一部（最大1/3程度）に抑え、残りは価値提供・共感投稿でフォロワー基盤を先に拡大する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 睡眠

**市場トレンド（Web検索による）**
- Threadsは画像より短い一言のテキスト投稿の方が伸びやすく、<cite index="1-1">「本音を言うと、がんばれない日が一番しんどい」のような共感を呼ぶ一言投稿が保存され、会話が生まれる</cite>傾向がある
- <cite index="2-1">インプレッションの半分は返信から生まれ、リプライは最大の集客コンテンツとされている</cite>ため、質問で終える投稿設計が引き続き有効
- 2026年のThreadsは単発バズより関係構築が評価されており、<cite index="5-1">2026年のThreadsは認知よりも関係の継続を評価するプラットフォームであり、またこの人を読みたいと思われるかが重視される</cite>
- 睡眠不足・不眠の悩みは季節を問わずSNSで共感を集めやすいテーマで、<cite index="13-1">「明日仕事前の不眠」といった投稿でSNS上に共感の波が広がる</cite>事例が見られる
- <cite index="2-1">最低でも週7回（1日1回）の投稿頻度がThreads運用攻略のポイントとされている</cite>ため、継続投稿による露出量の底上げが重要

**自アカウント実測の所見**: 現時点でsample_size=0のため自アカウントの実測データが存在せず、伸びた投稿・伸びなかった投稿の傾向を定量比較できない。まずは市場トレンドに沿った投稿を一定数（最低1〜2週間・週7本目安）継続投稿し、閲覧数・保存・返信数のベースラインを取得することが最優先。

**改善アクション**
- [ ] データ蓄積のため、まず1〜2週間は毎日投稿し、views/保存/返信の実測値を記録してベースラインを作る
- [ ] 1投稿1テーマの短文・一言型（共感の観察＋質問締め）を中心に据え、リプライ誘発を狙う
- [ ] 睡眠にまつわる『あるある』チェックリスト型（保存されやすい構造）を週1〜2本混ぜて保存率を検証する
- [ ] リンク付き投稿は認知拡大フェーズの方針通り最大1本/週程度に抑え、残りは価値提供・共感投稿に配分する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
