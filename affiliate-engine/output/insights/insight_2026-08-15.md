# インサイトレポート 2026-08-15

## 筋トレ

**市場トレンド（Web検索による）**
- Threadsは画像より言葉が伸びやすく、日常の本音や共感を誘う一言が保存・会話を生みやすい
- 話題のトピックや旬のネタに乗せることで返信を促し、リーチが伸びやすい設計になっている
- 2026年は単発バズより「学びを一つ入れる」「思考の背景や再現方法を示す」投稿が信頼構築・継続的な伸びにつながりやすいとされる
- フォロワーが少なくても一投稿でフォロワー外まで届く『外部リーチ』の仕組みがあり、実用性の高い投稿が新規フォロワー獲得の武器になりやすい

**自アカウント実測の所見**: 上位3投稿（睡眠×回復、タンパク質摂取の合計量、環境設計/準備の手間）はいずれも413〜622viewsと平均431を上回り、『通説を疑う切り口＋実用的な行動提案』が効いている一方、下位では『筋肉痛は成長指標か』が2回連投され重複により伸び悩み（369/355views）、逃げ道リストの投稿は途中で本文が『記録』で尻切れになっており保存価値を活かしきれていない。全体にいいねが0〜4件と極端に少なく、実測メモの通り質問オンリー構成がいいね率を下げている可能性が高い。

**改善アクション**
- [ ] 1行目を『結論、〜』『私は〜派』のような断定・立場表明で始め、質問オンリーの書き出しをやめる
- [ ] 『筋肉痛』ネタなど同一切り口の連投を避け、伸びた3テーマ（睡眠/摂取量/環境設計）を深掘りしたシリーズ化で差別化する
- [ ] チェックリストや逃げ道リストは本文を最後まで書き切り、保存されやすい完結型フォーマットに整える
- [ ] リンク付き投稿は月内1本に絞り、価値提供投稿とセットで信頼を積み上げてからCTAを出す

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 教育

**市場トレンド（Web検索による）**
- Threadsのアルゴリズムは『いいね数』よりも『リプライ数＝会話の継続』を評価軸として重視する設計になっている
- フィードでは投稿冒頭の2行しか表示されないため、断定的な意見や具体的数字で始まる『続きが気になる書き出し』が伸びやすい
- Q&A形式・問いかけ型で読者からの返信を誘発する構造の投稿が、企業アカウント事例でも高評価を得ている
- 『なぜそれが起きるのか／どうすれば再現できるのか』という因果構造を言語化した投稿は保存・議論されやすいとされている
- 教育ジャンルでは『情報Ⅰの受験科目化』のような制度変化ネタが継続的に注目トピックになっている

**自アカウント実測の所見**: 自アカウントはビュー上位の投稿でも「〜ことがある」「〜らしい」といった中立・断定回避の語尾が多く、いいねが0〜3件と極端に低い。制度変化ネタ（情報Ⅰ）はビューを稼げているが意見表明がなく、質問締めの声かけ投稿もビューは出るがいいね率が低い実測結果と整合しており、書き手の立場・結論の明言不足がいいね転換を妨げていると考えられる。

**改善アクション**
- [ ] 全投稿の1文目を『結論、私は◯◯だと考えている』のような具体的意見・数字提示に統一し、質問文や中立表現（〜ことがある/〜らしい）での書き出しをやめる
- [ ] 情報Ⅰ受験科目化や教室選びなど伸びたトピックを、単なる事実紹介で終わらせず『なぜ起きているか→どう対応すべきか』という因果構造＋書き手の立場を明示する構成に発展させる
- [ ] 保存要素として3項目程度のチェックリスト・判断基準を必ず1つ入れ、文末は意見表明の後に軽く問いかける形（質問単独では締めない）に変更する
- [ ] リプライ増加を狙い、コメント欄で読者の回答例に対して書き手自身が返信する運用を組み合わせ、初速のエンゲージメントを底上げする

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 節約

**市場トレンド（Web検索による）**
- Threadsは会話（リプライの応酬）がスコアを左右するため、断定的な意見や具体的な数字を含む投稿の方が『共感→リプライ→拡散』の連鎖を起こしやすい
- 『後で見返したい有益なリスト』型の投稿は保存代わりにリポストされやすく、節約ジャンルとの相性が良い（固定費チェックリストや手順化された節約術が伸びやすい）
- 抽象的な『節約しよう』ではなく、『インプレッションが1.8倍になった』のような具体的な数字を出す投稿が説得力・拡散力ともに強い
- 画像より言葉（テキスト単体）の方が伸びやすい傾向が続いており、節約ジャンルでも装飾少なめの『生の意見＋数字』が刺さりやすい
- 一方的な発信より、リプライへの返信を重ねて会話を続けるアカウントの方がおすすめ表示（For You）に載りやすい

**自アカウント実測の所見**: 現時点で自アカウントの実測データはサンプル数0件のため、投稿単位での傾向比較はできない。ただし既知の実測として『質問だけで始める投稿はビューは出るがいいね率0.1%に留まる』ことが分かっており、これは中立的な問いかけだけでは読者が『自分ごと化』できず、いいねやフォローという行動にまで至っていない可能性が高い。今後はまず数十件規模のデータを蓄積し、冒頭の型（数字/意見 vs 質問）別にいいね率・保存率を比較検証する必要がある。

**改善アクション**
- [ ] 冒頭1行目を『質問』から『具体的な数字』または『はっきりした意見（◯◯派・結論◯◯でいい）』に統一し、A/Bで最低20投稿ずつ比較する
- [ ] 全投稿に『手順・基準・チェックリスト』か『共感できる具体的観察（円安後の値上げ実感など）』のどちらかを必ず1つ入れる
- [ ] 質問で締める投稿は必ず自分の意見を先出しした後にする（意見→根拠→軽い質問、の順番を固定フォーマット化）
- [ ] 保存されやすいリスト・チェックリスト形式の投稿比率を増やし、リプライへの返信で会話を継続させて露出を伸ばす

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
