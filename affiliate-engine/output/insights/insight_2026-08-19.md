# インサイトレポート 2026-08-19

## ペット

**市場トレンド（Web検索による）**
- Threads全体で2026年は「いいね数」より「返信・会話の質」が評価軸の中心になっており、共感型の投稿より“会話が生まれる”投稿がリーチを伸ばしやすい状況が続いている
- 画像や動画より言葉（テキスト）主体の投稿の方が伸びやすい傾向が指摘されており、ペット系でも一言添える程度の写真+短文構成が有効と考えられる
- 投稿頻度そのものよりも“質”と初動の反応速度が重視され、投稿直後にコメントが付くかどうかがその後の露出を左右する仕組みになっている
- 一方的な発信ではなく読者を巻き込む問いかけや自分の立場を明言する投稿がリプライを誘発しやすく、ペットジャンルでも「うちはこう」「私は◯◯派」のような立場表明型の投稿が会話を生みやすい
- 朝7〜9時・昼12〜14時・夜21〜24時の生活時間帯に投稿するとエンゲージメントが上がりやすいという分析が複数の運用ノウハウ記事で共通して指摘されている

**自アカウント実測の所見**: 現時点でサンプル数0・平均ビュー0・伸びた/伸びなかった投稿のデータがなく、実測に基づく傾向分析はできない状態です。ただしヒアリング情報として『質問だけの投稿はビューは出てもいいね率0.1%』という結果が出ており、これはThreadsのアルゴリズムが会話（返信）とはっきりした立場表明を評価する仕組みと整合しており、質問先出し型の構成が弱かったことの裏付けになります。

**改善アクション**
- [ ] 1行目を「数字」または「はっきりした意見」で始める形に統一し、質問文から始まる投稿は今後作らない
- [ ] 各投稿に『私は◯◯派』『結論、◯◯でいい』のような立場表明を必ず1文入れ、中立的な一般論での書き出しをやめる
- [ ] 保存されやすい実用情報（選び方の基準・チェックリスト・手順）を最低1つは投稿に含め、共感だけで終わる投稿を減らす
- [ ] 投稿は7〜9時/12〜14時/21〜24時の時間帯に絞って配信し、初動でコメントが付きやすい問いかけを文末に軽く添える形に変更する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 睡眠

**市場トレンド（Web検索による）**
- 2026年のThreadsは『なぜ起きるのか・どう再現できるのか』を構造的に説明する投稿が評価されやすく、睡眠ジャンルでも『入眠儀式』『室温』『寝具』などの背景ロジックを言語化した投稿が保存・議論を呼びやすい
- 書き出しで結論や意見を明言し、共感を呼ぶ一文（『子どもが寝た後の静けさ』のような日常の実感）を添えるパターンが伸びやすい傾向
- Threadsはいいね数より会話（コメント往復）が評価軸になっており、断定的な意見を出して賛否を誘う『私は◯◯派』型の投稿がコメントを生みやすい
- 夜（就寝前）の時間帯は可処分時間が増え返信が増えやすく、睡眠ジャンルとの相性が良い投稿タイミングとされている
- 長文よりも1行20文字程度の短い改行＋箇条書き構成が好まれ、保存されやすい『チェックリスト・手順型』が定番の切り口になっている

**自アカウント実測の所見**: 現時点でsample_size=0のため定量比較はできないが、要件メモにある実測（質問だけの投稿はビューは出るがいいね率0.1%）から、閲覧は集まってもファン化・エンゲージメントに繋がっていない状態と判断できる。これは1行目が問いかけのみで、書き手の立場や実用性のある結論が提示されていなかったことが主因と考えられる。

**改善アクション**
- [ ] 1行目を『数字』または『はっきりした意見』で始め、質問文を先頭に置かない（例：室温・時間・◯派などの明言から開始）
- [ ] 投稿の中盤に保存したくなるチェックリストや3ステップの手順を必ず1つ入れ、閲覧だけで終わらせない設計にする
- [ ] 断定的な立場表明（『私は◯◯派』『結論、◯◯でいい』）を先に置き、その後に理由→実用情報→軽い問いかけで締める型に統一する
- [ ] 就寝前の時間帯を中心に投稿し、コメントで賛否が分かれやすい『派閥系』の睡眠トピック（入浴タイミング・室温設定・寝具の買い替え基準など）を優先的に扱う

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
