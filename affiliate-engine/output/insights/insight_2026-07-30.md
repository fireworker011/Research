# インサイトレポート 2026-07-30

## 副業

**市場トレンド（Web検索による）**
- 「後で見返したい有益なリスト」や「マインドセット」系の投稿は保存代わりにリポストされやすい傾向がある
- 伸びているアカウントは闇雲な投稿ではなく、インサイト機能でデータを記録しながら『どんな投稿が伸びるか』を検証している
- 同ジャンルで既にバズっている投稿の返信欄に価値あるコメントを残し、そこから自分のプロフィールへ流入させる『コメント経由の露出戦略』が使われている
- 投稿時間帯×テーマを意図的に組み合わせて検証するなど、感覚ではなく再現性のある『型』を意識した投稿設計がトレンドになっている
- 副業ジャンルでは特定の切り口（AI活用・スキル販売・地域密着など）でポジションを確立する『ジャンル特化型』の運用が増えている

**自アカウント実測の所見**: サンプル数が1件のみのため統計的な断定は難しいが、『観察＋二択質問』という構造の投稿は平均viewsを上回る1941viewsを記録しており、共感を呼ぶ切り口自体は機能している可能性がある。一方でlikesが0件だったことから、閲覧はされても『いいね』という軽いアクションにはつながっておらず、質問設計や締めの一言に改善余地がありそうだ。

**改善アクション**
- [ ] サンプル数を増やすため、リスト型・観察型・比較型など複数の投稿構造を並行してテストし、型ごとの反応差をデータで蓄積する
- [ ] 質問は二択のままにせず『あなたの場合は？』のように具体的な分岐を作り、返信のハードルをさらに下げる
- [ ] 同ジャンルでバズっている投稿の返信欄に価値あるコメントを残し、プロフィール流入の導線を増やす
- [ ] 認知拡大フェーズ中はリンク入り投稿を全体の一部（1本程度）に抑え、保存・返信を狙う価値提供投稿の比率を高める

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 美容

**市場トレンド（Web検索による）**
- 冒頭1行で「悩みをズバッと提示」する“お悩みフック”が、動画・テキスト問わず離脱を防ぐ鍵になっている
- 「メリット＋意外性」の組み合わせ（知らないと損する系の一言）が反応を集めやすいと複数の解説記事で共通して指摘されている
- 数字や「たった一つ」「初心者でも」といった具体性ワードが目に留まりやすいとされている
- 2026年上半期は、バスタイムを単なる洗浄時間ではなく「自分をいたわる有意義な時間」と捉える動きが広がっている
- 美容市場では若年層で「バズ離れ」が起き、インフルエンサー起点の消費より個人の観察・実感ベースの情報への関心が高まっている

**自アカウント実測の所見**: 直近2投稿はいずれも900前後のビューを獲得しており、平均902に対して大きな乖離はない。共通点は「一般論の観察→自分の判断→問いかけ」という構成と、専門家（皮膚科）の言及や現実的な数値（10分→5分）を絡めている点。一方でいいねは1〜4件と少なく、ビュー数に対する反応率（保存・返信含む）はまだ低い水準にとどまっている。

**改善アクション**
- [ ] 投稿の1行目を「観察」からではなく「悩みの提示」に変え、フックを強める（例：多くの人が抱える具体的な小さな悩みを冒頭に置く）
- [ ] 保存を狙う「まとめ・リスト型」投稿を1本組み込み、価値提供の密度を上げる
- [ ] 質問は二択やYes/No形式にして返信のハードルを下げる（自由回答より即レスしやすくする）
- [ ] 季節性トレンド（夏の疲労・寒暖差・入浴時間の価値見直し）を切り口に取り込み、共感ポイントを増やす

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
