# インサイトレポート 2026-08-21

## 筋トレ

**市場トレンド（Web検索による）**
- Threadsは『いいね数』より『会話（リプライの往復）』がスコアに直結する設計になっており、断定的な一言や賛否が割れるテーマほど伸びやすい
- 完璧に説明しきる長文より、あえて『ツッコミ代・隙』を残して読者にコメントさせる投稿が評価されやすい
- 画像より言葉（テキストのみ）の投稿の方が伸びやすく、共感・本音系のフレーズが保存・会話を生みやすい
- 投稿は『7〜9時／12〜14時／21〜24時』の生活導線に沿った時間帯に出すと初速が付きやすい
- 単発のバズよりも『同じテーマの専門家ポジション』を継続発信して信頼を積み上げるアカウントが2026年は強い

**自アカウント実測の所見**: 伸びた3投稿はいずれも『結論、〜派』『〜と言われる』など書き手の立場や仮説を先に明言してから二択・比較の問いで締めており、閲覧はいいね（4件）を除きほぼ反応が薄い＝視聴はされるが会話・保存には至っていない。伸びなかった3投稿は『〜らしい』『〜という見方もある』と中立的な一般論で終始し、書き手自身の結論が不在なうえ文末が尻切れ（本文が途中で切れている）ため、読者が反応する『取っ掛かり』を失っている。

**改善アクション**
- [ ] 全投稿の1行目を『結論、私は◯◯派』『◯◯は△△だと思っている』という明確な一人称の立場表明に固定し、『〜らしい』『〜という見方もある』の中立表現を排除する
- [ ] 文末は必ず二択・比較形式の問い（例：A派？B派？）にし、読者がワンタップでリプライしやすい『会話の余地』を意図的に残す
- [ ] 本文が途中で切れる投稿（下位3件で発生）をなくすため、投稿前に文字数と結びの一文の完結性を必ずチェックする
- [ ] 睡眠×筋トレ（トップ投稿）のように『体感できる具体的シーン＋数字』を絡めたテーマを優先し、21〜24時・7〜9時の投稿枠に寄せてテストする

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 教育

**市場トレンド（Web検索による）**
- 写真や画像より「言葉」だけの投稿が伸びやすく、本音・共感を誘うテキストが保存や会話を生みやすい
- Threadsは「いいね」より「リプライ数・会話の連鎖」が評価される設計になっており、意見表明→軽い問いかけで返信を誘発する投稿が有利
- 冒頭2行で続きを読ませる「結論ファースト」の書き出し（数字・断定的な意見）が閲覧維持に直結する
- 教育ジャンルでは「声かけの言い換え」「習い事の比較・選び方」など、悩みに直結した実用リスト・チェックリスト系投稿が保存されやすい
- 投稿頻度よりも質と会話設計が重視される流れが強まっており、単発バズより継続的な関係構築型の投稿が評価されやすい

**自アカウント実測の所見**: 自アカウントの上位2投稿はいずれも「言い換えリスト」「比較で選び方を示す」という実用フォーマットで、平均を上回る閲覧を獲得している。一方でいいねが0件なのは、書き手自身の立場や結論を明言せず「〜らしい」「別物」といった中立的な説明で終わっており、共感や意見への同意ボタンとしての『いいね』を押す動機が弱いためと考えられる。

**改善アクション**
- [ ] 1行目を「〜らしい」「〜だと思う」ではなく、数字か断定的な意見（結論、私は◯◯派）から始める形に統一する
- [ ] 実用リスト・比較フォーマットは継続しつつ、必ず冒頭で書き手自身の結論・立場を先出しする
- [ ] 締めの質問は「教えてください」だけでなく、自分の意見を出した後に軽く問いかける形に変え、リプライで会話が続く設計にする
- [ ] PR投稿は全体の一部（最大1本）に抑え、価値提供型の投稿でアカウントの立場・キャラクターを先に確立してから紹介する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 節約

**市場トレンド（Web検索による）**
- Threadsは『いいね数』より『コメントでの会話』がスコアを押し上げる仕組みのため、断定・本音型の一言オープニングが保存・会話を生みやすい
- 情報提供や共感投稿を8割、サービス訴求を2割に抑えるバランスが伸びやすいとされており、節約ジャンルでも『固定費見直し』『サブスク解約』『ふるさと納税』などの実用ノウハウ投稿が情報提供枠として機能しやすい
- 超大バズ（数十万インプレッション）よりも、数千〜数万インプレッション規模の投稿の方がフォロー転換率が高い傾向があり、節約ジャンルでも狭く深く刺さる具体的な数字ネタが有利
- Threadsは画像より言葉（テキスト）そのものが伸びやすく、『本音を言うと〜』のような感情の一言から入る投稿が保存・会話を誘発しやすい

**自アカウント実測の所見**: 現状サンプルサイズが0件のため定量的な傾向は抽出できないが、タスク条件にある『質問だけの投稿はビュー数は出るがいいね率0.1%に留まった』という事実は、質問オープニングが受動的な閲覧止まりを招き、書き手の立場が不明瞭な投稿はエンゲージメントに直結しないことを示唆している。データが十分蓄積され次第、top3/bottom3の比較で『数字提示型』と『問いかけ型』の変換率差を検証する必要がある。

**改善アクション**
- [ ] 1行目を必ず『具体的な数字』または『はっきりした意見』で始め、質問文でのオープニングを禁止するルールをテンプレに固定化する
- [ ] 書き手の立場（◯◯派、結論◯◯でいい）を投稿の前半2行以内で明言し、中立的な一般論の羅列を避ける
- [ ] 保存誘発のためのチェックリスト・手順型フォーマット（①②③）を最低月2回は投稿に組み込み、保存率を計測する
- [ ] PR投稿はテンプレ全体の2割以下に抑え、価値提供投稿とセットで運用し、コメント返信で会話を継続させる

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
