# インサイトレポート 2026-08-03

## 筋トレ

**市場トレンド（Web検索による）**
- Threads全体では「冒頭フック→具体的な価値提供→返信を誘う締め」という3段構成が伸びる投稿の定石として広がっている
- 一般常識と逆のことを提示する『逆説型』の冒頭（例：頑張っても成果が出ない理由は“努力のしすぎ”かも）が、意外性で目を止めさせる手法として定着してきている
- Threadsは投稿単位で評価される特性上、専門性の強い内容より『日常の共感ネタ』の方がフォロワー外の幅広い層に届きやすいという認識が広がっている
- インプレッションが伸びてもフォロワーが増えない事例が多く指摘されており、『バズる』だけでなく投稿内に“フォローする理由”を設計する重要性が語られ始めている
- 筋トレジャンル特有の傾向として、極端なノウハウよりも『生活への組み込み方』『続けられる人/続かない人の違い』のような自分ごと化しやすい切り口が支持されやすい

**自アカウント実測の所見**: 直近の実測では、時間帯・タンパク質の始め方・継続習慣という『生活密着×質問締め』の投稿がviews上位を占めており、単発のTips提示（10分ルール）や体感依存テーマ（睡眠時間）はviewsが伸び悩んでいる。一方でいいね数はview数と必ずしも比例せず、共感軸の強い投稿（続けられる人の違い）に集中しているため、視聴と共感は別軸で最適化する必要がある。

**改善アクション**
- [ ] 冒頭2行に『逆説型』または『問題提起型』のフックを入れ、一般論とのギャップで最初の視線を止める設計に変える
- [ ] 質問締めは維持しつつ、投稿の最後に軽い自己開示や次回予告的な一言を添え、フォローする理由を作る
- [ ] views上位だった『生活シーン×選択肢提示（朝/昼/夜、曜日固定/気分次第など）』のパターンをテンプレ化し出稿頻度を上げる
- [ ] views下位だった単発Tips系・体感依存系は、逆説フックとチェックリスト形式を組み合わせて保存価値を強化した上で再テスト

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 教育

**市場トレンド（Web検索による）**
- Threadsのアルゴリズムは表示後の反応速度を重視するため、教育ジャンルでも「読者がすぐコメントしたくなる二択・あるある型」の投稿が伸びやすい傾向が続いている
- 画像や図解のみの投稿より、状況説明を添えたテキスト中心の投稿の方がアルゴリズムに趣旨を認識されやすいとされ、教育系でも文章での丁寧な状況描写が評価されている
- 「最初の一文で興味を引けるかどうかが勝負」とされ、数字や具体的シーン提示から入る投稿が読了・反応につながりやすい
- フォロワーの役に立つ投稿・共感される投稿を軸に、コメント返信で会話を重ねるアカウントが信頼を築きやすいという運用が主流になっている
- ジャンルを一貫させることで「何を伝えたいアカウントか」をアルゴリズムに認識させ、関連ユーザーへの露出を広げる設計が推奨されている

**自アカウント実測の所見**: 上位3投稿はいずれも『家庭によって分かれる二択+問いかけ』構造で閲覧数が明確に高く、特に宿題の進め方投稿は5726viewsと突出している一方、いいね数は低めで『見るだけで反応はしない』層に多く届いている。下位3投稿は情報整理型（連絡帳・情報Ⅰ・休み方）で、価値提供の質は高いものの、最初の一文が具体的なシーン想起を誘発しにくく、二択型ほどの閲覧数に届いていない。

**改善アクション**
- [ ] 『家庭によって方針が分かれるテーマ×二択質問』の型を主軸フォーマットとして継続・量産し、宿題・テスト・習い事以外のテーマ（デジタル時間、ゲーム、お小遣い等）にも横展開する
- [ ] 情報整理・tips型の投稿は、冒頭一文を『結論・数字・意外性』から始める形に変更し、二択型に近い引き込み構造を持たせる
- [ ] 低いいね数を改善するため、末尾の問いかけを『はい/いいえで即答できる』形式に統一し、コメント返信のハードルを下げる
- [ ] 認知拡大フェーズ中はリンク投稿を全体の1割以下に抑え、保存・共感・質問の3型をローテーションしてフォロワー化を優先する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 節約

**市場トレンド（Web検索による）**
- Threadsは画像より『言葉』中心の投稿が伸びやすく、共感・問題提起型のひとことがコメントを呼びやすい構造になっている
- いいね数よりコメント（会話）の量がアルゴリズム評価に直結しており、断定的な正しさより『共感できるか』が重視される
- 『後で見返したい有益なリスト』や固定費・節約ノウハウなど保存性の高い情報は、保存代わりにリポストされやすい
- 新機能・値上げニュースなど話題性のある出来事に、個人の一言コメントを添える『速報＋自分の意見』型が反応を得やすい
- 冒頭で結論や結果を先出しし、箇条書き・絵文字で区切る『先に見せてから深掘りする』構成が読了率を高めている

**自アカウント実測の所見**: 現在は投稿サンプルが0件のため、伸びた投稿・伸びなかった投稿の傾向を定量的に判断できる実測データがありません。まずは異なる切り口（共感型・リスト型・質問型）を各数本ずつ投稿し、閲覧数とコメント数のベースラインを取得することが優先課題です。

**改善アクション**
- [ ] 共感型（生活あるある）・保存型（節約リスト）・質問型（読者に問いかける）の3パターンを最低週3本ずつ投稿し、閲覧数とコメント数を比較できるログを作る
- [ ] 投稿冒頭2行で『結論・結果』を先出しし、本文は箇条書き＋絵文字で視認性を高める構成に統一する
- [ ] 投稿後1〜2時間は自分の投稿への返信・他アカウントの節約系バズ投稿への有益なコメントを行い、初動の会話量を増やす
- [ ] リンク付き投稿は全体の1本以下に抑え、認知拡大フェーズでは『保存したくなる情報』『共感の一言』の比率を8〜9割にする

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
