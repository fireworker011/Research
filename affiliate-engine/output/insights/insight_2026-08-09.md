# インサイトレポート 2026-08-09

## 筋トレ

**市場トレンド（Web検索による）**
- Threadsは文章のみの投稿でも伸びやすく、凝った画像や動画がなくてもテキスト単体でインプレッションを稼げる傾向がある
- 投稿に「いいね」や「コメント」が集まるとアルゴリズムが人気コンテンツと判断し、非フォロワーにも配信範囲を広げる仕組みになっている
- 1投稿につき1つのトピックタグを明確に設定し、テーマを絞ることで同じ関心を持つユーザーに届きやすくなる
- ジャンルを絞り込み『自分が強みを持つ切り口』で発信することが、フォロワーが少ない段階でも伸びるカギとされている
- Threadsはフィードの地域親和性が高く、フォロワー数に関わらず新規参入でもバズが起きやすいフェーズにあるとされる

**自アカウント実測の所見**: 上位3投稿は『まず卵1個から』『家で10分に落とす』のように行動の基準を先に示す構造で、閲覧数は767〜1163と高いが、いいねは0〜6件に留まっており視聴はされても感情的な反応（いいね）には結びついていない。下位3投稿は『〜と言われる』『〜らしい』『どっちですか？』のように書き手の立場が曖昧なまま問いかけで終わっており、閲覧数も469〜621と伸び悩んでいる。全体として、断定や具体的な行動提案があるほど閲覧は伸びる一方、書き手自身の意見表明が弱いといいね率が上がらないという課題が見える。

**改善アクション**
- [ ] 1行目を必ず「数字」か「私は◯◯派／結論◯◯」という明確な意見から始め、中立な伝聞（〜と言われる、〜らしい）で書き出さない
- [ ] 上位投稿で機能していた『具体的な行動基準（卵1個を足す、家で10分）』の型を、他のテーマ（睡眠・コンビニ食・タイミング論）にも展開し、保存したくなるチェックリスト化を進める
- [ ] 質問で終わる投稿は、質問の前に必ず自分の結論・立場を1文入れてから軽く問いかける形に統一する（質問単独で終わる投稿は廃止）
- [ ] PRリンク投稿は本数を絞り、価値提供投稿の合間に月1〜2本程度で挿入し、リンク前に必ず自分の結論を明言してから自然に紹介する

## 節約

**市場トレンド（Web検索による）**
- ふるさと納税は2025年10月の『ポイント全廃』、2026年10月の『地場産品基準厳格化』という制度変更が話題の中心。家電など消える可能性のある返礼品への『駆け込み寄付』を煽る投稿が伸びやすい
- 格安SIMは2026年8月現在、乗り換え(MNP)向けポイント還元・端末セット割引などキャンペーン内容が具体的な金額付きで拡散されやすい
- ふるさと納税の投稿は『◯年連続1位』『訳あり◯個』のような具体的な数字＋ランキング訴求＋アフィリンクの組み合わせが定番の型として機能している
- Threadsは画像より言葉が伸びやすく、共感や本音がにじむ一文が『保存』『会話』を生みバズにつながりやすい構造がある
- 『結論だけ先に言う』構成の投稿がインスタ・Threads双方で反応を集めやすい傾向がある

**自アカウント実測の所見**: 実測データが sample_size=0 のため定量比較はできない。ただし提示された『質問だけの投稿はいいね率0.1%に留まった』という事実から、疑問形オープニング＝中立姿勢が反応を鈍らせている可能性が高いと推測できる。

**改善アクション**
- [ ] 1行目を必ず『具体的な数字』または『はっきりした意見』で始めるようテンプレを統一し、疑問形オープニングを撤廃する
- [ ] ふるさと納税10月改正・格安SIMキャンペーンなど『期限がある制度変更』を切り口にし、緊急性で保存・フォローを誘発する
- [ ] チェックリスト形式（3項目前後）を全テンプレに組み込み、保存されやすい実用コンテンツ比率を上げる
- [ ] 質問で締める場合も、必ず自分の結論・立場を先に明言してから軽く問いかける形に固定する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
