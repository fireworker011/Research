# インサイトレポート 2026-08-23

## 婚活

**市場トレンド（Web検索による）**
- 「婚活あるある」形式でBefore（最初の期待）→After（審査モード化）の変化を描き、最後に断定的な気づきで締める投稿が拡散しやすい
- 結婚相談所カウンセラー自身が「方法論の押し付けは求められていない」と本音を漏らす投稿型が支持されている
- 電車・百貨店・カフェなど「たまたま聞いてしまった/見てしまった」観察エピソード型は婚活ジャンルで頻出の定番フォーマットになっている
- 「戦うほどうまくいかない」「審査するのをやめた瞬間に恋が始まる」など、条件面接化への警鐘＋マインド転換を促す切り口が共感を集めている
- 行動リスト（サイン・チェック項目）を箇条書きで見せ、保存・共感を狙う投稿が定番化している

**自アカウント実測の所見**: 自アカウントでは、①②③の具体的行動リスト＋断定的な冒頭を持つ投稿が997viewsかついいね率約0.8%と最も高く、逆に観察エピソード単体（隣席の会話）は587viewsでいいね率0.34%、意見はあるが具体策が弱い投稿は544viewsで0.18%に留まっている。ビュー数自体は大差ないが、冒頭の断定の強さとチェックリストの実用性がいいね率を左右している。

**改善アクション**
- [ ] 全投稿の1行目を「結論、〜」「私は〜派」など断定・数字始まりに統一し、観察エピソードもオチの前に必ず自分の立場を明言する
- [ ] 市場で伸びている『Before→After（期待→審査モード化などの変化）』構造を取り入れ、単なる観察報告で終わらせず変化の兆候をチェックリスト化する
- [ ] 質問で締める場合は、自分の意見・基準を述べた直後に軽く問いかける形に限定し、質問単体投稿は行わない（いいね率0.1%だった反省を踏まえる）
- [ ] エピソード型投稿は伸びたが保存性が低いため、体験談ではなく「観察している」「◯◯だと考えている」という一般化した形で行動基準を必ず添える

## 美容

**市場トレンド（Web検索による）**
- <cite index="7-1">最初の一文で興味を引けるかどうかが勝負とされ、数字や「たった一つ」「初心者でも」といった言葉が反応を得やすい</cite>
- <cite index="7-1">「メリット＋意外性」の組み合わせが読まれる投稿に多く、意外性のある切り口が効いている</cite>
- <cite index="10-1">ランキング型（○○の特徴TOP7）や習慣型（○○の習慣10選）といった保存されやすいリスト形式の投稿が伸びやすい傾向にある</cite>
- <cite index="11-1">Threadsでは「発信の目的」よりも「感情の共鳴度」が拡散トリガーとなり、語りかける文章が集客に強いとされる</cite>
- <cite index="9-1">コメント（リプライ）やリポスト機能を使い、ユーザーに問いかけて交流を活発化させる投稿設計もトレンドとして紹介されている</cite>

**自アカウント実測の所見**: 実測はサンプル数2件と少なく断定は難しいが、両投稿とも「〜と言われるけど」「〜と思っている」といった柔らかい書き出しや中立的な情報提示から入り、最後に質問で締める構成でビューは獲得できたもののいいねは0件に留まっている。特にビュー最多だった投稿は一般論の紹介に終始し、書き手自身の明確な結論やチェックリストが弱く、保存・共感による『いいね』への転換が起きていないと考えられる。

**改善アクション**
- [ ] 1行目を「結論：〜」「私は〜派」のように明確な意見・数字から始め、一般論の紹介から入る構成をやめる
- [ ] 本文中に3つ以内のチェックリストや見直し手順を必ず入れ、保存したくなる実用性を担保する
- [ ] 質問で締める場合も、必ず自分の立場・結論を先出しした後に軽く問いかける形に統一する
- [ ] ランキング・習慣型など保存されやすいフォーマットを月1〜2本取り入れ、投稿バリエーションを増やす

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
