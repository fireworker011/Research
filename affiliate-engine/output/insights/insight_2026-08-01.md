# インサイトレポート 2026-08-01

## 転職

**市場トレンド（Web検索による）**
- 「新卒で辞める＝甘え」という旧価値観に対し、心身の不調をきっかけに退職を決意した求職者のリアルな心境変化を描く体験談型投稿が反応を集めている
- 育児・介護休業法などの制度改正を「知らないと損」の切り口で紹介し、企業選びの判断材料として提示する情報型投稿が伸びやすい
- 冒頭の一文で強くフックし、スクロールを止めさせる「最初の5秒」設計が拡散の起点になっている
- 専門ジャンルのアカウントでも、日常の共感ネタ（働き方・人間関係の悩みなど）を挟むことでジャンル外のユーザーにも届きやすくなっている
- 「問題提起→解決策→問いかけ」の3段構成で締める投稿が、返信・保存を誘発しやすい型として定着しつつある

**自アカウント実測の所見**: 現時点で自アカウントの投稿実績データが0件のため、伸びた/伸びなかった投稿の傾向比較はできません。まずは複数パターンを投下し、次回分析用のベースデータを蓄積することが最優先です。

**改善アクション**
- [ ] 認知拡大フェーズにあわせ、体験談・あるある共感型と法改正など情報提供型の投稿を並行して試し、どちらの型がフォロワー増につながるか比較検証する
- [ ] 投稿冒頭1文を「フックになる一言」に固定するテンプレルールを設け、A/Bで反応差を測定する
- [ ] 全投稿の末尾に「あなたはどう思いますか？」等の問いかけを入れ、返信率をKPIとして週次で振り返る
- [ ] リンク入り投稿は全体の1/3以下に抑え、価値提供投稿でフォローする理由（続きが気になる・保存したくなる）を明確に設計する

## ペット

**市場トレンド（Web検索による）**
- ChatGPTなどの画像生成AIで愛犬・愛猫を擬人化する投稿が一時トレンド1位になるなど大きな話題化を見せた（<cite index="12-1">SNS「Threads」で、ChatGPTの画像生成機能を使い、愛犬や愛猫を“擬人化”して投稿する行為がはやり始めている。4月7日には「ペット擬人化」のワードが日本のトレンド入り。夜にはトレンドランキングの1位にもなった。</cite>）
- 猫の仕草・行動あるあるなど「あるある系」の共感投稿は継続的にコメントを集めやすい（<cite index="8-1">猫は自分からぶつかってきた癖にその場に倒れて「人間に蹴られた！ひどい！」みたいに睨んでくること</cite>）
- 情報量の多さに疲れた層に向けた「純粋な癒し」系の投稿・動画が高い再生・いいねを獲得しやすい（<cite index="10-1">先日、私がThreadsに投稿した一本のAI動画が、約24時間で24万回表示され、1.7万を超える「いいね」をいただきました。</cite>）
- 保護犬・保護猫の背景を持つアカウントは、癒しの枠を超えた社会性のある共感を呼びやすい（<cite index="4-1">「保護猫・元保健所猫」というバックグラウンドが視聴者の共感を深く引き出すため、単なる癒しコンテンツの枠を超えた社会性を持つのも特徴です。</cite>）
- Threadsは画像より「言葉」自体が保存・会話を生みやすく、本音や問いかけ調の投稿が伸びやすい傾向がある（<cite index="1-1">Threadsは画像より言葉のほうが圧倒的に伸びやすい。</cite>）

**自アカウント実測の所見**: 現時点でsample_size=0・avg_viewsも計測データが無いため、伸びた/伸びなかった投稿の傾向比較はできない状態です。まずは認知拡大フェーズ内で複数投稿を出し、閲覧数・保存・返信数のベースラインデータを取得することが最優先課題です。

**改善アクション**
- [ ] データが0件のため、まず1〜2週間で「価値提供型」「質問型」「観察共感型」を最低5本ずつ投稿し、閲覧数・保存・返信数のベースラインを取得する
- [ ] 擬人化AI加工トレンドはリスク（過度な演出・著作権懸念）もあるため模倣はせず、代わりに『あるある観察＋問いかけ』という構造だけを応用し独自の文面で作成する
- [ ] 保護犬・保護猫の物語性は体験談捏造禁止のため、自身の実体験ではなく一般的な観察・啓発の切り口（例：迎える前に知っておきたいポイント）として扱う
- [ ] 画像より言葉が伸びやすい傾向を踏まえ、テキスト単体でも保存したくなる『チェックリスト・気づき系』の投稿を優先的に増やす

## 睡眠

**市場トレンド（Web検索による）**
- 「〜ってない？」形式の一文共感投稿が保存・コメントを呼びやすく、Threadsでは画像より言葉主体の投稿が伸びやすい傾向がある
- 深夜帯に「おやすみ」を呼びかけ合う投稿が急増し、ユーザー同士の会話が生まれるコミュニティ的なムーブメントが観測されている
- 「寝ピク（入眠時ミオクローヌス）」など、体の不思議な生理現象をわかりやすく解説する豆知識投稿が興味を引きやすい
- 睡眠専門医など専門家目線で「よくある誤解」をまとめて正すQ&A・◯選形式の投稿が信頼感とともに保存されやすい
- 寝具の硬さ・室温・光など生活環境の小さな要因が入眠の質を左右するという生活者目線の投稿が共感を集めやすい

**自アカウント実測の所見**: 現在サンプルサイズが0件のため、伸びた投稿・伸びなかった投稿を比較する分析はまだ実施できない状態。まずは切り口の異なる複数テンプレを並行投稿し、初期データを蓄積することが最優先。

**改善アクション**
- [ ] 共感一文型・豆知識型・チェックリスト型など切り口の異なる投稿を並行してテストし、初期データを集める
- [ ] 投稿時間を7〜9時／12〜14時／21〜24時の3帯に分散させ、時間帯別の反応差を検証する
- [ ] 全投稿の末尾に開かれた質問を入れ、コメント数・返信内容を主要KPIとして計測する
- [ ] 認知拡大フェーズ中はリンク投稿を週1本以内に抑え、保存・共感を軸にした投稿でフォロー動機を作ることを優先する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
