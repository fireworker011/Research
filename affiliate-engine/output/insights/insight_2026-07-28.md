# インサイトレポート 2026-07-28

## 筋トレ

**市場トレンド（Web検索による）**
- Threadsのアルゴリズムは「エンゲージメント率（返信・リポスト・いいね）と投稿の継続性」を評価軸に、フォロワー外への露出量を決めているため、<cite index="11-1">Threadsのアルゴリズムは「エンゲージメント率（返信・リポスト・いいね）と投稿の継続性」を評価軸に、フォロワー外の「おすすめフィード」への表示量を決定します。</cite>という設計思想がジャンル問わず主流になっている
- 一般常識と逆のことを言う「逆説型」の切り口が注目を集めやすく、<cite index="12-1">一般的な常識と逆のことを言うことで、「えっ？」と関心を引く。人は意外性のある情報に興味を持ちやすい</cite>という手法が筋トレ・ダイエット系でも定説見直し系の話題として使われている
- 投稿直後の反応速度が拡散を左右するため、<cite index="14-1">Threadsでは、投稿してからの1時間がとても大事です。この時間に反応（いいね・コメント・リポスト）が集まるほど、さらに多くの人のタイムラインに載りやすくなります。</cite>という初速重視の運用が浸透している
- ジャンルを絞った一貫発信が推奨されており、<cite index="9-1">内容の一貫性を持たせることで、Threadsが「あなたが何を伝えたいのか」を認識し、より多くの人に届けてくれます。</cite>という傾向がフォロワー基盤の薄いアカウントほど重要視されている
- バズ投稿分析では模倣ではなく構造抽出が推奨され、<cite index="13-1">他者の成功事例をそのまま模倣するだけでは思うような成果が得られない場合があります。自分のターゲット層や発信ジャンルに合わせてアレンジすることが大切です。</cite>という考え方が広がっている

**自アカウント実測の所見**: 3投稿とも再生数は1000〜1600台に集まっているが、いいねは0〜1件と極端に少なく、閲覧はされても反応（いいね・保存・返信）には結びついていない。特に「時間帯」を聞くシンプルな質問投稿が最も再生されており、日常の生活パターンに関する軽い問いかけがおすすめフィードで拾われやすい一方、プロテインの通説見直しネタは文章がやや長く途中で離脱されている可能性がある。

**改善アクション**
- [ ] 質問系投稿は二択・三択形式にして返信のハードルを下げ、投稿直後にリプライへ即レスして初速エンゲージメントを作る
- [ ] 定説見直し・逆説型の切り口を増やしつつ、文章量を3行以内に圧縮して最後の一文を明確な問いで締める
- [ ] 筋トレというジャンルテーマを維持したまま「頻度・時間帯・食事・モチベーション維持」など小テーマをローテーションし、一貫性を保ちながら話題の幅を広げる
- [ ] 認知拡大フェーズ方針に合わせ、リンク入り投稿は1本に絞り、CTAは押しつけない implicit〜direct の中間トーンにする

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 教育

**市場トレンド（Web検索による）**
- 「AとB、あなたはどちら派？」のような二択・スタンス表明型の問いかけがコメントを誘発し、アルゴリズム評価を押し上げやすい
- 高校受験や塾代など教育費の経済的負担感が話題化しており、費用・お金に関する家庭ごとの工夫を尋ねるテーマへの関心が高い
- 投稿時間帯は朝7〜9時・夜20〜22時台に反応が集中しやすく、同じテーマでも昼間の投稿は伸びが半減する傾向
- 完璧に整った内容よりも人間味のある等身大の投稿の方が共感を呼びやすい、いわゆる「オーセンティシティ」が重視される
- 「◯◯の言い換え3選」のような保存前提の実用リスト型投稿がテキストのみでも反応を得やすい

**自アカウント実測の所見**: 上位3投稿はいずれも「宿題のやり方」「テストの点数の扱い」など、ほぼ全家庭が直面する普遍的な日常ルーティンを二択形式で問いかけたもので、閲覧数は伸びている一方でいいね数は非常に少なく、保存や返信中心の反応構造になっていると考えられる。下位3投稿は「習い事の月謝」「ご褒美制度」「テスト勉強法」など条件依存性が高いテーマで、かつ投稿者自身の意見や結論を先に述べてしまっているため、読者が「自分はどちらか」を考える余地が狭まり、参加率が下がった可能性がある。

**改善アクション**
- [ ] 二択・スタンス表明型の問いかけは継続しつつ、テーマを『宿題・声かけ・朝の支度』など条件を選ばない普遍的な日常行動にさらに寄せる
- [ ] 投稿文中で自分の意見や結論を先出しせず、純粋なオープンクエスチョンで終える形に統一し、返信のハードルを下げる
- [ ] 投稿時間を朝7〜9時・夜20〜22時に集中させ、同一テーマの当たり外れを時間帯別に検証する
- [ ] 二択問いかけ以外に『保存したくなる言い換え・チェックリスト型』の価値提供テンプレを並走させ、フォーマットの偏りをなくす

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 節約

**市場トレンド（Web検索による）**
- Threadsは『いいね』より『リプライ（返信）』が約10倍重視される仕組みになっており、節約ジャンルでも質問形式で締める投稿がフォロー・保存につながりやすい
- 専門ジャンルに閉じず『日常のあるある』的な共感ネタを混ぜることで、フォロワー外の層にも拡散されやすい構造になっている
- 冒頭一文のフックが重要視されており、『知らないと損する』『◯分でできる』のような“得する予感”を一行目に置く投稿が目に留まりやすい
- 保存・会話が生まれる“心に触れる短い言葉”（本音・生活の実感）が節約ジャンルでも伸びやすい傾向にある
- 投稿頻度が高いアカウントほど1投稿あたりの表示回数が伸びやすく、認知拡大フェーズでは低頻度の大作より小さな投稿の積み重ねが有利

**自アカウント実測の所見**: 現状、投稿サンプル数・閲覧数ともに0件で実測データが存在しないため、伸びた/伸びなかった投稿の傾向分析は行えない。まずは一定量（最低10〜20投稿）を安定投稿し、リプライ数・保存率を軸にした計測基盤を作ることが優先課題。

**改善アクション**
- [ ] 投稿末尾に『あなたは◯◯派？』『これ他にもある人いますか？』など返信しやすい質問を必ず1つ入れ、初動のリプライを増やす
- [ ] 節約という専門テーマに閉じず、『物価高で地味に痛い出費』のような生活実感の共感ネタを週1〜2本混ぜて拡散口を広げる
- [ ] 1行目に『知らないと損してるかも』『実は◯円浮く』など続きを読みたくなるフックを置き、最初の3秒で離脱させない
- [ ] 認知拡大フェーズ中はリンク投稿を全体の1〜2割以下に抑え、価値提供・質問系の投稿でリプライ→フォロー導線を優先する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
