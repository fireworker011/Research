# インサイトレポート 2026-08-11

## 婚活

**市場トレンド（Web検索による）**
- 「婚活あるある」形式で、最初は期待→途中で審査(採点)モードに変質→気づきという展開構造が支持されている
- 書き手が先に明確な結論・スタンスを提示し（「一回やめた方がいい」「面接官をやめた時に恋が始まる」等）、その後に理由を展開する『断定→根拠』の構造が伸びている
- 電車や街中で見かけた他人の婚活風景（敬語・距離感・相談所仮交際など）を実況・観察する『目撃談型』投稿が共感を集めている
- チェックリスト・診断形式（「◯◯が出てくるようになったら△△のサイン」）が保存・共感の両方を取りやすい構造として使われている
- 絵文字（😂💍👀）を使ったテンポの良い改行構成と、最後に軽く問いを添えて会話を誘発するスタイルが定着している

**自アカウント実測の所見**: 自アカウントの2投稿はいずれも「敬語のまま2時間」という同じ観察テーマを扱っており、意見・チェックリストを先出しした投稿（538ビュー/いいね1）の方が、質問止まりの投稿（473ビュー/いいね0）よりわずかに上回った。ビュー数自体はほぼ同水準で伸びていないため、テーマそのものの新規性が乏しく、いいね率も低いことから『意見の強度』と『保存価値』が足りていないと考えられる。

**改善アクション**
- [ ] 1行目を「結論、◯◯だと思う」「私は◯◯派」という明確な断定文に統一し、質問や中立的な観察から書き出さない
- [ ] 婚活あるある×チェックリストの組み合わせを継続しつつ、テーマを敬語以外（写真選び・LINE頻度・相談所の仮交際・年収欄の信頼度など）に広げてネタの重複を避ける
- [ ] 目撃談型（他人の婚活風景を実況する切り口）を新たに試し、自分語りではなく観察者視点で共感を狙う
- [ ] 絵文字を1〜2個に絞り、末尾は『意見を出した後の軽い問いかけ』で統一しリプライを誘発する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 美容

**市場トレンド（Web検索による）**
- 「再生系成分」（PDRNなど）がスキンケアの話題の中心になっており、成分名を軸にした情報発信が伸びやすい
- 肌のゆらぎ対策として「攻めるケア」と「守るケア」を両立させる“お守り的スキンケア”への関心が高まっている
- Threadsでは冒頭一文のフック（数字・意外性・断定的な一言）が拡散の分岐点になっている
- 美容師・専門職の投稿では「悩みの明確な提示→具体的な手順」の構成が反応を集めやすい
- 宣伝色の強い投稿より、役立つ情報や共感を中心にした投稿の方が信頼されやすく、リンク誘導は結びに軽く添える形が支持されている

**自アカウント実測の所見**: 現時点で投稿データ（sample_size=0）が収集できていないため定量的な傾向は把握できないが、提供された観察情報から、質問のみで終わる投稿はビューは獲得できてもいいね率が0.1%程度に留まっており、書き手の意見や立場が明示されていないことが「保存・いいね」への転換を妨げている可能性が高い。

**改善アクション**
- [ ] 直近10投稿は「意見を先に明言→根拠や基準を提示→軽い質問で締める」型に統一し、比較データを取得する
- [ ] 質問だけで始まる投稿・断定を避けた中立的な投稿を廃止し、1行目は数字またははっきりした意見で始める
- [ ] 市場で話題の「再生系成分」「お守りケア」等のトレンドを、保存されやすいチェックリスト・基準形式に変換して発信する
- [ ] リンク付き投稿は月1〜2本程度に抑え、価値提供型投稿とのバランスを保って宣伝色を薄める

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
