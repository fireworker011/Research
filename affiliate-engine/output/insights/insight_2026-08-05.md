# インサイトレポート 2026-08-05

## 婚活

**市場トレンド（Web検索による）**
- 「婚活あるある」形式で、時系列の変化（最初は◯◯→数ヶ月後には◯◯）を見せて最後に一言オチ・教訓をつける構造が支持されている
- 婚活を『採用面接』のような別の行為に例える比喩型投稿が共感を集めており、条件チェックリスト思考への警鐘という切り口が定着している
- 結婚相談所やお見合いでの他者観察エピソードから『金銭感覚のズレ』『モラハラの芽』など気づきを抽出し、教訓として提示する投稿が伸びている
- 婚活・恋愛ジャンル全体で愚痴や悪口系の投稿が増えすぎており、それに対する『もっと前向き・実用的な投稿を見たい』という反発の声も存在し、ポジティブ×実用性の投稿は差別化しやすい状況
- 自分の思い込みや行動パターンを『こういう罠にハマりやすい』と指摘し、書き出し・振り返りを促す自己診断型の投稿も一定の反応を得ている

**自アカウント実測の所見**: 実測データが0件のためサンプルからの傾向抽出はできないが、既知の実測知見として「質問だけで始まる投稿はビューが出てもいいね率0.1%に留まる」ことが確認されている。これは1行目に立場や結論がなく、読み手が反応する動機（共感・保存したくなる実用性）が弱いためと考えられる。

**改善アクション**
- [ ] 1行目を数字（例：3つ、10分、24時間以内）か断定的な意見（結論、〜だと思う／私は〜派）に統一し、質問始まりのテンプレを廃止する
- [ ] 『婚活あるある』の時系列変化＋オチ構造を借用しつつ、書き手自身の立場・結論を明言する形に再構成する（模倣ではなく自分の意見ベースで再構築）
- [ ] チェックリスト・基準・手順など保存されやすい実用パーツを必ず1つ投稿に含める（例：進展する人の共通行動3つ、など）
- [ ] リンク付き投稿は全体の1本までに絞り、残りは価値提供型として観察・教訓を軸に構成し、最後に軽い質問で締めてコメントを誘発する

## 副業

**市場トレンド（Web検索による）**
- 保存・リポストされやすいのは「後で見返したいリスト」や「マインドセット」系の投稿で、Threadsでは保存代わりにリポストされる傾向が強い
- 冒頭の数秒でスクロールを止める「フック」が拡散の決定的要因になっており、シンプルで強い一言から始まる投稿がリーチを伸ばしやすい
- AI活用・不動産投資などジャンルを絞り込み「このジャンルならこの人」というポジションを確立したアカウントが先行者利益を得やすい状況
- Threadsは交流型プラットフォームとして評価されており、伸びているアカウントの投稿欄に有益なコメントを残す・引用されやすい投稿を作ることが集客の鍵になっている
- フォロワー数よりも投稿単位のエンゲージメント（いいね・保存・リポスト）をアルゴリズムが重視する傾向が指摘されている

**自アカウント実測の所見**: サンプルサイズが0件のため定量的な傾向は判定不能。ただし別途得られている実測所見として、質問文のみで開始する投稿はビュー数は出るもののいいね率が0.1%に留まっており、意見や数字を示さない中立的な問いかけは反応を呼びにくいことが示唆される。次回計測ではまず一定数の投稿データを蓄積し、1行目の型（数字/意見スタート）別にいいね率を比較できるようにする必要がある。

**改善アクション**
- [ ] 質問のみで始まる投稿テンプレを廃止し、1行目を必ず「具体的な数字」または「はっきりした意見（◯◯派など）」で開始する型に統一する
- [ ] 各投稿に保存性の高いチェックリスト・判断基準（3項目程度）を1つ必ず入れ、リポスト・保存を狙う
- [ ] 同ジャンルで伸びている投稿のリプライ欄に価値のある補足コメントを残し、プロフィール流入経路を増やす
- [ ] 副業ジャンルの中でもさらに切り口（スキル販売の値付け／案件選定基準など）を絞り込み、差別化ポジションを作る

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 美容

**市場トレンド（Web検索による）**
- 2026年7月時点で「エクスペンシブ・ブルネット」という髪色トレンドが夏〜秋のヘアカラー話題として急浮上しており、サロン界隈のSNS投稿ネタとして活用が推奨されている
- 食材由来成分（コリアンダー由来のセノリティクス作用など）がエイジングケア文脈で話題化しており、「身近な食材が美肌成分になる」という切り口が関心を集めている
- Threadsのアルゴリズムは「いいね数」よりも「リプライの量と会話の継続」を重視する傾向が強まっており、一方的な発信より読者を巻き込む構成が評価されやすい
- 美容サロン系Threads運用では、Instagram的な「綺麗な写真＋キラキラ文面」ではなく、書き手の考え方や人柄が伝わる“言葉の温度”が重視される
- 伸びる投稿の型として「1行目で手を止めるフック構文」「投稿の分割・ツリー化」「テーマの定タグ化による習慣化」が共通して挙げられている

**自アカウント実測の所見**: 現時点でアカウントの実測データ（サンプル数・平均ビュー・伸びた投稿/伸びなかった投稿）が未取得のため、投稿単位の定量比較はできない状態。ただし過去の運用知見として、質問だけで終わる投稿はビュー数は出てもいいね率0.1%にとどまっており、書き手の立場や結論が示されない中立的な投稿はエンゲージメントに変換されにくいことが確認されている。

**改善アクション**
- [ ] 投稿の1行目を「質問」から「具体的な数字」または「はっきりした意見（結論・◯◯派）」に統一し、次回計測で開封後のいいね率の変化を比較する
- [ ] 保存されやすい実用要素（チェックリスト・基準・手順）を各投稿に最低1つ組み込み、情報の“持ち帰り価値”を明示する
- [ ] 時流ワード（エクスペンシブブルネット、食材由来のエイジングケア成分など）に対して中立紹介ではなく自分の見解・注意点を添えて発信し、リプライを誘発する構成にする
- [ ] 質問で締める場合も、意見→根拠・チェックリスト→軽い問いかけの順番を固定し、テンプレ化して次回データ計測時に型ごとの反応率を比較できるようにする
