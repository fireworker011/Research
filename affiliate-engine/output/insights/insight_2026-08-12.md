# インサイトレポート 2026-08-12

## 筋トレ

**市場トレンド（Web検索による）**
- Threadsでは画像より言葉（テキストのみ）が伸びやすく、心情や気づきに寄せた一文が保存・会話を生みやすいとされる
- アルゴリズムは「会話の深さ」を最重視し、リプライはいいねの約10倍のスコア価値を持つとされるため、質問締めより“意見への反応”を誘う設計が有利
- 完璧に言い切らず「それってどうなの？」と読者が突っ込みたくなる“隙（ツッコミ代）”を文章内に残す手法が伸びる投稿の共通点として挙げられている
- 投稿量より“設計力”、つまり結論・立場を先出しし、再現可能な基準や手順を示す一貫した専門性訴求がフォロー転換に効くとされる
- 初動（投稿後7〜9時/12〜14時/21〜24時）の反応速度が拡散に直結するため、断定的な一文で立ち止まらせる導入が重要視されている

**自アカウント実測の所見**: 現状は「中立な一般論＋最後に質問」という構成が多く、唯一いいねが伸びた睡眠投稿（4いいね/622views）も本文中盤で意見を出せていたのに、質問で始めた投稿や結論を後回しにした投稿はビューは出てもいいね率が低い傾向。逆に卵・納豆の具体行動を示した投稿はビュー最多（1163）だが、断定的な意見表明が弱くいいねは1にとどまっており、"数字・断定オープニング"と"保存できる基準"の両立ができていない。

**改善アクション**
- [ ] 1行目を必ず「数字」または「◯◯派/結論◯◯でいい」という断定意見で始め、中立な説明文を書き出しに使わない
- [ ] 本文中に3点程度のチェックリストや基準（①②③形式）を入れ、保存動機を作る
- [ ] 質問は本文の最後、かつ自分の意見を出した後の“軽い問いかけ”に限定し、質問だけの投稿は行わない
- [ ] リンク付き投稿は月内1本に絞り、価値提供が先・CTAは短く末尾に置く

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 教育

**市場トレンド（Web検索による）**
- <cite index="9-1">Threadsで伸びている投稿は「最初の1行で止める」ことが共通要素として指摘されている</cite>
- <cite index="14-1">「最近○○が流行ってるけど、私は△△派！」のように新しい話題に対して自分の立場を一言添える型が反応されやすいとされている</cite>
- <cite index="7-1">保存されやすい構成として「共感→気づき→ノウハウ→保存促し」の4段構成をテンプレ化する動きが広がっている</cite>
- <cite index="13-1">「あなたはどう思いますか？」のように質問で行動喚起を作るとコメントが増えアルゴリズム評価が上がるとされている</cite>
- <cite index="2-1">Threadsは「刺さる投稿一本」でバズが起こる設計であり、会話が生まれる言葉が評価されやすいと分析されている</cite>

**自アカウント実測の所見**: 現在の投稿は全て中立的な観察や状況提示から始まり質問で終わる構成のため、閲覧数（736〜1041）は一定水準出ているものの、いいねは0〜3件と極端に低く「立場を明言しない中立投稿は見られるが反応されない」という実測課題と一致している。特にtop3も筆者自身の意見や結論が入っておらず「どちらにも一長一短」「どちらが合いやすい」という両論併記型で、読者が同意・保存する対象が明確でないことがいいね率低迷の主因と考えられる。

**改善アクション**
- [ ] 1行目を「状況説明」ではなく「結論・意見・具体的な数字」で始める（例：結論、〜派／〜が3つある）よう全テンプレを修正する
- [ ] 両論併記・中立トーンをやめ、書き手の立場を先に明言してから根拠や観察を続ける構成に統一する
- [ ] 箇条書き・基準・チェックリストなど保存要素を全投稿に最低1つ入れる
- [ ] 質問での締めは残しつつ、必ず意見表明の後に配置する『意見→問いかけ』の順序を徹底する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 節約

**市場トレンド（Web検索による）**
- 「本音を言うと〜」など个人の意見をはっきり言い切る投稿が保存・会話を生みやすい傾向。実例として悩みや共感ワードから始める投稿形式が伸びている
- 固定費見直し（格安SIM・保険・サブスク解約）を『手順・基準』として提示する保存系ノウハウ投稿がジャンル定番として安定した反応を得やすい
- ふるさと納税・ポイ活・新NISAとの併用など『お得制度の使い方比較』が季節性のある鉄板トピックとして繰り返しバズる
- 円安・物価高に対する『生活防衛の工夫』を日記的に共感ベースで語る投稿が会話を誘発しやすい
- 投稿の冒頭2行で結論を明示し、リプライで会話が続くことがおすすめ表示の評価軸として重視されている

**自アカウント実測の所見**: サンプル数が0件のため統計的な傾向分析はできない状態。ただし実測メモにある「質問だけの投稿はビュー止まりでいいね率0.1%」という結果は、質問先行型は閲覧を集めても行動（いいね・フォロー）に繋がりにくいことを示しており、今後のテンプレ改善の起点として扱う。

**改善アクション**
- [ ] 1行目を質問形式から「具体的数字」または「はっきりした意見」に統一し、書き手の立場を先に明言する構成へ全面的に切り替える
- [ ] 節約ノウハウは『手順・基準・チェックリスト化』して保存させる設計を必須要素にする（例：見直す順番、判断基準の数値化）
- [ ] 質問で締める場合も、必ず自分の結論を先出しした上での軽い問いかけに限定し、質問のみの投稿は今後作らない
- [ ] 最低でも投稿ごとに『伸びた/伸びなかった』を書き出し口・切り口別に記録し、次回以降のテンプレ設計にフィードバックする体制を作る

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
