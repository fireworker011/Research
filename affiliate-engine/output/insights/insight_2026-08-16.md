# インサイトレポート 2026-08-16

## 転職

**市場トレンド（Web検索による）**
- 1行目に「数字」や「たった一つ」など具体性の高い言葉を入れて興味を引く投稿が伸びやすい
- 推敲しすぎた綺麗な文章より、会話体で結論を先に言い切る投稿の方が反応が生まれやすい
- 自分の専門分野（転職）だけでなく、日常の共感ネタを絡めることでフォロワー外の広い層にも届きやすい
- 保存されるノウハウ・チェックリスト型の投稿は「価値がある」と判定されリーチが伸びやすい
- カジュアルな一人称の意見表明（仲間募集的トーン）がDMや反応を生みやすい

**自アカウント実測の所見**: 現時点でサンプル数が0件のため定量的な傾向は判断できないが、実測で共有されている『質問だけの投稿はいいね率0.1%にとどまった』という結果は、リサーチした市場傾向とも一致する。中立な問いかけだけでは共感や保存の動機が弱く、エンゲージメントに繋がりにくいと考えられる。

**改善アクション**
- [ ] 1行目を『質問』から『数字提示』または『はっきりした意見』に変更し、疑問形での書き出しを禁止する
- [ ] 投稿本文に必ず1つ、保存したくなる基準・手順・チェックリストを入れる（ノウハウ濃縮型）
- [ ] 質問で締める場合も、必ず自分の意見・結論を先に述べてから軽く問いかける構成に統一する
- [ ] 推敲しすぎた広告的な文章を避け、会話体・断定調で投稿し、反応が薄い投稿は次投稿で軽く触れて回収する

## ペット

**市場トレンド（Web検索による）**
- 犬猫の『勘違い・ギャップ』系日常エピソード（ピザを見て祝い事だと勘違いする犬など）が視覚的インパクトとセットで拡散されやすい
- 『癒し』特化コンテンツ（純粋にほっとする画像・短尺動画）が高再生を獲得しやすく、24時間で数十万回表示された事例も報告されている
- 断定・結論から入り『なぜそうなるか／どう再現するか』まで言語化した“構造のある投稿”が保存・議論を生みやすいとされる
- 進行中のプロセスを見せる連載型投稿（記録・チャレンジ企画）がフォロワーの再訪率を高める傾向
- フォロー率は超高インプレッションの投稿より、数千〜数万インプレッション規模で共感性の高い投稿の方が高くなるケースが報告されている

**自アカウント実測の所見**: 現時点でsample_size=0のため自アカウントの定量比較はできないが、過去の実測で判明している『質問オープニングのみの投稿はいいね率0.1%に留まる』という事実は、市場trendの『断定・結論から入る投稿が保存される』という傾向と一致しており、書き出しの型自体が改善余地の中心と考えられる。

**改善アクション**
- [ ] 1行目を必ず「数字」または「はっきりした意見・結論」に変更し、質問文からの書き出しを廃止する
- [ ] 感情移入を誘う『あるある観察』と『再現可能なチェックリスト』のどちらかを毎投稿に1つ組み込む
- [ ] 直近20投稿分のview／いいね／保存数を再計測し、top3・bottom3を明確化してテンプレのA/Bテストを再開する
- [ ] 単発バズ狙いだけでなく、進行中の記録・比較企画などの連載フォーマットを1本試し、フォロー転換率を検証する

## 睡眠

**市場トレンド（Web検索による）**
- 2026年8月は猛暑とお盆休みで生活リズムが崩れ、<cite index="4-1">「多くのユーザーが「寝れない」とツイートし、スマホやゲームで夜更かししたり、コーヒーやASMRで眠気と格闘したりして、朝まで起きている様子が広がっている」</cite>という「眠れない共感」系の投稿が拡散しやすくなっている
- Threadsは煽り文句より<cite index="9-1,9-5,9-6">「情報系・ノウハウ系・体験談といった〝落ち着いた投稿〟でも、しっかりと初速が出ます」「単に煽るだけの投稿よりも、「読んで納得した」「役に立った」「共感できた」と感じてもらえる投稿の方が、結果的に伸びやすくなります」</cite>という傾向が強まっている
- 保存・議論を生む投稿は「なぜ起きるか」「どう再現できるか」を言語化した“構造がある投稿”で、<cite index="3-1">「構造がある投稿は保存されます。構造がある投稿は議論を生みます。構造がある投稿は再利用されます」</cite>という指摘がある
- 成果や変化を語るときは曖昧な感想より数値化した表現の方が説得力を持つとされ、<cite index="3-1">「「伸びました」では弱い。「インプレッションが1.8倍になった」なら強い」</cite>という傾向が言われている
- 投稿時間帯は夜が「共感・本音トーク」と相性が良く、<cite index="14-1">「朝は「今日も頑張ろう系」、昼は「息抜きになる話題」、夜は「共感や本音トーク」が伸びやすいです」</cite>という時間帯設計が定石になっている

**自アカウント実測の所見**: サンプル数0件のため定量的な傾向は判定不可。ただし提供された運用メモから、質問形式のみの投稿はビュー数は出るもののいいね率0.1%と極めて低く、閲覧はされても『意見・立場が見えない投稿』は共感や保存につながっていないことが示唆される。

**改善アクション**
- [ ] 1行目を必ず「入眠時間の目安は◯分」等の具体的数字か「結論、◯◯派」という明言で始め、質問スタートを廃止する
- [ ] 本文中に書き手の立場（例：室温派／習慣派など）を先に置き、その後に根拠や観察を続ける構成にテンプレートを統一する
- [ ] 保存される『基準・チェックリスト』要素を毎投稿に1つ必ず入れる（例：判断基準3つ、やることリスト等）
- [ ] 夜21〜24時台に『共感・本音トーク』寄りの投稿を集中投稿し、時間帯別の反応差を実測データとして次回蓄積する
