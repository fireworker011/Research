# インサイトレポート 2026-07-29

## 転職

**市場トレンド（Web検索による）**
- 『人事・採用担当の裏側を明かす』切り口が反応を集めやすい（例：年齢や経験で見られている選考基準の暴露）
- 『転職あるある』形式で共感を狙う投稿（内定後の迷い、エージェントからの電話ラッシュ、退職理由の言い換えなど）が伸びやすい
- 『質問で締める』投稿形式がフォロワー参加を誘発しやすいと言われている
- 求人・仲間募集も『広告っぽさ』を消し、雰囲気や人柄ベースのカジュアルな語り口にすると反応が出やすい
- Threadsは共感・会話重視のSNSであり、作り込みすぎない『生の声』トーンが好まれる傾向

**自アカウント実測の所見**: 現時点で自アカウントの投稿データがサンプル0件のため、伸びた/伸びなかった投稿の傾向比較はできない。まずは投稿量を確保し、次回分析で『あるある共感系』『裏側暴露系』『質問締め系』の3タイプを均等に試して初期データを蓄積することを推奨する。

**改善アクション**
- [ ] 認知拡大フェーズのため、まずは『あるある共感』『人事の裏側』『質問締め』の3パターンをそれぞれ最低3投稿ずつ試し、初期の反応データを集める
- [ ] リンク付き投稿は全体の1/3以下に抑え、価値提供・共感・質問系の投稿を軸にフォロワーとの接点を増やす
- [ ] 返信・引用への反応を毎回チェックし、コメントが多かった質問文言や切り口をストックしてテンプレ化する
- [ ] 投稿は断定表現を避け、『〜という声がある』『〜と感じる人も多い』など一般論・観察ベースの言い回しに統一する

## ペット

**市場トレンド（Web検索による）**
- AIで愛犬・愛猫を『擬人化』したビジュアルコンテンツ（ジブリ風変換など）が『思わず吹き出す』『声出して笑う』レベルで拡散しやすい傾向
- 保護犬・保護猫の迎え方や飼育スタンスをめぐる『賛否が分かれる意見投稿』がコメント欄で活発な議論を呼び、リプライ数が伸びやすい
- 『あるある』『大喜利』形式の短文投稿がタイムラインで頻出し、共感ベースで拡散されやすい構造になっている
- 投稿時間帯によって求められるトーンが変わり、夜は『共感・本音トーク』系が伸びやすいという運用知見が広く共有されている
- 冒頭の一文で興味を引く『最初の数秒（数行）』の設計が拡散の起点になっている

**自アカウント実測の所見**: 現時点でsample_size=0のため、伸びた投稿・伸びなかった投稿の傾向を実測データから読み取ることはできません。まずは投稿を蓄積し、閲覧数・保存数・返信数を可視化することが優先課題です。

**改善アクション**
- [ ] 直近1〜2週間は『あるある観察』『比較質問』『チェックリスト保存』の3タイプを均等investmentで投稿し、どの切り口が自アカウントで反応するかベースラインデータを取る
- [ ] 保護犬・保護猫や『しつけ論』など賛否が分かれるテーマは、断定を避けた『どちらの考え方に共感しますか？』形式の問いかけにして、攻撃的にならない範囲でリプライを誘発する
- [ ] 投稿末尾に必ず1つの質問を置き、返信のハードルを下げる（Yes/No選択式や『あなたの子は？』形式）
- [ ] リンク付き投稿は週1本までに抑え、認知拡大フェーズでは価値提供・保存訴求を投稿本数の大半に配分する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 睡眠

**市場トレンド（Web検索による）**
- Threadsは画像より言葉が伸びやすく、日常のワンシーンを切り取った短い一文が保存・会話を生みやすい傾向がある
- 「見たことのある光景」への強い共感が反応の鍵になっており、睡眠ジャンルでは『夜中に目が冴える』『スマホを置けない』などの生活あるあるが特に刺さりやすい
- アルゴリズムはリプライを「いいね」より高く評価するため、問いかけ型の投稿でコメント（会話）を誘発する設計が重視されている
- インプレッションが伸びてもフォロー理由が投稿内に設計されていないとフォロワー増につながらないため、シリーズ化・専門性の明示が必要
- 投稿後1時間の初速反応（特にリプライ返信）が拡散の起点になるという運用ノウハウが複数の解説記事で共通して語られている

**自アカウント実測の所見**: 現時点でサンプル数0件のため、自アカウントの傾向分析はまだ行えない状態です。まずは一定量（20〜30投稿目安）のデータを蓄積し、閲覧数・保存・リプライ率を比較できる基盤を作る必要があります。

**改善アクション**
- [ ] 認知拡大フェーズ中は画像なしのテキスト主体投稿を増やし、共感型の『あるある』観察投稿と保存型Tips投稿を1:1程度で試す
- [ ] 全投稿の末尾に軽い問いかけを入れ、投稿後1時間はリプライへの即時返信を行う「ゴールデンタイム運用」を徹底する
- [ ] 投稿ごとにジャンル一貫性（睡眠特化）を保ちつつ、プロフィールと投稿内で『何を発信しているアカウントか』を明示しフォロー理由を作る
- [ ] リンク付き投稿は全体の中で最小限（今回は1本）に留め、価値提供型・会話誘発型の比率を優先しデータが溜まり次第、伸びた型を横展開する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
