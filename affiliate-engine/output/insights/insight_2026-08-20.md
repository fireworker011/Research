# インサイトレポート 2026-08-20

## 婚活

**市場トレンド（Web検索による）**
- 婚活の場をたまたま目撃した『盗み聞き・遭遇』系エピソードが引き続き強い切り口として使われている。<cite index="9-1">百貨店内のブルガリから出てきた2人。たまたま地下鉄が一緒でしばらく会話を聞いてしまった</cite>という投稿のように、日常の偶然の場面から婚活のリアルを描く構造が支持されている
- 『婚活あるある』という共感ワードを冒頭に置き、時系列の変化を見せる構造が伸びている。<cite index="8-1">婚活あるある、これ全員やってる説😂 最初の頃は「どんな人だろう、楽しみ！」半年後「年収は、職種は、実家は、将来は」</cite>のように、初期と現在を対比させて『気づき』を提示する型が多い
- 『審査モード』『面接化』というメタファーで婚活の停滞を言語化し、最後に価値観の転換を提示する構成が人気。<cite index="8-1">面接官をやめた時に恋が始まる💍</cite>のように、格言的な一文で締めて保存・シェアを狙う投稿が目立つ
- 同棲・将来設計に対する男女の温度差を『すれ違いの構造』として提示する投稿も伸びている。<cite index="11-1">女性が一番ハマりやすい罠は、プロポーズ前の「とりあえず同棲」。男性の「一緒に住もう」は、ただの現状維持</cite>という対比構造が典型
- 断定口調（〜派、結論〜でいい）から入り、途中で具体的なチェックリストに落とし込む二段構成が、単なる中立解説よりも反応を得やすい傾向がある

**自アカウント実測の所見**: 自アカウントでは「結論／私は◯◯派」と意見を先出しした上でチェックリストを提示した投稿（997 views・8 likes）が最も高いいいね率を記録しており、市場で伸びている『意見先出し＋実用リスト』構造と一致している。一方、目撃談だけで結論が弱い・後半に埋もれている投稿（587 views・2 likes、544 views・1 like）はビューは出てもいいねが伸びておらず、意見の明確さ不足がボトルネックと考えられる。ボトム3位の投稿（400 views）も含め、1行目に数字・断定がない、または結論の提示が遅い投稿ほど視聴後の反応（いいね）につながっていない。

**改善アクション**
- [ ] 全投稿の1行目を『結論、◯◯だと思う』『私は◯◯派』の形に統一し、目撃談・あるあるネタも意見表明を冒頭に前倒しする
- [ ] 『盗み聞き・目撃談』の切り口は市場でも強いため継続するが、単なる描写で終わらせず、必ず自分なりの結論とチェックリスト（3項目程度）をセットにする
- [ ] 『婚活あるある』という共感ワードや『審査モード／面接化』のような比喩を自分の言葉で作り、保存したくなる一文（格言的な締め）を最後に置く
- [ ] 質問締めは意見表明の後に軽く添える形に限定し、質問だけで終わる投稿は作らない（実測でいいね率0.1%に留まったパターンを排除）

## 副業

**市場トレンド（Web検索による）**
- Threadsは投稿の約半分がリプライで構成されており、賛否が分かれる意見や会話が続く投稿ほどアルゴリズムに『価値が高い』と判断され拡散されやすい
- 『作業時間が月20〜25時間→8〜10時間』のようなAI活用によるビフォーアフター・効率化ネタが副業ジャンルで増加傾向
- 画像は必須ではなく、テキストのみでも意見や結論を明確に述べる短文投稿が伸びやすく、画像を使う場合も解説テキストを添えるのが定石
- 投稿頻度を上げるほど1投稿あたりの表示回数が伸びる傾向があり、通勤時間帯（朝7〜8時）の投稿が反応を得やすいとされる
- 短文＋画像→リンク誘導の型でアフィリエイトに繋げる構成が定番化しており、ジャンル選定と再現性のある構文の型化が重視されている

**自アカウント実測の所見**: 実測データがsample_size 0のため定量的な傾向分析はまだ行えない。ただし運用メモにある『質問だけの投稿はビューが出てもいいね率0.1%に留まった』という結果は、中立な問いかけだけでは共感や保存行動に繋がりにくいという市場トレンド（意見表明→リプライ誘発の構造が評価される）とも整合しており、まず主張・結論を先出しする構造に転換する余地が大きい。

**改善アクション**
- [ ] 1行目を『質問』から『具体的な数字』または『はっきりした意見・結論』に統一し、書き手の立場を必ず明言する構成にテンプレを固定する
- [ ] 保存されやすい『チェックリスト・手順・基準』要素を各投稿に1つ以上組み込み、実用性のある型を繰り返し使う
- [ ] 賛否が分かれやすい切り口（『単価より再現性』『丁寧すぎる文章は逆効果』等）を意図的に混ぜ、リプライを誘発してアルゴリズム評価を狙う
- [ ] sample_sizeが0の状態からまず投稿を蓄積し、意見ファースト型・観察共感型・リンク誘導型の3パターンでA/Bテストしてtop3/bottom3データを取得する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 美容

**市場トレンド（Web検索による）**
- Threadsの美容/サロン系では『写真の世界観』より『人柄・言葉の温度』で信頼を積み上げる投稿が伸びやすい傾向がある
- 1行目に読者の手を止める明確なフック（意見・数字）を置く『フック構文』が推奨されている
- Threadsのアルゴリズムは『保存』よりも『返信・再投稿（会話の総量）』を重視する設計になっている
- 『日常＋専門性』型（施術風景や学びをゆるく発信）や、テーマを固定タグで習慣化する『テーマ定着型』投稿が信頼形成に効果的とされている
- お客様の声を引用リプ形式で紹介する『共感波及』型のフォーマットも伸びやすい切り口として挙げられている

**自アカウント実測の所見**: 2投稿とも閲覧数（397〜728）は一定確保できているが、いいねは0件。1本目は中立的な一般論＋質問で締める構成、2本目は意見表明とチェックリストを含むが文末が途中で切れており、完結した保存価値やCTAが提示できていない点が、いいね率0.1%という結果につながっていると考えられる。

**改善アクション**
- [ ] すべての投稿の1行目を『数字』または『はっきりした意見（◯◯派/結論◯◯）』で開始し、質問文や中立的な前置きから始めない
- [ ] チェックリストや基準（①②③）を必ず最後まで書き切り、保存・再読したくなる完結した実用情報にする
- [ ] 文末は『意見を言った後の軽い問いかけ』に統一し、返信を誘発してThreadsのアルゴリズムが重視する会話量を増やす
- [ ] テーマを固定化（例：季節ケア/頻度管理などの定番シリーズ化）し、プロフィール遷移や継続フォローにつなげる

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
