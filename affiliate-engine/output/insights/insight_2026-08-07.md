# インサイトレポート 2026-08-07

## 転職

**市場トレンド（Web検索による）**
- 「転職ネイティブ世代」志向 — 若手層は転職前提でポータブルスキル（コミュニケーション力・問題解決力など汎用能力）の習得を重視する価値観が共感を集めやすい
- 法改正の動きで『働く人の健康とプライベートを守る制度強化』が進み、企業を見極める基準（ホワイト企業判定チェックリスト）が保存されやすいネタになっている
- 8月は応募者数が減り、中小・ベンチャー企業がスピード重視で採用するため『今が狙い目』という時流訴求が刺さりやすい
- Threads全体の構造として、共感を呼ぶ一人称の本音・観察系投稿と、保存したくなるノウハウ/チェックリスト型投稿が伸びやすく、単純な質問投稿は反応が広がっても保存・フォローには繋がりにくい
- コメント→会話→スコア上昇という仕組みがあるため、意見を明言した上で軽く問いかける『対話誘発型』の締め方が拡散に寄与しやすい

**自アカウント実測の所見**: 現状はサンプルサイズ0で自アカウントの定量データはまだ蓄積されていないが、既知の実測として質問形式単体の投稿はビュー数は出てもいいね率0.1%に留まっており、閲覧はされても『意見・立場の提示』が無いと感情的な反応（いいね・フォロー）に転化していないことが示唆される。

**改善アクション**
- [ ] 1行目を必ず具体的な数字またははっきりした意見（『私は◯◯派』『結論、◯◯』）で始め、質問文からのスタートを禁止する
- [ ] 投稿本文に保存要素（チェックリスト・基準・手順）を最低1つ組み込み、単なる感想投稿を減らす
- [ ] 中立的な一般論の書き出しをやめ、書き手自身の立場・結論を冒頭付近で明言してから理由・根拠を展開する構成に統一する
- [ ] リンク付き投稿は月間の投稿本数に対して最大1本に抑え、残りは無償の価値提供投稿にしてアカウントの信頼残高を優先的に積む

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
