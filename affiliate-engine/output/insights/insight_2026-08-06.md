# インサイトレポート 2026-08-06

## 筋トレ

**市場トレンド（Web検索による）**
- 冒頭で「私は◯◯派」と自分の意見・立場を先に明言してから展開する『意見表明型フック』が反応を集めやすい
- リール・テキスト問わず「悩みをズバッと提示→自分ごと化させる」冒頭フックが伸びる投稿の共通構造になっている
- 『◯選』『3つの基準』のような箇条書き・チェックリスト形式で保存性を高める投稿が定着している
- 投稿時間帯（朝7-8時台・昼12時台・夜20-22時台）とテーマを掛け合わせた設計で反応率を検証する運用が増えている
- Threadsは作り込み過ぎた『バズ狙い』より自然な発言・本音ベースの発信が好まれる空気感が強い

**自アカウント実測の所見**: 質問だけで始まる投稿（時間帯アンケート）はビュー1611と最も伸びたがいいね0で、閲覧はされても『自分の意見への共感』が生まれていない。一方で「続けられる人とやめる人の差」「家で10分に落とす」「睡眠と回復」など、書き手なりの観察・結論を含む投稿はビューは中位でもいいねが相対的に多く、共感・保存性のある内容がエンゲージメントに直結している。

**改善アクション**
- [ ] 1行目を疑問文から『具体的な数字』または『はっきりした意見』に変更し、読み手が立場を確認できるようにする
- [ ] すべての投稿で書き手自身の結論・派閥（「私は◯◯派」「結論、◯◯でいい」）を最初の2行以内に明言する
- [ ] 手順・基準・チェックリストなど保存したくなる実用パーツを1つ以上必ず含める（例：判断基準3つ、置き換えルールなど）
- [ ] 質問は締めの1文のみに使い、意見→根拠→軽い問いかけの順で構成を固定化する

## 教育

**市場トレンド（Web検索による）**
- 最初の1行で読者の目を止める『BLUF型』が主流。伸びている投稿は共通して冒頭で結論や強い一言を置く構造になっている
- 『最近○○が流行ってるけど、私は△△派！』のように、話題に対して自分の立場をひとこと添えるスタイルが反応されやすいとされている
- 数値を使った投稿やカウントダウン形式など、具体的な数字を見せる文章テクニックがバズ投稿の型として整理されている
- 保存・シェアされやすい投稿は箇条書きや絵文字でポイントを区切り、情報を整理して見せている
- 『あなたはどう思いますか？』といった質問での行動喚起はコメントを増やしやすく、アルゴリズム評価の向上につながるとされている

**自アカウント実測の所見**: 自アカウントの上位投稿は『対立軸を提示して質問で締める』構造でビュー数自体は伸びているが、冒頭が状況説明で始まり書き手の立場が明言されていないため、いいね率が0.1%程度に留まっている。一方、実用系（連絡帳チェック・言い換え例）の投稿はビュー数が伸び悩んでおり、保存価値はあるものの冒頭のフックが弱く『スクロールを止める』要素が不足している可能性がある。

**改善アクション**
- [ ] 1行目を状況説明ではなく『結論、◯◯派です』という明確な意見表明に変更し、スクロールを止める設計にする
- [ ] 対立軸ネタは中立紹介で終わらせず、書き手自身の判断基準（数字・手順）を先に提示してから質問で締める形に統一する
- [ ] 実用系（連絡帳・言い換え）投稿は冒頭に具体的な数字（③つ・70点以下など）を置き、保存訴求を強化してから公開する
- [ ] 質問締めは『意見なし単独の問いかけ』を避け、必ず自分の基準を出した後の軽い問いに限定していいね転化率を検証する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 節約

**市場トレンド（Web検索による）**
- 物価高騰を背景に、固定費（通信費・サブスク・保険・住居費）の見直しが継続的な人気トピックになっている
- 「月◯円」「年間◯円」など具体的な節約額を明示した投稿が支持されやすい
- 「我慢する節約」より「仕組みを一度整えれば自動で続く節約（摩擦の低い節約）」という切り口が新しいトレンドとして出てきている
- 日銀の利上げによる住宅ローン金利上昇など、時事ネタと家計を絡めた投稿が話題になっている
- Threads自体は画像より言葉が伸びやすく、断定的な一言や本音・共感系のフレーズが会話を生みやすいとされている

**自アカウント実測の所見**: 実測データのサンプル数が0件のため、伸びた投稿・伸びなかった投稿の傾向を数値から検証することはできない。まずは直近の投稿でview数・いいね数・保存数を最低20〜30件分記録し、次回分析で構造別（数字始まり/意見始まり/質問始まり）の比較ができる状態を作る必要がある。

**改善アクション**
- [ ] 投稿ごとにview・いいね・保存・フォロー転換を記録する簡易トラッキングシートを作り、次回改善分析のためのサンプルを最低20件確保する
- [ ] 質問オンリーの1行目を廃止し、必ず「具体的な数字」または「はっきりした意見（◯◯派/結論◯◯）」から書き始める構成に統一する
- [ ] 固定費見直し（通信費・サブスク・保険）など、具体的な金額と手順・チェックリストを含む保存系投稿を優先的に増やす
- [ ] 時事ネタ（物価高・金利上昇など）に自分の立場を明言してから展開する投稿を月1〜2本試し、共感型と実用型のどちらが伸びるか比較する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
