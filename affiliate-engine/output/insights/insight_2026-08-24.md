# インサイトレポート 2026-08-24

## 筋トレ

**市場トレンド（Web検索による）**
- 結論・意見を最初に明言する『BLUF型／〜派宣言』構成が反応を集めやすい傾向
- 『実は逆』『半分間違い』のような常識逆説型フックで興味を引く投稿が目立つ
- 箇条書き・チェックリスト形式で『保存したくなる実用情報』を提示する構成が定番化
- 挫折パターンや継続の工夫など『共感できる観察』系トピックが根強い人気
- 数字（週◯回、③つの理由、5選など）を使い具体性を出すテンプレが多い

**自アカウント実測の所見**: 上位3投稿・下位3投稿ともに閲覧数は350〜525と大きな差はなく、共通して『〜な気がする』『〜らしい』など意見をぼかす表現が多いため、いいねが0件に留まっている。下位2投稿は全く同一文面の複製投稿であり、目新しさが薄れて閲覧が伸び悩んだと考えられる。全体として『質問投げかけ型・中立解説型』に寄りすぎており、書き手自身の明確な立場表明が不足していることが、いいね転換率の低さの主因と推測される。

**改善アクション**
- [ ] 冒頭1文を『結論、私は◯◯派』『◯◯は半分間違いだと思っている』など断定的な意見文に変更し、質問や引用符から書き始めない
- [ ] 『〜な気がする』『〜らしい』の多用を減らし、チェックリスト部分は事実提示＋自分の見解で締める
- [ ] 同一文面の複製投稿をやめ、同テーマでも切り口（逆説／数字／挫折あるある）を毎回変える
- [ ] 質問で締める場合も、必ず自分の意見・基準を先出ししてから軽く問いかける形に統一する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 教育

**市場トレンド（Web検索による）**
- Threadsは2026年にかけて「投稿頻度より質」を評価する仕組みへシフトしており、「どれだけリプライがつき、その会話が続いたか」が評価されるため、教育ジャンルでも一方向の説明文より会話を誘発する投稿が伸びやすい
- 保存率・再訪・共有数がアルゴリズム評価に影響し始めているため、教育系では「基準・チェックリスト・比較表」のような保存されやすい実用コンテンツが優位
- 教育ジャンルの共感型投稿では、「子どもが寝た後の静けさって、なんか泣けるときない？」のような本音・共感の短文が保存され、会話が生まれる構造が有効
- フォロワーが少なくても伸びる設計のため、“刺さる投稿一本”でバズが起こる傾向があり、1投稿の完成度（1行目のインパクト）が重要
- 地域・生活密着型の教育アカウントでは、「近所の数百人〜数千人に毎回届けば、少しづつでも確実にお客様が増えていく」という中規模リーチ×継続発信の戦略が主流

**自アカウント実測の所見**: 2投稿とも閲覧数は300〜450と一定の露出は取れているが、いいねは0件で、両投稿とも「比較の提示」や「問いかけ」で終わる中立的な構成になっており、書き手自身の立場や結論が明言されていない点が共通している。実測要件にある通り、質問締めのみでは閲覧はつくがいいね率が伸びない傾向が裏付けられた形。

**改善アクション**
- [ ] 1行目を「結論、〜だと思う」「私は〜派」のように、書き手の立場を数字または断定で明示する形に変更する
- [ ] 比較・二択の投稿には必ず自分の意見（どちらを支持するか）を先に書き、その後に理由や基準を2〜3点添える保存要素を加える
- [ ] 質問で締める場合も、既に自分の意見を出した後の軽い問いかけに限定し、質問単体の投稿は避ける
- [ ] リプライへの反応を投稿直後に行い、会話を継続させることでスコア上昇を狙う（Threadsはリプライの連鎖が露出に直結するため）

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）

## 節約

**市場トレンド（Web検索による）**
- 値上げラッシュへの対抗策として「固定費（通信・保険・サブスク）を最初に見直す」切り口が定番化しており、複数の家計メディアが同様の優先順位を提示している
- 「節約の根性より“崩れにくい家庭の仕組み”を作る」という、精神論から仕組み化への転換を訴える投稿が増えている
- 節約が家庭内の負担の偏り（誰が我慢させられるか）という共感・あるあるネタとして語られるケースが目立つ
- Threadsでは画像より言葉が伸びやすく、断定的な一言や共感を呼ぶ本音フレーズが保存・会話を生みやすいとされる
- 電気代・通信費など「具体的な金額差」を提示する投稿（例: LEDと白熱電球の年間差額など）が実用系コンテンツとして機能している

**自アカウント実測の所見**: 実測データが0件のため定量比較はできないが、運用側からの報告では質問だけで始まる投稿はビューが出てもいいね率0.1%に留まっており、意見・数字が先にない投稿はエンゲージメントに繋がりにくいことが示唆される。まずは直近投稿の『冒頭1行目のパターン（数字/意見 vs 質問）』ごとにいいね率を分けて記録し、次回分析のベースラインを作る必要がある。

**改善アクション**
- [ ] 冒頭1行目を必ず『具体的数字』か『はっきりした意見』にし、質問開始の投稿は当面停止する
- [ ] 固定費見直し（通信・保険・サブスク）をテーマにしたチェックリスト型の保存されやすい投稿を週1本以上入れる
- [ ] 家庭内の節約負担の偏りなど、共感ベースの『あるある』投稿を月1〜2本混ぜて会話（コメント）を誘発する
- [ ] PRリンク付き投稿は全体の1〜2割に抑え、価値提供投稿の後に挟む8:2バランスを維持する

**新テンプレ草案**: 3本（data/proposed_templates.json に出力）
