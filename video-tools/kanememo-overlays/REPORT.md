2026-10-28 に、添付台本4本の「表・出典・大きな金額」を透明の重ね素材にした。投稿・送信はしていない。人物は描いていない。数字は台本の表と画面文字から写し、足していない。

この作業では出典の公開ページは開き直していない。円の額は添付台本にあるものだけを使った。公開前に出典URLを開き直す作業は、下の「PCへの引き渡し」に残している。

静止画は各本 `out/frames/<slug>-0.0.png`、`-0.5.png`、`-end-1.png`（14.0秒、最後の1秒前）。

- preview: 1080x1920、H.264、yuv420p、24fps、15.000秒、AAC。白背景に重ね素材と台本SRTを焼いたもの。
- overlay: ProRes 4444（codec tag `ap4h`）、1080x1920、24fps、15.000秒、画素 `yuva444p12le`、音声トラックなし。左上20x20のアルファは 0（透明）。文字の板は不透明。

`npm run render` は preview・静止画・overlay をまとめて出す。overlay は `.gitignore` の `out/*.mov` に入る。

```bash
cd video-tools/kanememo-overlays
npm install
npm run render
```

overlay だけ:

```bash
node scripts/render-all.mjs --overlay-only
```

中身は `npx remotion render src/index.ts <slug>-overlay out/<slug>-overlay.mov --codec=prores --prores-profile=4444 --pixel-format=yuva444p10le --image-format=png`。書き出した実測の画素は `yuva444p12le`、タグは `ap4h`（ProRes 4444、アルファあり）。

## 画面に出していないもの

- 台本SRTにあるフック2行と下部の台詞。preview ではSRTとして焼く。overlay には入れない（二重にしない）。
- 「PR」「広告」、CTA、プロフィール誘導。
- 人物・いらすとや風の絵。イラストクレジットは、絵を置くPC側の仕事。この素材には「VOICEVOX:冥鳴ひまり」だけ入れた。
- 台本が「表に出さない」とした月額70,608円、夫婦の月237,279円、昭和31年4月1日以前の年額844,900円、約9.3万円。

大きな金額は画面中央の黄色の板（0.0–3.0秒）。台本の「右」は、左に人物がいる編集を前提にしている。この素材は人物を描かないので、スマホで読める大きさで中央に置いた。

## 動画チェック5つ

1. この素材にナレーションは入れていない。overlay に音声トラックは無い。preview には、機械チェック M6/M8 を通すための 440Hz（平均 -36.1dB）だけ入っている。声でもBGMでもない。PCで声を乗せるときは preview の音を使わず、無音の overlay に VOICEVOX と BGM だけを乗せる。元の映像の音は乗せない。
2. 表の行が出る秒と、その金額を読む秒はシーン表で見た。高額療養費は直し後、読む「9万2,940円」のあいだ 100万円の行（92,940円）が明るい。
3. 人物は描いていない。指・顔・体の崩れは起きない。いらすとや風の絵はPC側。
4. 字幕の間は台本SRTのまま。下部字幕の最大の間は4本とも 0.4秒（1.5秒以内）。
5. preview を 0.5秒ごとの接触シートと、0.0 / 0.5 / 6.5前後 / 14.0秒の静止画で最初から最後まで見た。シーン表は下。

1秒目: 4本とも 0.0秒から、上部の表題（SRT）と大きな金額が出ている。0.5秒の静止画でも同じ。

表と字幕: 0.0・0.5・14.0秒の静止画で、表や大きな金額は下部字幕・クレジット・出典と重なっていない。表は画面の上半分、字幕は下端。
