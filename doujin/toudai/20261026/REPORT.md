- 見た目は product.json を使った。CG棚卸し（2026-10-18）は、瀬戸澪以外の服と髪はプロジェクト内に文章が無い、と書いている。product.json には7人ぶんの髪と服がある。ゲーム内の文章と一致するかは要確認。

- product.json の価格案は、本文に書いていない。
- 指示書の見出しにある発売予定日は、作品ページの文に書いていない。公開ヘルプは、販売希望日を設定してもその日になるとは限らない、と書いている（出典は checklist.md のAI生成作品の販売に関する行）。

- 1位の公開JSONでは、入力の「催眠」（id 157）の表示名が「トランス/暗示」、「陵辱」（id 134）の表示名が「屈辱」だった。古い名のまま登録しないこと。

## readme.txt の cp932 変換

`python` は PATH に無かったので、同じ式を `python3` で実行しました。作業ディレクトリは `doujin/toudai/20261026` です。

```
python3 -c "open('readme.txt',encoding='utf-8').read().encode('cp932')"
```

結果: 終了コード 0。標準出力なし。標準エラーなし。

タイトルの波ダッシュは product.json と同じ U+301C です。この変換ではエラーになりませんでした。
