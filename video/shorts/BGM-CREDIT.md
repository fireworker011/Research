# BGM・効果音（自作。正弦波のベッドは使わない）

作者はナオミチの箱で合成した音源。フリー素材の借用はない。著作権のある楽曲は使っていない。
BGM の音量は混ぜるとき、声の実効値の約15%（`VIDEO_BGM_RATIO`、既定 0.15）。
ファイルは `video/shorts/bgm/`（写しは `/home/box/shorts/daihon/bgm/`）。長さは 14.0 秒、48kHz、モノラル。尺が足りないときは先頭からループする。
効果音は `video/shorts/sfx/`（写しは `/home/box/shorts/daihon/sfx/`）。ワンショットで、BGM とは別ファイル。ループしない。音量は混ぜるとき声の実効値の約40%（`VIDEO_SFX_RATIO`、既定 0.40）。`VIDEO_SFX` にパスを置く。

`make_short.mix_bed` は `VIDEO_BGM` の wav を声の下に混ぜる。`VIDEO_BGM_SILENT_HEAD`（秒）を置くと、その秒まで BGM を無音にし、そのあと 0.08 秒でフェードインする（H2「無音で動きから」用。今回の9本では H を中身に合わせて付けたため使っていない）。

計測は BGM が 2.0〜10.0 秒、効果音は全長。窓は Hann。スペクトル重心は 40Hz 以上のパワー加重平均。旧実装の減衰正弦波（196/247/294/392Hz の和）との重なりは、各周波数±8Hz のエネルギー比で示す。

| musicbox | bgm/musicbox.wav | オルゴール風。高いベル系の減衰音を五音で並べたもの | 1865.7 Hz | 2109.4 Hz | 0.00033 | 1757.8 Hz | 0.002% |

4本の重心は 278.0 / 1865.7 / 2372.1 / 5551.6 Hz。piano と pad は、以前の「同じ 196/247/294/392Hz の減衰正弦波で、違うのは減衰だけ」という作り方をやめた。今のピークは piano が 550.8 / 328.1 / 820.3 Hz、pad が 93.8 / 164.1 / 222.7 Hz で、重ならない。

効果音は BGM のどれとも長さも重心も違う。H5 の「物音から」は、この効果音を 0 秒から鳴らす。BGM そのものを物音にしない。

概要欄の書き方:
`BGMは自作（識別: musicbox／piano／rain／pad。出どころは video/shorts/BGM-CREDIT.md）。`
H5 の回は続けて:
`冒頭の物音も自作（識別: rustle／boxtap）。`

金メモの画面に出す「BGM: 自作」はそのまま使える。ペットは概要欄に識別名を書く。正弦波（110Hz+164.81Hz）のベッドは、`VIDEO_BGM` が無いときの後方互換だけで、この9本には使わない。
