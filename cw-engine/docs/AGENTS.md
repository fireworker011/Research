# 必要なエージェントと Grok Bot の数

結論を先に書く。増やすのはコードと非公開リポジトリであり、チャット人格ではない。

| 種類 | 数 | 理由 |
|---|---|---|
| **HQ の Grok clone に足す変更** | **0** | 総統括の命令。100万本線の dump に CW を差さない（`HQ_COMMAND.md`） |
| **CW 前面（Grok の別会話）** | **0〜1（任意）** | 非公開リポジトリを読めるときだけ。読めなければ人間が GitHub アプリで Issue を見る |
| **CW 司令塔（機械）** | **1**（GitHub Actions・イベント駆動） | 取込〜納品パッケージまでコード。人間のコメントでだけ動く |
| **Cursor CW 総責任者** | **1**（`参謀へ:` の日だけ） | コードと文書。日常はしない |
| **常時稼働 Cloud Agent** | **0** | 時計進行は仕事ではない |
| **ジャンルbot / 案件ごとの Bot** | **0** | 作らない |

## なぜ「エージェント」ではなく「関数」か

XM は EA が発注し Grok が止め役。CW には公式の応募 API が無く、送信・契約・納品ボタンは人間の外部クリック。
だから CW の「エージェント」は常駐ワーカーではなく、**人間の 1 コメントに 1 回答える関数の列** にした。

| 役 | 実体 | いつ動く | LLM を使うか |
|---|---|---|---|
| 取込・資格判定 | `intake.js` `qualify.js` | `CW: JOB` | 使わない（allowlist / deny。LLM に選ばせない） |
| 応募稿 | `apply-draft.js` | 資格 OK | サンプル 1 段落だけ（無くても稿は出る） |
| 定型返信 | `reply-draft.js` | `CW: MSG` | 使わない（意図分類 → 定型） |
| 業務の把握 | `brief.js` | `CW: CONTRACT` | 構成案だけ（素材があるとき） |
| 完成品 | `make.js` | `CW: MAKE` / `REVISE` | 使う（無ければ作らない・発明しない） |
| 検品 | `compliance.js` | 稿と完成品の全部 | 使わない（決定論） |
| 納品パッケージ | `deliver.js` | QA 合格 | 使わない |
| 自己PR | `profile-draft.js` | `CW: PROFILE` | 使わない |
| 台帳・ファネル | `ledger.js` `funnel.js` | `CW: PAID` / 毎回 | 使わない |

## 人間が残る手（機械にしない）

1. ログイン 2. 応募送信 3. **受注可否**（`CONTRACT` / `REJECT`） 4. 仮払い確認 5. 素材の受け取り 6. 納品ボタン 7. 確定報酬を見た日の `PAID`

下書きが 3 件たまると機械は「新しい JOB は増やすな」と言う。毎晩の宿題を連発しない。

## やらない増設

- remain / n10 の復活。1語チェーンの CW 版
- 案件ごと・ジャンルごとの Grok
- ログイン代行、いいね・スカウト自動返信
- 公開リポジトリで回す司令塔（守秘が破れる）
- 「月100万まで帰れま10」チェーンの日常化。CW の円を 100万本線の分母にしない
