# 必要なエージェントと Grok Bot の数

結論を先に書く。増やすのは dump とコードであり、チャット人格ではない。

| 種類 | 数 | 理由 |
|---|---|---|
| **Grok Bot の clone** | **1** | 既存 HQ。CW 用に 2 体目を作ると dump が結合する。ジャンルbot禁止の延長 |
| **Grok dump（CW）** | **+1** | `cw-engine/docs/grok-bots/G_cw.txt`。remain / n10 は数に入れない |
| **Cursor の起動役** | **3**（常時 0） | 司令塔保守は本線。資格判定はコード。人が起こすのは応募稿と納品 |
| **常時稼働 Cloud Agent** | **0** | 時計進行は仕事ではない |

## Grok Bot は 1 体

既存の入口 `dump/G_hq_boot.txt` が、Issue のレーンで dump を切り替える。

| レーン | 人間の1行 | 開く dump |
|---|---|---|
| 既定 | （なし） | XM `G_xm_trade.txt` |
| アフィ | `AFFI: GO` | `G_hq_sns_next.txt` から1ファイルずつ |
| **CW** | `CW: GO` | `G_cw.txt` だけ |

AFFI 側の多数の `G_hq_*.txt` は **別 Bot ではなく手順のカード**。CW でも同じ型にする。案件ごと・ジャンルごとの Bot は作らない。

2 体目が要る条件は1つだけ: CW の表が XM の表を毎週潰すとき。今は作るな。作るなら clone を増やす前に Issue を分けて dump を分ける（XM が既に Issue を分けている）。

## Cursor エージェント役（常時は立てない）

XM で EA が発注し Grok が止め役なのに対し、CW に公式発注 API が無い。だから「エージェント」は **パイプラインの関数** であり、常駐ワーカーではない。

| 役 | 実体 | いつ | 必須 |
|---|---|---|---|
| **0. 司令塔** | 本線 Cursor + `hq-instruct` + `G_cw.txt` | 仕組みが足りないときだけ | 必須 |
| **1. 資格判定** | `src/qualify.js`（LLM に選ばせるな） | キュー投入 | 必須・コード |
| **2. 応募稿** | Cursor 1回 | 資格OKの1件。完成稿。送信しない | 必須 |
| **3. 納品** | Cursor 1回（短尺編集の仕組み） | 契約 + 素材受領のあと | 受注後 |
| **4. メッセージ稿** | Cursor 1回 | クライアントから文が来たとき | 任意（3のあと） |
| **5. 検品** | 納品内のゲート | 納品ボタンの前 | 納品に内包で足りる |

**今すぐ必要な起動役は 0+1+2。3 は初契約まで起こすな。** 4 と 5 は増設しない。コードで足りる判定をエージェントにしない。

### 役 1 がコードである理由

FX で LLM に majors を選ばせないのと同じ。CW でも LLM に「この募集は取れ」と選ばせない。allowlist（素材支給・縦型短尺・顔出しなし・AI禁止でない・実績必須なら納品済み）で落とす。

### 役 2 がエージェントである理由

募集が聞く空欄（年代・経歴）は人間の事実カードだけ。無い実績は「無し」。これは申請文の 100% 下書きであり、日常ではない。

### 役 3 がエージェントである理由

受注後の編集は仕組み（素材→カット/テロップ→検品→人間が納品ボタン）。AI 利用は隠さない（CW AI ポリシー）。クライアント素材を無断で外部学習に投げない。

## 人間が残る手（エージェントにしない）

公式 API が無いので、次は人間の外部クリックのまま。

1. ログイン
2. 応募送信（下書きのコピペ）
3. 契約同意・仮払い確認
4. 素材の受け取り
5. 納品ボタン
6. 出金
7. 確定報酬を見た日だけ円の1行（カタログは拒否）

Grok はこれらを **毎晩の1手として連発しない**。下書きが既に1件以上ある日は「新しい応募宿題を出すな」。

## やらない増設

- remain / n10 を第4・第5 Bot として復活
- 案件 ID ごとに Bot
- いいね・スカウト返信の自動 Bot
- ログイン代行エージェント
- ジャンルbot（ペット編集 bot、旅行編集 bot）
- 「月100万まで帰れま10」チェーンの日常化
