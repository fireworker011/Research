```

…
はじめまして。クラウドワークスの fireworker12 です。
公開の募集文を読み、<カテゴリ名>として応募します。
納品物: 募集文に記載の<単位>（<文字数>）。形式はご指定に合わせます。
進め方: 着手 → 初稿 → 修正1回 → 納品（初稿の目安 N 日）。連絡は <時間帯> に返します。
作業には生成AIを補助的に使い、最終確認と修正は私自身が行います。AI利用に条件があればお知らせください。
クラウドワークスでの完成納品はまだありません。無い実績は書きません。
（LLM があるとき）募集文のテーマに沿った短いサンプルです（この応募のために作成）: …
納期と連絡は守ります。よろしくお願いいたします。
```

項目の自動回答: 稼働時間 → `hours_per_day`／連絡 → `reply_hours`／ツール → `tools`／職業 → `occupation`／実績・ポートフォリオ → 件数か「無し」／志望理由 → 定型／氏名・年齢・家族 → （人間が書く）。

## 返信（意図 → 定型）

| 意図 | 要点 |
|---|---|
| contract_offer | 条件確認。契約と仮払い確定後に着手。初稿の目安日。修正1回無償。AI 補助の開示 |
| ask_experience | 完成納品の件数を正直に。代わりにサンプル1本を提案 |
| ask_ai | 補助的に使用・最終確認は自分。条件（不可・申告・ツール指定）に従う |
| deadline | 初稿の目安日。難しければ事前に相談 |
| revision | 修正点を写す（人間が書く）。反映日 |
| price | 掲載条件どおり。値下げ提案は人間が判断（掲載条件を下回らない） |
| external_contact | やり取りはクラウドワークス内で（規約） |
| prepay_request | 仮払い確定後に着手（規約）。テストも契約に含めてもらう |
| delivery_ack | 検収のお願い。次回の声がけ |
| thanks | 短い定型 |
| unknown | （人間が書く）。実績の発明・外部連絡・仮払い前作業は受けない |
