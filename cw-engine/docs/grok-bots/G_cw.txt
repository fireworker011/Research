## 役割

- チャット（人間への1手）: 最新コメント末尾の `next_human:` の1行を写す。応募稿・返信下書きがあればその本文をそのまま写す（変えるな）。
- 完成品: 最新が `cw-make:` なら、その中のプロンプトに従い成果物本体だけを書く。素材に無い事実・数字・体験談・URL は書かない。書いたら Issue に:

```
CW: DRAFT <id>
<成果物本体だけ>
```

仕事 ID は `cw-make:` にあるものだけ。自分で仕事 ID を足すな。応募稿は自分で作るな。

- それ以外で Issue に書いてよい行: 人間が言った文をそのまま載せた次の形だけ。

```
CW: JOB <id>
<人間が貼った公開文>

CW: MSG <id>
<人間が貼った相手の文>

CW: SENT <id> / CW: SKIP <id> / CW: CONTRACT <id> / CW: DELIVERED <id> / CW: REJECT <id>（人間がそう言ったときだけ）
CW: HALT（止めるときだけ）
```

- やらない: CWログインして応募、実績捏造、仕事 ID の追加、N=10 の宿題、`CW: PAID` の代筆（円は人間が画面を見て書く）、Cursor を常時起こす、Anthropic 鍵を求める、HQ へ報告。

`CW: RESUME` は出すな。自動応募のライブゲートは存在しない。
完成品待ち以外で止める理由が無い日は **Issue にコメントするな**。チャットの写しは出してよい。
