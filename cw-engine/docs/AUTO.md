# CW 自動システム — いま組むもの / まだ組まないもの

ナオミチは外部サイトだけ。CrowdWorks のパスワードは Grok に渡さない。Threads の自動投稿は触らない。remain / n10 は駐車。

自動は **2層**。混ぜると BAN か納品不能になる。

| 層 | 何が自動か | 応募送信？ | いま |
|---|---|---|---|
| **A. GitHub ペーパー** | allowlist で資格判定し、キューとデスクを書く。Grok は表を写すだけ | いいえ | この PR をデフォルトへマージし、Issue に `CW: GO` |
| **B. 応募稿 + 納品パイプライン** | 資格OKの1件の完成稿。契約後の短尺編集 | 人間が送る | 初契約まで納品役は起こさない |

GitHub cron は遅延する。**応募締切のクロックには使わない。** 応募送信の cron は置かない。

## 層A（今やる）

1. PR をデフォルトブランチへマージする。
2. Issue `Grok Bot — 指示` に `CW: GO`。
3. Grok の日常入口は `G_hq_boot.txt`（中で `G_cw.txt` を開く）。remain / n10 と混ぜるな。
4. Issue `CW — 司令塔` を Subscribe。`cw-desk:` は告知。

動くもの:

- 資格判定: 素材支給・縦型短尺・顔出しなし・AI禁止でない・実績必須なら納品済み
- 同時契約 1 / 下書き待ち 3 で宿題化を止める
- カタログ円は `approved_yen` にしない
- Grok は止めるときだけ `CW: HALT`

やらない: ログイン自動化、仕事 ID の suffixed 追加、N=10、Threads cron 再開、ジャンルbot。

## 層B（受注後）

契約と素材が来てから納品の仕組みを起こす。仮払い前に作業しない。AI 利用は隠さない。

## ナオミチの1手

- **今夜〜マージまで**: CrowdWorks に Bot をログインさせるな。Grok が「この4件へ応募せよ」と remain 型で書いたら捨てる。
- **CW: GO した日**: デスクの表を見る。キュー空なら応募しない。
- **下書きが1件ある日**: その1件だけ送るか、送らない。新しい ID を Bot に足させるな。
