# 台本の型（全ライン共通：婚活・美容・金メモ・ペット・ねむり）2026-10-25
ファイル名: scripts/YYYY-MM-DD-<ジャンル>-<短い名前>.md

## 0〜1秒フック（画＋文字）※必須。空欄の台本は出さない
- ビジュアルフック（1秒目に止まる画）: 変な表情／大写しの数字／意外な動き など。映っているものを具体的に
- テキストフック（1秒目の画面文字）: 穴埋め／問い／数字の差。短く
- 悩み・商品とのつながり: （このフックがどの悩み or 商品につながるか1行）
- NG確認: 無関係な釣りでない／他人の出演映像の転載でない／無い数字・体験を作っていない
- ライン別の見本:
  - 金メモ: 給与明細の数字をいきなり大写し＋「この差、何？」
  - 婚活（顔なし）: 玄関に揃わない靴が3足＋「この靴で、もう3回目」
  - 美容（3Dキャラ）: 鏡の前で片頬だけ照明が当たる手元＋「夜の乾き、ここだけ残る」
  - ペット（猫だけ）: 猫が水皿の前で固まって横を見る＋「飲まない理由、ここ？」
